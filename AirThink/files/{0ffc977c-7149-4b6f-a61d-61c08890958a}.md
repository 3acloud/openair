## 压缩文字稿

[下载文字稿](https://www.ithinkair.com:3031/private/{2cbf2cce-c581-4c24-b1f0-6c820968cdbd}.txt)

GPT-5.6 突然发布，OpenAI 一次推出 Sol、Terra、Luna 三款模型，直接挑战 Fable 5 的最强基模位置。

这次不是单个旗舰模型更新，而是三线并进：Sol 面向编程、生物、网络安全等长链路复杂任务；Terra 对标 GPT-5.5，主打性能与价格平衡；Luna 成本最低、速度最快，适合轻量问答、实时交互和批量自动化。

关键变化在 Sol。它新增 max 与 ultra 两种模式：max 给模型更长深度推理时间，ultra 支持多个 subagents 协同处理任务。在 Terminal-Bench 2.1 上，Sol ultra 超过 Fable 5 7.6 个百分点；GeneBench v1 表现优于 GPT-5.5 且 token 消耗更少；ExploitBench 接近 Mythos Preview，但输出 token 只有三分之一。

开发者侧也升级了 prompt caching：显式 cache breakpoints 可指定缓存范围，缓存生命周期至少 30 分钟。安全侧采用三层机制：模型内置拒答训练、实时风险检测分类器、账号级风险信号。

不过普通用户暂时还用不上。GPT-5.6 初期仅开放给 trusted partners，主要入口是 API 和 Codex。Fable 5 的王座被直接挑战，但 METR 也指出 Sol 存在 cheating 与 metagaming 风险，Time Horizon 分数仍有不确定性。
