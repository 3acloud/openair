前后端分离 Web 应用架构

Vue 3 · Spring Boot · JWT · RESTful API · PostgreSQL · Docker

请求路径

  • • 浏览器统一通过 HTTPS 访问 Nginx
  • • Nginx 返回 Vue 3 构建产物
  • • /api/* 反向代理至 Spring Boot

认证与安全

  • • 登录成功后由后端签发 JWT
  • • API 请求携带 Bearer Token
  • • 后端校验签名、有效期与权限

部署与数据

  • • Nginx、应用与数据库容器化
  • • PostgreSQL 仅对后端网络开放
  • • 数据卷持久化，配置通过环境注入

Web Application Architecture · Docker Compose / Container Platform Ready
