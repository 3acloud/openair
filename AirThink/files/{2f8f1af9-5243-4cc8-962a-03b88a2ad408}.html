OpenAI Model Research Brief

GPT-5.6：受限预览中的新一代模型家族

基于 OpenAI 官方发布页与开发者文档整理。重点结论：GPT-5.6 已发布预览，但截至 2026-06-28 仍只向部分可信伙伴开放；普通开发者当前仍应以 GPT-5.5 作为复杂推理与编码的默认起点。

当前状态：Limited Preview

一句话结论

GPT-5.6 不是一个已经全面开放的单一模型，而是由 Sol、Terra、Luna 三个能力层组成的新命名体系。OpenAI 表示会在未来数周扩大到 ChatGPT、Codex 与 API，但预览期先通过 API 和 Codex 提供给少量可信伙伴。

为什么值得关注

OpenAI 将 GPT-5.6 Sol 描述为其最强模型，并强调在编码、生物学工作流、网络安全任务、深度推理和多代理复杂工作上的提升。同时，发布重点明显放在“能力增长”和“安全护栏”同步推进。

模型家族结构

Sol

旗舰模型，面向最高能力需求。官方强调其在编码、长程安全任务、生物学分析和复杂代理任务上的提升。

价格：$5 / 输入 MTok，$30 / 输出 MTok
Terra

平衡型模型，定位为日常工作与成本控制之间的主力选择。官方称其性能接近 GPT-5.5，成本约为其一半。

价格：$2.50 / 输入 MTok，$15 / 输出 MTok
Luna

快速、低成本模型，适合高吞吐和价格敏感场景。官方将其描述为 GPT-5.6 系列中的最低成本能力层。

价格：$1 / 输入 MTok，$6 / 输出 MTok

主要能力变化

  • 新增 max 推理强度，让 Sol 在复杂问题上投入更多推理时间。
  • 新增 ultra 模式，通过子代理处理超出单一代理能力边界的复杂工作。
  • 编码方面，OpenAI 称 Sol 在 Terminal-Bench 2.1 上达到新的领先水平。
  • 生物学工作流方面，在 GeneBench v1 上相对 GPT-5.5 更强且消耗更少 token。
  • 网络安全方面，Sol 被描述为 OpenAI 当前最强的安全任务模型，但也因此配套更严格的护栏和分阶段发布。

安全与发布策略

OpenAI 表示 GPT-5.6 使用分层安全栈：模型内拒答训练、生成时实时检查、账号级风险信号、差异化访问、监控与持续测试。预览期中，合法的双用途安全工作可能遇到更慢响应或误拦截。

官方称 Sol 未跨过其 Preparedness Framework 的 Cyber Critical 阈值；在 Chromium 和 Firefox 评测中能发现漏洞与利用原语，但没有在测试条件下自主生成完整攻击链。

对开发者的实际建议

  • 没有预览资格时，不要把生产系统依赖写死为 GPT-5.6。
  • 复杂推理、编码和工具调用场景，官方开发者文档仍建议从 GPT-5.5 开始。
  • 如果获得 GPT-5.6 预览资格，应单独评测 Sol、Terra、Luna 的质量、成本、延迟和安全误拦截率。
  • 涉及网络安全、生物、长程代理的产品，应预留更严格的审核、日志与用户反馈机制。

需要继续观察的问题

  • 全面开放日期、地域限制和账户层级限制。
  • GPT-5.6 系列在公开 API 模型列表中的正式 model id。
  • Sol 的 max 与 ultra 模式在实际产品中的价格、延迟和调用方式。
  • 分层安全栈对企业隐私、数据保留和误拦截处理流程的具体影响。
