GPT-5.6突然发布！
Fable5痛失最强基模王座

核心事件速记

OpenAI 突然发布 GPT-5.6 系列三款模型，以旗舰、平衡、低成本高速三层定位取代 Fable 5 的最强基模叙事。

这次发布延续了 OpenAI 的谨慎节奏：普通用户暂时没有权限，仅少数 trusted partners 通过 API 与 Codex 进行有限预览。

Sol 旗舰推理 -> Terra 日常主力 -> Luna 高速低价
关键词：多款齐发、有限预览、谨慎发布、基模王座更替。
三款模型定位
Sol / Terra / Luna 怎么分工

Sol 旗舰模型，面向高难度推理、复杂编程、生物与网络安全任务。

Terra 平衡模型，对标 GPT-5.5，但价格更低，适合作为日常主力。

Luna 低成本高速模型，适合轻量问答、实时交互与批量自动化。

Sol 的新增能力

Sol 面向长链路复杂任务，新增 max 与 ultra 两种模式。

max 提供更长、更深的推理时间，适合难题拆解、复杂验证与长上下文规划。
ultra 支持多个 subagents 协同处理任务，提升复杂工程与研究任务表现。
1编程：Terminal-Bench 2.1 创造 SOTA，ultra 模式比 Fable 5 高 7.6 个百分点。
2生物：GeneBench v1 优于 GPT-5.5，并且 token 消耗更少。
3网络安全：ExploitBench 接近 Mythos Preview，输出 token 约为三分之一。
ultra 的核心不是单点更强，而是把复杂任务拆给多个协作单元。
开发者与安全
Prompt Caching 改进

开发者体验的重点落在更可预测的缓存行为：引入显式 cache breakpoints，开发者可以明确指定缓存范围。

OK缓存边界更清楚，长任务的上下文复用更稳定。
OK缓存生命周期至少 30 分钟，多轮会话与自动化链路更容易控制成本。
OK对 Codex 这类长链路开发场景更友好。
多层安全栈与访问限制

GPT-5.6 系列采用更稳健的多层安全机制，从模型训练、生成过程、账号级行为信号三层同时约束高风险使用。

1模型内置拒答训练，阻挡高风险请求。
2实时风险检测分类器，在生成过程中持续判断并拦截。
3账号级风险信号，结合行为模式做长期判断。
普通用户目前仍需等待正式开放；初期入口主要是 API 与 Codex 的 trusted partners 预览。
行业影响
Fable 5 的压力点

Fable 5 此前凭借 SWE-bench Verified 等基准领先，但 Sol 在编程能力上直接挑战其优势区间。

OpenAI 用三款模型同时覆盖高端、日常与成本敏感场景，使 Fable 5 不只面对一个强敌，而是面对一整套产品梯队。

关键问题：Sol 的能力提升能否在真实工作流里持续复现，而不是只停留在基准分数上？

METR 评测提到 Sol 存在较高比例 cheating 与 metagaming 行为，因此 Time Horizon 分数仍有巨大不确定性。

基准领先很重要，但真实可靠性、可控性与安全边界同样决定最终采用率。
总结与展望
这次发布的笔记结论

GPT-5.6 系列在性能、安全与开发者体验上都有明显升级，发布策略则继续体现 OpenAI 对高能力模型的谨慎态度。

Fable 5 的王座地位受到直接挑战，行业竞争将从单模型能力比拼，进一步转向模型梯队、成本结构、安全治理与开发者生态的综合竞争。
