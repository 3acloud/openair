# 一页朗读：儿童语文 App 视觉方向探索

已完成三种视觉方向及手机小样，**推荐 01「书页晨光」**：用语文读本的排版建立家长信任，用大字、明确动作与短促反馈照顾儿童。

[打开或下载风格对比页（独立 HTML，可离线打开）](https://www.ithinkair.com:3031/download/{4852bab9-7e6f-4f8d-9aa3-78f6b0c79912}.html)

打开后切换右上角「手机 390」，先并排看方向，再进入「单张」以实际尺寸 100% 看细节。单张小样支持选课文、进入跟读页、完成本篇与查看今日。当前交付为视觉探索原型。

## 需求与共同基线

| 项目 | 设计依据 |
| --- | --- |
| 品类 | 小学语文朗读教育 App，以课文阅读和跟读为中心 |
| 用户 | 6–10 岁儿童操作；家长判断内容、学习过程与完成情况 |
| 主要任务 | 选课文 → 跟读 → 查看今日完成情况 |
| 真实内容 | 《春晓》《村居》《咏柳》及对应作者、古诗短句；不放占位标题 |
| 品牌约束 | 儿童能亲近、家长能信任；文字与操作清晰，鼓励语气温和 |
| 设备 | 手机，核心设计视口 390 × 844；推荐方向另查 320px 窄屏 |
| 本轮假设 | 暂名「一页朗读」；以二年级古诗场景展示；每日三篇、初始完成一篇均为演示状态 |

三种方向共用同一组内容、主动作与完成状态。未锁定具体教材版次、册次和课序，因此未标注单元或课号。全龄课文库、拼音开关与分年级配置不在本轮小样范围内。

## 三种方向比较

| 方向 | 01 书页晨光 · 推荐 | 02 朗读小径 | 03 小小朗读台 |
| --- | --- | --- | --- |
| 北极星 | 打开自己的语文读本 | 把今日朗读变成清楚的三步 | 把古诗读成自己的小节目 |
| 生成引擎 | 语文读本的纸页与书签 | 学习过程的路线与节点 | 朗读活动中的节目台与声音节奏 |
| 首屏骨架 | 主课文书页 → 今日摘要 → 另选课文 | 今日目标 → 已完成节点 → 当前展开节点 → 下一篇 | 满宽主课文色块 → 今日数字摘要 → 换课文列表 |
| 主视觉 | 古诗排版与朱红书签 | 纵向虚线路线、实心当前节点 | 蓝色大字与静态声条 |
| 字体 | 宋体 / Songti SC 用于古诗；微软雅黑 / PingFang SC 用于操作 | 微软雅黑 / PingFang SC，粗体课文与步数 | 微软雅黑 / PingFang SC，48px 粗体标题与大数字 |
| 色彩身份 | 纸色 `#FAF5E9`、深绿 `#276148`、书签红 `#CB6B4F` | 乳白 `#FFFBF2`、陶橙 `#AF461F`、墨蓝 `#29344B` | 浅蓝 `#EDF3FC`、朗读蓝 `#2353AE`、声条蓝 `#A8C6FF` |
| 控件语法 | 14px 圆角、书页边缘、主按钮下沿 | 20px 圆角、圆形节点、明确的按钮底边 | 胶囊主按钮、满宽色块、细线列表 |
| 记忆点 | 高亮的当前诗句延续书页感 | 从当前课文看到下一步的位置 | 课文标题与声条构成朗读识别 |
| 主动取舍 | 减少角色与奖励装饰，把视觉空间留给字句 | 不增加排名或连续打卡压力，允许直接选下一篇 | 声条保持静态，避免长期循环影响阅读 |
| 待留意 | 宋体笔画较细，需在真实手机上核对低龄辨认 | 长标题和增加课文后可能使路线过长 | 蓝色区域视觉分量大，亲切感依赖文案与反馈 |

调性依据：三者都采用精确对齐、较疏密度与易辨认控件；01 能量较低、内容较重；02 能量适中、步骤更活泼；03 色块分量与声音识别最强。结构、主视觉与色彩均不同，02 与 03 共用中文无衬线字族，其余关键维度拉开差异。

**选择建议：**先以 01 建立品牌主方向。它把课文放在首屏中心，今日摘要和其他课文退到次级；儿童直接知道读什么、从哪里开始，家长也能看清内容与完成状态。02 更适合需要顺序引导的情境；03 更适合强调声音表达的品牌定位。本轮保留三种候选，不混合成第四套风格。

## 参考、取舍与减法

参考了 [Khan Academy Kids 官方页面与应用截图](https://en.khanacademy.org/kids)。其公开画面可见场景插画、大字号学习对象、分隔的字母块、路径提示、选中高亮、具象操作按钮、文字与图形并用的状态表达；官网还展示了自主探索和个性化学习路径。它面向 2–8 岁，本产品面向 6–10 岁，因此借鉴「对象明显、步骤看得见、状态有文字」的任务组织，把角色场景与多色背景替换为课文排版、步骤节点及声音图形。上述功能与年龄信息来自官网；各视觉手法的用途及取舍为本轮设计判断。未复制品牌角色、插画或标识。

本轮删去了路线方案中的两行鼓励口号，改为包含任务信息的「今日 · 三篇古诗」；把跟读提示缩为「听清字音，再读一遍」。收紧标题区和内容间距，使推荐方向的听句、完成操作在 390 × 844 首屏可见。保留课文名、作者、完成数量、当前句与主动作。
