# 街角咖啡 · 会员点单设计与验证

## 使用与边界

[可运行界面](https://www.ithinkair.com:3031/download/{4d7205ef-757a-4a66-af16-51bab728857e}.html)：下载 HTML 后用现代 Chrome / Edge 浏览器打开。CSS、Alpine.js 与商品图像已内嵌，无需安装依赖或构建。正常入口是无参数文件；不要用状态截图参数进行日常操作。

这是餐饮零售小程序的浏览器交互原型，不是已发布的微信小程序。价格、门店、营业时间、2860 积分及100积分抵1元规则是为本次设计假设的内容。订单只保存在当前浏览器；没有接入真实会员登录、积分账户、支付扣款、门店订单、库存和叫号服务。点“下单”只产生本地订单，取餐号不具有真实取餐效力；清除浏览器数据会丢失本地记录。失败状态保留原商品和积分。

## 需求与北极星

品类：餐饮零售会员自取点单；用户：25–40岁附近上班族；设备：手机，重点390×844，兼顾320×740。操作链：看商品→选杯型/温度/甜度/数量→购物袋→积分抵扣→查看取餐号。

真实品类内容：经典美式¥18起、燕麦拿铁¥28起、巴斯克蛋糕¥26/份、馥芮白¥24起。大杯加¥4，数量1–9；蛋糕按份供应且提示乳制品和鸡蛋。

品牌暖棕与奶油色，文案亲切、直接，不用萌系角色。北极星：像在熟悉的街角吧台，快速选一杯，再带着清楚的取餐号离开。

## 两个方向及选择

探索留档：[方向对比页](https://www.ithinkair.com:3031/download/{52090350-5464-4cfd-9b8a-fd2b5c35a341}.html)。其中保留探索阶段的小样，不等同于之后精修的最终界面；B为静态方向草图，最终A才是完整可交互产物。

| 维度 | A · 街角日常菜单（选定） | B · 烘焙纸菜单 |
|---|---|---|
| 引擎 | 晨光下的咖啡吧台与陶杯 | 店员每日更新的印刷菜单 |
| 骨架 | 推荐商品摄影+紧凑商品列表 | 无主图的编号文字菜单 |
| 字体 | 宋体标题、雅黑正文、Georgia价格 | 雅黑大标题、正文，Georgia序号 |
| 色彩 | #F8F3E9奶油、#513827暖棕、#A35936状态 | #F3EAD9烘焙纸、#563B2A油墨棕、#986444编号 |
| 识别 | 食物影像、杯型选择、醒目取餐数字 | 横线、直角控件与菜单编号 |
| 取舍 | 适合不熟悉商品的邻近上班族 | 浏览效率好，但对新客的商品识别较弱 |

两方案保留同一品牌暖色约束，骨架、字体关系与主视觉有明确差异，不用简单明暗换色凑方案。自主选A，原因是咖啡与甜点需要先被识别，会员权益应辅助点单。调性：安静、精致、中等密度、中等字重、偏日常；不做大促横幅、成长等级仪表盘和多层卡片。

功能基线参考[Starbucks官方移动应用介绍](https://www.starbucks.com/rewards/mobile-apps/?directory=true)：提前点单、个性化规格与会员权益。未获取竞品当前截图；以下是本任务的设计判断，不声称复刻其视觉：门店在下单前可见；商品名和价格成组；规格选中态明确；购物袋固定入口；抵扣在提交前展示；完成后取餐号成为主角。保留熟悉的点单顺序，改成社区咖啡的暖棕材质与内容，不沿用连锁品牌配色或标识。

## 实现与状态

商品分类、规格选择、购物袋合并及增减/移除、金额更新、积分开关、部分抵扣、全积分支付、余额耗尽、空购物袋、失败提示、订单历史与刷新读回均已实现。价格用整数分计算，积分每分对应1分钱，避免小数累加误差。先写入完整状态，再扣除积分和清空购物袋；保存失败不制造成功订单。

取餐号大字与虚线分隔来自咖啡取餐小票，但不堆砌拟物装饰。屏幕只保留“今日菜单”和“我的取餐”两个入口。规格抽屉内容可独立滚动，底部价格与加入按钮始终可见；有焦点样式、Esc关闭和焦点约束实现，但完整键盘与屏幕阅读器流程未验证。

为减法删除了英文品牌副标题、重复“今日推荐”角标、“今天，喝这一杯”口号、右侧“现磨咖啡·店内自制”填充文字和页底重复口号。空购物袋提示改为直接状态，保留商品名称、价格、选择信息、失败原因与主动作。

## 动效与证据

三处基本动效：首次菜单淡入并上移12px（450ms）；点按缩放与加入购物袋短提示；规格抽屉从下方28px升起并伴随遮罩（300ms）。取餐号另有450ms的小票数字出场。支持prefers-reduced-motion，关闭位移和淡入。

[首次入场](https://www.ithinkair.com:3031/download/{d78a45da-a9b8-4982-9e59-d876868a73b6}.mp4) · [抽屉切换](https://www.ithinkair.com:3031/download/{e7f58c8c-7aa1-4d6f-adeb-546928b34093}.mp4) · [加入反馈](https://www.ithinkair.com:3031/download/{e41cc211-30ef-46d4-8a45-30e8564c59b1}.mp4)。每段均保存录屏及开始/中间/结束三帧。已查看关键帧，未逐帧播放全部视频，不能据此宣称动效所有细节通过。

最终动效探测：首次入场1个运动元素，最大位移10px、透明度变化0.86；打开规格抽屉5个运动元素，最大位移28px、透明度变化1。工具报告中唯一动效问题为“滚动无变化”；此界面是点单App而非落地页，滚动叙事不适用，原始警告保留在证据包中。

截图工具最初浏览器连接失败；在任务副本加入无沙盒启动参数后恢复，并仅在取证浏览器中明确设置no-preference来记录正常动效，不改变产物的减少动态效果设置。部分最终命令在证据写完后清理临时浏览器配置时出现EPERM，导致非零退出；截图报告本身通过、录屏和图片已生成，此环境清理错误未被包装成命令完全成功。
