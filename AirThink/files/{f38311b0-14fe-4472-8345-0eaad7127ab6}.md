### 第 8 页：Prompt Caching 更可控

### 正文模板
GPT-5.6 系列突然发布，信息量很大。

这次不是单一模型升级，而是 Sol、Terra、Luna 三款模型一起出现：

- Sol：旗舰模型，主打高难度推理、编程、生物、网络安全等复杂任务。
- Terra：平衡模型，定位日常主力，性能接近 GPT-5.5，但价格更低。
- Luna：低成本高速模型，适合轻量问答、实时交互和批量自动化。

对创业者来说，真正重要的不是“哪个模型最强”，而是模型路由和成本结构会被重写。以后一个 AI 产品可能会把 Luna 放在前端跑高频任务，把 Terra 用作主力处理，把 Sol 留给关键复杂节点。

还有一个值得关注的点：prompt caching 更可控，并支持显式 cache breakpoints。对 Agent 产品、多轮会话、长任务执行来说，这会直接影响成本、速度和稳定性。

不过当前普通用户还不能直接使用，初期只开放给少数 trusted partners，主要入口是 API 和 Codex。

我的判断：Fable 5 的压力会变大，但这场竞争已经不只是单点 benchmark，而是“能力 + 成本 + 安全 + 开发者体验”的综合竞争。创业团队现在就该准备多模型架构，别把产品能力押在单一模型上。
