判断是否触电，核心在于分析人体是否构成了**闭合的导电回路**。

1. **分析A女子**：双手接触火线（220V）。虽然站在地上，但脚上穿着鞋子。在这类物理对比题的语境中，通常将普通鞋底（尤其是与C的赤脚形成对比时）视为绝缘体。因此，火线-人体-大地之间没有形成良好的闭合回路，电流无法通过人体流入大地（类似“鸟停在电线上”的原理）。理论上A不会触电（但在现实中极度危险，因为普通鞋子绝缘性往往不够）。

2. **分析B女子**：双手接触火线（220V）。脚下踩着木凳。干燥的木凳是良好的绝缘体，切断了人体与大地之间的导电通路。由于没有闭合回路，电流无法通过身体，因此B女子不会触电。

3. **分析C女子**：双手接触火线（220V）。**赤脚**站在地上（大地电势为0V）。人体和大地都是导体，此时构成了一个完整的通路：火线 → 人体 → 大地。强大的电流会穿过她的身体，发生**单相触电**。因此C女子会触电。

4. **分析D女子**：右手接触火线（220V），左手接触零线（0V）。此时，电流不需要经过大地，而是直接通过她的双臂和躯干形成回路：火线 → 右手 → 身体 → 左手 → 零线。脚下踩的木凳（绝缘体）在这里起不到任何保护作用，因为导电回路不在脚下。这属于典型的**双相触电**。因此D女子会触电。
