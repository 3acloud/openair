# 手绘画布动画工坊
	这是一个手绘画布动画网页应用，根据故事创意、时长和画面风格，使用AI智能体制作手绘画布动画，交付可播放网页、离线视频及完整源文件。包含首页、创作工坊、作品画廊三个页面。不需要用户登录页面。
	整体主题为暖色宣纸手绘工坊：背景为米白宣纸肌理渐变（#F7F1E5 到 #EDE4D4），主色墨黑 #1C1917，点缀朱砂 #C2410C、藤黄 #D4A017、松烟灰 #57534E；卡片像钉在画板上的素描纸，细铅笔描边、轻微纸纤维纹理；按钮为圆角墨线描边，悬停时出现朱砂下划线和轻微纸面掀起阴影；字体为柔和衬线与无衬线混排，标题带手写感。各页面操作按钮对应的功能必须要都实现。列表一律用卡片形式。
	页面顶部导航栏，使用墨色半透明宣纸背景，底部一根手绘细线
		左侧显示Logo（卷轴画布与毛笔图标）和「手绘画布动画」
		右侧显示标签：首页、创作工坊、作品画廊
	首页
		主标题：把故事画成会动的手稿
		说明：写下创意、选定时长与画风，工坊将以 Canvas 手绘动画交付可播放网页、离线视频和完整源文件
		中央大按钮：开始创作，点击跳转到「创作工坊」页面
		接下来是并列的三个卡片：作品总数、竖屏作品数、横屏作品数
			作品总数卡片显示全部创作记录数量
				API名称:GetRecordCount,数据源:动画创作/默认表格
			竖屏作品数卡片显示画面比例为「9:16」的数量
				API名称:GetTableCSV,数据源:动画创作/默认表格,字段:[画面比例]
				筛选画面比例为「9:16」的记录计算数量
			横屏作品数卡片显示画面比例为「16:9」的数量
				API名称:GetTableCSV,数据源:动画创作/默认表格,字段:[画面比例]
				筛选画面比例为「16:9」的记录计算数量
		接下来是「画风分布」一排小色块卡片：墨线、铅笔、孔版印刷、丝网印刷、照片涂鸦各自的作品数量
			API名称:GetTableCSV,数据源:动画创作/默认表格,字段:[绘画风格]
			绘画风格为多选项，按包含该风格的记录计数
		接下来是最近作品列表：显示最近 4 条，以卡片形式，字段包括：创作要求（前 60 字）、时长（秒）、画面比例、绘画风格、输出分辨率
			API名称:GetTableCSV,数据源:动画创作/默认表格,字段:[创作要求,时长（秒）,画面比例,输出分辨率,绘画风格,参考文件,动画交付文件]
			按表格原有顺序取前 4 条（最新在前）
			每张卡片左上角用画面比例徽章（16:9 / 9:16 / 1:1 / 4:3），中部手写摘录创作要求，底部显示时长与风格标签
			点击最近列表卡片进入该条作品详情（当前行设为对应行号，跳转作品画廊并打开详情）
	「创作工坊」页面
		左上显示大标题：创作工坊，说明：像在画案上写下分镜——交代故事、角色、动作、情绪与声音，其余交给画师智能体
		右上是按钮：查看画廊，跳转到「作品画廊」页面
		页面分左右两栏（窄屏上下堆叠）
		左栏为创作表单
			表单标题:动画创作,表:动画创作,字段:[{字段名:创作要求,类型:文本},{字段名:时长（秒）,类型:数值},{字段名:画面比例,类型:单选项,可选项:16:9,9:16,1:1,4:3},{字段名:输出分辨率,类型:文本},{字段名:绘画风格,类型:多选项,可选项:墨线,铅笔,孔版印刷,丝网印刷,照片涂鸦},{字段名:参考文件,类型:文本},{字段名:动画交付文件,类型:指令流}]
			创作要求用大号多行输入，占位提示：「一只狐狸在雨巷里收起油纸伞，墨线慢慢被雨水晕开……」
			时长（秒）用数字输入，旁注常见建议：8 / 12 / 15 / 24
			画面比例以四个可视化画框按钮单选，选中后用朱砂描边；切换比例时若输出分辨率为空或仍是默认值，则自动填入对应建议：16:9→1920x1080，9:16→1080x1920，1:1→1080x1080，4:3→1024x768
			输出分辨率用文本输入，占位「例如 1920x1080」
			绘画风格用可多选的纸片标签，选中后呈墨色填充
			参考文件：显示已选文件名；按钮「选择参考文件」调用 SelectFile 返回文件全局文件名并写入该字段；可清除
			动画交付文件为指令流，不在表单中手工填写，提交后由后台异步生成
			表单不含任何未在表定义中出现的字段，不编造 ID 或日期字段
		左栏底部主按钮：生成手绘动画
			仅当创作要求非空、时长（秒）为正数、已选画面比例时启用
			点击使用 SubmitRecord 提交表单，表单数据是 json 文本
				API名称:SubmitRecord,数据源:动画创作,payload:表单数据
			提交后当前行是 1
			参考文件字段值为 SelectFile 返回的全局文件名
		右栏为「画案预览」
			提交前：展示当前比例的空白画框、已选风格标签和时长，像一张待动笔的稿纸
			提交后进入生成态：画框内循环播放铅笔打形、墨线勾勒、纸面晕染的等待动画，等待消息：「画师正在铺纸、起稿、曝光……」
			轮询标题:动画创作,表:动画创作,字段:动画交付文件,输出到:交付结果,等待消息:画师正在铺纸、起稿、曝光……
			指令流不是用户手工填写，SubmitRecord 后由后台 AI 异步生成；本指令描述未指定「以 JSON 格式输出」，因此轮询该指令流字段「动画交付文件」
			轮询时反复调用 GetCellValue，直到单元格有有效内容
				API名称:GetCellValue,数据源:动画创作/默认表格,payload:动画交付文件/当前行
			生成结束后：
				指令流详情用 Markdown 主题显示（可先 GetCellValue，再 GetCellBullet 作为补充）
				若单元格文本是全局文件名，则视为 ZIP 交付包
					下载成片：访问 https://www.ithinkair.com:3031/download/全局文件名
					在浏览器打开：访问 https://www.ithinkair.com:3031/private/全局文件名
				提供按钮：下载 ZIP、在新页打开交付包
				画框中显示「成片已装订」的完成态与创作要求摘要、时长、比例、分辨率、风格
		生成完成后右栏下方按钮：再画一部，点击清空表单与交付结果，当前行设为 0，等待动画复位
		当前行初始是 0
	「作品画廊」页面
		左上显示大标题：作品画廊，说明：翻看每一部装订好的手稿动画，继续修改说明或取走成片
		右上是按钮：+ 新的画稿，跳转到「创作工坊」并清空表单、当前行设为 0
		搜索框，可按创作要求关键词搜索
		筛选器：按画面比例筛选（全部 / 16:9 / 9:16 / 1:1 / 4:3）；按绘画风格筛选（多选标签，匹配包含该风格的记录）
		主体是作品卡片墙，不使用传统密表；卡片展示字段与表单字段一致，以便点击单卡即可编辑同一条记录
			API名称:GetTableCSV,数据源:动画创作/默认表格,字段:[创作要求,时长（秒）,画面比例,输出分辨率,绘画风格,参考文件,动画交付文件]
			调用 GetTableCSV 获取表格数据；csv 中文件字段的文本是文件的全局文件名；逗号分隔的字段名必须是本表字段
			每张卡片显示：创作要求前 80 字、时长（秒）、画面比例徽章、输出分辨率、绘画风格纸片标签
			参考文件若有全局文件名，卡片底部显示「含参考文件」小标记，点击可下载 https://www.ithinkair.com:3031/download/全局文件名
			动画交付文件通过 GetCellValue 取详情；有全局文件名时显示「成片可取」朱砂点，否则显示「绘制中」灰点
			每张卡片操作按钮：查看详情、编辑、删除、下载成片（无交付文件时禁用）
				查看详情：弹出画稿模态，当前行=该行行号
					逐字段 GetCellValue 填充
						API名称:GetCellValue,数据源:动画创作/默认表格,payload:字段名/行
					创作要求、时长、比例、分辨率、风格用稿纸排版展示
					参考文件：有值则提供下载与「在浏览器打开」（private 链接）
					动画交付文件：文本内容用 Markdown 主题显示；若为全局文件名，同时给出下载 ZIP 按钮（download 链接）与打开按钮（private 链接）
				编辑：打开编辑表单，当前行=行号，GetCellValue 逐字段回填（参考文件显示文件名，可再 SelectFile 替换）
					表单标题:编辑画稿,表:动画创作,字段与创作工坊相同（不含指令流手工输入）
					修改表单是依次通过 SetCellValue 设当前记录行各字段的值，而不是用 SubmitRecord 提交
						API名称:SetCellValue,数据源:动画创作/默认表格,payload:字段名/行/值
					布尔类型字段值用「是」或「否」表示（本表无布尔字段）
					指令流字段不可手工改写；用户若要重新生成动画，应返回创作工坊新建一条并 SubmitRecord
				删除：确认后调用 DeleteRecord
					API名称:DeleteRecord,数据源:动画创作/默认表格,payload:行号.toString()
					payload 参数接收的是文本，所以行号需要 toString() 再传给 payload
				下载成片：GetCellValue 取动画交付文件全局文件名，跳转 https://www.ithinkair.com:3031/download/全局文件名
			点击卡片主体等同查看详情
		需要定位某一行时
			API名称:GetRecordRow,数据源:动画创作/默认表格,payload:字段名/值
			行号从 1 开始计数
		需要记录总数时
			API名称:GetRecordCount,数据源:动画创作/默认表格
	详情与编辑补充
		查看字段详情调用 GetCellValue 获取单元格详情数据
		指令流类型字段要显示详情内容时，先调用 GetCellValue，文本内容用 Markdown 主题显示
		HTML 文件的链接是 https://www.ithinkair.com:3031/private/全局文件名 ，若交付说明中出现 HTML 全局文件名，可在 iframe 中打开预览
		选择图片调用 SelectImage，拍摄调用 CapturePhoto（本应用主路径用 SelectFile 选择参考文件；若用户改用图片参考，也允许 SelectImage，返回值同样写入参考文件）
		必要时可用 ImageUrl / FileUrl / ReadFile 辅助预览，不得编造表字段
	统一约定
		数据源表名为「动画创作」，GetTableCSV / GetCellValue 等使用「动画创作/默认表格」
		字段名必须是表定义中定义过的字段：创作要求、时长（秒）、画面比例、输出分辨率、绘画风格、参考文件、动画交付文件；不要自行编造 ID 或创建日期等字段
		主体卡片上显示的字段及对应 GetTableCSV 的字段要和表单字段一致，以便点选单条可以编辑表单
		当前行初始为 0；SubmitRecord 之后当前行是 1
		各页面使用统一的宣纸手绘主题，卡片与按钮具有悬停纸面效果，点击卡片展开详情
