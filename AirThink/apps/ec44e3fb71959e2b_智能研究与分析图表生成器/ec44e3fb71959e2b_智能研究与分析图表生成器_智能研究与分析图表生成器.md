# 智能研究与分析图表生成器

这是一个智能研究与分析图表生成器网页应用，包含首页、创建研究任务、研究任务库页面。页面统一采用科技感现代主题，背景为极浅的冷灰色，内容区采用白色背景卡片，按钮和卡片带有轻微的阴影悬停效果，字体为专业清晰的无衬线字体，强调色为科技蓝。

页面顶部导航栏，使用深蓝色专业背景
- 左侧显示Logo（分析图表图标）和‘智能研究与分析图表生成器’
- 右侧显示标签：首页、创建研究任务、研究任务库

首页
- 主标题：智能研究与分析图表生成器
- 介绍区：以一张白色背景的中文文字列表图为视觉元素，展示了多种可由 AI 生成的图表、分析框架和商业模型类型。内容包括：思维导图、流程图、用户旅程图、鱼骨图、甘特图、组织结构图、商业画布、SWOT 分析、PEST 分析、5Why 分析、平衡计分卡、时间管理四象限、胜任力模型、价值链、用户画像、Smart 分析、波士顿矩阵、波特五力模型、4P 营销理论模型、竞品分析、安索夫矩阵、Grow 模型和 AARRR 模型等。
- 中央大按钮：+ 新建分析图表，点击跳转到‘创建研究任务’页面
- 统计卡片：
  - 累计研究任务数：显示已生成的图表任务总数
    API名称:GetRecordCount,数据源:研究与制图任务/默认表格
- 最近研究任务：显示最近5条生成记录，字段包括：任务标题、研究主题、图表类型、任务提交时间。以列表或卡片形式显示。
  - API名称:GetTableCSV,数据源:研究与制图任务/默认表格,字段:[任务标题,研究主题,图表类型,任务提交时间]
  - 按任务提交时间降序排列，显示前5条。

‘创建研究任务’页面
- 左上显示大标题：创建研究任务，说明：通过任务智能体对选定主题进行深度搜索和专业研究，并自动转换为专业的分析框架图表。
- 右上是按钮：前往任务库，跳转到‘研究任务库’页面
- 表单区域：
  - 表单标题:研究与制图任务,表:研究与制图任务,字段:[{字段名:任务标题,类型:文本},{字段名:研究主题,类型:文本},{字段名:图表类型,类型:单选项,可选项:思维导图,流程图,用户旅程图,鱼骨图,甘特图,组织结构图,商业画布,SWOT 分析,PEST 分析,5Why 分析,平衡计分卡,时间管理四象限,胜任力模型,价值链,用户画像,Smart 分析,波士顿矩阵,波特五力模型,4P 营销理论模型,竞品分析,安索夫矩阵,Grow 模型,AARRR 模型},{字段名:研究结果图表SVG,类型:指令流,指令类型:任务智能体,指令描述:请对主题“{{研究主题}}”进行深度搜索和研究，梳理相关的信息与数据。接着，根据提取的研究内容，结合所选的“{{图表类型}}”的逻辑结构将其可视化表达。最终结果必须使用纯正的 SVG 代码格式输出，以白色为背景色，直接输出从<svg>到</svg>的完整代码，不要包含多余的 Markdown 标记或其他解释说明文字。},{字段名:任务提交时间,类型:日期时间}]
  - 任务提交时间自动获取当前日期时间，在表单上隐藏不显示给用户。
  - 提交按钮：开始智能研究与绘制，点击提交表单。
  - 使用SubmitRecord提交，提交后当前行为1。
- 结果展示区域（SVG图表渲染区）：
  - 提交后，轮询标题:等待生成,表:研究与制图任务,字段:研究结果图表SVG,输出到:“可视化图表结果”。
  - 初始状态显示加载动画及文字“智能体正在深度搜索与逻辑构建中，请耐心等待...”。
  - 轮询结束后，获取到的如果是带有 ````svg ... ```` 的 Markdown 格式文本，需要自动提取 `<svg>...</svg>` 标签部分。将提取出的纯正 SVG 代码以 HTML 的方式直接渲染展示在白底的容器框内，呈现出真实的图像效果，而不应只显示源代码。

‘研究任务库’页面
- 左上显示大标题：研究任务库，说明：管理和浏览历史生成的分析研究图表
- 右上是按钮：+ 新增任务，跳转到‘创建研究任务’页面
- 搜索框：可按照任务标题或研究主题进行模糊搜索
- 筛选器：提供按“图表类型”筛选的下拉菜单
- 主体是任务表格，显示关键字段：任务标题、研究主题、图表类型、任务提交时间
  - API名称:GetTableCSV,数据源:研究与制图任务/默认表格,字段:[任务标题,研究主题,图表类型,任务提交时间]
  - 表格按任务提交时间降序排列
  - 每行右侧包含操作按钮：查看图表、删除
  - 删除操作：调用 DeleteRecord, 数据源:研究与制图任务/默认表格, payload:行号.toString()
  - 查看图表操作：点击后弹出大号模态框，模态框标题显示为“【图表类型】任务标题”。
    - 通过 API名称:GetCellValue,数据源:研究与制图任务/默认表格,字段名:研究结果图表SVG,行号:当前操作的行号 获取 SVG 内容。
    - 在模态框内去除多余 Markdown 标记后，将纯正的 SVG 源码渲染为可视化的图形供用户查看。
    - 模态框底部包含“关闭”按钮。
