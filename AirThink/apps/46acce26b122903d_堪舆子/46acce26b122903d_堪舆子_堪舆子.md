# 堪舆子
	这是一个传统堪舆问事网页应用，以三元玄空飞星与八宅明镜为纲，为阳宅布局、入宅开业择吉及化煞提供可操作建议。包含首页、宅主名册、起课问吉、问事卷宗四个页面。不包含用户登录页面。
	页面统一采用夜观星象的玄门主题：背景为玄青到墨黑的纵向渐变（#0b1020 → #16110c），隐约水墨远山与淡金八卦罗盘水印；主色朱砂红 #c23a2b，辅色鎏金 #d4af37、青玉 #3d6b5a、宣纸米白 #f4ead5；卡片为半透明宣纸底（米白 92% 不透明）加细金边，悬停时金边发光、轻微上浮；标题用楷体/宋体风格，正文柔和 sans-serif；按钮朱砂底鎏金字，次要按钮青玉描边。各页面表格与卡片均有悬停效果，点击卡片或行可展开详情。操作按钮对应的功能必须要都实现。

	数据与桥接约定
		使用 callAppBridge({type:"GetTableCSV", data:"数据源", payload:"逗号分隔的字段名"}) 获取不包含标题行的 csv 文本。csv 中图片字段的文本是图片的全局文件名。逗号分隔的字段名必须是数据源对应的表的字段。
		使用 callAppBridge({type:"SubmitRecord", data:"表", payload:"表单数据"}) 提交记录，表单数据是 json 文本。
		使用 callAppBridge({type:"GetRecordCount", data:"数据源"}) 获取记录数。
		使用 callAppBridge({type:"GetRecordRow", data:"数据源", payload:"字段名/值"}) 获取行号。行号从 1 开始计数。
		使用 callAppBridge({type:"DeleteRecord", data:"数据源", payload:"行"}) 删除指定行号的记录。payload 接收文本，行号需要 toString() 再传给 payload。
		使用 callAppBridge({type:"GetCellBullet", data:"数据源", payload:"字段名/行"}) 获取表单元格的 Bullet。
		使用 callAppBridge({type:"GetCellValue", data:"数据源", payload:"字段名/行"}) 获取表单元格的值。
		使用 callAppBridge({type:"SetCellValue", data:"数据源", payload:"字段名/行/值"}) 设表单元格的值。
		使用 callAppBridge({type:"SelectImage"}) 选择图片，返回图片全局文件名。
		使用 callAppBridge({type:"CapturePhoto"}) 拍摄图片，返回图片全局文件名。
		字段名必须是表定义中出现过的字段名，禁止为这两张表编造 ID、编号、创建日期等字段。
		只读内容不要用单独页面承载；「堪舆批断」在问事卷宗的卷轴模态与起课问吉的批断区显示即可。
		主体列表上显示的字段及对应 GetTableCSV 的字段要和表单字段一致。
		各页面操作按钮功能必须全部实现。
