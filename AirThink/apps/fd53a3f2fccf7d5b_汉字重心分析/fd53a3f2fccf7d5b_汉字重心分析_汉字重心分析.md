# 汉字重心分析

开发一个名为“汉字重心分析”的响应式网页应用。应用基于分量、距离与斜度模型，帮助用户分析汉字的视觉重心、结构平衡和中宫分布，并由后台任务智能体生成 PNG 可视化分析图片。

## 整体设计

- 页面采用“东方书法 × 精密测量仪器”的视觉主题：宣纸白背景叠加极淡米字格，主色为墨黑，强调色为朱砂红与青黛蓝。
- 顶部导航栏左侧显示圆形篆刻风 Logo 和“汉字重心分析”，右侧显示“分析工作台”“历史分析”。
- 卡片使用轻微纸张纹理、细墨线边框和柔和阴影；按钮、输入框、滑杆及弹窗风格统一，并提供清晰的悬停、按下、禁用和加载状态。
- 桌面端采用宽屏双栏布局，移动端改为单栏；所有控件必须可通过键盘操作，并具有明确标签。
- 不需要用户登录页面。
- 当前行初始为 0。新建分析提交后当前行设为 1；从历史列表选择记录后，当前行设为该记录对应的行号。
- 数据源统一使用“汉字分析/默认表格”。不得自行增加或使用表定义之外的字段。

## 分析工作台

页面标题为“看见汉字的视觉重心”，说明为“调整结构参数，让分量、距离与斜度共同揭示字形的平衡关系”。

页面顶部提供“历史分析”按钮，点击切换到历史分析页面；右下角提供悬浮“新建分析”按钮，点击后清空全部表单值、预览和结果，并将当前行设为 0。

### 参数表单

左侧显示参数控制卡片。

表单标题：汉字重心分析  
表：汉字分析  
字段：[{字段名:"汉字",类型:"文本"},{字段名:"字体",类型:"单选项",可选项:["楷书","宋体","黑体","仿宋","明体","思源宋"]},{字段名:"分量权重",类型:"数值"},{字段名:"中宫收紧",类型:"数值"},{字段名:"斜度影响",类型:"数值"},{字段名:"偏上偏差",类型:"数值"},{字段名:"偏右偏差",类型:"数值"},{字段名:"对比字",类型:"文本"}]

- “汉字”为必填的单字输入框，实时显示已输入字数，仅允许提交一个汉字。
- “对比字”为可选的单字输入框；填写后可用于对照分析，同样限制为一个汉字。
- “字体”使用带字体样张感的单选卡片，默认选择“楷书”。
- 数值字段使用“滑杆 + 可直接输入的数值框”的组合控件，两者双向同步。默认值均为 0；界面应显示正负方向提示，但不得擅自改变用户输入的数值。
- 为“分量权重”“中宫收紧”“斜度影响”“偏上偏差”“偏右偏差”分别提供简短解释和重置按钮。
- 表单底部提供主按钮“生成重心分析”。汉字无效或正在提交、轮询时按钮禁用，避免重复提交。

### 提交与生成

点击“生成重心分析”时：

1. 校验汉字与对比字的长度和必填项；校验失败时在对应控件下显示错误，不提交。
2. 调用：
   `callAppBridge({type:"SubmitRecord", data:"汉字分析", payload: JSON.stringify({汉字,字体,分量权重,中宫收紧,斜度影响,偏上偏差,偏右偏差,对比字})})`
3. 提交成功后将当前行设为 1。字段“分析图片”为指令流类型，不由用户填写，也不放入提交数据。
4. 立即在结果区显示骨架屏、动态米字格和“正在计算视觉重心并绘制分析图…”消息。
5. 轮询：`callAppBridge({type:"GetCellValue", data:"汉字分析/默认表格", payload:"分析图片/1"})`，直到“分析图片”生成完成并返回非空全局文件名。轮询期间提供明确的等待状态；合理设置轮询间隔和超时，超时或失败时显示错误以及“重新获取结果”按钮，不要重复提交记录。
6. 获取全局文件名后，以 `https://www.ithinkair.com:3031/download/全局文件名` 作为图片地址展示 PNG，并提供“打开原图”按钮，使用 `https://www.ithinkair.com:3031/private/全局文件名` 在新窗口打开。
7. 图片加载成功后刷新历史分析数据。

### 分析结果

右侧为结果展示卡片。未生成时显示米字格占位图、引导文案“输入一个汉字，开始观察它的视觉平衡”；生成后显示：

- 主汉字、字体和可选对比字摘要。
- 大尺寸 PNG 分析图片，支持点击放大到沉浸式预览弹窗；弹窗支持关闭、打开原图。
- 参数快照：分量权重、中宫收紧、斜度影响、偏上偏差、偏右偏差，以紧凑指标卡显示。
- “再次调整”按钮：保留当前参数并聚焦左侧表单。

## 历史分析

页面标题为“历史分析”，说明为“回看不同汉字与参数组合下的视觉重心结果”。右上角显示“+ 新建分析”，点击返回分析工作台并清空表单、预览和当前结果，当前行设为 0。

### 数据读取与概览

- 页面加载时调用：`callAppBridge({type:"GetRecordCount", data:"汉字分析/默认表格"})`，显示“分析总数”统计卡片。
- 调用：`callAppBridge({type:"GetTableCSV", data:"汉字分析/默认表格", payload:"汉字,字体,分量权重,中宫收紧,斜度影响,偏上偏差,偏右偏差,对比字,分析图片"})`。
- CSV 不包含标题行，必须按上述字段顺序可靠解析；需正确处理引号、逗号、换行和空值。列表使用卡片网格展示，卡片字段与 GetTableCSV 读取字段保持一致。
- 提供按“汉字或对比字”搜索、按字体筛选，以及清除筛选按钮；筛选与搜索即时生效，并显示匹配数量和空状态。
- 最近分析区域取读取结果最前面的最多 4 条记录，以横向紧凑卡片显示；点击最近项打开详情。

### 历史卡片

每张卡片显示主汉字、字体、对比字（为空时显示“无对比字”）、五项参数摘要和分析图片缩略图。图片字段的 CSV 文本是全局文件名，缩略图地址为 `https://www.ithinkair.com:3031/download/全局文件名`；图片为空或尚未生成时显示“生成中”占位状态。

每张卡片提供以下操作，所有按钮都必须实现：

- “查看详情”：记录对应行号为当前行；依次调用 GetCellValue 获取详情：
  - `callAppBridge({type:"GetCellValue", data:"汉字分析/默认表格", payload:"汉字/行号"})`
  - 对字体、分量权重、中宫收紧、斜度影响、偏上偏差、偏右偏差、对比字、分析图片采用相同方式读取。
  - 在详情抽屉或弹窗中展示完整参数和大图；分析图片仍为空时允许在详情内继续轮询该行的“分析图片”。
- “编辑参数”：先按上述方式逐字段读取当前行并填入分析工作台，然后切换到分析工作台进入编辑模式。
- “删除”：弹出二次确认，确认后调用 `callAppBridge({type:"DeleteRecord", data:"汉字分析/默认表格", payload: 当前行.toString()})`；成功后关闭详情、将当前行设为 0，并重新读取总数和列表。

点击卡片本身等同于“查看详情”。

## 编辑模式

编辑历史记录时，表单标题变为“编辑分析参数”，主按钮变为“保存修改”。保存时不得调用 SubmitRecord，必须针对当前行依次调用：

- `callAppBridge({type:"SetCellValue", data:"汉字分析/默认表格", payload:"汉字/行号/值"})`
- 对字体、分量权重、中宫收紧、斜度影响、偏上偏差、偏右偏差、对比字分别调用 SetCellValue。

“分析图片”是后台异步生成的指令流字段，不允许用户直接编辑，也不要用 SetCellValue 写入。保存成功后显示成功提示，退出编辑模式，重新读取列表，并打开该记录详情以展示最新字段值。提供“取消编辑”按钮，放弃未保存更改并返回历史分析。

## 行号与数据一致性

- CSV 本身不含行号，前端按照 GetTableCSV 返回的记录顺序为每条数据建立从 1 开始的行号映射；执行查看、编辑、删除前，如需防止筛选或刷新造成行号错位，可调用 `callAppBridge({type:"GetRecordRow", data:"汉字分析/默认表格", payload:"汉字/值"})` 获取行号。但汉字可能重复，因此列表加载后必须保留原始顺序对应的行号，不能使用筛选后数组下标作为行号。
- 所有修改后都重新调用 GetRecordCount 与 GetTableCSV 刷新数据，重新建立行号映射。
- 数值 0 必须作为有效值显示和提交，不能被当作空值。
- 所有异步操作都要有加载、成功、失败反馈；删除、提交、保存过程中防止重复点击。
- 全部 API 调用必须使用准确的数据源、表名、字段名和文本 payload 格式。

## 交互细节

- 顶部导航切页时保留尚未提交的表单草稿；点击“新建分析”才清空草稿。
- 结果图片和历史缩略图应保持比例、支持加载失败占位，不将全局文件名直接展示给用户。
- 使用轻量动画表现重心点、十字辅助线和米字格扫描效果，但动画不能影响可读性。
- 搜索、筛选、详情、编辑、删除、新建、提交、重新获取、图片放大和打开原图等所有可见操作必须真实可用，不能只制作静态界面。
