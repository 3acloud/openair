# 智能记账助手
	这是一个面向个人和家庭的口语化智能记账网页应用，包含首页、一句话记账、记账记录三个页面。页面统一采用温暖家庭账本主题：背景为米白到浅暖金的柔和渐变，主色松石绿，强调色琥珀金，卡片大圆角、轻阴影，悬停轻微上浮并带金色描边，字体为圆润易读的 sans-serif。整体像一本温柔的家庭账本，而不是冷冰冰的财务系统。不需要用户登录页面。操作按钮对应的功能必须要都实现。列表一律用卡片形式。字段名只能使用表定义中的「用户指令」「执行结果」，不要自行编造 ID、创建日期或其他字段。
	页面顶部导航栏，使用深松石绿背景，底部一条细琥珀金线
		左侧显示 Logo（打开的小钱包图标）和「智能记账助手」
		右侧显示标签：首页、一句话记账、记账记录
	首页
		主标题：智能记账助手
		说明：一句话记下生活里的每一笔。支持一句话记多笔、自动分类收支、查询统计、修改和删除流水。仅支持人民币和文字输入。
		中央大按钮：开始记账，点击跳转到「一句话记账」页面
		其下是一排口语快捷口令胶囊（点击跳转「一句话记账」并预填到用户指令输入框，不提交）
			今天午饭38，地铁6，咖啡15
			发工资15000
			这个月餐饮花了多少
			把刚才那笔咖啡改成28
			删除上一条记账
		接下来是并列的两个统计卡片
			累计记账次数卡片显示全部记账任务数量
				API名称:GetRecordCount,数据源:记账任务/默认表格
			最近一次记账卡片显示最近一条用户指令的前30字（无记录时显示「还没有记账」）
				API名称:GetTableCSV,数据源:记账任务/默认表格,字段:[用户指令,执行结果]
				取第1条用户指令截取前30字
		接下来是最近记账列表：显示最近5条，以卡片形式展示
			每张卡片上方显示用户指令全文（过长则两行截断），下方显示执行结果摘要（前80字，去掉 Markdown 标记）
			API名称:GetTableCSV,数据源:记账任务/默认表格,字段:[用户指令,执行结果]
			显示前5条
			点击任一最近列表卡片，进入详情：当前行通过 GetRecordRow 获取（payload为「用户指令/该条用户指令文本」），再调用 GetCellValue 读取用户指令与执行结果，弹出详情模态；执行结果用 Markdown 主题渲染
	「一句话记账」页面
		左上显示大标题：一句话记账
		说明：像跟家人说话一样记账。一句话可记多笔，也能查询、修改、删除。仅人民币，仅文字。
		右上是按钮：查看记录，点击跳转到「记账记录」页面
		页面中部是一张暖色大卡片，像一张待填写的记账便笺
			便笺顶部小字：对账本说一句话
			多行输入框绑定字段「用户指令」，占位示例：「昨天买菜67.5，孩子牛奶32，收到稿费800」
			输入框下方再次给出可点选的口语示例胶囊，点击写入输入框
			主按钮标题：记一笔，仅当用户指令非空时启用
		表单标题:智能记账,表:记账任务,字段:[{字段名:用户指令,类型:文本},{字段名:执行结果,类型:指令流,指令类型:任务智能体,指令描述:请使用技能0a1ac19a62567d09_smart-expense-tracker，根据用户指令完成个人与家庭日常记账。支持一句话记多笔、自动分类收支、查询统计、修改和删除记录。仅支持人民币和文字输入。用户指令如下\n---\n{{用户指令}},输出类型:文本}]
			用户只填写用户指令
			执行结果不是用户手工填写的，提交后由后台 AI 异步生成
			点击「记一笔」使用 SubmitRecord 提交，表单数据是 json 文本，仅包含用户指令
			提交后当前行是1
		提交后进入等待与结果区
			轮询标题:智能记账,表:记账任务,字段:执行结果,输出到:记账结果,等待消息:正在为你记账，请稍候…
			因指令描述未要求以 JSON 格式输出，故轮询该「指令流」类型字段「执行结果」
			轮询使用 GetCellValue，数据源:记账任务/默认表格, payload:执行结果/当前行
			生成结束后，记账结果区域用 Markdown 主题显示执行结果全文，排版像一张清晰的电子收据：分类、金额、结余与说明层次分明
			API名称:GetCellValue,数据源:记账任务/默认表格,字段名:用户指令,行号:当前行
			API名称:GetCellValue,数据源:记账任务/默认表格,字段名:执行结果,行号:当前行
		结果区右上角是翻阅按钮
			按钮标题:< ，点击读取上一行的用户指令、执行结果，数据来源于 GetCellValue
			按钮标题:> ，点击读取下一行的用户指令、执行结果，数据来源于 GetCellValue
			API名称:GetRecordCount,数据源:记账任务/默认表格
			当前行初始是0
			当前行<=1时，<按钮不可操作
			当前行>=RecordCount时，>按钮不可操作
		右下新建按钮标题:+，点击清空用户指令输入框和记账结果，并且当前行设为0，输入框重新获得焦点
		未提交且当前行为0时，记账结果显示一句温暖空状态文案：「账本已打开，等你说第一句话。」
	「记账记录」页面
		左上显示大标题：记账记录
		说明：回看每一次口语记账，点开卡片即可阅读完整执行结果
		右上是按钮：+ 再记一笔，点击跳转到「一句话记账」页面并清空表单、当前行设为0
		搜索框，可按照用户指令关键词搜索
		主体是记账任务卡片列表，不要用传统密表格做主视图；卡片字段必须与表单字段一致，以便点击单卡即可进入编辑
			API名称:GetTableCSV,数据源:记账任务/默认表格,字段:[用户指令,执行结果]
			每张卡片显示：用户指令全文、执行结果摘要（前100字）
			每张卡片有操作按钮：查看详情、编辑、删除
			查看详情：弹出模态，上方展示用户指令，下方用 Markdown 主题展示执行结果全文（先 GetCellValue 获取执行结果）
			编辑：当前行通过 GetRecordRow 获取（payload为「用户指令/该条用户指令文本」），再用 GetCellValue 逐字段填充表单；用户指令可改，执行结果在表单中只读并以 Markdown 预览
			删除：调用 DeleteRecord，数据源:记账任务/默认表格，payload:行号.toString()；删除前需确认
			点击卡片空白区域等同于查看详情
		表单标题:编辑记账任务,表:记账任务,字段:[{字段名:用户指令,类型:文本},{字段名:执行结果,类型:指令流}]
			修改表单依次通过 SetCellValue 设当前记录行各字段的值，而不是用 SubmitRecord 提交
			SetCellValue 的 payload 为「字段名/行/值」
			执行结果为指令流，编辑时不要当作普通输入框让用户手写；若只改用户指令，仅 SetCellValue 更新用户指令
			布尔值若出现用「是」或「否」（本表无布尔字段）
		空列表时显示空状态：还没有流水，去说一句「今天午饭38」吧；按钮「去记账」跳转「一句话记账」
	详情与指令流显示规则
		查看字段详情一律调用 GetCellValue 获取单元格详情数据
		要显示「指令流」类型字段的详情内容，先调用 GetCellValue 获取内容，文本内容用 Markdown 主题显示
		csv 中若出现文件或图片全局文件名（本应用无此类字段），图片链接为 https://www.ithinkair.com:3031/download/全局文件名
	各页面使用统一的松石绿 + 琥珀金家庭账本主题，卡片与按钮均有悬停效果，点击最近列表项或记录卡片可查看详情。所有操作按钮功能必须实现。当前行初始为0，SubmitRecord 成功后当前行为1并开始轮询执行结果。
