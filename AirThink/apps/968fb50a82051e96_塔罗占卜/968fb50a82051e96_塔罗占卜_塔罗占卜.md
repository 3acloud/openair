# 塔罗占卜
	这是一个塔罗占卜网页应用，包含首页、起卦占卜、占卜记录三个页面。页面统一采用暗夜星空紫金主题：背景为深靛紫到墨黑的径向渐变并点缀缓慢漂浮的微光星点；主色为夜空紫 `#1a0b2e`、烛金 `#d4af37`、月光银 `#e8e4f0`、暮霭紫 `#6b3fa0`；卡片仿塔罗牌造型，金边暗纹、轻微浮起阴影，悬停时金边发光并微微上浮；标题使用优雅衬线字体，正文使用柔和无衬线字体。不包含用户登录页面。操作按钮对应的功能必须要都实现。字段名必须是表定义中出现过的字段：求问事项、牌阵、占卜解读，禁止自行编造 ID、创建日期或其他字段。

	页面顶部导航栏，使用半透明深紫背景加细金线底边
		左侧显示Logo（新月与星星图标）和「塔罗占卜」
		右侧显示标签：首页、起卦占卜、占卜记录
		导航栏随滚动保持吸顶

	首页
		主标题：塔罗占卜
		副标题：输入求问事项并选择牌阵，由塔罗智能体抽牌解读。建议可执行，选择权在你，不做命运宣判。
		中央主按钮：立即起卦，点击跳转到「起卦占卜」页面
		其下一条金线分隔的引言：「牌面只是镜子，决定仍在你手中。」
		接下来是并列的两个统计卡片：
			总占卜次数卡片
				API名称:GetRecordCount,数据源:占卜记录/默认表格
			本周求问次数卡片
				API名称:GetTableCSV,数据源:占卜记录/默认表格,字段:[求问事项,牌阵,占卜解读]
				以当前列表长度作为次数展示（若无法按周切割则展示全部次数并标注「累计」）
		接下来是「最近求问」区域，标题：最近求问
			以卡片形式展示最近 5 条占卜记录（不足 5 条则全部展示）
			API名称:GetTableCSV,数据源:占卜记录/默认表格,字段:[求问事项,牌阵,占卜解读]
			每张卡片显示：牌阵名称（作为金色小标签）、求问事项（最多两行，超出省略）、占卜解读摘要（截取前 60 字，去除 Markdown 标记）
			卡片右侧显示对应牌阵的简笔画图标（单张牌/三牌/五牌/月亮/马蹄/十字）
			点击任一最近卡片进入详情：先用 GetRecordRow 定位行号，再 GetCellValue 读取该行求问事项、牌阵、占卜解读，弹出详情模态
		底部一句轻提示：「每一次抽牌，都是一次与自己的对话。」

	「起卦占卜」页面
		左上显示大标题：起卦占卜
		说明：写下你真正想问的事，选择牌阵。抽牌与解读由塔罗智能体完成；建议具体可执行，不宣判固定命运。
		右上是按钮：查看记录，点击跳转到「占卜记录」页面

		表单标题:塔罗起卦,表:占卜记录,字段:[{字段名:求问事项,类型:文本},{字段名:牌阵,类型:单选项,可选项:单张牌,三牌阵,五牌阵,月亮牌阵,马蹄形,凯尔特十字},{字段名:占卜解读,类型:指令流}]
			求问事项：多行文本框，占位符「例如：我该如何推进眼下的选择？请尽量具体。」，必填
			牌阵：不要用普通下拉，改为六张可选牌阵卡，单选，选中金边高亮
				单张牌：一句话洞察，适合聚焦当下
				三牌阵：过去 / 现在 / 未来
				五牌阵：情境、挑战、建议、外力、结果
				月亮牌阵：潜意识与周期
				马蹄形：路径与阻碍
				凯尔特十字：完整局势
			占卜解读不由用户填写，表单上不出现输入框；提交后由后台异步生成

		主按钮标题：抽牌解读
			仅当求问事项非空且已选择牌阵时启用
			点击后使用 SubmitRecord 提交，表单数据是 json 文本，仅包含求问事项与牌阵
			提交后当前行是 1
			提交过程中按钮变为不可点，文案改为「牌已入阵…」

		提交后必须轮询等待指令流异步生成结束
			轮询标题:塔罗起卦,表:占卜记录,字段:占卜解读
			API名称:GetCellValue,数据源:占卜记录/默认表格,字段名:占卜解读,行号:当前行
			因指令描述未要求「以JSON格式输出」，轮询该指令流字段本身
			等待消息：随机轮换展示「洗牌中，请静心…」「牌面正在展开…」「解读生成中，选择权在你…」
			等待期间在按钮下方展示三张背面朝上的塔罗牌来回翻动的动画
			当 GetCellValue 返回的占卜解读非空且不再是生成中占位时，停止轮询

		解读结果区（初始隐藏，生成完成后展开）
			顶部显示本次求问事项与牌阵标签
			占卜解读使用 Markdown 主题呈现（支持标题、列表、加粗、引用）
			API名称:GetCellValue,数据源:占卜记录/默认表格,字段名:求问事项,行号:当前行
			API名称:GetCellValue,数据源:占卜记录/默认表格,字段名:牌阵,行号:当前行
			API名称:GetCellValue,数据源:占卜记录/默认表格,字段名:占卜解读,行号:当前行
			结果区底部固定一句：「以上为能量参考与可执行建议，最终选择权在你，不做命运宣判。」
			结果区右下两个按钮：
				再问一事：清空求问事项与牌阵选择、收起解读结果、当前行设为 0，停留在本页
				查看全部记录：跳转到「占卜记录」页面

		当前行初始是 0

	「占卜记录」页面
		左上显示大标题：占卜记录
		说明：回看每一次求问与解读。牌是镜子，决定仍在你手中。
		右上是按钮：+ 新的起卦，点击跳转到「起卦占卜」页面
		搜索框：可按求问事项或牌阵关键词过滤
		筛选器：按牌阵筛选，可选项为 全部 / 单张牌 / 三牌阵 / 五牌阵 / 月亮牌阵 / 马蹄形 / 凯尔特十字

		主体列表用卡片形式，不要用传统数据表格行
			API名称:GetTableCSV,数据源:占卜记录/默认表格,字段:[求问事项,牌阵,占卜解读]
			GetTableCSV 返回不含标题行的 csv 文本
			卡片字段必须与表单字段一致：求问事项、牌阵、占卜解读，以便点击卡片可打开表单/详情
			每张卡片显示：牌阵金色标签、求问事项全文（最多三行）、占卜解读摘要（前 80 字）
			每张卡片底部操作按钮：查看详情、编辑、删除
				查看详情：GetRecordRow 定位行号（payload 为「求问事项/该条求问事项」；若同问事项重复，结合牌阵再取），再 GetCellValue 逐字段读取，弹出详情模态。占卜解读用 Markdown 主题显示。
				编辑：当前行=该行行号，用 GetCellValue 逐字段填充编辑表单；求问事项、牌阵可改，占卜解读只读并以 Markdown 展示。保存时依次 SetCellValue 更新求问事项与牌阵，禁止用 SubmitRecord。payload 格式为「字段名/行/值」。
				删除：调用 DeleteRecord，数据源:占卜记录/默认表格，payload 为行号.toString()；删除前二次确认「此条求问与解读将消失，确定吗？」
			点击整张卡片等同于查看详情
			列表为空时展示空状态：一轮明月插画 + 「还没有求问。此刻就可以抽第一张牌。」+ 按钮「立即起卦」

		详情模态
			标题：牌面解读
			依次展示求问事项、牌阵、占卜解读（Markdown）
			底部提示：「建议可执行，选择权在你。」
			关闭按钮关闭模态

		编辑表单标题:编辑占卜记录,表:占卜记录,字段:[{字段名:求问事项,类型:文本},{字段名:牌阵,类型:单选项,可选项:单张牌,三牌阵,五牌阵,月亮牌阵,马蹄形,凯尔特十字},{字段名:占卜解读,类型:指令流}]
			占卜解读只读
			保存用 SetCellValue，取消关闭表单不改数据

	数据与桥接约定（全应用遵守）
		数据源统一为：占卜记录/默认表格
		列表与表单字段保持一致：[求问事项,牌阵,占卜解读]
		调用 GetTableCSV 获取表格数据，payload 为逗号分隔字段名：求问事项,牌阵,占卜解读
		新建使用 SubmitRecord，payload 为 json 文本；提交后当前行是 1，然后轮询占卜解读
		修改使用 SetCellValue，不要用 SubmitRecord
		删除使用 DeleteRecord，payload 必须是行号的字符串
		行号从 1 开始；GetRecordRow 的 payload 为「字段名/值」
		GetCellValue / SetCellValue 的 payload 分别为「字段名/行」「字段名/行/值」
		指令流字段占卜解读不是用户手工填写，SubmitRecord 后由后台 AI 异步生成；展示详情时必须 GetCellValue，并用 Markdown 主题渲染
		当前行初始为 0；新建成功后当前行为 1

	各页面使用统一的暗夜星空紫金主题，卡片与按钮具有悬停金光效果，点击卡片可展开详情。所有操作按钮功能必须实现。
