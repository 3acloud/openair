# 生肖黏土表情工坊
	这是一个生肖黏土表情包网页应用，像走进一间暖光黏土手作小店：用户挑选生肖、职场人设与日常场景，成套捏出可投稿微信的软萌黏土贴纸。包含首页、开捏工作台、表情橱窗三个页面。不需要用户登录页面。
	统一视觉主题：聚合物黏土工坊风。背景为奶油纸色到陶土暖橙的柔和渐变（#FFF8F1 → #F3D5C2），点缀陶泥指纹纹理与细碎金箔光斑。主色陶土橘 #C4785A，辅色蜜桃粉 #E8A598、抹茶霜 #B7C7A3、黏土棕 #8B5E3C、奶油白 #FFFDF8。卡片像刚出炉的黏土块：大圆角、轻微厚度阴影、按压凹陷的悬停效果。按钮像彩色黏土印章，点击有压泥回弹。字体为圆润柔和的无衬线。十二生肖剪影作为弱装饰水印，不遮挡内容。列表一律用卡片，不用冷冰冰的密表。
	页面顶部导航栏，黏土条造型，背景为陶土橘到蜜桃粉的横向渐变
		左侧显示Logo（一枚圆滚滚的黏土生肖章）和「生肖黏土表情工坊」
		右侧显示标签：首页、开捏工作台、表情橱窗
	首页
		主标题：生肖黏土表情工坊
		说明：用原创十二生肖角色，捏出聚合物黏土软胶质感、头身比约 1:1 的 chibi 软萌表情包，覆盖多工种职场人设与日常微场景，成套产出可投稿微信的贴纸。
		中央大按钮：开始捏一套，点击跳转到「开捏工作台」页面
		下方一排十二枚不可点击的生肖黏土章（鼠牛虎兔龙蛇马羊猴鸡狗猪），仅作氛围装饰
		接下来是并列的三个黏土统计卡：已捏套数、十六张套装、二十四张套装
			已捏套数卡片显示全部表情包套装总数
				API名称:GetRecordCount,数据源:生肖表情包/默认表格
			十六张套装卡片显示张数为「16」的套装数量
				API名称:GetTableCSV,数据源:生肖表情包/默认表格,字段:[生肖,职业,场景主题,张数]
				通过筛选张数字段为"16"的记录计算数量
			二十四张套装卡片显示张数为「24」的套装数量
				API名称:GetTableCSV,数据源:生肖表情包/默认表格,字段:[生肖,职业,场景主题,张数]
				通过筛选张数字段为"24"的记录计算数量
		接下来是「最近出炉」列表：以卡片形式显示最近 6 套表情包
			每张卡片展示：生肖（彩色黏土标签）、职业、场景主题、张数
			API名称:GetTableCSV,数据源:生肖表情包/默认表格,字段:[生肖,职业,场景主题,张数]
			按记录倒序取前 6 条
			点击任一最近卡片，进入详情：当前行设为对应行号，跳转开捏工作台并加载该行，调用GetCellValue读取表情包字段，用Markdown主题展示整套黏土表情图
	「开捏工作台」页面
		左上显示大标题：开捏工作台
		说明：像在陶桌上摆模具——点选生肖、给人设穿上职业小衣服、选定生活或职场微场景，再选择 16 或 24 张出炉。
		右上按钮组：表情橱窗（跳转到「表情橱窗」）、再捏一套（清空表单与黏土表情墙，当前行设为 0）
		页面左右分栏，像「模具盘 + 出炉墙」
		左侧为捏制表单（黏土模具盘）
			表单标题:生肖黏土表情包,表:生肖表情包,字段:[{字段名:生肖,类型:多选项,可选项:鼠,牛,虎,兔,龙,蛇,马,羊,猴,鸡,狗,猪},{字段名:职业,类型:单选项,可选项:按生肖推荐,教师,学生,工程师,护士,医生,产品,设计师,运营,销售,财务,老板,客服,外卖,科研,行政,厨师,安保,建筑,HR,法务,自由职业,通用},{字段名:场景主题,类型:单选项,可选项:日常与职场混合,日常生活,职场场景},{字段名:张数,类型:单选项,可选项:16,24}]
			生肖用十二枚可多选的圆形黏土章展示，选中时章面凹陷并亮起陶土描边
			职业、场景主题、张数用圆角黏土胶囊单选
			默认值：职业为「按生肖推荐」，场景主题为「日常与职场混合」，张数为「16」
			表单不包含表情包字段（指令流由后台异步生成，禁止用户手工填写）
			禁止编造 ID、创建日期等表定义中不存在的字段
			底部主按钮：开捏出炉
				仅当至少选中 1 个生肖，且职业、场景主题、张数均已选择时启用
				点击使用SubmitRecord提交记录，表单数据是json文本，字段仅含：生肖、职业、场景主题、张数
				提交后当前行是 1
		右侧为「黏土表情墙」
			提交后开始轮询等待后台 AI 异步生成结束
			轮询标题:生肖黏土表情包,表:生肖表情包,字段:表情包,输出到:黏土表情墙,等待消息:黏土还在烤箱里，软萌表情正在成型，请喝一口热可可再等片刻…
			API名称:GetCellValue,数据源:生肖表情包/默认表格,字段名:表情包,行号:当前行
			黏土表情墙使用Markdown主题呈现整套表情图
			生成前或当前行为 0 时，右侧展示空态：一团未塑形的浅色黏土与文案「选好模具，开捏出炉」
		黏土表情墙右上角为翻页按钮 < 和 >
			按钮标题:< ，点击读取上一行的生肖、职业、场景主题、张数、表情包，数据来源于GetCellValue
			按钮标题:> ，点击读取下一行的生肖、职业、场景主题、张数、表情包，数据来源于GetCellValue
			API名称:GetCellValue,数据源:生肖表情包/默认表格,字段名:生肖,行号:当前行
			API名称:GetCellValue,数据源:生肖表情包/默认表格,字段名:职业,行号:当前行
			API名称:GetCellValue,数据源:生肖表情包/默认表格,字段名:场景主题,行号:当前行
			API名称:GetCellValue,数据源:生肖表情包/默认表格,字段名:张数,行号:当前行
			API名称:GetCellValue,数据源:生肖表情包/默认表格,字段名:表情包,行号:当前行
			API名称:GetRecordCount,数据源:生肖表情包/默认表格
			当前行初始是 0
			当前行<=1时，<按钮不可操作
			当前行>=RecordCount时，>按钮不可操作
		工作台底部次要按钮：保存改模具
			仅当当前行>0 时启用
			用于修改当前套装的生肖、职业、场景主题、张数
			修改表单是依次通过SetCellValue设当前记录行各字段的值，而不是用SubmitRecord提交
			API名称:SetCellValue,数据源:生肖表情包/默认表格,payload:字段名/行/值
			不修改表情包字段（指令流不可手工写入）
	「表情橱窗」页面
		左上显示大标题：表情橱窗
		说明：已经出炉的黏土表情包，像店铺橱窗里一盒盒软萌贴纸。点击卡片查看整套表情，也可改模具或下架。
		右上是按钮：+ 再捏一套，点击跳转到「开捏工作台」并清空表单，当前行设为 0
		搜索框，可按照生肖或职业搜索
		筛选器：按生肖筛选、按职业筛选、按场景主题筛选、按张数筛选
		主体以卡片墙展示全部套装，不使用传统数据密表
			卡片显示字段与表单字段一致：生肖、职业、场景主题、张数
			API名称:GetTableCSV,数据源:生肖表情包/默认表格,字段:[生肖,职业,场景主题,张数]
			生肖在卡片上渲染为彩色小黏土标签；职业与场景主题用短文案；张数显示为「16 张」或「24 张」的陶泥角标
			卡片悬停微微下压，像手指按进黏土
			每张卡片有操作：查看整套、改模具、下架
				查看整套：当前行=该行行号，弹出橱窗灯箱，调用GetCellValue获取表情包字段，文本内容用Markdown主题显示整套表情图；灯箱内提供「拿到工作台」跳转开捏工作台并加载该行
				改模具：当前行=该行行号，跳转开捏工作台，API名称:GetCellValue逐字段获取生肖、职业、场景主题、张数填充表单；表情包同时加载到黏土表情墙。修改后用SetCellValue逐字段更新当前行，无需SubmitRecord
				下架：调用DeleteRecord,数据源:生肖表情包/默认表格,payload:行号.toString()；删除前二次确认「这盒黏土贴纸要下架吗？」；删除成功后刷新卡片墙与首页统计
			点击整张卡片等同查看整套
		空态：橱窗里只有未着色的模具，文案「还没有出炉的表情包，去工作台捏第一套吧」，按钮跳转开捏工作台
	交互与数据约定
		数据源统一为：生肖表情包/默认表格
		字段名只能使用表定义中的：生肖、职业、场景主题、张数、表情包，禁止自行编造 ID 或创建日期
		主体卡片墙显示的字段及对应的GetTableCSV字段必须和表单字段一致（生肖、职业、场景主题、张数），以便点击单卡进入表单编辑
		表情包是指令流类型，不是用户手工填写；SubmitRecord提交后由后台AI异步生成；要显示详情先GetCellValue，用Markdown主题显示
		指令描述未要求以JSON格式输出，因此轮询该指令流字段「表情包」
		布尔值若出现用「是」或「否」
		callAppBridge 按约定调用：GetTableCSV、SubmitRecord、GetRecordCount、GetRecordRow、DeleteRecord、GetCellValue、SetCellValue 等；DeleteRecord 的 payload 必须把行号 toString()
		行号从 1 开始；新建提交后当前行是 1；首页与橱窗点击某条时用GetRecordRow或列表顺序定位行号
		所有操作按钮功能必须实现；表格/卡片支持按记录新旧排序；当前行初始为 0
		各页面使用统一的陶土奶油主题，卡片与黏土按钮具有按压悬停，点击卡片展开或进入详情。
