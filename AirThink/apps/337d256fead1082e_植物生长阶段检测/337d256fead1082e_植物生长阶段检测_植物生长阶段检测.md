# 植物生长阶段检测
	这是一个植物生长阶段检测网页应用，通过固定摄像头或相册中的植物图像，自动识别子叶展开、真叶数量、花芽分化、开花、结果、果实成熟等物候特征，判定发芽期、幼苗期、生长期、开花期、结果期、成熟期，并给出阶段性通用养护方向。包含首页、物候检测、生长档案三个页面。不包含用户登录页面。页面统一采用「林间晨雾」植物主题：浅苔绿到奶油白的纵向渐变背景，点缀极淡的叶脉水印；主色为森绿 `#2F6B4F`，点缀芽绿 `#8FCB6A`、花瓣粉 `#E7A6B1`、暖土 `#C4A574`；卡片圆角、柔阴影，悬停时轻微上浮并出现叶脉纹理光泽；字体为柔和 sans-serif。操作按钮对应的功能必须要都实现。
	页面顶部导航栏，使用深森绿半透明背景，底部一条细芽绿高光线
		左侧显示Logo（一枚由种子发芽到展开真叶的小图标）和「植物生长阶段检测」
		右侧显示标签：首页、物候检测、生长档案
	首页
		主标题：守望一株植物的物候时钟
		说明：拍下或载入植株照片，识别关键物候特征，判定当前生长发育阶段，辅助精准养护（仅提供阶段性通用方向，不涉及具体农事操作）
		中央主按钮：开始物候检测，点击跳转到「物候检测」页面
		下方并列四个统计卡片（各卡片颜色不同：森绿、芽绿、花瓣粉、暖土）
			检测总数
				API名称:GetRecordCount,数据源:生长阶段检测/默认表格
			本档案最新一条的阶段摘要
				API名称:GetTableCSV,数据源:生长阶段检测/默认表格,字段:[植物图片,检测结果]
				取第一条记录的检测结果文本，截取前40字；无记录时显示「尚无检测」
			发芽/幼苗记录倾向
				API名称:GetTableCSV,数据源:生长阶段检测/默认表格,字段:[检测结果]
				在检测结果文本中统计含「发芽期」或「幼苗期」的条数
			开花/结果/成熟倾向
				API名称:GetTableCSV,数据源:生长阶段检测/默认表格,字段:[检测结果]
				在检测结果文本中统计含「开花期」或「结果期」或「成熟期」的条数
		物候阶段图例条：横向展示 发芽期 → 幼苗期 → 生长期 → 开花期 → 结果期 → 成熟期，仅作视觉引导，不可点击编辑
		接下来是最近检测列表，标题「最近物候记录」，以卡片形式展示最近4条
			API名称:GetTableCSV,数据源:生长阶段检测/默认表格,字段:[植物图片,检测结果]
			卡片左侧为植物图片缩略图，图片地址为 `https://www.ithinkair.com:3031/download/` + 植物图片全局文件名；右侧为检测结果摘要（前80字，无内容时显示「识别中或暂无结果」）
			点击任一最近列表卡片，进入详情：当前行设为对应行号（行号从1开始），跳转或弹出详情，调用GetCellValue展示该行完整内容
	「物候检测」页面
		左上显示大标题：物候检测，说明：拍摄或选择植株图片，识别物候特征并判定生长发育阶段
		右上是按钮：查看生长档案，点击跳转到「生长档案」页面
		中部为取景台卡片：上方大图预览当前植物图片（初始显示空状态插画「把镜头对准植株」）；图片地址规则同上
		取景台下方按钮组
			按钮：拍摄植株，调用CapturePhoto，返回图片全局文件名，赋给当前植物图片并刷新预览
			按钮：从相册选择，调用SelectImage，返回图片全局文件名，赋给当前植物图片并刷新预览
			按钮：清除预览，清空当前植物图片（不提交）
		主操作按钮：开始检测，仅当已有植物图片时启用；点击提交表单
			表单标题:生长阶段检测,表:生长阶段检测,字段:[{字段名:植物图片,类型:图片},{字段名:检测结果,类型:指令流,指令类型:任务智能体,指令描述:请使用技能d8db3811d02ade35_smyx-plant-growth-stage-detection-analysis，识别子叶展开、真叶数量、花芽分化、开花、结果、果实成熟等关键物候特征，判定当前生长发育阶段（发芽期、幼苗期、生长期、开花期、结果期、成熟期），输出阶段名称、置信度及阶段性通用养护方向。不要提供农业操作具体细节。,文件字段:植物图片,输出类型:文本}]
			植物图片字段值：当前图片全局文件名
			检测结果字段不由用户填写，SubmitRecord提交后由后台AI异步生成
			使用SubmitRecord提交，表单数据为json文本；提交后当前行是1
		提交后必须轮询等待后台AI异步生成结束（指令描述未要求以JSON格式输出，故轮询该指令流字段本身）
			轮询标题:生长阶段检测,表:生长阶段检测,字段:检测结果,输出到:物候判定结果,等待消息:正在识别子叶、真叶、花芽与果实等物候特征…
			API名称:GetCellValue,数据源:生长阶段检测/默认表格,字段名:检测结果,行号:当前行
			轮询期间「物候判定结果」区域显示等待消息与轻量叶片旋转动画；生成结束后用Markdown主题呈现完整文本
		物候判定结果区域在取景台下方：
			顶部用六段阶段胶囊高亮当前文本中出现的阶段名称（发芽期、幼苗期、生长期、开花期、结果期、成熟期），未识别到则全部为淡色
			正文以Markdown显示检测结果（阶段名称、置信度、阶段性通用养护方向）
			无结果且当前行为0时显示引导文案「选择或拍摄一张植株照片后点击开始检测」
		当前行初始是0
	「生长档案」页面
		左上显示大标题：生长档案，说明：以卡片回看每一次物候判定，点击卡片查看详情
		右上是按钮：+ 新的检测，点击跳转到「物候检测」页面并清空预览、物候判定结果，当前行设为0
		搜索框：按检测结果文本关键词搜索（如阶段名称）
		筛选器：按阶段关键词筛选（全部、发芽期、幼苗期、生长期、开花期、结果期、成熟期），在检测结果文本中匹配
		主体不用传统密表格，改用卡片网格；卡片展示字段必须与表单字段一致，便于点击单卡进入编辑/详情
			API名称:GetTableCSV,数据源:生长阶段检测/默认表格,字段:[植物图片,检测结果]
			每张卡片：封面为植物图片（`https://www.ithinkair.com:3031/download/` + 全局文件名），下方为检测结果摘要（前100字），并尝试从文本中抽出阶段名称作为彩色角标
			每张卡片操作按钮：查看详情、编辑图片后重新检测、删除
				查看详情：当前行=该行行号，弹出或侧滑详情
					API名称:GetCellValue,数据源:生长阶段检测/默认表格,字段名:植物图片,行号:当前行
					API名称:GetCellValue,数据源:生长阶段检测/默认表格,字段名:检测结果,行号:当前行
					详情中大图展示植株，检测结果用Markdown主题完整显示
				删除：调用DeleteRecord,数据源:生长阶段检测/默认表格,payload:行号.toString()（payload必须是文本），删除后刷新卡片列表与首页统计
				编辑图片后重新检测：当前行=该行行号，进入表单，允许重新CapturePhoto或SelectImage；修改使用SetCellValue逐字段更新当前行，而不是SubmitRecord
					API名称:SetCellValue,数据源:生长阶段检测/默认表格,payload:字段名/行/值
					仅允许更新植物图片；检测结果为指令流，不可手工填写。若用户更换了图片并希望重新识别，则改为新建：使用SubmitRecord提交仅含新植物图片的新记录，提交后当前行是1，并按「物候检测」页相同规则轮询检测结果
		点击卡片主体（非按钮区域）等同查看详情，当前行=行号
		表单标题:生长阶段检测,表:生长阶段检测,字段:[{字段名:植物图片,类型:图片},{字段名:检测结果,类型:指令流,指令类型:任务智能体,指令描述:请使用技能d8db3811d02ade35_smyx-plant-growth-stage-detection-analysis，识别子叶展开、真叶数量、花芽分化、开花、结果、果实成熟等关键物候特征，判定当前生长发育阶段（发芽期、幼苗期、生长期、开花期、结果期、成熟期），输出阶段名称、置信度及阶段性通用养护方向。不要提供农业操作具体细节。,文件字段:植物图片,输出类型:文本}]
			字段名只能使用表定义中的植物图片、检测结果，不得自行编造ID、创建日期等字段
			检测结果只读展示（GetCellValue + Markdown），表单中不作为手工输入项
	详情与翻看
		API名称:GetRecordCount,数据源:生长阶段检测/默认表格
		详情右上角提供按钮「<」与「>」，用于读取上一行 / 下一行的植物图片与检测结果，数据来源于GetCellValue
