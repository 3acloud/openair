# 知识星图工坊
	这是一个把主题与资料锻造成精美知识卡片与知识图谱的网页应用，包含首页、锻造图谱、图谱典藏三个页面。页面统一采用「深空星图」主题：背景为深夜靛蓝到墨紫的径向渐变，点缀极淡的星点与细金连线；标题使用优雅衬线，正文使用清晰无衬线；卡片为半透明深色玻璃质感，细琥珀金描边，悬停时微微上浮并亮起节点光晕；按钮为琥珀金填充或描边，圆角胶囊。不需要用户登录页面。操作按钮对应的功能必须要都实现。
	页面顶部导航栏，使用深靛蓝半透明背景，底部一条细金线
		左侧显示Logo（六芒星座节点图标）和「知识星图工坊」
		右侧显示标签：首页、锻造图谱、图谱典藏
	首页
		主标题：把任何主题，锻造成一张星图
		说明：检索、整合并生成精美 HTML 知识卡片与知识图谱，十七种版面，手机一屏与桌面默认两种尺寸
		中央大按钮：开始锻造图谱，点击跳转到「锻造图谱」页面
		接下来是并列的三个统计卡片
			图谱总数卡片显示全部记录数量
				API名称:GetRecordCount,数据源:知识图谱/默认表格
			手机一屏卡片显示画面尺寸为「手机一屏」的数量
				API名称:GetTableCSV,数据源:知识图谱/默认表格,字段:[画面尺寸]
				通过筛选画面尺寸字段为「手机一屏」的记录计算数量
			默认版卡片显示画面尺寸为「默认版」的数量
				API名称:GetTableCSV,数据源:知识图谱/默认表格,字段:[画面尺寸]
				通过筛选画面尺寸字段为「默认版」的记录计算数量
		接下来是版面星谱：以可横向滚动的小芯片展示十七种版面模板名称（自动推荐、经典卡片、列表清单、左右双栏、信息图、时间线、对比表、多分类网格卡片、综合知识海报、中心辐射、层级树、环形轨道、流程链、左右汇聚、网状矩阵、思维导图、混合/组合图、地铁图），点击某芯片跳转「图谱典藏」并按该版面模板筛选
			版面分布数据来源
				API名称:GetTableCSV,数据源:知识图谱/默认表格,字段:[版面模板]
				按版面模板分组统计数量，芯片右上角显示对应数量
		接下来是最近星图列表：显示最近 6 条记录，以卡片形式展示，字段包括：主题、版面模板、画面尺寸
			API名称:GetTableCSV,数据源:知识图谱/默认表格,字段:[主题,资料文件,版面模板,画面尺寸]
			按表格顺序取前 6 条（最新在前，若能取得行号则按行号升序视为最新）
			每张卡片显示主题（大标题）、版面模板徽章、画面尺寸徽章；若资料文件非空则显示「含资料」小标记
			点击最近列表卡片查看详情（打开图谱预览抽屉，加载对应行）
	「锻造图谱」页面
		左上显示大标题：锻造图谱，说明：填写主题、可选上传资料，选择版面与尺寸，提交后由知识图谱技能异步生成精美 HTML
		右上是按钮：查看典藏，跳转到「图谱典藏」页面
		中央为锻造台表单
			表单标题:知识图谱,表:知识图谱,字段:[{字段名:主题,类型:文本},{字段名:资料文件,类型:文件},{字段名:版面模板,类型:单选项,可选项:自动推荐,经典卡片,列表清单,左右双栏,信息图,时间线,对比表,多分类网格卡片,综合知识海报,中心辐射,层级树,环形轨道,流程链,左右汇聚,网状矩阵,思维导图,混合/组合图,地铁图},{字段名:画面尺寸,类型:单选项,可选项:手机一屏,默认版}]
			主题为必填多行输入，占位符：「例如：量子纠缠、唐代茶文化、强化学习从入门到直觉…」
			资料文件区域：显示已选文件名；按钮「选择资料」调用 SelectFile 返回文件全局文件名并填入资料文件；按钮「清除资料」将资料文件置空；资料文件可为空
			版面模板以可视化芯片网格选择，默认「自动推荐」；每个芯片旁用一句话微说明（如：时间线=按年代铺陈，中心辐射=核心概念向外扩散，地铁图=线路换乘式知识）
			画面尺寸以两块预览卡片选择：手机一屏（窄屏紧凑）、默认版（桌面宽幅），默认「默认版」
			不包含用户未定义的 ID 或创建日期字段，不要自行编造字段名
		主按钮：点燃星图，仅当主题非空时启用，点击提交表单
			使用 SubmitRecord 提交，表单数据是 json 文本，字段仅含：主题、资料文件、版面模板、画面尺寸
			提交后当前行是 1
		提交后进入生成舞台
			轮询标题:知识图谱,表:知识图谱,字段:图谱文件,输出到:星图画布,等待消息:星图正在连线，知识节点生长中…
			因指令描述未指定「以 JSON 格式输出」，轮询该「指令流」类型字段「图谱文件」
			轮询方式：反复调用 GetCellValue
				API名称:GetCellValue,数据源:知识图谱/默认表格,字段名:图谱文件,行号:当前行
			当返回的全局文件名非空时视为生成结束，停止轮询
			星图画布：将图谱文件作为 HTML 在 iframe 中打开
				HTML 文件链接：https://www.ithinkair.com:3031/private/全局文件名
				若画面尺寸为「手机一屏」，iframe 宽度约 390px、高度约 844px，居中置于深色手机外框中
				若画面尺寸为「默认版」，iframe 铺满画布区域，最小高度 720px
			画布右上角工具条
				按钮：新窗口打开，访问 https://www.ithinkair.com:3031/private/全局文件名
				按钮：下载，访问 https://www.ithinkair.com:3031/download/全局文件名
			生成舞台下方显示本次锻造摘要：主题、版面模板、画面尺寸、资料文件名（若有）
		新建按钮标题：再锻一张，位置：生成舞台右下，点击清空表单与星图画布并且当前行设为 0，回到锻造台
		当前行初始是 0
		页面右下角提供历史翻页（仅当 RecordCount>0 时显示）
			API名称:GetRecordCount,数据源:知识图谱/默认表格
			按钮标题：< 上一张，点击读取上一行的主题、资料文件、版面模板、画面尺寸、图谱文件
			按钮标题：下一张 >，点击读取下一行的主题、资料文件、版面模板、画面尺寸、图谱文件
			数据来源于 GetCellValue，逐字段获取
				API名称:GetCellValue,数据源:知识图谱/默认表格,字段名:主题,行号:当前行
				API名称:GetCellValue,数据源:知识图谱/默认表格,字段名:资料文件,行号:当前行
				API名称:GetCellValue,数据源:知识图谱/默认表格,字段名:版面模板,行号:当前行
				API名称:GetCellValue,数据源:知识图谱/默认表格,字段名:画面尺寸,行号:当前行
				API名称:GetCellValue,数据源:知识图谱/默认表格,字段名:图谱文件,行号:当前行
			读取到图谱文件后同样在 iframe 中打开
			当前行<=1 时，< 按钮不可操作
			当前行>=RecordCount 时，> 按钮不可操作
	「图谱典藏」页面
		左上显示大标题：图谱典藏，说明：浏览、预览与管理已锻造的知识星图
		右上是按钮：+ 锻造新星图，跳转到「锻造图谱」页面
		搜索框，可按照主题搜索（前端对 CSV 文本过滤）
		筛选器：按版面模板筛选、按画面尺寸筛选
		视图切换：卡片视图（默认）、表格视图
		主体数据
			API名称:GetTableCSV,数据源:知识图谱/默认表格,字段:[主题,资料文件,版面模板,画面尺寸]
			主体表格上显示的字段及对应的 GetTableCSV 的字段要和表单的字段一致，以便点表格单行可以编辑表单
		卡片视图：每张卡片显示主题、版面模板徽章、画面尺寸徽章、资料文件是否存在；底部操作：预览、编辑、删除
			列表用卡片形式
			点击整张卡片打开预览抽屉
		表格视图：列为主题、资料文件、版面模板、画面尺寸；每行有操作按钮：预览、编辑、删除
			点击行同样打开预览抽屉，并允许进入编辑
		预览抽屉（详情）
			标题显示该行主题
			调用 GetCellValue 获取该行各字段详情
				API名称:GetCellValue,数据源:知识图谱/默认表格,字段名:主题,行号:当前行
				API名称:GetCellValue,数据源:知识图谱/默认表格,字段名:资料文件,行号:当前行
				API名称:GetCellValue,数据源:知识图谱/默认表格,字段名:版面模板,行号:当前行
				API名称:GetCellValue,数据源:知识图谱/默认表格,字段名:画面尺寸,行号:当前行
				API名称:GetCellValue,数据源:知识图谱/默认表格,字段名:图谱文件,行号:当前行
			图谱文件为指令流生成的 HTML 文件，文本内容用其全局文件名；在 iframe 中打开 https://www.ithinkair.com:3031/private/全局文件名
			若画面尺寸为「手机一屏」使用窄屏外框，否则宽屏铺满
			若资料文件非空，显示「下载资料」链接：https://www.ithinkair.com:3031/download/资料文件全局文件名
			若图谱文件非空，显示「下载星图」链接：https://www.ithinkair.com:3031/download/图谱文件全局文件名
			抽屉内按钮：编辑、删除、关闭
		编辑
			点击编辑后，当前行=行号，用 GetCellValue 逐字段填充表单（主题、资料文件、版面模板、画面尺寸）
			表单标题:编辑知识图谱,表:知识图谱,字段与锻造台相同
			资料文件支持重新调用 SelectFile 更换，或清除
			图谱文件不由用户手工填写，编辑表单中不提供该输入框
			修改表单是依次通过 SetCellValue 设当前记录行各字段的值，而不是用 SubmitRecord 提交
				API名称:SetCellValue,数据源:知识图谱/默认表格,payload:字段名/行/值
			保存按钮依次写入：主题、资料文件、版面模板、画面尺寸
			编辑不会重新触发生成指令流；若需重新生成星图，引导用户到「锻造图谱」用相同主题再提交一份新记录
		删除
			调用 DeleteRecord，数据源:知识图谱/默认表格，payload:行号.toString()
			删除前弹出确认：「将这张星图从典藏中移除？」
			删除成功后刷新列表与统计
		空状态：当记录数为 0 时展示星空插画与按钮「锻造第一张星图」，跳转锻造图谱页面
	各页面使用统一的深空星图主题，表格和卡片具有悬停光晕，点击行或卡片可展开详情。当前行初始为 0，SubmitRecord 之后当前行为 1。所有操作按钮功能必须实现。字段名必须是表定义中出现过的：主题、资料文件、版面模板、画面尺寸、图谱文件。
