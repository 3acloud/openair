# 英语词典

这是一个用于查询英语单词、短语或中英词义的智能英语词典网页应用。应用调用“词典查询”表的任务智能体生成专业、详细的词典解析，包括音标、词性、中英文释义、词形变化、常用搭配、双语例句，并在适用时给出同义词、反义词或词语辨析。

## 整体设计

- 采用沉静、专业而富有书卷气的蓝绿色主题，背景使用浅米白到淡蓝灰的柔和渐变。
- 页面顶部使用半透明磨砂导航栏，左侧显示圆形字母书本 Logo 和应用名“Lexi 英语词典”，右侧显示“词典查询”“最近查询”两个锚点入口。
- 使用清晰的 sans-serif 字体展示界面文字，英文单词和音标可使用优雅的衬线字体。
- 卡片采用圆角、细边框和柔和阴影；按钮、历史卡片均有轻微悬停上浮效果。
- 桌面端使用左右分栏布局，移动端改为单栏，保证搜索、结果阅读和历史操作均易于使用。
- 不需要用户登录页面。
- 页面加载后自动聚焦查询输入框。

## 页面抬头

- 主标题：查一个词，真正理解它
- 说明：输入英语单词、短语、中文词义或想辨析的词语，获取结构清晰的专业解析。
- 主标题下方展示简短能力标签：音标发音、双语释义、词形变化、常用搭配、例句辨析。

## 词典查询区

- 页面上方主体是一张醒目的搜索卡片。
- 表单标题：英语词典查询
- 表：词典查询
- 字段：`[{字段名:"查询内容",类型:"文本"}]`
- “查询内容”使用大尺寸输入框，支持输入英语单词、短语、中文词义或辨析请求。
- 输入框占位文字：例如：serendipity、坚持、affect 和 effect 的区别
- 提供“清空”小按钮，点击后清空输入内容、当前结果和错误提示，并将当前行设为 0。
- 主按钮标题：查询
  - 查询内容为空或仅包含空白字符时按钮不可用，并提示“请输入要查询的内容”。
  - 点击按钮或在输入框中按 Enter 后，使用 SubmitRecord 提交新记录。
  - API 名称：SubmitRecord
  - 表：词典查询
  - 表单数据：将 `{"查询内容":"用户输入的原始内容"}` 转为 JSON 文本后传入 payload。
  - “查询结果”是指令流字段，不允许让用户手工填写，也不要在 SubmitRecord 的表单数据中伪造该字段。
  - 提交成功后当前行设为 1。
  - 提交期间禁用查询按钮，按钮显示加载状态“查询中…”并防止重复提交。

## 异步查询结果

- 搜索卡片下方是“词典解析”结果卡片。
- 提交成功后立即显示词典骨架屏和提示“正在查阅词典并整理例句…”，然后轮询指令流字段“查询结果”。
- 轮询标题：英语词典查询
- 表：词典查询
- 数据源：词典查询/默认表格
- 字段：查询结果
- 行号：当前行
- API 名称：GetCellValue
- 每次调用：
  - `callAppBridge({type:"GetCellValue", data:"词典查询/默认表格", payload:"查询结果/"+当前行})`
- 持续轮询，直到“查询结果”返回非空且不再处于后台生成中的有效内容；轮询期间保持加载状态。
- 查询完成后停止轮询，并将返回文本以 Markdown 主题完整渲染，不要以纯文本或代码块显示。
- Markdown 结果区域需要为标题、音标、词性、释义、词形变化、常用搭配、双语例句、同义词、反义词和词语辨析提供清晰的层级、间距与强调样式；仅渲染后台实际返回的章节，不虚构缺失内容。
- 结果卡片顶部显示本次“查询内容”，右侧提供：
  - “复制结果”按钮：复制完整解析文本到剪贴板，成功后短暂显示“已复制”。
  - “重新查询”按钮：以当前查询内容再次调用 SubmitRecord 创建新查询并重新轮询。
- 若请求失败或等待超时，停止加载并显示友好错误卡片，提供“重试”按钮；重试时仍使用当前查询内容重新提交。
- 发起新的查询时必须清除上一条结果，避免新旧内容混淆。

## 最近查询

- 页面下方设置“最近查询”区域，标题旁显示记录总数。
- 记录总数：
  - API 名称：GetRecordCount
  - 数据源：词典查询/默认表格
- 查询历史：
  - API 名称：GetTableCSV
  - 数据源：词典查询/默认表格
  - 字段：`[查询内容,查询结果]`
  - 调用：`callAppBridge({type:"GetTableCSV", data:"词典查询/默认表格", payload:"查询内容,查询结果"})`
- GetTableCSV 返回的是不包含标题行的 CSV 文本，必须使用可靠的 CSV 解析方式处理引号、逗号和换行，不能直接用换行或逗号粗暴拆分。
- 主体列表和 GetTableCSV 必须使用同样的字段“查询内容、查询结果”。
- 历史记录使用卡片列表展示，默认按表中返回顺序显示最近记录，并限制首屏展示最近 8 条；提供“展开更多/收起”。
- 每张卡片显示：
  - 查询内容；
  - 查询结果的纯文本摘要，移除 Markdown 标记后截取适合长度，尚未生成时显示“结果生成中”；
  - “查看详情”和“删除”按钮。
- 提供历史搜索框，可按“查询内容”在已加载记录中即时筛选；无匹配项时显示空状态。
- 点击历史卡片或“查看详情”：
  - 将该记录对应的实际行号设为当前行。
  - 调用 GetCellValue 获取完整字段详情：
    - `callAppBridge({type:"GetCellValue", data:"词典查询/默认表格", payload:"查询内容/"+当前行})`
    - `callAppBridge({type:"GetCellValue", data:"词典查询/默认表格", payload:"查询结果/"+当前行})`
  - 将查询内容填回输入框，并把查询结果滚动显示在“词典解析”结果卡片中。
  - “查询结果”仍以 Markdown 主题渲染；如果内容尚未生成，则继续轮询该行。
- 点击“删除”：
  - 先弹出确认对话框，明确显示将删除的查询内容。
  - 用户确认后调用 DeleteRecord。
  - API 名称：DeleteRecord
  - 数据源：词典查询/默认表格
  - payload：目标行号调用 `toString()` 后传入。
  - 删除成功后重新调用 GetRecordCount 和 GetTableCSV 刷新总数与列表；如果删除的是当前正在查看的记录，则清空结果并将当前行设为 0。
- 因删除记录会改变后续行号，每次删除后必须重新获取列表并重建行号映射，不得继续使用旧行号。
- 每次新查询完成后也要重新获取记录总数和历史数据，使最近查询立即出现。

## 初始状态与交互要求

- 当前行初始为 0。
- 页面首次加载时调用 GetRecordCount 和 GetTableCSV 加载历史记录，但不自动打开某条结果。
- 没有查询结果时，结果卡片显示轻量空状态：书本图标、文字“输入一个词，开始探索它的含义”。
- 没有历史记录时，显示“还没有查询记录，试着查一个新词吧”。
- 所有按钮功能必须真实实现，不允许只做视觉占位。
- 表单提交必须使用 SubmitRecord；历史记录详情必须使用 GetCellValue；删除必须使用 DeleteRecord。
- 不提供编辑历史记录功能；如需改变查询内容，应发起一次新的查询记录。
- 只使用表定义中存在的“查询内容”和“查询结果”字段，不得自行添加 ID、创建日期、收藏状态、发音文件等字段。
- 做好 CSV 解析、Markdown 安全渲染、空值、重复点击、轮询停止、超时、接口错误和响应式布局处理。
点查询按钮查询一个词语，先从历史查询查找，没有的话再提交查询。
