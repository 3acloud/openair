# 思维导图学习法
	这是一个面向中小学生的思维导图学习网页应用，把一章课文、一个单元或课堂笔记梳理成中心突出、层级清晰的思维导图，方便背诵复习和考前快速回顾。包含三个页面：首页、绘制导图、我的导图。不需要用户登录页面。
	页面统一采用「知识萌芽」主题：米白到淡青绿的柔和竖向渐变背景，点缀极浅的放射状节点纹理；主色为翠绿 `#2F9E7A` 与青蓝 `#3A8FBF`，点缀暖琥珀 `#E8A838` 与珊瑚橙；卡片如浅色便签纸，大圆角、轻阴影，悬停时微微上浮并出现一圈枝叶光晕；标题使用圆润友好的 sans-serif，正文舒适易读；操作按钮为圆角胶囊形，主按钮翠绿填充，次按钮描边。全站动效轻快但不花哨，适合中小学生长时间复习。
	页面顶部固定导航栏，使用深绿到青绿的横向渐变
		左侧显示Logo（一个中心圆点向四周伸出五条彩色细枝的思维节点图标）和「思维导图学习法」
		右侧显示标签：首页、绘制导图、我的导图
		当前页标签高亮为暖琥珀下划线
	首页
		主标题：把课文变成一棵会发光的知识树
		说明：选学科、贴笔记、上传资料，一键生成中心突出、层级清晰、关键词为主的思维导图，考前翻一翻就能回忆整章。
		中央大按钮：开始绘制导图，点击跳转到「绘制导图」页面
		接下来是并列的四个统计小卡片，颜色各异（翠绿、青蓝、琥珀、珊瑚），带数字滚动动画
			知识树总数：显示全部导图记录数
				API名称:GetRecordCount,数据源:学习导图/默认表格
			语数英导图数：语文+数学+英语的记录数
				API名称:GetTableCSV,数据源:学习导图/默认表格,字段:[学科]
				筛选学科为「语文」或「数学」或「英语」后计数
			理科导图数：物理+化学+生物的记录数
				API名称:GetTableCSV,数据源:学习导图/默认表格,字段:[学科]
				筛选学科为「物理」或「化学」或「生物」后计数
			小学 / 初中分布：小学一条、初中（初一+初二+初三）一条，用迷你双色进度条对比
				API名称:GetTableCSV,数据源:学习导图/默认表格,字段:[学段]
		接下来是「最近生长的知识树」最近列表，以卡片形式展示最近 6 条
			API名称:GetTableCSV,数据源:学习导图/默认表格,字段:[内容范围,学科,学段,学习内容,资料文件,导图结果]
			按表格原有顺序取最后 6 条（最新在前，可倒序渲染）
			每张卡片左上角学科色标徽章（语文朱红、数学青蓝、英语琥珀、物理靛紫、化学草绿、生物翠绿、其他灰色），右上角学段小标签
			卡片主标题显示「内容范围」，副文显示「学习内容」前 40 字（超出省略）
			底部一行：学科 · 学段；若资料文件非空，显示一个小小的回形针图标
			点击任意最近卡片进入详情：当前行设为该卡片对应行号（行号从 1 开始，等于 GetTableCSV 中的行序号），跳转到「绘制导图」页并加载该行详情
		首页底部一行温馨提示：「关键词越短越好记，中心主题只写一个。」
	「绘制导图」页面
		左上显示大标题：绘制导图
		说明：填写范围和笔记，可选上传课本扫描件或课堂照片，提交后稍等片刻，知识树会自己长出来。
		右上按钮组
			按钮：我的导图库，跳转到「我的导图」页面
			按钮：再画一张，点击清空表单与导图画布，当前行设为 0，资料文件清空
		页面主体左右分栏（窄屏上下堆叠）
		左侧为「播种区」表单
			表单标题:学习导图,表:学习导图,字段:[{字段名:内容范围,类型:文本},{字段名:学科,类型:单选项,可选项:语文,数学,英语,物理,化学,生物,其他},{字段名:学段,类型:单选项,可选项:小学,初一,初二,初三},{字段名:学习内容,类型:文本},{字段名:资料文件,类型:文件},{字段名:导图结果,类型:指令流}]
			字段名必须使用表定义中的字段，不要自行编造 ID 或创建日期字段
			内容范围：单行输入，占位符如「四年级下册·第三单元 自然的奥秘」
			学科：单选按钮组或下拉，选项必须是 语文、数学、英语、物理、化学、生物、其他
			学段：单选按钮组，选项必须是 小学、初一、初二、初三
			学习内容：多行文本域，占位符如「把这一课的重点、公式、人物、时间线或老师板书贴进来……」
			资料文件：不是手工填文件名
				按钮：选择资料，调用 SelectFile 返回文件全局文件名，填入资料文件字段
				若已有文件，显示文件名；提供「打开资料」与「下载资料」
					打开资料访问 https://www.ithomeair.com:3031/private/全局文件名 （以实际全局文件名为准，链接主机为 https://www.ithinkair.com:3031/private/全局文件名）
					下载资料访问 https://www.ithinkair.com:3031/download/全局文件名
				按钮：清除资料，将资料文件置空
			导图结果不在表单里让用户填写，提交后由后台异步生成
			主按钮：生成思维导图（仅当「内容范围」或「学习内容」至少一项非空时启用）
				当前行是 0 或新建时：使用 SubmitRecord 提交
					API名称:SubmitRecord,数据源:学习导图,payload:表单数据的json文本
					json 仅包含表定义字段：内容范围、学科、学段、学习内容、资料文件（资料文件填全局文件名，无文件则空字符串）
					不要提交导图结果字段
					提交后当前行是 1
				当前行大于 0 且为修改已有记录时：不要用 SubmitRecord，依次 SetCellValue 更新当前行的 内容范围、学科、学段、学习内容、资料文件
					API名称:SetCellValue,数据源:学习导图/默认表格,payload:字段名/行/值
					布尔值若出现用「是」或「否」（本表无布尔字段）
			提交新建后必须轮询等待后台 AI 异步生成结束
				因指令描述未指定「以JSON格式输出」的字段，故轮询该指令流字段本身
				轮询标题:学习导图,表:学习导图,字段:导图结果,输出到:导图画布,等待消息:正在抽丝剥茧，让知识树发芽……
				轮询时调用 GetCellValue
					API名称:GetCellValue,数据源:学习导图/默认表格,payload:导图结果/当前行
				每隔约 2 秒轮询一次，直到返回的文本非空且不再是生成中状态
		右侧为「知识树画布」
			顶部标题：导图画布
			右上角一对小按钮 < 和 >
				API名称:GetRecordCount,数据源:学习导图/默认表格
				API名称:GetCellValue,数据源:学习导图/默认表格,payload:字段名/当前行
				按钮 < ：当前行减 1，并读取该行 内容范围、学科、学段、学习内容、资料文件、导图结果 填回表单与画布
				按钮 > ：当前行加 1，同样逐字段 GetCellValue 填回
				当前行初始是 0
				当前行<=1 时 < 不可操作
				当前行>=RecordCount 时 > 不可操作
				当前行是 0 时画布显示空状态插画（一颗还没发芽的小树）和文案「填好左侧信息，让知识树长出来」
			导图画布内容
				先 GetCellValue 取导图结果，文本内容用 Markdown 主题显示（支持标题、列表、加粗、代码块、引用）
				画布容器为浅米色便签风，左侧一条翠绿书签线
				若导图结果为空且正在轮询，显示等待消息与缓慢生长的树苗动画，不要空白干等
				画布下方次按钮：复制导图文本（复制当前 Markdown 纯文本）、全屏阅读（模态全屏展示同一份 Markdown）
			查看字段详情一律用 GetCellValue，不要用别的接口替代
		绘制页底部提示：「中心只放一个主题，分支写关键词，句子越短越好背。」
	「我的导图」页面
		左上显示大标题：我的导图
		说明：所有已经长成的知识树都在这里，点开就能复习。
		右上是按钮：+ 绘制新导图，跳转到「绘制导图」页面并清空（当前行设为 0）
		搜索框：可按内容范围或学习内容的关键词搜索（前端对 GetTableCSV 结果过滤）
		筛选器：
			按学科筛选（全部 / 语文 / 数学 / 英语 / 物理 / 化学 / 生物 / 其他）
			按学段筛选（全部 / 小学 / 初一 / 初二 / 初三）
		主体不要用传统密集表格当主视图，列表用卡片网格（每行 2～3 张，窄屏 1 张）
			API名称:GetTableCSV,数据源:学习导图/默认表格,字段:[内容范围,学科,学段,学习内容,资料文件,导图结果]
			主体卡片上展示的字段必须与表单字段一致，便于点击单卡进入编辑：内容范围、学科、学段、学习内容、资料文件、导图结果
			卡片视觉：
				顶部学科色标 + 学段徽章
				标题：内容范围
				摘要：学习内容前 60 字
				若资料文件非空，显示回形针和「有资料」
				导图结果取前 80 字纯文本作预览（去掉 Markdown 标记），没有结果时显示「尚未生成」
			每张卡片底部操作按钮必须全部实现：
				查看详情：当前行=该卡行号，弹出大模态
					模态内用 GetCellValue 逐字段取详情
					导图结果用 Markdown 主题渲染
					资料文件提供打开（https://www.ithinkair.com:3031/private/全局文件名）与下载（https://www.ithinkair.com:3031/download/全局文件名）
				编辑：当前行=该卡行号，跳转「绘制导图」页
					用 GetCellValue 逐字段填充表单（资料文件显示已有全局文件名，可重新 SelectFile）
					保存时用 SetCellValue 按字段更新当前行，不用 SubmitRecord
					导图结果只读展示，不在编辑时手工改写
				删除：二次确认后调用 DeleteRecord
					API名称:DeleteRecord,数据源:学习导图/默认表格,payload:行号.toString()
					payload 必须是文本，行号先 toString()
					删除成功后刷新卡片列表和首页统计
			点击卡片非按钮区域同样进入查看详情
			空状态：插画小树苗 +「还没有知识树，去绘制第一张吧」按钮跳转绘制页
		需要行号时
			API名称:GetRecordRow,数据源:学习导图/默认表格,payload:字段名/值
			行号从 1 开始
		GetTableCSV 返回的是不含标题行的 csv 文本；文件字段的文本是文件的全局文件名；若将来遇到图片字段，图片字段文本也是全局文件名
	数据与交互总规则
		数据源统一为：学习导图/默认表格（SubmitRecord 的 data 为表名「学习导图」）
		callAppBridge 按说明调用：GetTableCSV、SubmitRecord、GetRecordCount、GetRecordRow、DeleteRecord、GetCellBullet、GetCellValue、SetCellValue、SelectFile 等
		指令流字段不是用户手工填写的，SubmitRecord 之后由后台 AI 异步生成；展示时先 GetCellValue，再用 Markdown 主题显示
		本表指令描述未要求「以JSON格式输出」，因此轮询字段就是「导图结果」
		全局文件名图片链接为 https://www.ithinkair.com:3031/download/全局文件名（本应用以资料文件为主）
		要下载导出文件访问 https://www.ithinkair.com:3031/download/全局文件名
		要在浏览器打开文件访问 https://www.ithinkair.com:3031/private/全局文件名
		不要出现用户登录页；不要编造表定义里没有的字段（没有 ID、没有创建日期就不要造）
		操作按钮对应的功能必须全部实现；卡片、筛选、搜索、轮询、前后翻页、< > 禁用逻辑、空状态、复制、全屏、打开/下载资料都要能用
		各页面视觉统一为「知识萌芽」青绿主题，卡片和按钮均有悬停反馈，点击卡片可展开或进入详情。
