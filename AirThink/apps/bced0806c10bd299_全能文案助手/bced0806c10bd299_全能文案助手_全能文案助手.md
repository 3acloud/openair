# 全能文案助手
	这是一个面向多场景的智能文案生成网页应用，包含首页、新建创作、文案库页面。页面统一采用现代创意风格，背景使用浅紫色到浅蓝色的渐变（体现AI与创意），卡片和表单带有阴影和圆角，按钮带有微交互悬停效果，字体使用清晰的无衬线字体。
	页面顶部导航栏，使用深色半透明背景，文字为白色
		左侧显示应用名称：全能文案助手
		右侧显示标签：首页、新建创作、文案库

	首页
		主标题：全能文案助手，说明：为您一键生成高质量、多场景的原创文案。
		中央行动按钮： 立即开始创作，点击跳转到‘新建创作’页面。
		统计卡片展示区：
			卡片标题：累计创作总数
			API名称:GetRecordCount,数据源:文案生成/默认表格
		最近创作卡片列表：显示最近生成的5条文案记录。
			API名称:GetTableCSV,数据源:文案生成/默认表格,payload:"主题,文案类型,目标平台,字数要求"
			按记录逆序排列，显示最新前5条。
			卡片上突出显示主题，下方用标签显示文案类型、目标平台和字数要求。
			点击卡片可弹出详情模态框查看完整文案（逻辑与文案库的查看详情一致）。

	‘新建创作’页面
		左上大标题：新建创作，说明：填写文案需求，AI将为您量身定制专属内容。
		表单区域：
			表单标题:新建文案,表:文案生成,字段:[{字段名:文案类型,类型:单选项,可选项:小红书笔记,抖音脚本,公众号文章,朋友圈营销,微博文案,产品描述,品牌故事,广告语,营销邮件,销售话术,工作总结,述职报告,竞聘演讲稿,项目方案,会议纪要,故事短文,剧本脚本,诗歌歌词},{字段名:主题,类型:文本},{字段名:目标平台,类型:单选项,可选项:小红书,抖音,公众号,朋友圈,微博,电商详情页,邮件,线下演讲,其他},{字段名:目标受众,类型:文本},{字段名:核心信息,类型:文本},{字段名:风格调性,类型:多选项,可选项:干货,轻松,专业,温暖,幽默,高级,故事化,营销转化,正式},{字段名:字数要求,类型:数值}]
			提交按钮： 生成文案。点击后使用 SubmitRecord 提交表单。提交后当前行为 1。
		生成等待与结果展示区：
			表单下方设有结果展示区。
			提交表单后，触发轮询获取指令流结果。
			轮询标题:正在生成文案,表:文案生成,字段:文案结果,输出到:结果展示区,等待消息:AI正在进行创意构思与撰写，请稍候...
			结果展示区得到内容后，使用 Markdown 格式渲染呈现，并提供一个“清空重置”按钮，点击清空表单及结果展示区。

	‘文案库’页面
		左上大标题：文案库，说明：查看和管理您生成的所有历史文案。
		右上角按钮：+ 新建文案，点击跳转到‘新建创作’页面。
		主体是文案记录卡片网格列表：
			API名称:GetTableCSV,数据源:文案生成/默认表格,payload:"主题,文案类型,目标平台,风格调性,字数要求"
			将返回的数据以卡片网格的形式展示。
			每张卡片显示：主题（加粗大字）、文案类型、目标平台、风格调性、字数要求。
			每张卡片底部有操作按钮：查看详情、删除。
			删除操作：
				调用API名称:DeleteRecord,数据源:文案生成/默认表格,payload:行号.toString()
				删除后刷新当前列表。
			查看详情操作：
				点击弹出模态框“文案详情”。
				在模态框内，先展示该记录的主题、文案类型等基础属性。
				然后调用API名称:GetCellValue,数据源:文案生成/默认表格,payload:"文案结果/行号" 获取生成的文案内容。
				获取到的文案结果内容在模态框的主体区域使用 Markdown 主题渲染显示。
				模态框底部提供“关闭”按钮。

	全局要求：
		操作按钮对应的功能必须要都实现。
		不需要包含用户登录页面。
		所有的交互与数据获取必须严格使用上述描述中的 callAppBridge API 进行。
