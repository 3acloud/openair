# 英文句子主干提取器
	这是一个英文句子主干提取网页应用，用于录入英文句子，自动分析句子结构并提取主谓宾、主系表或主谓等核心主干。应用包含首页、句子分析、任务记录、复核中心四个页面。
	整体主题采用清爽学术风格：主色为深青色，辅助色为靛蓝和琥珀色，背景为浅灰白，表格紧凑清晰，结果区使用 Markdown 排版呈现语法分析内容。页面顶部固定导航栏。
	页面顶部导航栏
		左侧显示 Logo（句法树或文本分析图标）和“英文句子主干提取器”
		右侧显示标签：首页、句子分析、任务记录、复核中心

	首页
		主标题：英文句子主干提取器
		说明：输入英文句子，快速识别主语、谓语、宾语或表语，辅助英语阅读、语法学习和文本分析
		主按钮：开始分析，点击跳转到“句子分析”页面
		接下来显示四个统计卡片：
			总任务数
				API名称:GetRecordCount,数据源:句子提取任务/默认表格
			已复核数量
				API名称:GetTableCSV,数据源:句子提取任务/默认表格,字段:[是否已复核]
				通过筛选是否已复核为“是”的记录计算数量
			复杂句数量
				API名称:GetTableCSV,数据源:句子提取任务/默认表格,字段:[难度等级]
				通过筛选难度等级为“复杂”的记录计算数量
			今日新增
				API名称:GetTableCSV,数据源:句子提取任务/默认表格,字段:[创建时间]
				通过筛选创建时间为今天的记录计算数量
		接下来是最近分析列表：显示最近5条句子提取任务，字段包括：任务标题、英文句子、提取目标、难度等级、是否已复核
			API名称:GetTableCSV,数据源:句子提取任务/默认表格,字段:[任务标题,英文句子,句子来源,提取目标,难度等级,创建时间,是否已复核,复核备注]
			按创建时间降序排列，显示前5条
			英文句子超过120个字符时截断显示
			点击某条记录跳转到“任务记录”页面并打开该记录详情

	“句子分析”页面
		左上显示大标题：句子分析
		说明：录入英文句子并选择提取目标，系统将自动生成主干分析结果
		右上是按钮：查看任务记录，点击跳转到“任务记录”页面
		页面主体为左右两栏布局：
			左侧是录入表单
			右侧是分析结果预览区
		表单标题:新建句子提取任务,表:句子提取任务,字段:[{字段名:任务标题,类型:文本},{字段名:英文句子,类型:文本},{字段名:句子来源,类型:文本},{字段名:提取目标,类型:多选项,可选项:主谓宾,主系表,主谓},{字段名:难度等级,类型:单选项,可选项:基础,中等,复杂},{字段名:创建时间,类型:日期时间},{字段名:是否已复核,类型:布尔},{字段名:复核备注,类型:文本}]
			创建时间字段在表单中隐藏，提交时自动填入当前日期时间
			是否已复核字段在表单中隐藏，提交时默认填“否”
			复核备注字段在新建表单中隐藏，提交时默认空文本
			任务标题为空时，自动取英文句子的前30个字符作为任务标题
		操作按钮：
			按钮：分析句子
				点击后使用SubmitRecord提交表单数据到表“句子提取任务”
				提交数据必须包含字段：任务标题、英文句子、句子来源、提取目标、难度等级、创建时间、是否已复核、复核备注
				布尔字段是否已复核用“否”表示
				提交后当前行设为1
				因为“主干提取结果”是指令流字段，SubmitRecord提交后需要轮询等待后台AI异步生成结束
				轮询标题:句子分析,表:句子提取任务,字段:主干提取结果,输出到:分析结果,等待消息:正在分析句子结构...
				轮询时调用GetCellValue获取主干提取结果字段内容
				分析结果区域使用 Markdown 主题显示内容
			按钮：清空
				点击清空表单、分析结果和当前行，当前行设为0
		右侧分析结果预览区
			初始显示空状态：“等待输入英文句子”
			提交后显示“正在分析句子结构...”
			轮询完成后显示“主干提取结果”的 Markdown 内容
			结果区顶部显示当前任务标题、难度等级和提取目标标签
		页面底部显示一个紧凑的最近3条分析记录：
			API名称:GetTableCSV,数据源:句子提取任务/默认表格,字段:[任务标题,英文句子,句子来源,提取目标,难度等级,创建时间,是否已复核,复核备注]
			按创建时间降序显示前3条
			点击记录可读取该行详情并显示到右侧结果区
			读取详情时调用GetCellValue获取字段：任务标题、英文句子、句子来源、提取目标、难度等级、主干提取结果、创建时间、是否已复核、复核备注

	“任务记录”页面
		左上显示大标题：任务记录
		说明：浏览、筛选、编辑和删除所有句子主干提取任务
		右上是按钮：+ 新建分析，点击跳转到“句子分析”页面并清空表单
		顶部工具栏：
			搜索框：可按照任务标题、英文句子、句子来源搜索
			筛选器：按提取目标筛选，可选：全部、主谓宾、主系表、主谓
			筛选器：按难度等级筛选，可选：全部、基础、中等、复杂
			筛选器：按复核状态筛选，可选：全部、已复核、未复核
		主体是任务表格，显示字段：任务标题、英文句子、句子来源、提取目标、难度等级、创建时间、是否已复核、复核备注
			API名称:GetTableCSV,数据源:句子提取任务/默认表格,字段:[任务标题,英文句子,句子来源,提取目标,难度等级,创建时间,是否已复核,复核备注]
			主体表格显示的字段必须和表单字段一致，不显示“主干提取结果”指令流字段
			表格支持按创建时间降序排序，支持按任务标题排序
			英文句子超过100个字符时截断显示，鼠标悬停显示完整句子
			每行有操作按钮：查看详情、编辑、删除、标记复核
		查看详情
			点击后弹出详情抽屉
			通过GetRecordRow获取当前记录行号，匹配字段优先使用“任务标题/值”
			调用GetCellValue逐字段读取：任务标题、英文句子、句子来源、提取目标、难度等级、主干提取结果、创建时间、是否已复核、复核备注
			详情抽屉上方显示基础信息，下方使用 Markdown 显示“主干提取结果”
		编辑
			点击后打开编辑表单，当前行设为该记录行号
			表单标题:编辑句子提取任务,表:句子提取任务,字段:[{字段名:任务标题,类型:文本},{字段名:英文句子,类型:文本},{字段名:句子来源,类型:文本},{字段名:提取目标,类型:多选项,可选项:主谓宾,主系表,主谓},{字段名:难度等级,类型:单选项,可选项:基础,中等,复杂},{字段名:创建时间,类型:日期时间},{字段名:是否已复核,类型:布尔},{字段名:复核备注,类型:文本}]
			创建时间字段在表单上包含但隐藏
			提交修改时不用SubmitRecord，依次调用SetCellValue设置当前记录行的各字段值
			API名称:SetCellValue,数据源:句子提取任务/默认表格,payload:字段名/行/值
			编辑英文句子、提取目标或难度等级后，提示用户“保存后将更新基础信息，若需要重新生成主干结果请新建一条分析任务”
		删除
			点击后弹出确认框
			确认后调用DeleteRecord
			API名称:DeleteRecord,数据源:句子提取任务/默认表格,payload:行号.toString()
			删除后刷新表格、统计和筛选结果
		标记复核
			点击后将是否已复核切换为“是”
			API名称:SetCellValue,数据源:句子提取任务/默认表格,payload:是否已复核/行/是
			如果当前记录已经是“是”，按钮显示为“取消复核”，点击后设置为“否”

	“复核中心”页面
		左上显示大标题：复核中心
		说明：集中复核AI生成的句子主干提取结果，补充教师或学习备注
		顶部显示三个统计卡片：
			未复核任务数
				API名称:GetTableCSV,数据源:句子提取任务/默认表格,字段:[是否已复核]
				通过筛选是否已复核为“否”的记录计算数量
			已复核任务数
				API名称:GetTableCSV,数据源:句子提取任务/默认表格,字段:[是否已复核]
				通过筛选是否已复核为“是”的记录计算数量
			复杂待复核数
				API名称:GetTableCSV,数据源:句子提取任务/默认表格,字段:[难度等级,是否已复核]
				通过筛选难度等级为“复杂”且是否已复核为“否”的记录计算数量
		主体为左右两栏：
			左侧是待复核列表
			右侧是复核详情和备注编辑区
		待复核列表
			API名称:GetTableCSV,数据源:句子提取任务/默认表格,字段:[任务标题,英文句子,句子来源,提取目标,难度等级,创建时间,是否已复核,复核备注]
			默认只显示是否已复核为“否”的任务
			支持切换查看：未复核、已复核、全部
			点击列表项后，通过GetRecordRow获取行号，再通过GetCellValue读取完整详情
		复核详情区
			显示字段：任务标题、英文句子、句子来源、提取目标、难度等级、创建时间、是否已复核
			“主干提取结果”通过GetCellValue获取，并用 Markdown 呈现
			复核备注为可编辑文本框
		操作按钮：
			按钮：保存备注
				调用SetCellValue设置复核备注字段
				API名称:SetCellValue,数据源:句子提取任务/默认表格,payload:复核备注/当前行/备注内容
			按钮：标记为已复核
				调用SetCellValue设置是否已复核为“是”
				API名称:SetCellValue,数据源:句子提取任务/默认表格,payload:是否已复核/当前行/是
			按钮：取消复核
				调用SetCellValue设置是否已复核为“否”
				API名称:SetCellValue,数据源:句子提取任务/默认表格,payload:是否已复核/当前行/否
			按钮：删除记录
				调用DeleteRecord删除当前行
				API名称:DeleteRecord,数据源:句子提取任务/默认表格,payload:当前行.toString()

	数据与交互规则
		所有数据源名称使用“句子提取任务/默认表格”
		表名使用“句子提取任务”
		字段名只能使用表定义中已有字段：任务标题、英文句子、句子来源、提取目标、难度等级、主干提取结果、创建时间、是否已复核、复核备注
		主体表格显示的字段及GetTableCSV字段必须和表单字段一致，不包含“主干提取结果”指令流字段
		指令流字段“主干提取结果”不是用户手工填写字段，不能出现在新建表单或编辑表单中
		显示“主干提取结果”时，必须先调用GetCellValue获取内容，再使用 Markdown 主题显示
		新建记录使用SubmitRecord提交
		修改记录使用SetCellValue逐字段更新，不使用SubmitRecord
		删除记录使用DeleteRecord，payload必须是行号.toString()
		布尔字段“是否已复核”用“是”或“否”表示
		当前行初始值为0
		SubmitRecord提交后当前行设为1
		调用GetTableCSV获取表格数据时，payload必须是逗号分隔字段名
		所有操作按钮对应功能必须完整实现
		表格刷新、统计刷新、筛选刷新要在新增、修改、删除、复核状态变化后同步执行
