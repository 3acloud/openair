# 拍照识万物
	这是一个拍照识万物网页应用，包含首页、开始识别、万物图鉴三个页面。页面统一采用「博物镜头」主题：午夜靛蓝到墨青的深色渐变背景，点缀琥珀金与青绿高光；卡片为半透明米白玻璃质感，圆角柔和，悬停时轻微上浮并出现细镜头光圈描边；主按钮为琥珀金渐变，次按钮为青绿描边；字体为现代无衬线，标题略带宋体韵味。整体像一本可拍照的智能博物图鉴，不包含用户登录页面。
	页面顶部导航栏，使用深靛蓝半透明背景，底部一条细琥珀金线
		左侧显示Logo（相机光圈与展开的图鉴书页图标）和「拍照识万物」
		右侧显示标签：首页、开始识别、万物图鉴
	首页
		主标题：拍照识万物
		说明：对准镜头，万物可识。上传或拍摄一张图片，即可识别物品、动植物及场景，分析实际状态与需求，给出相关知识、选购建议和配件兼容提醒。
		中央主按钮：开始识别，点击跳转到「开始识别」页面
		主按钮下方并排两个次按钮：拍照识物（跳转「开始识别」并自动唤起拍摄）、从图鉴回看（跳转「万物图鉴」）
		接下来是并列的两个统计卡片
			累计识别卡片：显示全部识别记录数量
				API名称:GetRecordCount,数据源:拍照识别/默认表格
			图鉴条目卡片：与累计识别相同数据源，用卡片强调「已收录万物」的图鉴感
				API名称:GetRecordCount,数据源:拍照识别/默认表格
		接下来是「最近识别」卡片列表：显示最近 4 条记录，列表使用卡片形式
			API名称:GetTableCSV,数据源:拍照识别/默认表格,字段:[图片,识别需求,识别结果]
			按记录倒序取前 4 条
			每张卡片左侧显示图片缩略图（图片链接为 https://www.ithinkair.com:3031/download/全局文件名），右侧显示识别需求（为空时显示「默认识别主体与场景」），底部显示识别结果摘要（取纯文本前 60 字，没有结果时显示「识别生成中或暂无结果」）
			点击最近列表项进入详情：当前行设为对应行号，用 GetCellValue 读取该行「图片」「识别需求」「识别结果」，弹出详情层
				API名称:GetCellValue,数据源:拍照识别/默认表格,字段名:图片,行号:当前行
				API名称:GetCellValue,数据源:拍照识别/默认表格,字段名:识别需求,行号:当前行
				API名称:GetCellValue,数据源:拍照识别/默认表格,字段名:识别结果,行号:当前行
				详情层大图展示原图，识别需求以标签展示，识别结果用 Markdown 主题完整渲染
				详情层按钮：再识一次（跳转「开始识别」并带入该图片文件名）、编辑、删除
	「开始识别」页面
		左上显示大标题：开始识别
		说明：拍摄或上传图片，可选填写你想知道的问题；留空则自动识别主体并分析场景。
		右上是按钮：打开图鉴，跳转到「万物图鉴」页面
		中部为取景框风格的图片区：深色圆角画框，四角有相机对焦标记；有图时展示预览（https://www.ithinkair.com:3031/download/全局文件名），无图时显示「对准万物，轻触取景」占位
		图片区下方按钮组（必须全部实现）
			按钮：拍摄照片，调用 CapturePhoto 返回图片全局文件名，写入当前图片
			按钮：相册选择，调用 SelectImage 返回图片全局文件名，写入当前图片
			按钮：清除图片，清空当前图片预览（不提交）
		识别需求输入框：多行文本，占位符为「例如：这是什么型号？配件能通用吗？这株植物好养活吗？也可以留空」
		主按钮：开始识别，仅当已有图片时启用；点击提交表单
			表单标题:拍照识别,表:拍照识别,字段:[{字段名:图片,类型:文本},{字段名:识别需求,类型:文本},{字段名:识别结果,类型:指令流}]
			图片字段值：当前图片全局文件名
			识别需求字段值：输入框文本，可为空
			识别结果为指令流，不由用户填写，不在提交表单中手工录入
			使用 SubmitRecord 提交，表单数据是包含「图片」「识别需求」的 json 文本
			提交后当前行是 1
		提交后进入识别等待：取景框叠加扫描光带，等待文案为「正在观察画面中的万物…」
			因指令描述未指定「以JSON格式输出」，轮询该指令流字段「识别结果」
			轮询标题:拍照识别,表:拍照识别,字段:识别结果,输出到:识别详情,等待消息:正在观察画面中的万物…
			API名称:GetCellValue,数据源:拍照识别/默认表格,字段名:识别结果,行号:当前行
			生成结束后，识别详情用 Markdown 主题完整显示， ident 结果区标题为「图鉴结论」
		识别详情上方保留本次图片与识别需求，右上提供按钮
			按钮：再拍一张，清空图片、识别需求和识别详情，当前行设为 0，停留本页
			按钮：收入图鉴，跳转到「万物图鉴」并刷新列表
		当前行初始是 0
	「万物图鉴」页面
		左上显示大标题：万物图鉴
		说明：回看每一次识别，核对结论、补充需求或重新编辑。
		右上是按钮：+ 新的识别，跳转到「开始识别」页面
		搜索框：按识别需求关键词过滤卡片
		筛选器：全部 / 已填写需求 / 未填写需求（识别需求为空）
		主体为卡片网格，不用单独只读页；卡片形式展示，字段与表单一致
			API名称:GetTableCSV,数据源:拍照识别/默认表格,字段:[图片,识别需求,识别结果]
			每张卡片显示：图片缩略（https://www.ithinkair.com:3031/download/全局文件名）、识别需求（空则显示「默认识别」）、识别结果摘要（前 80 字）
			每张卡片操作按钮：查看详情、编辑、删除，功能必须全部实现
			点击卡片或查看详情：当前行=行号，逐字段 GetCellValue 填充详情
				API名称:GetCellValue,数据源:拍照识别/默认表格,字段名:图片,行号:当前行
				API名称:GetCellValue,数据源:拍照识别/默认表格,字段名:识别需求,行号:当前行
				API名称:GetCellValue,数据源:拍照识别/默认表格,字段名:识别结果,行号:当前行
				详情中识别结果用 Markdown 主题显示
			删除：调用 DeleteRecord，数据源:拍照识别/默认表格，payload 为行号.toString()，删除后刷新卡片列表
			API名称:GetRecordCount,数据源:拍照识别/默认表格
		编辑使用表单，而不是 SubmitRecord
			表单标题:编辑识别,表:拍照识别,字段:[{字段名:图片,类型:文本},{字段名:识别需求,类型:文本},{字段名:识别结果,类型:指令流}]
			打开编辑时当前行=行号，用 GetCellValue 逐字段回填
			图片可重新拍摄或选择：CapturePhoto 或 SelectImage，预览使用下载链接
			识别结果在编辑表单中只读展示（Markdown），不提供手工编辑
			保存时依次 SetCellValue 更新当前行的「图片」「识别需求」，不要用 SubmitRecord
				API名称:SetCellValue,数据源:拍照识别/默认表格,payload:图片/当前行/新图片全局文件名
				API名称:SetCellValue,数据源:拍照识别/默认表格,payload:识别需求/当前行/新需求文本
			主体列表展示字段必须与表单字段一致，以便点击单行/单卡即可进入编辑
	详情层与结果展示规范
		图片一律按全局文件名拼接 https://www.ithinkair.com:3031/download/全局文件名
		指令流「识别结果」必须先 GetCellValue 再以 Markdown 呈现，不把原始指令当作用户输入
		无法识别或生成中的状态要明确提示，不编造名称、规格或兼容结论
	各页面使用统一的博物镜头主题，卡片与按钮具有悬停光圈效果；首页最近列表、图鉴列表均用卡片；所有操作按钮功能必须实现。
弹出的窗口显示的内容滚动底部要有较大的空白间隔。
