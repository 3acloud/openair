# HTML幻灯片生成器
	这是一个自动生成响应式HTML幻灯片并内嵌中文语音音频的网页应用，包含首页、幻灯片生成器、生成历史页面。页面统一采用现代科技感、商务简约的蓝色主题风格，背景为淡灰偏蓝，卡片和按钮有轻量阴影及悬停过渡效果。
	页面顶部导航栏，使用深蓝色背景，白色文字。
		左侧显示Logo和‘HTML幻灯片生成器’
		右侧显示标签导航：首页、幻灯片生成器、生成历史
	首页
		主标题：智能HTML幻灯片生成器，说明：根据主题与内容一键生成响应式HTML幻灯片，内嵌AI中文语音音频，自动播放与翻页，让演示更生动高效。
		中央大按钮：立即开始生成，点击跳转到‘幻灯片生成器’页面
		统计指标卡片：
			累计生成数量：显示已生成的幻灯片总数
				API名称:GetRecordCount,数据源:幻灯片生成/默认表格
		最近生成记录：显示最近生成的幻灯片列表，包含字段：主题、展示风格、受众、页数，以网格卡片形式显示。
			API名称:GetTableCSV,数据源:幻灯片生成/默认表格,字段:[主题,展示风格,受众,页数]
			点击卡片可以跳转到‘生成历史’页面对应查看。
	‘幻灯片生成器’页面
		左上显示标题：创建新幻灯片，说明：填写各项参数，AI将为您自动生成精美的带语音播报的单文件HTML幻灯片
		表单区域（以卡片包裹，左右分栏或居中对齐）：
			表单标题:幻灯片生成,表:幻灯片生成,字段:[{字段名:主题,类型:文本},{字段名:受众,类型:文本},{字段名:页数,类型:数值},{字段名:展示风格,类型:单选项,可选项:商务简洁,教学课件,科技感,图文展示,故事叙述},{字段名:音色,类型:单选项,可选项:xiaoxiao,xiaoyi,xiaomeng,yunxi,yunyang,yunjian,tw-male,tw-female,hk-male,hk-female},{字段名:语速,类型:单选项,可选项:-20%,-10%,+10%,+20%,+30%},{字段名:素材文件,类型:文件}]
			素材文件字段：提供按钮“选择素材文件”，点击调用SelectFile返回文件全局文件名并填入字段内。
			按钮：开始生成，点击后通过SubmitRecord提交表单。提交后当前行设为1。
		生成等待与预览区域：
			提交表单后，显示加载动画提示“AI正在为您生成带语音的幻灯片，请耐心等待...”
			后台轮询等待：轮询标题:幻灯片生成,表:幻灯片生成,字段:HTML文件,输出到:幻灯片成品。
			等待结束后，调用API获取生成的HTML文件名：API名称:GetCellValue,数据源:幻灯片生成/默认表格,payload:HTML文件/1。
			由于HTML文件不能直接下载，使用宽大的iframe展示生成的幻灯片，iframe的src设为"https://www.ithinkair.com:3031/private/全局文件名"。
			提供“继续创建”按钮，点击清空表单和iframe并重置当前行。
	‘生成历史’页面
		左上显示大标题：生成历史，说明：管理和回放过往生成的HTML幻灯片
		主体表格：以表格显示所有历史记录
			API名称:GetTableCSV,数据源:幻灯片生成/默认表格,字段:[主题,受众,页数,展示风格,音色,语速]
			每行右侧提供操作按钮：播放预览、删除
			点击“播放预览”按钮：
				获取该行生成的HTML文件：API名称:GetCellValue,数据源:幻灯片生成/默认表格,payload:HTML文件/行号
				弹出一个全屏或大尺寸的模态对话框，内部包含iframe，src设为"https://www.ithinkair.com:3031/private/全局文件名"以便直接在iframe里打开幻灯片观看。
			点击“删除”按钮：
				调用DeleteRecord,数据源:幻灯片生成/默认表格,payload:行号.toString()
				删除成功后重新刷新当前表格数据。
	全局交互与规范要求：
		各个页面的API调用、表单提交和轮询逻辑必须严格按照说明实现。
		不要包含任何用户登录及无关的页面，操作按钮对应的功能必须要都实现。
