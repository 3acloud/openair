# 一句话成书
	这是一个「一句话成书」网页应用：输入一句话即可自动生成书名、大纲、章节正文、封面与朗读音频，按分类管理书架，并支持沉浸式在线阅读与听书。包含首页、创作工坊、我的书架、分类管理四个主导航页面，以及从书架/首页进入的书籍详情与在线阅读页。不需要用户登录页面。
	根据开发需求设计统一的「墨香书房」主题：背景为暖羊皮纸色径向渐变（#f7f1e3 → #efe4d0），导航栏为墨蓝近黑（#1b1a2e）加细金线分隔，主色墨金（#c6a35a），点缀胭脂红（#8b2942）与松烟墨（#2c2a32）。标题使用衬线字体，正文使用柔和 sans-serif。卡片模拟精装书质感（轻微倾斜阴影、封面比例、纸纹边），按钮与卡片具有悬停浮起与金边高光。列表一律优先卡片形式。操作按钮对应的功能必须全部实现。

	页面顶部导航栏
		左侧显示打开的书本 Logo 与应用名「一句话成书」，副标「一念落墨，万卷自成」
		右侧显示标签：首页、创作工坊、我的书架、分类管理
		当前页标签使用墨金下划线高亮

	首页
		全宽英雄区：主标题「一句话成书」，说明「写下你的一句话灵感，AI 策划编辑与畅销书作家将为你起名、搭大纲、写正文、绘封面、录朗读，一气呵成。」
		主按钮：开始创作，点击跳转到「创作工坊」页面
		次按钮：走进书架，点击跳转到「我的书架」页面
		接下来是并列的四个统计卡片（各卡片颜色不同，悬停浮起）：
			藏书总数
				API名称:GetRecordCount,数据源:书籍/默认表格
			创作中
				API名称:GetTableCSV,数据源:书籍/默认表格,字段:[完结状态]
				筛选完结状态为「创作中」的记录计算数量
			已完结
				API名称:GetTableCSV,数据源:书籍/默认表格,字段:[完结状态]
				筛选完结状态为「已完结」的记录计算数量
			分类数
				API名称:GetRecordCount,数据源:书籍分类/默认表格
		接下来是「最近落墨」最近书籍卡片列表：显示最近 6 本，以封面卡片形式展示（封面、书名、一句话摘要前 36 字、写作风格、完结状态）
			API名称:GetTableCSV,数据源:书籍/默认表格,字段:[书籍编号,一句话,分类名称,写作风格,目标篇幅,完结状态,创建时间,书名]
			按创建时间降序，取前 6 条；创建时间仅用于排序，卡片上不显示书籍编号与创建时间
			封面来源：
				API名称:GetTableCSV,数据源:书籍封面/默认表格,字段:[书籍编号,封面图片]
				用书籍编号匹配；封面图片为全局文件名，图片地址为 https://www.ithinkair.com:3031/download/全局文件名
				若无封面则显示羊皮纸占位与书名首字印章
			点击任一最近卡片进入该书籍的「书籍详情 / 在线阅读」页（按书籍编号定位）
		底部一句文案：「书架尚空时，显示空状态插画与按钮：用一句话写下第一本书，跳转创作工坊。」

	创作工坊页面
		左上大标题：创作工坊，说明：用一句话点燃一部作品。提交后将依次生成书名、大纲与封面，再拆章撰写与朗读。
		右上按钮：返回书架，跳转「我的书架」
		页面采用竖向五步进度条（可回看已完成步骤，未完成步骤不可跳过）：① 一句话设定 ② 生成书名 ③ 生成大纲 ④ 生成封面 ⑤ 拆章成书
		步骤① 一句话设定
			表单标题:一句话成书,表:书籍,字段:[{字段名:书籍编号,类型:文本},{字段名:一句话,类型:文本},{字段名:分类名称,类型:关联表,关联表名:书籍分类,关联字段名:分类名称},{字段名:写作风格,类型:单选项,可选项:现实文学,科幻未来,玄幻奇幻,武侠仙侠,悬疑推理,历史传记,都市言情,儿童童话,科普百科,心理励志,其他},{字段名:目标篇幅,类型:单选项,可选项:短篇,中篇,长篇},{字段名:完结状态,类型:单选项,可选项:创作中,已完结},{字段名:创建时间,类型:日期时间},{字段名:书名,类型:指令流}]
				书籍编号自动取随机数，在表单上隐藏
				创建时间取当前日期时间，在表单上隐藏
				完结状态默认「创作中」，在表单上隐藏
				书名为指令流，不由用户填写，表单上不显示输入框
				一句话使用多行大输入框，占位符：「例如：一座永不靠岸的列车上，售票员发现每位乘客都在重复自己的某一天。」
				分类名称的可选值来源:
					API名称:GetTableCSV,数据源:书籍分类/默认表格,字段:[分类名称,分类简介,排序号]
					按排序号升序；下拉显示分类名称，副文案显示分类简介
					若分类表为空，提示先去「分类管理」创建分类，并提供跳转按钮
				写作风格、目标篇幅以下拉或标签选择器展示，必须使用表定义中的可选项
			主按钮标题：落笔成书，点击校验一句话、分类名称、写作风格、目标篇幅均已填写后，使用SubmitRecord提交书籍表单，提交后当前行是1
			提交后进入步骤②，开始轮询书名
		步骤② 生成书名
			轮询标题:生成书名,表:书籍,字段:书名,输出到:书名展示区,等待消息:策划编辑正在为这部作品起名…
				API名称:GetCellValue,数据源:书籍/默认表格,payload:书名/当前行
				书名为指令流文本，使用Markdown主题、衬线大标题展示；只展示书名本身
			书名生成完成后自动进入步骤③
		步骤③ 生成大纲
			书名展示完成后，立即再提交大纲：
			表单标题:书籍大纲,表:书籍大纲,字段:[{字段名:书籍编号,类型:关联表,关联表名:书籍,关联字段名:书籍编号},{字段名:大纲内容,类型:指令流}]
				书籍编号使用刚创建的书籍编号
				大纲内容为指令流，不由用户填写
				使用SubmitRecord提交，提交后当前行是1
			轮询标题:生成大纲,表:书籍大纲,字段:大纲内容,输出到:大纲展示区,等待消息:结构编辑正在搭建全书骨架…
				API名称:GetCellValue,数据源:书籍大纲/默认表格,payload:大纲内容/当前行
				大纲内容使用Markdown主题呈现（作品定位、核心主题、主要人物、故事主线、章节目录）
			大纲生成完成后自动进入步骤④
		步骤④ 生成封面
			表单标题:书籍封面,表:书籍封面,字段:[{字段名:书籍编号,类型:关联表,关联表名:书籍,关联字段名:书籍编号},{字段名:封面图片,类型:指令流}]
				书籍编号使用刚创建的书籍编号
				封面图片为指令流，不由用户填写
				使用SubmitRecord提交，提交后当前行是1
			轮询标题:生成封面,表:书籍封面,字段:封面图片,输出到:封面展示区,等待消息:封面设计师正在绘制书籍封面…
				API名称:GetCellValue,数据源:书籍封面/默认表格,payload:封面图片/当前行
				封面图片单元格文本是全局文件名，图片地址 https://www.ithinkair.com:3031/download/全局文件名 ，以精装书封面比例展示
			封面生成完成后进入步骤⑤，并展示「创作完成预览」：左封面右书名/一句话/风格/篇幅/分类/大纲摘要
			按钮：进入这部书，跳转该书籍的「书籍详情 / 在线阅读」页
			按钮：再写一本，清空工坊表单，当前行设为0，回到步骤①
		步骤⑤ 拆章成书（在预览区下方）
			说明：请根据大纲中的章节目录，为每一章建立章节记录，再生成正文与朗读。
			按钮：+ 添加章节，弹出章节表单
			表单标题:添加章节,表:章节,字段:[{字段名:章节编号,类型:文本},{字段名:书籍编号,类型:关联表,关联表名:书籍,关联字段名:书籍编号},{字段名:章节序号,类型:数值},{字段名:章节标题,类型:文本},{字段名:本章要点,类型:文本},{字段名:章节正文,类型:指令流}]
				章节编号自动取随机数，在表单上隐藏
				书籍编号使用当前书籍编号，在表单上隐藏
				章节正文为指令流，不由用户填写
				章节序号默认取「当前书已有章节数+1」
					API名称:GetTableCSV,数据源:章节/默认表格,字段:[章节编号,书籍编号,章节序号,章节标题,本章要点]
					筛选书籍编号=当前书籍，计算最大章节序号
			使用SubmitRecord提交章节后当前行是1，随即轮询章节正文
			轮询标题:撰写正文,表:章节,字段:章节正文,输出到:章节正文预览,等待消息:作家正在撰写本章正文…
				API名称:GetCellValue,数据源:章节/默认表格,payload:章节正文/当前行
				章节正文使用Markdown主题呈现
			正文生成完成后，自动提交朗读：
			表单标题:章节朗读,表:章节朗读,字段:[{字段名:章节编号,类型:关联表,关联表名:章节,关联字段名:章节编号},{字段名:朗读音频,类型:指令流}]
				章节编号为刚创建章节的章节编号
				朗读音频为指令流，不由用户填写
				使用SubmitRecord提交，提交后当前行是1
			轮询标题:生成朗读,表:章节朗读,字段:朗读音频,输出到:朗读播放器,等待消息:朗读者正在录制有声书…
				API名称:GetCellValue,数据源:章节朗读/默认表格,payload:朗读音频/当前行
				朗读音频单元格文本是全局文件名，音频地址 https://www.ithinkair.com:3031/download/全局文件名 ，使用 HTML audio 控件播放
			该步骤同时列出当前书已创建的章节卡片（序号、标题、要点、是否已有正文、是否已有音频）
				API名称:GetTableCSV,数据源:章节/默认表格,字段:[章节编号,书籍编号,章节序号,章节标题,本章要点]
				筛选当前书籍编号，按章节序号升序
				正文与音频有无分别用 GetCellValue 判断

	我的书架页面
		左上大标题：我的书架，说明：按分类浏览、检索与管理全部作品
		右上按钮：+ 一句话成书，跳转「创作工坊」
		搜索框：可按书名或一句话关键词搜索
		筛选器：按分类名称筛选、按写作风格筛选、按目标篇幅筛选、按完结状态筛选
		分类快速标签栏：全部 + 全部分类名称（按排序号升序）
			API名称:GetTableCSV,数据源:书籍分类/默认表格,字段:[分类名称,分类简介,排序号]
		主体是书籍封面卡片墙（不要用普通数据表格做主展示），每张卡片显示：封面、书名、一句话前 40 字、分类名称、写作风格、目标篇幅、完结状态徽章
			API名称:GetTableCSV,数据源:书籍/默认表格,字段:[书籍编号,一句话,分类名称,写作风格,目标篇幅,完结状态,书名]
			主体展示字段与编辑表单可见字段一致（书籍编号、创建时间不在卡片上显示）
			封面匹配：
				API名称:GetTableCSV,数据源:书籍封面/默认表格,字段:[书籍编号,封面图片]
			分类名称若为关联值，必要时再取分类表：
				API名称:GetTableCSV,数据源:书籍分类/默认表格,字段:[分类名称,分类简介,排序号]
			完结状态用不同颜色徽章：创作中为墨金，已完结为松柏绿
			卡片底部操作按钮：阅读、编辑、删除、详情
				阅读：进入「书籍详情 / 在线阅读」
				详情：弹出详情层，展示书名、一句话、分类、风格、篇幅、状态、大纲（Markdown）、封面大图
					大纲：
						API名称:GetTableCSV,数据源:书籍大纲/默认表格,字段:[书籍编号,大纲内容]
						匹配书籍编号后，API名称:GetCellValue 取大纲内容，Markdown 呈现
					封面用 GetCellValue 取封面图片全局文件名
				编辑：打开编辑书籍表单，当前行=该行行号
					API名称:GetRecordRow,数据源:书籍/默认表格,payload:书籍编号/该书籍编号
					API名称:GetCellValue 逐字段取值填充
					表单标题:编辑书籍,表:书籍,字段与创作工坊书籍表单相同
						书籍编号、创建时间包含但隐藏
						书名只读展示（指令流，不让用户手工改输入框）
						一句话、分类名称、写作风格、目标篇幅、完结状态可改
						修改使用SetCellValue逐字段更新当前行，不得使用SubmitRecord
						布尔值若出现用「是」或「否」
				删除：确认后
					先删关联的章节朗读、章节、书籍封面、书籍大纲，再删书籍
					查找行号：API名称:GetRecordRow,数据源:对应表/默认表格,payload:书籍编号或章节编号/值
					API名称:DeleteRecord,数据源:对应表/默认表格,payload:行号.toString()
					删除章节朗读时先按章节编号匹配
			点击整张卡片（非按钮区）进入「书籍详情 / 在线阅读」
		编辑书籍表单的分类名称可选值来源同创作工坊（GetTableCSV 书籍分类）

	书籍详情 / 在线阅读页（由首页最近列表、书架卡片、阅读按钮进入，不单独作为主导航；无书籍时不可进入）
		顶部返回「我的书架」
		左侧书脊信息列（宽约 320px）：封面大图、书名、一句话、分类名称、写作风格、目标篇幅、完结状态
			数据：
				API名称:GetTableCSV,数据源:书籍/默认表格,字段:[书籍编号,一句话,分类名称,写作风格,目标篇幅,完结状态,书名]
				API名称:GetTableCSV,数据源:书籍封面/默认表格,字段:[书籍编号,封面图片]
				封面图片 https://www.ithinkair.com:3031/download/全局文件名
			操作按钮：继续创作章节、标记完结/重新开写、编辑资料、删除作品
				继续创作章节：弹出与创作工坊相同的「添加章节」表单（书籍编号锁定为当前书），SubmitRecord 后轮询章节正文，再自动提交并轮询章节朗读，逻辑与创作工坊步骤⑤完全一致
				标记完结：当前完结状态为创作中时显示，SetCellValue 将完结状态设为「已完结」
				重新开写：当前为已完结时显示，SetCellValue 设为「创作中」
				编辑资料、删除作品：同书架页
		左侧下方「目录」：章节列表卡片，按章节序号升序
			API名称:GetTableCSV,数据源:章节/默认表格,字段:[章节编号,书籍编号,章节序号,章节标题,本章要点]
			筛选当前书籍编号
			每章显示序号、标题、要点摘要；若有朗读显示小喇叭
			每章操作：阅读本章、生成/重读正文、生成朗读、编辑、删除
				阅读本章：右侧阅读区加载该章
				生成/重读正文：若章节正文为空则视为首次生成（该章若已存在记录，用轮询 GetCellValue；若未生成则保持等待）。若需重新触发生成，不可伪造字段名；仅对已有记录轮询指令流结果并展示。编辑本章要点/标题用 SetCellValue 更新（章节编号隐藏不可改）
				生成朗读：若该章节在朗读表无记录，则 SubmitRecord 到章节朗读并轮询朗读音频；若已有记录则 GetCellValue 取音频并播放
					API名称:GetTableCSV,数据源:章节朗读/默认表格,字段:[章节编号,朗读音频]
				编辑：打开章节表单，当前行=该章行号，GetCellValue 填充；章节编号隐藏；章节正文只读 Markdown 展示；修改标题、序号、要点用 SetCellValue，不用 SubmitRecord
				删除：确认后先删对应章节朗读再删章节
					API名称:GetRecordRow 定位行号
					API名称:DeleteRecord,payload:行号.toString()
		右侧为沉浸阅读区（羊皮纸背景、衬线正文、舒适行宽）
			阅读区顶部显示书名 · 第N章 · 章节标题
			正文：
				API名称:GetCellValue,数据源:章节/默认表格,payload:章节正文/该章行号
				指令流文本用 Markdown 主题渲染；未生成时显示「正文正在赶来，或请点击生成正文」
			阅读区右上角音频条：有朗读则显示播放器
				音频 https://www.ithinkair.com:3031/download/全局文件名
			阅读区底部：上一章、下一章（按章节序号，越界按钮不可操作）

	全局数据与交互规则
		当前行初始为 0；SubmitRecord 成功后当前行是 1；从列表进入编辑或阅读时，当前行设为对应行号。
		创建日期/时间字段及自动编号的 ID 类字段（书籍编号、章节编号、创建时间）在主体列表/卡片上不显示，在表单上要包含但要隐藏；ID 类字段值取随机数。
		字段名必须是表定义中出现过的字段，不得编造。
		主体列表用于点选编辑时，GetTableCSV 取出的业务字段与表单字段对齐；ID 与创建时间仅供隐藏定位与关联，不在卡片展示。
		关联表字段必须再 GetTableCSV 取关联表数据（分类名称、书籍编号、章节编号）。
		查看指令流详情一律 GetCellValue；文本/大纲/正文用 Markdown 主题显示；图片用下载域名；音频用下载域名在 audio 中播放。
		指令流字段禁止用户手工填写。SubmitRecord 后必须轮询等待后台异步生成结束：书名轮询书名，大纲轮询大纲内容，封面轮询封面图片，章节轮询章节正文，朗读轮询朗读音频。
		修改已有记录只能逐字段 SetCellValue，不能用 SubmitRecord。
		删除时 payload 必须把行号 toString()。
		GetTableCSV 返回不含标题行的 CSV；图片/文件字段文本即全局文件名。
		全局文件图片与音频链接：https://www.ithinkair.com:3031/download/全局文件名
		首页最近列表与书架卡片点击后必须进入详情/阅读，不得空跳。
		所有页面统一墨香书房主题，卡片与按钮均需悬停效果；空数据、加载中、生成中、失败重试都要有明确文案。操作按钮（开始创作、落笔成书、添加章节、生成朗读、阅读、编辑、删除、标记完结、添加分类、上一章/下一章、再写一本等）功能必须全部实现。
