# VoiceDrop语音归档
	这是一个名为 VoiceDrop 的语音记录与 AI 归档网页应用，包含首页、开口即记、语音笔记、待办事项四个页面。不包含用户登录页。整体采用米白色背景、橙红色强调色和黑色文字，设计简洁克制、留白充足，像一张可交互的宣传长页，同时真正能开口录音、自动转写、提取要点并分类归档。
	统一视觉主题
		页面背景色：#F7F3ED（米白）
		主强调色：#E85A3C（橙红）
		主文字色：#1A1A1A
		次要文字色：#6B6560
		卡片背景：#FFFbf7，圆角 20px，极浅暖灰描边，悬停时轻微上浮并带橙红阴影
		主按钮：橙红实心、白字、大圆角；次按钮：米白底+橙红描边
		字体：简洁 sans-serif，标题字重偏大，口号感强
		列表一律使用卡片，不要用拥挤的电子表格风格作为主展示
	页面顶部导航栏，使用半透明米白底+底部细暖灰线，滚动时保持顶部固定
		左侧显示圆形橙红 Logo（声波/话筒剪影）和「VoiceDrop」
		右侧显示标签：首页、开口即记、语音笔记、待办事项；当前页标签用橙红下划线
		最右侧一个橙红小按钮「立即体验」，点击跳转到「开口即记」页面
	首页
		整页按宣传长截图的节奏纵向排布，像产品官网，但数据真实来自表格。
		第一屏主视觉
			主标题：「开口说，它自己归档。」
			副文案：「把灵感、待办、会议和生活碎片，变成可检索、可执行的语音笔记。」
			右侧或下方展示手机端录音界面示意图：圆形大录音按钮、波形、计时、「松手即归档」提示
			主按钮：「打开，说一句」→ 跳转「开口即记」
			次按钮：「添加到主屏幕」→ 弹出轻提示：可把 VoiceDrop 固定到主屏幕，开口即记
		「三秒钟的事」流程，三列卡片
			01 打开并说话
			02 系统进行整理（转写、润色、提要点）
			03 内容保存归档（可检索、可执行）
		数据概览，四个并列小卡片
			语音笔记总数
				API名称:GetRecordCount,数据源:语音笔记/默认表格
			待整理
				API名称:GetTableCSV,数据源:语音笔记/默认表格,字段:[归档状态]
				筛选归档状态为「待整理」的记录计算数量
			已归档
				API名称:GetTableCSV,数据源:语音笔记/默认表格,字段:[归档状态]
				筛选归档状态为「已归档」的记录计算数量
			待办事项
				API名称:GetRecordCount,数据源:待办事项/默认表格
		能力说明横幅
			标题：「碎片要管，属于你」
			说明：自动命名、标记重点、提取待办，把零散语音变成条理清晰的记录
			四个示例胶囊：灵感 / 待办 / 会议内容 / 生活记录，点击跳转「开口即记」并预填对应记录类型
		最近语音，卡片列表
			标题：「最近开口」
			显示最近 5 条，按记录时间理解的顺序取前 5（若无时间则按表格顺序）
			API名称:GetTableCSV,数据源:语音笔记/默认表格,字段:[笔记标题,录音文件,记录类型,标签,是否重点,归档状态]
			每张卡片显示：笔记标题、记录类型橙红标签、标签组、是否重点星标、归档状态、迷你播放按钮
			点击整张卡片进入该条详情（当前行=对应行号，用 GetCellValue 逐字段填充，整理结果用 Markdown 呈现）
			若没有记录，显示空状态：「还没有声音。打开，说一句，剩下的它来办。」按钮跳转「开口即记」
		常见问题 FAQ 手风琴
			如何开始？打开「开口即记」，按住说话或选择已有录音。
			AI 会做什么？生成标题、转写润色、提取要点和待办、给出标签建议。
			录音存在哪？每条语音笔记都会归档，可随时检索、标记重点、转为待办。
			能否只说话不取名？可以，标题可留空，提交后由 AI 整理。
		底部行动号召区，深暖橙红或深黑底
			文案：「打开，说一句，剩下的它来办」
			按钮：「立即体验」跳转「开口即记」
	「开口即记」页面
		左上大标题：「开口即记」
		说明：「三秒钟的事——打开并说话，系统进行整理，内容保存归档。」
		右上按钮：「查看归档」跳转「语音笔记」
		中央录音台，模拟手机录音界面
			大圆形橙红录音按钮，周围有呼吸光圈和简易波形
			状态文案随状态切换：待开始 / 录音中 / 已暂停 / 已完成
			按钮与桥接
				开始录音：callAppBridge({type:"StartRecordVoice"})
				暂停：callAppBridge({type:"PauseRecordVoice"})
				继续：callAppBridge({type:"ContinueRecordVoice"})
				取消：callAppBridge({type:"CancelRecordVoice"})，清空当前录音文件并复位界面
				完成：callAppBridge({type:"FinishRecordVoice"})，返回语音 mp3 的全局文件名，写入表单「录音文件」
			另提供「选择已有录音」：callAppBridge({type:"SelectFile"})，返回文件全局文件名，写入「录音文件」
			已有录音时显示播放条，音频地址使用 "https://www.ithinkair.com:3031/private/全局文件名"
		录音完成后展开归档表单（无录音时「开始归档」按钮禁用）
			表单标题:语音笔记,表:语音笔记,字段:[{字段名:笔记标题,类型:文本},{字段名:录音文件,类型:文件},{字段名:记录类型,类型:单选项,可选项:灵感,待办,会议,生活记录,其他},{字段名:标签,类型:多选项,可选项:工作,学习,生活,灵感闪现,重要,紧急,会议纪要,随手记},{字段名:是否重点,类型:布尔},{字段名:记录时间,类型:日期时间},{字段名:归档状态,类型:单选项,可选项:待整理,已归档,已完成},{字段名:整理结果,类型:指令流}]
			记录时间自动取当前日期时间，在表单上包含但隐藏
			归档状态默认「待整理」
			是否重点用「是」或「否」
			笔记标题可留空，占位符：「可留空，让 AI 为你命名」
			记录类型可被首页示例胶囊预填
			录音文件为完成录音或 SelectFile 得到的全局文件名，表单上显示文件名与播放器，不让用户手打路径
			「整理结果」不是用户手工填写
		主按钮标题：开始归档，点击提交表单
			仅当录音文件非空时启用
			使用 SubmitRecord 提交，表单数据是 json 文本
			API名称:SubmitRecord,数据源:语音笔记,payload:表单json
			提交后当前行是 1
		提交后进入整理等待
			在录音台下方展示等待卡片，文案：「AI 正在转写、提取要点并分类归档…」带橙红细进度动画
			轮询标题:语音笔记,表:语音笔记,字段:整理结果,输出到:整理结果面板,等待消息:正在把这句口语音变成可检索的记录…
			因为指令描述未要求 JSON，轮询「整理结果」该指令流字段
			API名称:GetCellValue,数据源:语音笔记/默认表格,payload:整理结果/当前行
			生成结束后，整理结果面板用 Markdown 主题显示，按【标题】【转写正文】【要点清单】【待办事项】【标签建议】结构呈现
			同时提供操作：确认归档（SetCellValue 将归档状态改为「已归档」）、标为重点、去添加待办、再记一条（清空录音与表单，当前行设为 0）
		当前行初始是 0
	「语音笔记」页面
		左上大标题：「语音笔记」
		说明：「零散语音，已变成可检索、可执行的记录。」
		右上按钮：+ 开口即记，跳转「开口即记」
		搜索框：按笔记标题、记录类型、标签模糊搜索
		筛选器：记录类型、归档状态、是否重点、标签
		主体用卡片网格而不是密集表格，但卡片数据字段必须与表单字段一致，便于点卡片进入编辑
			API名称:GetTableCSV,数据源:语音笔记/默认表格,字段:[笔记标题,录音文件,记录类型,标签,是否重点,归档状态]
			记录时间不在主体卡片上作为主字段展示
			每张卡片显示：标题（空则显示「未命名语音」）、记录类型、标签胶囊、重点星标、归档状态、短音频播放
			录音播放使用 "https://www.ithinkair.com:3031/private/全局文件名"；下载使用 "https://www.ithinkair.com:3031/download/全局文件名"
			每张卡片操作：查看详情、编辑、删除、转为待办
				查看详情：当前行=行号，调用 GetCellValue 逐字段取详情；整理结果必须 GetCellValue 后用 Markdown 显示；弹层或侧栏展示完整转写、要点、待办建议、音频
					API名称:GetCellValue,数据源:语音笔记/默认表格,payload:字段名/行
				编辑：当前行=行号，GetCellValue 填充表单；修改后依次 SetCellValue 更新当前行各字段，不用 SubmitRecord
					API名称:SetCellValue,数据源:语音笔记/默认表格,payload:字段名/行/值
					布尔仍用「是」或「否」
					录音文件可重新 StartRecordVoice/FinishRecordVoice 或 SelectFile 后 SetCellValue
					不要把指令流当成用户输入框；若用户只改分类/标题/状态，保留已有整理结果
				删除：callAppBridge({type:"DeleteRecord", data:"语音笔记/默认表格", payload:行号.toString()})
				转为待办：跳转「待办事项」并打开新建表单，关联笔记标题预填为当前笔记标题
		点卡片即视为选中该行，可编辑表单。表单与卡片字段对齐。
			表单标题:语音笔记,表:语音笔记,字段:[{字段名:笔记标题,类型:文本},{字段名:录音文件,类型:文件},{字段名:记录类型,类型:单选项,可选项:灵感,待办,会议,生活记录,其他},{字段名:标签,类型:多选项,可选项:工作,学习,生活,灵感闪现,重要,紧急,会议纪要,随手记},{字段名:是否重点,类型:布尔},{字段名:记录时间,类型:日期时间},{字段名:归档状态,类型:单选项,可选项:待整理,已归档,已完成},{字段名:整理结果,类型:指令流}]
			记录时间在表单包含但隐藏
			无自动编号 ID 字段，不要编造 ID
			若在本页误用 SubmitRecord 新建，提交后当前行为 1，并按同样规则轮询整理结果

		搜索框：按任务标题、任务说明、关联笔记标题搜索

			笔记标题是关联表，需再取语音笔记相关字段

			笔记标题可选值来源:

	详情呈现规则
		查看字段详情一律 GetCellValue
		指令流「整理结果」用 Markdown 主题显示，不要当普通单行文本
		文件字段展示文件名、播放、在浏览器打开、下载
			打开：https://www.ithinkair.com:3031/private/全局文件名
			下载：https://www.ithinkair.com:3031/download/全局文件名
		首页最近列表点击后查看详情，不必另做只读表的独立页面
	通用交互与约束
		操作按钮对应的功能必须都实现：录音开始/暂停/继续/取消/完成、选择文件、提交归档、轮询整理结果、播放、编辑、删除、筛选搜索、标记重点、切换归档状态、待办勾选、关联跳转、立即体验、添加到主屏幕提示
		字段名只能使用表定义中出现的字段名，不要编造 ID
		创建时间/记录时间类字段主体列表不作为主列，表单里要有但隐藏；没有自动编号 ID 就不要造
		布尔类型字段值用「是」或「否」
		主体卡片/表格用于编辑的字段集合与表单可见业务字段一致，点击单行/单卡即可编辑
		当前行初始为 0；SubmitRecord 成功后当前行为 1
		表格与卡片有悬停效果；移动端优先，录音台在小屏居中放大
		各页面统一米白 + 橙红 + 黑字主题，文案语气干脆，重复出现口号：「开口说，它自己归档。」「碎片要管，属于你。」「打开，说一句，剩下的它来办。」

所有页面的底部增加较大的间隔
