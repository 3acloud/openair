# 可视化解释器
	这是一个将系统、代码变更、方案、数据或复杂表格转换为自包含的可视化HTML报告或幻灯片文件的Web应用。包含首页、新建可视化、历史记录页面。
	页面统一采用科技感IDE主题，深色背景（深空灰），辅以代码蓝（#569CD6）和荧光绿（#4EC9B0）高亮，卡片采用圆角和磨砂玻璃效果，字体使用现代无衬线体及等宽字体，营造专业开发工具的沉浸感。
	页面顶部导航栏，使用深色磨砂背景和底边蓝色发光线
		左侧显示Logo（网络节点/代码块图标）和‘可视化解释器’
		右侧显示导航标签：首页、新建可视化、历史记录
	首页
		主标题：可视化解释器，说明：输入源文件与解释要求，一键生成精美架构图、流程图与数据仪表盘。
		中央大按钮：+ 创建可视化，点击跳转到‘新建可视化’页面
		接下来是并列的两个统计数据卡片：总生成次数、各类形式分布
			总生成次数卡片显示所有记录数量
				API名称:GetRecordCount,数据源:可视化解释/默认表格
			各类形式分布卡片显示不同输出形式的数量占比
				API名称:GetTableCSV,数据源:可视化解释/默认表格,payload:"输出形式"
				通过统计"HTML页面"和"幻灯片HTML"的数量分别显示。
		接下来是最近生成记录：显示最近4条记录，以卡片网格形式排列。
			API名称:GetTableCSV,数据源:可视化解释/默认表格,payload:"源文件,解释要求,内容类型,视觉风格"
			按获取顺序倒序显示前4条，截取解释要求前40个字符作为卡片标题，显示内容类型和视觉风格徽章。
			卡片点击跳转到‘历史记录’页面查看。
	‘新建可视化’页面
		采用左右分栏布局。左侧为配置表单区，右侧为结果预览区。
		左侧配置表单区
			大标题：任务配置
			表单标题:生成配置,表:可视化解释,字段:[{字段名:源文件,类型:文件},{字段名:解释要求,类型:文本},{字段名:内容类型,类型:单选项,可选项:架构概览,流程图,序列图,数据流,ER图,状态机,思维导图,数据表,时间线,仪表盘,文档可视化},{字段名:输出形式,类型:单选项,可选项:HTML页面,幻灯片HTML},{字段名:视觉风格,类型:单选项,可选项:蓝图,编辑排版,纸张墨迹,单色终端,IDE主题,数据密集}]
			源文件字段旁提供按钮“选择文件”，调用 SelectFile 返回全局文件名填充到此字段的值中。
			表单底部主按钮：生成可视化。
			点击“生成可视化”后，使用 SubmitRecord 提交表单数据。提交后当前行设为 1。
		右侧结果预览区
			大标题：可视化结果
			初始状态或空闲时显示状态提示（如“等待任务输入...”）。
			当触发 SubmitRecord 后，开始轮询等待后台AI异步生成结束。
			轮询标题:生成中,表:可视化解释,字段:可视化结果,输出到:右侧结果预览区,等待消息:AI正在分析源文件并生成图表代码...
			轮询结束后，调用API名称:GetCellValue,数据源:可视化解释/默认表格,payload:"可视化结果/1"，获取可视化结果字段的全局文件名。
			得到全局文件名后：
				在区域内通过 iframe 渲染HTML文件，iframe的src链接为 "https://www.ithinkair.com:3031/private/全局文件名"。
				右上角提供两个操作按钮：
					“在新标签页打开”：浏览器新开窗口访问链接 "https://www.ithinkair.com:3031/private/全局文件名"。
					“下载文件”：访问链接 "https://www.ithinkair.com:3031/download/全局文件名"。
		左下角悬浮按钮：清空重置。点击后清空表单数据、停止轮询并重置右侧结果预览区，当前行设为 0。
	‘历史记录’页面
		左上大标题：历史记录，说明：查看和管理过去生成的可视化文件
		右上按钮：+ 新建可视化，点击跳转到‘新建可视化’页面
		操作区：提供基于“内容类型”的下拉筛选器。
		主体是历史记录列表，采用宽卡片形式，每行显示：源文件（文件图标+全局文件名）、解释要求（摘要）、内容类型（彩色徽章）、输出形式、视觉风格。
			API名称:GetTableCSV,数据源:可视化解释/默认表格,payload:"源文件,解释要求,内容类型,输出形式,视觉风格"
			每张卡片右侧包含操作按钮：查看结果、编辑配置、删除。
			点击“查看结果”：弹出全屏模态框，模态框内根据该卡片对应行号调用 GetCellValue 获取“可视化结果”的全局文件名，并用 iframe 打开对应链接 "https://www.ithinkair.com:3031/private/全局文件名"，模态框上方提供“下载”按钮。
			点击“编辑配置”：弹出编辑表单模态框，包含字段：解释要求、内容类型、输出形式、视觉风格。
				打开时根据行号获取当前数据填充表单。
				确认保存时，依次通过调用 SetCellValue(payload:"字段名/行/值") 设置该行对应字段的新值，无需 SubmitRecord，完成后更新界面。
			点击“删除”：弹出二次确认，确认后调用API名称:DeleteRecord,数据源:可视化解释/默认表格,payload:行号.toString()，成功后刷新列表数据。
	全局规范与要求
		所有的 API 调用如 GetTableCSV, SubmitRecord, GetRecordCount, GetCellValue, DeleteRecord, SetCellValue, SelectFile 必须正确实现。
		文件字段的数据仅显示为文件的全局文件名，调用SelectFile后的结果直接绑定至表单项。
		未选中记录或未提交任务时，当前行为0。
		各个操作按钮对应的功能、轮询等待状态展示以及 iframe 的预览逻辑必须在页面中完全实现。
