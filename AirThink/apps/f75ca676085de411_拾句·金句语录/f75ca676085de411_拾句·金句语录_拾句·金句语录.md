# 拾句·金句语录
	这是一个金句精选与日签卡片网页应用，包含首页、拾句工坊、金句馆三个页面。不包含用户登录页面。页面统一采用「宣纸鎏金」中式文人主题：背景为暖宣纸色浅渐变（#f7f1e4 → #efe6d4）并叠加极淡纸纹；主色墨黑 #1f1c18，点缀鎏金 #c4a35a 与朱砂 #9e2a2b；标题使用衬线宋体（Noto Serif SC），正文使用柔和黑体；卡片如宣纸笺，细金边、轻阴影，悬停微抬起并显墨痕；按钮为墨底金字或金描边文字按钮。加载与轮询时使用水墨晕开动画。操作按钮对应的功能必须全部实现。

	页面顶部导航栏，使用深墨色背景、鎏金细线分隔
		左侧显示Logo（卷轴/一句印章图标）和「拾句·金句语录」
		右侧显示标签：首页、拾句工坊、金句馆
		当前页标签鎏金下划线高亮

	首页
		主标题：拾句·金句语录
		说明：按主题和使用场景精选金句，标注出处与适用场景，支持朋友圈文案、内容素材及日签卡片生成，让好句随取随用。
		中央主按钮：开始拾句，点击跳转到「拾句工坊」页面
		接下来是并列的三个统计卡片（卡片形式，各有不同淡彩：墨金、朱砂、青瓷）
			累计拾句卡片：显示全部拾句记录数
				API名称:GetRecordCount,数据源:拾句/默认表格
			日签卡片数：显示生成日签卡片为「是」的记录数量
				API名称:GetTableCSV,数据源:拾句/默认表格,字段:[生成日签卡片]
				筛选生成日签卡片为「是」后计数
			主题覆盖：显示不重复「主题」个数
				API名称:GetTableCSV,数据源:拾句/默认表格,字段:[主题]
				对主题去重后计数
		接下来是「最近拾句」：以卡片形式显示最近5条，字段包括主题、使用场景、句数、生成日签卡片、拾句结果摘要
			API名称:GetTableCSV,数据源:拾句/默认表格,字段:[主题,使用场景,句数,生成日签卡片,拾句结果]
			列表倒序取前5条；拾句结果在卡片上截取前80字，生成日签卡片用鎏金/墨色小印章显示「日签」或「语录」
			点击最近列表项打开详情：调用GetCellValue获取该行拾句结果，用Markdown主题完整呈现；若内容含图片链接或全局文件名，图片以 https://www.ithinkair.com:3031/download/全局文件名 显示，日签卡片按3:4比例展示
		首页底部一行诗意空状态文案：尚无记录时显示「墨未落纸，去工坊拾一句吧」，按钮跳转拾句工坊

	「拾句工坊」页面
		左上显示大标题：拾句工坊，说明：选定主题与场景，智能精选金句，可一键生成日签卡片
		右上是按钮：金句馆，点击跳转到「金句馆」页面
		中部为拾句笺表单区（宣纸卡片）
			快捷主题标签（点击填入「主题」字段，可多选其一）：励志、爱情、人生、友情、读书、时光、故乡、治愈、孤独、事业、春天、月亮、坚持、放下、旅行、晚安
			快捷场景标签（点击填入「使用场景」字段）：朋友圈文案、日签、演讲开头、文案素材、自我激励、祝福问候、早安、晚安、告别、节日
			表单标题:拾句,表:拾句,字段:[{字段名:主题,类型:文本},{字段名:使用场景,类型:文本},{字段名:句数,类型:数值},{字段名:生成日签卡片,类型:布尔},{字段名:拾句结果,类型:指令流}]
			表单仅展示用户可填字段：主题、使用场景、句数、生成日签卡片；拾句结果不手工填写
			主题占位：未填写时按通用主题精选
			使用场景占位：如朋友圈文案、日签、演讲开头
			句数：数字输入，占位提示「可留空：通用1句 / 主题精选3-5句 / 朋友圈2-3条」
			生成日签卡片：开关，布尔值用「是」或「否」表示，默认「否」
			当前行初始是0
		主按钮标题：开始拾句，点击提交表单（主题与使用场景都为空时也可提交，走通用精选）
			使用SubmitRecord提交，表单数据为json文本，字段仅含主题、使用场景、句数、生成日签卡片
			提交后当前行是1
			提交后需要轮询等待后台AI异步生成结束
			轮询标题:拾句,表:拾句,字段:拾句结果,输出到:拾句结果区,等待消息:墨香酝酿中，金句精选请稍候…
			轮询API名称:GetCellValue,数据源:拾句/默认表格,字段名:拾句结果,行号:当前行
			拾句结果为指令流，详情必须用Markdown主题显示；不输出目录；若含日签图片链接则在文案上方以3:4卡片展示图片
			生成结束后在结果区底部固定显示「图语录 Tuyulu.com 出品」样式署名条（若正文已有则不重复堆叠）
		拾句结果区
			无结果且当前行为0时显示空白笺：静候一句
			轮询中显示水墨加载与等待消息
			完成后渲染Markdown金句、出处、适用场景；日签图可点击放大
			结果区右上角按钮组
				按钮标题：再拾一句，点击清空表单与结果区，当前行设为0，生成日签卡片恢复「否」
				按钮标题：< ，点击读取上一行的主题、使用场景、句数、生成日签卡片、拾句结果
				按钮标题：> ，点击读取下一行的主题、使用场景、句数、生成日签卡片、拾句结果
				数据来源于GetCellValue
				API名称:GetCellValue,数据源:拾句/默认表格,字段名:主题,行号:当前行
				API名称:GetCellValue,数据源:拾句/默认表格,字段名:使用场景,行号:当前行
				API名称:GetCellValue,数据源:拾句/默认表格,字段名:句数,行号:当前行
				API名称:GetCellValue,数据源:拾句/默认表格,字段名:生成日签卡片,行号:当前行
				API名称:GetCellValue,数据源:拾句/默认表格,字段名:拾句结果,行号:当前行
				API名称:GetRecordCount,数据源:拾句/默认表格
				当前行<=1时，<按钮不可操作
				当前行>=RecordCount时，>按钮不可操作
		右下新建按钮标题：+，点击清空表单及拾句结果并且当前行设为0

	「金句馆」页面
		左上显示大标题：金句馆，说明：浏览、检索与管理已拾金句和日签卡片
		右上是按钮：+ 去拾句，点击跳转到「拾句工坊」页面
		搜索框，可按照主题或使用场景搜索
		筛选器：按使用场景筛选、按是否生成日签卡片筛选（全部 / 是 / 否）
		列表用卡片形式，不用普通密表；每张卡片展示主题、使用场景、句数、生成日签卡片、拾句结果摘要（前100字）
			主体列表字段必须与表单字段一致
			API名称:GetTableCSV,数据源:拾句/默认表格,字段:[主题,使用场景,句数,生成日签卡片,拾句结果]
			生成日签卡片在卡片上显示为「是」「否」对应的「日签」鎏金章或「语录」墨章
			拾句结果摘要若过长省略号收起；日签记录优先尝试从该行详情中解析图片并显示缩略
			查看指令流详情必须调用GetCellValue，文本用Markdown主题显示
			API名称:GetCellValue,数据源:拾句/默认表格,字段名:拾句结果,行号:对应行
		每张卡片有操作按钮：查看详情、编辑、删除、再次拾句
			查看详情：弹出宣纸模态，标题为该条主题；用GetCellValue逐字段展示主题、使用场景、句数、生成日签卡片；拾句结果Markdown渲染；图片用 https://www.ithinkair.com:3031/download/全局文件名 展示
			点击卡片空白处等同查看详情
			编辑：当前行=该行行号，用GetCellValue逐字段填充表单（主题、使用场景、句数、生成日签卡片）；拾句结果只读展示不进入可编辑输入；修改后依次SetCellValue更新当前行各可改字段，不用SubmitRecord
				API名称:GetCellValue,数据源:拾句/默认表格,payload:字段名/行
				API名称:SetCellValue,数据源:拾句/默认表格,payload:字段名/行/值
				布尔字段写入「是」或「否」
				行号从1开始；GetRecordRow用于按「主题」等定位行号
				API名称:GetRecordRow,数据源:拾句/默认表格,payload:字段名/值
			删除：确认后调用DeleteRecord
				API名称:DeleteRecord,数据源:拾句/默认表格,payload:行号.toString()
			再次拾句：读取该行主题、使用场景、句数、生成日签卡片，跳转拾句工坊并填入表单，当前行设为0，等待用户点击「开始拾句」以SubmitRecord生成新记录（不覆盖旧指令流）
		编辑表单标题:拾句,表:拾句,字段:[{字段名:主题,类型:文本},{字段名:使用场景,类型:文本},{字段名:句数,类型:数值},{字段名:生成日签卡片,类型:布尔},{字段名:拾句结果,类型:指令流}]
			无ID类字段、无创建日期字段，禁止自行编造此类字段
			拾句结果只读，Markdown展示
		空列表时显示：馆中尚无金句，去工坊拾一句
		列表支持按主题排序；卡片网格在宽屏3列、平板2列、手机1列

	数据与交互总则
		数据源表名为「拾句」，GetTableCSV、GetRecordCount、GetRecordRow、GetCellValue、SetCellValue、DeleteRecord、SubmitRecord 的数据源均为 拾句/默认表格
		GetTableCSV 获取不含标题行的csv文本；逗号分隔的字段名必须是表字段：主题,使用场景,句数,生成日签卡片,拾句结果
		指令流字段拾句结果不是用户手工填写，SubmitRecord后由后台AI异步生成；显示详情先GetCellValue，用Markdown主题显示
		本表指令描述未要求「以JSON格式输出」，故轮询该指令流字段「拾句结果」本身
		全局文件名图片链接为 https://www.ithinkair.com:3031/download/全局文件名
		主体列表显示字段及GetTableCSV字段必须和表单字段一致，以便点击单行进入编辑
		字段名只能使用表定义中的：主题、使用场景、句数、生成日签卡片、拾句结果
		各页面表格与卡片均需悬停效果；点击行或卡片可展开详情
		操作按钮（开始拾句、再拾一句、+、查看详情、编辑、删除、再次拾句、导航跳转、<、>）功能必须全部实现
