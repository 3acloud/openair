# 斯多葛教练
	这是一个斯多葛哲学教练网页应用，包含首页、开始练习、洞察档案三个页面。帮助用户觉察情绪、澄清可控事项并积累个人洞察。不需要用户登录页面。
	页面统一采用「内在堡垒」主题：深海蓝与羊皮纸暖白为底，青铜金为点缀，卡片如大理石碑，引语区使用衬线字体，正文使用柔和无衬线字体。背景为缓慢流动的暗青渐变，点缀极淡的几何圆环与柱廊剪影。按钮、卡片带青铜描边与悬停浮起、微光效果。情绪相关控件使用克制的暖色，语录区使用金箔高光。整体气质沉静、庄重、留白充足。
	页面顶部导航栏，使用深海蓝背景、底部一条细青铜线
		左侧显示Logo（盾形堡垒图标）和「斯多葛教练」
		右侧显示标签：首页、开始练习、洞察档案
		导航栏右侧角落显示一句极短 Stoic 箴言轮播（仅展示，不调用接口）
	首页
		主标题：内在堡垒
		说明：一次只问一个问题。先看见情绪，再分辨可控与不可控，把洞察 brewed 成习惯。
		主标题下方三个并列意图入口大卡片（点击均跳转「开始练习」并预填用户意图）
			卡片一：引导练习 —— 「把此刻的不适拆开看」；副文案：共情之后，一步一问
			卡片二：进度复盘 —— 「回看你走过的路」；副文案：一句有温度的观察，一个可执行的建议
			卡片三：每日语录 —— 「今天只需一句」；副文案：语录、出处与短解读
		接下来是并列的四个统计卡片
			练习总数
				API名称:GetRecordCount,数据源:教练请求/默认表格
			引导练习次数
				API名称:GetTableCSV,数据源:教练请求/默认表格,字段:[用户意图]
				筛选用户意图为「引导练习」的记录计算数量
			进度复盘次数
				API名称:GetTableCSV,数据源:教练请求/默认表格,字段:[用户意图]
				筛选用户意图为「进度复盘」的记录计算数量
			语录领取次数
				API名称:GetTableCSV,数据源:教练请求/默认表格,字段:[用户意图]
				筛选用户意图为「每日语录」的记录计算数量
		统计卡片下方是「近期洞察」区域，标题：近期洞察，说明：最近 5 次教练对话，点击卡片查看详情
			以卡片形式展示，不用表格
			API名称:GetTableCSV,数据源:教练请求/默认表格,字段:[用户意图,不适程度,情况描述,练习偏好,教练回应]
			按记录倒序取前 5 条
			每张卡片顶部用意图徽章区分三种用户意图（引导练习为暖赭、进度复盘为青灰、每日语录为青铜金）
			卡片展示：用户意图、不适程度（仅当用户意图为引导练习时显示，格式如「不适 7/10」）、情况描述前 40 字（无则显示「—」）、教练回应前 60 字纯文本摘要
			点击卡片：当前行设为该行行号，跳转洞察档案并打开详情抽屉
		首页底部中央按钮：开始今天的练习，点击跳转「开始练习」
	「开始练习」页面
		左上显示大标题：开始练习
		说明：选择你此刻需要的陪伴。引导练习将一次只推进一个问题；语录只给一句；复盘只给一个建议。
		右上是按钮：查看洞察档案，点击跳转「洞察档案」
		页面分为左右两栏（窄屏上下堆叠）
		左栏为请求表单，右栏为教练回应舞台
		表单标题:斯多葛教练请求,表:教练请求,字段:[{字段名:用户意图,类型:单选项,可选项:引导练习,进度复盘,每日语录},{字段名:不适程度,类型:数值},{字段名:情况描述,类型:文本},{字段名:练习偏好,类型:文本},{字段名:教练回应,类型:指令流}]
			表单不含任何未在表定义中出现的字段，不编造 ID、创建日期等字段
			用户意图用三枚大号分段选择按钮展示，默认值为从首页带入的意图，否则为「引导练习」
			当用户意图为「引导练习」时显示：
				不适程度：1 到 10 的横向刻度滑杆，左侧标注「几乎无波」，右侧标注「难以承受」，数值即时显示
				情况描述：多行文本，占位符「发生了什么？身体和情绪此刻如何？只需如实写下。」
				练习偏好：单行文本，占位符「例如：更短的问题、只要行动建议、偏马可·奥勒留风格……可留空」
			当用户意图为「进度复盘」时：
				隐藏不适程度、练习偏好
				情况描述可选填，占位符「若有想被看见的阶段或卡点，写在这里；也可留空，直接复盘。」
			当用户意图为「每日语录」时：
				隐藏不适程度、情况描述、练习偏好，左栏只保留意图选择与一句提示「今天只需领取一句，不提问。」
			教练回应字段不出现在表单填写区，由后台异步生成
		左栏底部主按钮：提交给教练
			仅当用户意图已选择，且（引导练习时情况描述非空，或进度复盘/每日语录）时启用
			点击后使用 SubmitRecord 提交，表单数据是 json 文本，字段仅包含用户已填写项：用户意图必填；引导练习时附带不适程度、情况描述、练习偏好；进度复盘时附带情况描述（可空字符串）；每日语录只提交用户意图
			布尔值若出现用「是」或「否」（本表无布尔字段）
			SubmitRecord 提交后当前行是 1
		提交后右栏进入等待态，轮询后台指令流直到生成结束
			轮询标题:斯多葛教练请求,表:教练请求,字段:教练回应,输出到:教练舞台,等待消息:教练正在点灯，请稍候……
			因指令描述未要求以 JSON 格式输出，轮询该「指令流」类型字段本身
			API名称:GetCellValue,数据源:教练请求/默认表格,字段名:教练回应,行号:当前行
			生成结束后，教练舞台用 Markdown 主题渲染全文
			引导练习的回应区顶部显示细条：一次一问 · 先看见，再选择
			每日语录的回应区以居中语录卡片呈现（大号衬线、出处小字、解读正文）
			进度复盘的回应区以「观察 / 建议」两段视觉层次呈现（若原文未分节则整篇 Markdown 显示）
		教练舞台初始文案（当前行是 0 且未提交）：「把判断放在一边，先坐下。提交之后，回应会出现在这里。」
		右栏顶部工具：
			按钮：复制回应，将当前教练回应纯文本复制到剪贴板（无回应时禁用）
			按钮：再来一次，清空表单与教练舞台并且当前行设为 0，保留当前用户意图
		提交成功并完成轮询后，在舞台下方显示次级按钮：将这次收入档案，点击跳转「洞察档案」并定位当前行详情
	「洞察档案」页面
		左上显示大标题：洞察档案
		说明：你与自己的对话都留在这里。点开卡片，重读当时的判断与选择。
		右上是按钮：+ 新的练习，点击跳转「开始练习」，当前行设为 0
		搜索框，可按情况描述、练习偏好、教练回应关键词过滤
		筛选器：按用户意图筛选（全部 / 引导练习 / 进度复盘 / 每日语录）
		排序：默认最新在上
		主体不用表格，使用卡片列表
			API名称:GetTableCSV,数据源:教练请求/默认表格,字段:[用户意图,不适程度,情况描述,练习偏好,教练回应]
			主体列表展示的字段与表单字段一致，便于点击单卡进入编辑
			每张卡片显示：用户意图徽章、不适程度（引导练习时）、情况描述摘要（前 50 字）、练习偏好（有则显示）、教练回应摘要（前 80 字）
			每张卡片有操作按钮：查看详情、编辑、删除
				查看详情：打开右侧或底部详情抽屉。抽屉内用 Markdown 渲染完整教练回应；上方只读展示用户意图、不适程度、情况描述、练习偏好。
					查看详情时调用 GetCellValue 获取单元格详情
					API名称:GetCellValue,数据源:教练请求/默认表格,字段名:用户意图,行号:当前行
					API名称:GetCellValue,数据源:教练请求/默认表格,字段名:不适程度,行号:当前行
					API名称:GetCellValue,数据源:教练请求/默认表格,字段名:情况描述,行号:当前行
					API名称:GetCellValue,数据源:教练请求/默认表格,字段名:练习偏好,行号:当前行
					API名称:GetCellValue,数据源:教练请求/默认表格,字段名:教练回应,行号:当前行
					教练回应必须用 Markdown 主题显示
				编辑：当前行=该卡片行号，打开与「开始练习」相同字段的编辑表单并逐字段 GetCellValue 填充
					表单标题:编辑教练请求,表:教练请求,字段与新建表单相同
					用户意图、不适程度、情况描述、练习偏好可改；教练回应在编辑表单中只读并以 Markdown 预览
					保存时依次通过 SetCellValue 设当前记录行各字段的值，不得使用 SubmitRecord
					API名称:SetCellValue,数据源:教练请求/默认表格,payload:字段名/行/值
					不修改教练回应字段（指令流由后台生成，编辑时保持原值）
				删除：确认后调用 DeleteRecord
					API名称:DeleteRecord,数据源:教练请求/默认表格,payload:行号.toString()
					payload 参数接收的是文本，行号必须 toString()
			点击卡片空白区域等同查看详情
		详情抽屉右上角提供记录翻页
			按钮标题:< ，点击读取上一行各字段，数据来源于 GetCellValue
			按钮标题:> ，点击读取下一行各字段，数据来源于 GetCellValue
			API名称:GetRecordCount,数据源:教练请求/默认表格
			当前行初始是 0
			当前行<=1 时，< 按钮不可操作
			当前行>=RecordCount 时，> 按钮不可操作
		空态：档案为空时居中显示「还没有洞察。从一次呼吸开始。」以及按钮「开始第一次练习」
	通用数据与交互规则
		当前行初始是 0
		新建使用 SubmitRecord 提交，提交后当前行是 1，然后轮询教练回应
		修改已有记录只用 SetCellValue，不用 SubmitRecord
		列表、卡片、表单、GetTableCSV 使用的字段集合保持一致：用户意图,不适程度,情况描述,练习偏好,教练回应
		字段名必须是表定义中出现过的字段名，不得自行编造 ID 或日期字段
		本表无只读独立表，无需额外只读页
		操作按钮对应的功能必须全部实现：意图预填跳转、提交、轮询、Markdown 展示、复制、再来一次、搜索筛选、详情、编辑、删除、上下翻页、统计刷新
		提交或删除后刷新首页统计与近期洞察、洞察档案卡片
		若 GetTableCSV 暂无数据，统计显示 0，列表显示空态，不报错
		所有 callAppBridge 调用按约定：
			获取列表：callAppBridge({type:"GetTableCSV", data:"教练请求/默认表格", payload:"用户意图,不适程度,情况描述,练习偏好,教练回应"})
			提交新建：callAppBridge({type:"SubmitRecord", data:"教练请求", payload:表单json文本})
			记录数：callAppBridge({type:"GetRecordCount", data:"教练请求/默认表格"})
			定位行：callAppBridge({type:"GetRecordRow", data:"教练请求/默认表格", payload:"字段名/值"})
			删除：callAppBridge({type:"DeleteRecord", data:"教练请求/默认表格", payload:行号字符串})
			读单元格：callAppBridge({type:"GetCellValue", data:"教练请求/默认表格", payload:"字段名/行"})
			写单元格：callAppBridge({type:"SetCellValue", data:"教练请求/默认表格", payload:"字段名/行/值"})
		各页面使用统一的内在堡垒视觉主题，卡片与按钮具有悬停效果，点击卡片展开详情。
