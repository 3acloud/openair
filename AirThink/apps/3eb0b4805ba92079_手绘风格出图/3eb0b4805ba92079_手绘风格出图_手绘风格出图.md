# 手绘风格出图
	这是一个手绘插画生成网页应用，包含首页、落笔出图、速写本三个页面。整体像一本摊开的艺术家速写本：宣纸米白背景、墨褐手绘描边、赭石印章按钮、轻微纸张纹理；卡片像贴在本子上的速写纸，悬停时微微倾斜并出现胶带阴影。不包含用户登录页面。字体使用柔和的衬线与手写感标题。
	统一主题色
		背景：#F7F1E5 宣纸米白，带极淡网格速写底纹
		导航：#2C2416 墨褐，文字为米白
		主强调：#C45C26 赭石橙（主按钮、选中态）
		辅助：#4A7C8C 水彩青灰（统计卡片、标签）
		成功：#6B8F71 松绿
		卡片：#FFFBF3，1.5px 手绘深褐描边，圆角小
		标题字体略带手写感，正文 sans-serif
	页面顶部导航栏
		左侧显示速写本Logo（一本翻开的本子+铅笔图标）和「手绘风格出图」
		右侧标签：首页、落笔出图、速写本
		当前页标签以下划铅笔线高亮
	首页
		主标题：手绘风格出图
		说明：从 001 至 274 号画风里挑选一种，写下画面主题，切换纯图或图文，一键生成辨识度稳定的手绘插画
		中央主按钮：开始落笔，点击跳转到「落笔出图」页面
		接下来是并列三个统计卡片（各有不同水彩底色，悬停微抬起）
			总作品数
				API名称:GetRecordCount,数据源:手绘作品/默认表格
			纯图作品数
				API名称:GetTableCSV,数据源:手绘作品/默认表格,字段:[风格编号,主题,模式,图片]
				筛选模式为「纯图模式」的记录计算数量
			图文作品数
				API名称:GetTableCSV,数据源:手绘作品/默认表格,字段:[风格编号,主题,模式,图片]
				筛选模式为「图文模式」的记录计算数量
		接下来是最近作品：标题「最近落笔」，说明「点击卡片查看详情」
			以卡片网格显示最近 6 条，每张卡片展示：生成图片（优先）、风格编号徽章、主题（最多两行）、模式标签
			API名称:GetTableCSV,数据源:手绘作品/默认表格,字段:[风格编号,主题,模式,图片]
			列表顺序按表格原有顺序，取前 6 条（新提交记录在最前）
			图片字段文本是全局文件名，卡片封面使用链接 https://www.ithinkair.com:3031/download/全局文件名 ；若图片为空则显示铅笔草稿占位图
			点击最近列表项打开详情抽屉/模态：用 GetCellValue 读取当前行各字段；大图、风格编号、主题、模式；按钮包括「按此再画」（跳转落笔出图并预填风格编号、主题、模式）、「下载原图」（访问 https://www.ithinkair.com:3031/download/全局文件名）、「去速写本」
	「落笔出图」页面
		左上大标题：落笔出图
		说明：选择画风编号，写好主题，选定纯图或图文，提交后由后台按所选风格异步生图
		右上按钮：打开速写本，跳转到「速写本」页面
		页面左右分栏（窄屏改为上下）
			左侧为创作表单区，像一张钉在木板上的绘图纸
			右侧为画纸预览区，初始显示空白速写框与提示「主题落在纸上之后，画风会跟着编号走」

			表单只显示用户可填字段：风格编号、主题、模式
			图片为指令流字段，禁止用户手工填写，不在表单输入区出现
			不要编造表定义中不存在的 ID、创建日期等字段
			风格编号选择器：顶部可搜索编号（如输入 27 过滤出 027），下方为可滚动的三位数编号密铺网格，选中项用赭石手绘圆圈标注，并在网格上方大号显示当前编号如「No.027」
			主题：多行输入，占位符例如「雨后的老街灯笼、一只撑油纸伞的黑猫」
			模式：两个大选项卡，纯图模式（只出画面）、图文模式（画面中融入与主题相关的手绘文字），必须二选一，默认纯图模式
		主按钮标题：一键落笔
			仅当风格编号、主题（去空白后非空）、模式都已选择时启用
			点击使用 SubmitRecord 提交新建记录
			API名称:SubmitRecord,表:手绘作品,payload为json文本，仅包含风格编号、主题、模式
			提交后当前行是1
			不要用 SubmitRecord 去修改已有记录
		提交后进入绘制等待
			右侧预览区显示手绘等待动画与文案「铅笔沙沙作响，正在按所选编号落笔…」
			指令流由后台 AI 异步生成，必须轮询等待结束
			轮询标题:手绘作品,表:手绘作品,字段:图片,输出到:画纸预览,等待消息:正在落笔绘制中…
			轮询该指令流字段「图片」（指令描述未要求 JSON 输出）
			API名称:GetCellValue,数据源:手绘作品/默认表格,字段名:图片,行号:当前行
			当 GetCellValue 返回非空的全局文件名后结束轮询
			画纸预览用 Markdown 区域承载结果图，图片地址为 https://www.ithinkair.com:3031/download/全局文件名
			同时用 GetCellValue 读取风格编号、主题、模式，在预览图下方以标签展示
		预览成功后的操作按钮必须全部实现
			再画一张：保留当前风格编号、主题、模式，再次 SubmitRecord，提交后当前行=1 并重新轮询图片
			换个主题：清空主题输入，保留风格编号与模式，当前行保持，预览区回到空白画纸
			下载原图：打开 https://www.ithinkair.com:3031/download/全局文件名
			收入速写本：跳转「速写本」并高亮第 1 行
		当前行初始是 0；仅当当前行>=1 时预览区尝试读图
	「速写本」页面
		左上大标题：速写本
		说明：浏览、筛选、编辑和删除已经落下的手绘作品，列表使用卡片而不是冷冰冰的电子表
		右上按钮：+ 新的一张，跳转到「落笔出图」并清空表单、当前行设为 0
		搜索框：按主题关键字或风格编号搜索
		筛选器：模式（全部 / 纯图模式 / 图文模式）；风格编号区间（起止编号，可空）
		主体作品墙与表单字段、GetTableCSV 字段保持一致，以便点击单卡即可进入编辑
			API名称:GetTableCSV,数据源:手绘作品/默认表格,字段:[风格编号,主题,模式,图片]
			每张卡片显示：封面图、风格编号、主题、模式
			封面图：csv 中图片字段为全局文件名，使用 https://www.ithinkair.com:3031/download/全局文件名 ；空值显示占位速写框
			卡片悬停出现操作条，每张卡片按钮：查看详情、编辑、删除、按此再画
			查看详情：弹出大幅画纸模态。API名称:GetCellValue,数据源:手绘作品/默认表格,payload:字段名/行 ；图片用 GetCellValue 取全局文件名后以图片展示，主题与说明用 Markdown 呈现；模态内提供下载原图、编辑、删除
			编辑：当前行=该卡片行号，打开右侧/下方编辑表单，用 GetCellValue 逐字段回填风格编号、主题、模式；图片只读预览，不可手工改文件名。修改后依次 SetCellValue 更新当前行，禁止对该已有记录再调 SubmitRecord
				API名称:SetCellValue,数据源:手绘作品/默认表格,payload:字段名/行/值
				可改字段仅限风格编号、主题、模式
			删除：二次确认后调用 DeleteRecord
				API名称:DeleteRecord,数据源:手绘作品/默认表格,payload:行号.toString()
				删除后刷新卡片墙与首页统计
			按此再画：把该行风格编号、主题、模式带入「落笔出图」表单（不自动提交）
		编辑表单标题:手绘作品,表:手绘作品,字段与新建表单相同
			点卡片行即视为选中该行，当前行=行号
			API名称:GetRecordRow,数据源:手绘作品/默认表格,payload:字段名/值 可用于按风格编号+主题定位行号（行号从1开始）
			保存按钮：对当前行 SetCellValue；取消按钮：关闭表单不改值
		空状态：速写本还是空白一页，中央按钮「落下第一笔」跳转落笔出图
	详情与指令流显示规则
		查看指令流「图片」的详情内容时，先 GetCellValue，再以图片+Markdown 展示，不把原始指令描述直接给用户当结果
		全局文件名图片链接一律为 https://www.ithinkair.com:3031/download/全局文件名
		在浏览器中打开文件使用 https://www.ithinkair.com:3031/private/全局文件名
	数据与行号约定
		当前行初始为 0
		SubmitRecord 成功后当前行=1，并开始轮询
		主体列表/卡片用的 GetTableCSV 字段必须是：风格编号,主题,模式,图片，与表单字段一致
		字段名只能使用：风格编号、主题、模式、图片
		布尔值若出现用「是」或「否」（本表无布尔字段）
		所有导航、统计、搜索、筛选、提交、轮询、预览、下载、编辑、删除、按此再画、再画一张按钮的功能必须完整实现
		各页面表格/卡片支持按风格编号排序；卡片网格响应式，宽屏 3 列，平板 2 列，手机 1 列
