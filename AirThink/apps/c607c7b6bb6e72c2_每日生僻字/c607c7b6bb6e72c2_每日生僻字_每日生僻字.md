# 每日生僻字
	这是一个每日生僻字科普卡片网页应用，包含首页、生成卡片、卡片珍藏三个页面。不需要用户登录页面。页面统一采用宋代雅致水墨玉兰主题：背景为暖米色宣纸纹理浅渐变（#F7F1E8 至 #EDE4D4），点缀淡墨晕染与极淡玉兰花影；标题使用衬线中文（如宋体/思源宋体），正文与控件使用柔和无衬线字体；主色黛蓝 #1F3A5F，辅色青瓷绿 #6B8F71、暖橙 #D9894B、米波 #C9B99A、玉兰白 #F6F0E6；卡片为宣纸质感、细金边（#C6A15B 15%透明）、圆角 16px，悬停微扬并出现墨色阴影；按钮为墨色填充或金边幽灵按钮，点击有水墨扩散反馈。列表一律用卡片瀑布流，不用传统密集表格。操作按钮对应的功能必须全部实现。

	页面顶部导航栏，使用黛蓝墨色半透明背景，底部一根极细金线
		左侧显示Logo（玉兰折枝图标）和「每日生僻字」
		右侧显示标签：首页、生成卡片、卡片珍藏
		当前页标签用玉兰白下划金线高亮

	首页
		主标题：每日生僻字
		副标题：一日一字，一念一境
		说明：每天生成一组生僻字科普卡片，支持自动选字、多种模板和自定义背景，融合拼音释义与情感短句，方便学习与分享。
		中央主按钮：今日点墨成卡，点击跳转到「生成卡片」页面
		主按钮下方一行小字：留空生僻字即可自动挑选寓意美好的字
		接下来是并列的四个统计小卡片，配色分别对应四种卡片风格
			累计记录卡片：显示生僻字卡片总记录数
				API名称:GetRecordCount,数据源:生僻字卡片/默认表格
			蓝底玉兰卡片：统计卡片风格为「蓝底玉兰」的记录数
				API名称:GetTableCSV,数据源:生僻字卡片/默认表格,字段:[卡片风格]
				筛选卡片风格等于「蓝底玉兰」计算数量
			系列轮换卡片：统计卡片风格为「系列轮换」的记录数
				API名称:GetTableCSV,数据源:生僻字卡片/默认表格,字段:[卡片风格]
				筛选卡片风格等于「系列轮换」计算数量
			计划生成字数卡片：对生成数量求和（空值按 1 计）
				API名称:GetTableCSV,数据源:生僻字卡片/默认表格,字段:[生成数量]
		接下来是「风格一览」四枚并排色卡，仅展示不可跳转：蓝底玉兰、灰绿玉兰、暖橙扇形、米色波浪，作为主题氛围，不对应单独只读表页面
		接下来是最近卡片列表：以卡片形式显示最近 6 条，每张卡片展示生僻字（大号书法字）、卡片风格色点、生成数量、卡片标题、底部互动语
			API名称:GetTableCSV,数据源:生僻字卡片/默认表格,字段:[生僻字,生成数量,卡片风格,背景要求,卡片标题,底部互动语]
			因新提交记录当前行为 1，按返回顺序取前 6 条作为最近
			生僻字为空时卡片上显示「自动选字」
			卡片标题为空时显示「未自定义标题」
			底部互动语为空时显示「快试试你手机能打出来吗」
			首页如果有最近列表，点击最近列表项查看详情
			点击某张卡片：当前行设为该行行号（从 1 起），调用 GetCellValue 逐字段填充只读详情浮层
				API名称:GetCellValue,数据源:生僻字卡片/默认表格,payload:字段名/行
				详情浮层用 Markdown 主题显示「卡片结果」全文；图片若为全局文件名，则用 https://www.ithinkair.com:3031/download/全局文件名 展示；Markdown 图片语法直接渲染
				详情浮层底部按钮：去编辑（跳转卡片珍藏并打开该行编辑）、关闭
		无记录时展示空状态：一枝线描玉兰 +「墨还未落，去生成第一组生僻字」按钮，点击进入生成卡片页

	「生成卡片」页面
		左上显示大标题：点墨成卡
		说明：选定或留空生僻字，选择风格与背景，生成 1080×1440 科普卡片
		右上是按钮：查看珍藏，跳转到「卡片珍藏」页面
		左侧为表单区，右侧为结果区，宽屏左右分栏，窄屏上下堆叠
		表单标题:生僻字卡片,表:生僻字卡片,字段:[{字段名:生僻字,类型:文本},{字段名:生成数量,类型:数值},{字段名:卡片风格,类型:单选项,可选项:蓝底玉兰,灰绿玉兰,暖橙扇形,米色波浪,系列轮换},{字段名:背景要求,类型:文本},{字段名:卡片标题,类型:文本},{字段名:底部互动语,类型:文本},{字段名:卡片结果,类型:指令流}]
			字段名必须使用表定义中的字段，不要自行编造 ID 或创建日期字段
			生僻字：多行文本，占位「例如：邂 逅 寧；留空则自动挑选寓意好的生僻字」
			生成数量：数字步进器，占位「留空：已指定字则按字数生成，否则生成一张」
			卡片风格：五枚可视化单选色卡，选中描金边
				蓝底玉兰、灰绿玉兰、暖橙扇形、米色波浪、系列轮换
				未选择时按技能默认（单张默认蓝底玉兰，多张/系列轮换四种模板）
			背景要求：多行文本，占位「可选。填写后将先生成无文字、留白充足的装饰背景再叠字」
			卡片标题：单行文本，占位「可选，留空则使用模板默认标题」
			底部互动语：单行文本，占位「可选，留空则使用：快试试你手机能打出来吗」
			卡片结果不是用户手工填写，表单上不出现输入框，仅在右侧结果区展示
		主按钮标题：生成卡片，位于表单底部
			点击时使用 SubmitRecord 提交新建表单
			API名称:SubmitRecord,表:生僻字卡片,payload:表单数据JSON文本
			JSON 仅包含用户字段：生僻字、生成数量、卡片风格、背景要求、卡片标题、底部互动语
			生成数量未填则不要写 0，可省略或传空
			提交后当前行是 1
		提交后必须轮询等待后台 AI 异步生成结束
			指令描述未要求以 JSON 格式输出，因此轮询该指令流字段「卡片结果」
			轮询标题:生僻字卡片,表:生僻字卡片,字段:卡片结果,输出到:成片展读,等待消息:墨香酝酿中，正在点成卡片…
			轮询使用 GetCellValue
				API名称:GetCellValue,数据源:生僻字卡片/默认表格,payload:卡片结果/当前行
			当内容仍为空或明显未完成时继续等待并显示水墨加载动画；生成结束后停止轮询
		右侧「成片展读」结果区
			初始文案：静候墨迹。填写左侧表单后点击生成。
			生成完成后，文本内容用 Markdown 主题显示卡片结果；以 Markdown 图片语法展示所有卡片，不要做目录
			图片链接若为全局文件名，使用 https://www.ithinkair.com:3031/download/全局文件名
			结果区顶部显示本张记录的生僻字、拼音区来自 Markdown 原文，不另造字段
			结果区右上提供按钮：再生成一组（清空表单与成片展读，当前行设为 0，不提交）、收入珍藏（跳转卡片珍藏并高亮当前行）
		生成页底部提示条：自动确定心理锚点、拼音、谐音、一句话释义与 3 至 5 行情感文案（每行不超过 14 字）均由技能完成，前端只负责提交与展读

	「卡片珍藏」页面
		左上显示大标题：卡片珍藏
		说明：浏览、展读、修订与删藏每一组生僻字卡片
		右上是按钮：+ 点墨成卡，跳转到「生成卡片」页面
		搜索框：可按生僻字、卡片标题、底部互动语、背景要求模糊搜索
		筛选器：按卡片风格筛选，选项为全部、蓝底玉兰、灰绿玉兰、暖橙扇形、米色波浪、系列轮换
		主体不用传统表格，使用卡片瀑布流；主体卡片上显示的字段及对应 GetTableCSV 的字段必须和表单用户字段一致，以便点击单卡进入编辑
			API名称:GetTableCSV,数据源:生僻字卡片/默认表格,字段:[生僻字,生成数量,卡片风格,背景要求,卡片标题,底部互动语]
			每张珍藏卡展示：生僻字（大字）、生成数量、卡片风格色标、背景要求摘要（前 24 字）、卡片标题、底部互动语
			每张卡右下操作按钮：展读、编辑、删除
			点击卡片空白处等同展读
		展读
			当前行=该行行号
			调用 GetCellValue 获取各字段详情
				API名称:GetCellValue,数据源:生僻字卡片/默认表格,payload:字段名/行
			弹出宣纸模态：上方显示生僻字、生成数量、卡片风格、背景要求、卡片标题、底部互动语；下方用 Markdown 主题显示卡片结果
			图片按全局文件名规则或 Markdown 图片语法渲染
			模态内按钮：编辑、关闭
		编辑
			点击编辑后，当前行=行号，右侧或模态表单加载该行
			API名称:GetCellValue,数据源:生僻字卡片/默认表格,payload:字段名/行
			逐字段填充：生僻字、生成数量、卡片风格、背景要求、卡片标题、底部互动语
			卡片结果只读，仍用 Markdown 展示，不出现在可编辑表单输入里
			表单标题:修订卡片,表:生僻字卡片,字段与生成页相同（不含自造 ID）
			修改表单禁止 SubmitRecord，必须依次 SetCellValue 写回当前记录行
				API名称:SetCellValue,数据源:生僻字卡片/默认表格,payload:字段名/行/值
				可写字段：生僻字、生成数量、卡片风格、背景要求、卡片标题、底部互动语
			保存成功后刷新该卡与列表
			若用户点击「按新内容重新出片」：把当前表单值作为新记录 SubmitRecord（新建），提交后当前行是 1，并按生成页规则轮询新行的卡片结果；不要用 SetCellValue 去写指令流字段
		删除
			二次确认文案：此字一去，墨迹难追。确认删藏？
			确认后调用 DeleteRecord
				API名称:DeleteRecord,数据源:生僻字卡片/默认表格,payload:行号.toString()
			payload 必须是文本，行号先 toString()
			删除后刷新瀑布流与首页统计
		如需定位行号
			API名称:GetRecordRow,数据源:生僻字卡片/默认表格,payload:字段名/值
		如需卡片单元格项目符号或富文本
			API名称:GetCellBullet,数据源:生僻字卡片/默认表格,payload:字段名/行
		记录总数
			API名称:GetRecordCount,数据源:生僻字卡片/默认表格
		当前行初始是 0；仅在提交成功、展读、编辑、删除定位时更新当前行
		无数据时空状态与首页一致，按钮跳转生成卡片

	数据与桥接总则
		所有读表优先 GetTableCSV 获取不含标题行的 csv 文本；逗号分隔字段名必须是「生僻字卡片」表已定义字段
		csv 中图片字段文本是图片全局文件名，文件字段文本是文件全局文件名（本表无独立图片/文件字段，成品图在指令流 Markdown 中）
		查看字段详情一律 GetCellValue
		新建用 SubmitRecord；提交后当前行是 1；指令流由后台 AI 异步生成，必须轮询卡片结果
		修改用 SetCellValue，不用 SubmitRecord
		布尔值若出现用「是」或「否」（本表无布尔字段）
		不要为不存在的字段编造自动编号 ID 或创建日期；主体列表与表单用户字段保持一致
		不要为只读数据单独做页面；风格一览仅为首页装饰
		下载或展示文件使用 https://www.ithinkair.com:3031/download/全局文件名 ；在浏览器打开私有文件使用 https://www.ithinkair.com:3031/private/全局文件名
		本应用不调用拍照、录音、选图选文件；若结果 Markdown 需转链接，可使用 ImageUrl / FileUrl，不要无故调用 SelectImage

	交互与实现约束
		各页面统一水墨玉兰主题，卡片与按钮必须有悬停效果
		首页最近列表点击即详情；珍藏列表用卡片形式
		生成、展读、编辑、删除、搜索、筛选、再生成、跳转珍藏等按钮功能必须全部实现
		指令流详情必须 Markdown 渲染，并展示全部成品图片，不要输出目录式额外结构
		当前行初始为 0，SubmitRecord 后为 1
