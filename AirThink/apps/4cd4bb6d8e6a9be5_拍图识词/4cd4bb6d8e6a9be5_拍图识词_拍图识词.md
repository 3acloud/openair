# 拍图识词
	这是一个拍图识词网页应用，拍照或选图即可识别物体并生成英语学习卡片，支持中文释义、例句、标准发音与单词本收藏。包含首页、拍图识词、识物记录、我的单词本四个页面。
	页面统一采用「镜头单词」视觉英语主题：背景为 mist 蓝到暖米白的柔和渐变，点缀琥珀金与珊瑚橙；卡片做成略带倾斜阴影的单词闪卡（flashcard）风格，圆角 16px，悬停上浮并出现金色描边；主按钮为琥珀橙圆形/胶囊形，次按钮为描边靛蓝；分类徽章使用马卡龙色；字体为圆润现代 sans-serif。不包含用户登录页面。
	页面顶部导航栏，使用深靛蓝半透明背景，底部一条琥珀金细线
		左侧显示 Logo（镜头中有字母 A 的图标）和「拍图识词」
		右侧显示标签：首页、拍图识词、识物记录、我的单词本
	首页
		主标题：拍图识词，说明：举起镜头，让身边的物体变成会发音的英语单词卡
		中央大按钮：开始拍图识词，点击跳转到「拍图识词」页面
		接下来是并列的四个统计卡片（各有不同渐变色，悬停放大）
			总识物数卡片显示识物记录总数
				API名称:GetRecordCount,数据源:识物记录/默认表格
			单词本数量卡片显示单词本总数
				API名称:GetRecordCount,数据源:单词本/默认表格
			已掌握单词卡片显示掌握状态为「已掌握」的数量
				API名称:GetTableCSV,数据源:单词本/默认表格,字段:[掌握状态]
				通过筛选掌握状态为「已掌握」的记录计算数量
			收藏单词卡片显示是否收藏为「是」的数量
				API名称:GetTableCSV,数据源:单词本/默认表格,字段:[是否收藏]
				通过筛选是否收藏为「是」的记录计算数量
		接下来是「最近识物」列表：显示最近 5 条识物记录，以闪卡卡片形式展示（不要用普通表格）
			API名称:GetTableCSV,数据源:识物记录/默认表格,字段:[拍照图片,识别标题,物体名称,英文单词,音标,词性,中文释义,英文例句,例句翻译,记忆提示,识别时间]
			按识别时间降序排列，显示前 5 条
			每张卡片左侧显示拍照图片缩略图（图片链接为 https://www.ithinkair.com:3031/download/全局文件名，全局文件名来自拍照图片字段或 GetCellValue），右侧显示识别标题、英文单词、音标、词性徽章、中文释义摘要（前 24 字）、识别时间
			点击最近列表项打开详情弹层，用 Markdown 主题展示完整学习卡片（识别标题、物体名称、英文单词、音标、词性、中文释义、英文例句、例句翻译、记忆提示、原图）
	「拍图识词」页面
		左上显示大标题：拍图识词，说明：拍摄或选择一张照片，生成带音标、释义、例句和记忆提示的英语学习卡片
		右上是按钮：查看识物记录，跳转到「识物记录」页面
		上方取景区：大尺寸取景框（虚线琥珀边框，四角相机准星装饰），显示当前图片预览（初始展示插画占位「把镜头对准身边的物体」）；无图时识别按钮禁用
		取景框下方按钮组
			按钮：拍照识别，调用 CapturePhoto 返回图片全局文件名，写入当前图片并刷新预览
			按钮：相册选图，调用 SelectImage 返回图片全局文件名，写入当前图片并刷新预览
			预览图链接：https://www.ithinkair.com:3031/download/全局文件名
		识别按钮：生成单词卡，仅当已有图片时启用，点击提交表单
			表单标题:识物记录,表:识物记录,字段:[{字段名:拍照图片,类型:指令流,指令类型:生成格式化文本,指令描述:请识别图片中的主要物体，将其转化为英语学习卡片。识别标题使用物体中文名称加英文单词。以JSON格式输出"识别标题"、"物体名称"、"英文单词"、"音标"、"词性"、"中文释义"、"英文例句"、"例句翻译"、"记忆提示"。},{字段名:识别标题,类型:文本},{字段名:物体名称,类型:文本},{字段名:英文单词,类型:文本},{字段名:音标,类型:文本},{字段名:词性,类型:文本},{字段名:中文释义,类型:文本},{字段名:英文例句,类型:文本},{字段名:例句翻译,类型:文本},{字段名:记忆提示,类型:文本},{字段名:识别时间,类型:日期时间}]
				拍照图片字段值：当前图片全局文件名（指令流字段不是用户手工填写）
				识别时间：当前日期时间
				使用 SubmitRecord 提交，表单数据是 json 文本；提交后当前行是 1
		提交后必须轮询等待后台 AI 异步生成结束。指令描述指定了以 JSON 格式输出，因此轮询 JSON 字段「识别标题」（不要轮询拍照图片本身）
			轮询标题:识物记录,表:识物记录,字段:识别标题,输出到:单词学习卡,等待消息:镜头正在认物体，单词卡生成中…
			识别标题有值后，依次调用 GetCellValue 获取当前行的识别标题、物体名称、英文单词、音标、词性、中文释义、英文例句、例句翻译、记忆提示、拍照图片
				API名称:GetCellValue,数据源:识物记录/默认表格,payload:字段名/行
			单词学习卡用 Markdown 主题渲染为一张居中闪卡：顶部原图，主标题为识别标题，超大号英文单词 + 音标 + 词性徽章，中文释义，英文例句与例句翻译，底部记忆提示高亮引用块
		单词学习卡下方按钮组（识别成功后显示）
			按钮：加入单词本，弹出「加入单词本」表单，识别标题预填为当前识别标题且只读
			按钮：再拍一张，清空当前图片、单词学习卡，当前行设为 0，回到取景状态
	「识物记录」页面
		左上显示大标题：识物记录，说明：回看每一次镜头下的单词发现
		右上是按钮：+ 去拍图，跳转到「拍图识词」页面
		搜索框，可按识别标题、物体名称、英文单词、中文释义搜索
		筛选器：按词性筛选、按识别时间范围筛选
		主体用卡片网格展示识物记录（不要用普通表格当主视图），卡片字段必须与表单字段一致，以便点击卡片进入编辑
			API名称:GetTableCSV,数据源:识物记录/默认表格,字段:[拍照图片,识别标题,物体名称,英文单词,音标,词性,中文释义,英文例句,例句翻译,记忆提示,识别时间]
			按识别时间降序
			每张卡片显示缩略图、识别标题、英文单词、音标、词性、中文释义（前 40 字）、识别时间
			每张卡片操作按钮：查看详情、加入单词本、编辑、删除；所有按钮功能必须实现
				查看详情：弹出模态，原图 + 完整学习卡片，文本用 Markdown 主题显示；指令流详情先 GetCellValue 再渲染
				加入单词本：弹出「加入单词本」表单并预填识别标题
				编辑：当前行=该卡片行号，用 GetCellValue 逐字段填充编辑表单（拍照图片可用 SelectImage 或 CapturePhoto 重新选择）；修改后依次 SetCellValue 更新当前行各字段，禁止用 SubmitRecord
					API名称:SetCellValue,数据源:识物记录/默认表格,payload:字段名/行/值
				删除：调用 DeleteRecord，数据源:识物记录/默认表格,payload:行号.toString()；删除前确认
		点击卡片行进入编辑时，当前行=行号
			API名称:GetRecordRow,数据源:识物记录/默认表格,payload:字段名/值 可用于按识别标题定位行号
		编辑表单标题:编辑识物记录,表:识物记录,字段与新建一致（识别时间在表单中包含，拍照图片支持重新拍照/选图；指令流字段不可手工填写正文）
	「我的单词本」页面
		左上显示大标题：我的单词本，说明：收藏、复习、听读，把识物变成长期记忆
		右上是按钮：+ 从识物加入
		搜索框，可按识别标题搜索；同时提供英文单词搜索（通过关联表识物记录匹配）
		筛选器：按分类筛选、按掌握状态筛选、按是否收藏筛选
		分类色点：生活用品蓝、食物饮品橙、动物植物绿、交通出行青、自然景观teal、电子产品紫、人体部位粉、其他灰
		主体用单词闪卡网格展示（不要用普通表格当主视图），卡片字段必须与表单字段一致
			API名称:GetTableCSV,数据源:单词本/默认表格,字段:[识别标题,分类,掌握状态,是否收藏,加入时间,复习次数,单词发音]
			识别标题是关联表，必须再通过 GetTableCSV 获取关联表相关字段
				API名称:GetTableCSV,数据源:识物记录/默认表格,字段:[拍照图片,识别标题,物体名称,英文单词,音标,词性,中文释义,英文例句,例句翻译,记忆提示,识别时间]
			按加入时间降序
			每张闪卡正面：英文单词、音标、词性、中文释义、分类徽章、掌握状态、收藏星标、复习次数；可翻转看英文例句、例句翻译、记忆提示与关联缩略图
			每张卡片操作按钮：播放发音、收藏切换、标记掌握、复习一次、查看详情、编辑、删除；所有按钮功能必须实现
				播放发音：先 GetCellValue 获取单词发音（指令流，输出音频）；若尚无音频则提示生成中；有全局文件名时用音频播放器播放 https://www.ithinkair.com:3031/download/全局文件名
				收藏切换：是否收藏布尔值用「是」或「否」表示，SetCellValue 在「是」「否」之间切换
				标记掌握：循环或三段按钮设置掌握状态为 未学习 / 学习中 / 已掌握，SetCellValue 写回
				复习一次：复习次数 +1，若原掌握状态为「未学习」则同时设为「学习中」，SetCellValue 更新
				查看详情：模态展示关联识物记录的完整学习卡片 + 音频播放器 + 分类/掌握/收藏/复习次数
				编辑：当前行=该卡片行号，GetCellValue 逐字段填充；关联识别标题的可选值来源 GetTableCSV 识物记录 [识别标题,物体名称,英文单词]；修改后 SetCellValue 逐字段更新，禁止 SubmitRecord
				删除：DeleteRecord，数据源:单词本/默认表格,payload:行号.toString()
		「加入单词本」/「从识物加入」表单
			表单标题:加入单词本,表:单词本,字段:[{字段名:识别标题,类型:关联表,关联表名:识物记录,关联字段名:识别标题},{字段名:分类,类型:单选项,可选项:生活用品,食物饮品,动物植物,交通出行,自然景观,电子产品,人体部位,其他},{字段名:掌握状态,类型:单选项,可选项:未学习,学习中,已掌握},{字段名:是否收藏,类型:布尔},{字段名:加入时间,类型:日期时间},{字段名:复习次数,类型:数值},{字段名:单词发音,类型:指令流,指令类型:输出音频,指令描述:{{识物记录.英文单词}}. {{识物记录.中文释义}}. {{识物记录.英文例句}},音色:精英青年}]
				识别标题的可选值来源:
					API名称:GetTableCSV,数据源:识物记录/默认表格,字段:[识别标题,物体名称,英文单词]
				单词发音不是用户手工填写，SubmitRecord 后由后台 AI 异步生成
				掌握状态默认「未学习」，是否收藏默认「否」，复习次数默认 0，加入时间默认当前日期时间
				使用 SubmitRecord 提交，提交后当前行是 1
				提交后轮询指令流字段「单词发音」直到生成结束，等待消息：正在录制精英青年音色的单词发音…
					轮询标题:加入单词本,表:单词本,字段:单词发音,输出到:发音播放器
				生成结束后 GetCellValue 取单词发音并显示播放按钮
		单词本页下部增加「闪卡复习」条：筛选当前分类或「学习中」的卡片，大字号展示英文单词（可先隐藏释义），按钮「显示释义」「我会了」（掌握状态设为已掌握并复习次数+1）「再巩固」（掌握状态设为学习中并复习次数+1）
	各页面使用统一的镜头单词主题，闪卡与统计卡片具有悬停上浮和金色描边；首页最近列表点击查看详情；列表一律优先卡片形式。操作按钮对应的功能必须都实现。
	字段名必须是表定义中出现过的字段名，禁止编造 ID 类字段。创建日期字段及自动编号的 ID 类字段在主体列表上不显示，在表单上要包含但要隐藏；本应用表定义无 ID 类字段，不要自行添加。主体列表展示字段及对应 GetTableCSV 字段必须和表单字段一致，以便点选后编辑。指令流字段禁止用户手工填写正文。布尔类型字段值用「是」或「否」。当前行初始为 0，SubmitRecord 后当前行为 1。修改已有记录只能 SetCellValue，不能再 SubmitRecord。
