# 化学可视化工坊
	这是一个化学可视化网页应用，将化学题目与过程转化为中文交互式页面，支持分子结构、化学平衡、电化学等演示。包含首页、创建可视化、可视化库三个页面。不需要用户登录页面。页面统一采用深青实验室主题：背景为深蓝青径向渐变（#06141f → #0c2a3a），点缀极淡的分子轨道网格与玻璃器皿高光；导航栏深靛青半透明毛玻璃；主色氰蓝 #2ec4b6，辅色焰色琥珀 #f4a261、锂红 #e76f51、钾紫 #9b5de5；卡片为半透明玻璃拟态，圆角 16px，悬停时边框氰蓝辉光并轻微上浮；标题使用有科技感的无衬线字体，正文使用柔和中文无衬线；按钮有化学反应式闪光的悬停效果。不同可视化类型使用焰色配色徽章：分子结构3D蓝紫、氧化还原过程橙红、化学平衡青绿、电化学琥珀、工艺流程钢蓝、有机分子3D粉紫、晶胞结构青白、实验装置棕铜、离子平衡电青。
	页面顶部导航栏，使用深靛青毛玻璃背景
		左侧显示Logo（圆底烧瓶+苯环图标）和「化学可视化工坊」
		右侧显示标签：首页、创建可视化、可视化库
		当前页标签底部有氰蓝下划线
	首页
		主标题：化学可视化工坊
		说明：把题目与化学过程变成可探索的交互页面，观察分子、平衡与电极如何随参数变化
		主按钮：开始创建可视化，点击跳转到「创建可视化」页面
		次按钮：进入可视化库，点击跳转到「可视化库」页面
		接下来是并列的三个统计卡片（各有不同焰色描边）
			可视化总数卡片显示全部记录数量
				API名称:GetRecordCount,数据源:化学可视化/默认表格
			类型覆盖数卡片显示已出现过的可视化类型种数
				API名称:GetTableCSV,数据源:化学可视化/默认表格,字段:[可视化类型]
				对可视化类型去重后计数
			引导教学数卡片显示教学场景为「引导」的记录数量
				API名称:GetTableCSV,数据源:化学可视化/默认表格,字段:[教学场景]
				筛选教学场景为「引导」的记录计算数量
		接下来是可视化类型速览：九个可点击小卡片，对应可选项 分子结构3D、氧化还原过程、化学平衡、电化学、工艺流程、有机分子3D、晶胞结构、实验装置、离子平衡，每张显示类型名与该类型数量
			API名称:GetTableCSV,数据源:化学可视化/默认表格,字段:[可视化类型]
			按类型分组统计；点击某类型跳转「可视化库」并自动按该类型筛选
		接下来是最近可视化列表：以卡片形式显示最近 6 条，每张卡片显示可视化类型徽章、教学场景徽章、题目数据摘要（前 80 字）、展示重点摘要（前 40 字）
			API名称:GetTableCSV,数据源:化学可视化/默认表格,字段:[题目数据,可视化类型,展示重点,教学场景]
			列表倒序视为最近记录，取前 6 条
			点击卡片查看详情：当前行设为该行行号，用 GetCellValue 逐字段读取 题目数据、可视化类型、展示重点、教学场景、可视化文件，弹出详情模态
				详情模态左侧显示四个字段的完整内容（题目数据与展示重点用 Markdown 主题渲染），右侧用 iframe 打开可视化
				可视化文件的单元格值是全局文件名，iframe 地址为 https://www.ithomeair.com:3031/private/全局文件名
				若可视化文件为空，右侧显示「可视化仍在生成或尚未生成」
				模态内按钮：在库中打开（跳转可视化库并定位该行）、重新编辑（跳转创建可视化并载入该行到表单）
	「创建可视化」页面
		左上显示大标题：创建可视化
		说明：填写题目或过程，选择类型与教学场景，生成可独立打开的交互式 HTML
		右上按钮：查看可视化库，点击跳转到「可视化库」页面
		页面左右分栏（窄屏上下堆叠）
		左侧为表单工作台
			表单标题:化学可视化,表:化学可视化,字段:[{字段名:题目数据,类型:文本},{字段名:可视化类型,类型:单选项,可选项:分子结构3D,氧化还原过程,化学平衡,电化学,工艺流程,有机分子3D,晶胞结构,实验装置,离子平衡},{字段名:展示重点,类型:文本},{字段名:教学场景,类型:单选项,可选项:拆解,解题,多解,引导}]
			题目数据使用多行文本框，占位提示：可粘贴题目、化学过程、分子 SMILES、反应方程式、平衡常数、电极材料、工艺流程或晶胞参数
			可视化类型使用单选卡片组（带类型焰色徽章），必须实现选择
			展示重点使用多行文本框，占位提示：例如键角变化、平衡移动方向、电极电位实时值、晶胞堆垛方式
			教学场景使用单选胶囊：拆解、解题、多解、引导，必须实现选择
			表单不含可视化文件（指令流字段由后台异步生成，禁止用户手工填写）
			禁止编造表定义中不存在的 ID、创建日期等字段
			当前行初始为 0
			按钮：生成可视化，仅当题目数据非空且已选择可视化类型、教学场景时启用
				点击后使用 SubmitRecord 提交，data为「化学可视化」，payload为表单 JSON 文本，字段仅包含 题目数据、可视化类型、展示重点、教学场景
				提交后当前行是 1
			按钮：保存修改，仅当当前行>=1 时启用
				修改表单不得使用 SubmitRecord，须依次调用 SetCellValue 更新当前行的 题目数据、可视化类型、展示重点、教学场景
				API名称:SetCellValue,数据源:化学可视化/默认表格,payload:字段名/行/值
			按钮：清空表单，清空四个输入并把当前行设为 0，右侧预览恢复占位
			按钮：重新生成，仅当当前行>=1 时启用
				用当前表单值再次 SubmitRecord 生成新记录，提交后当前行是 1，并重新进入轮询
		右侧为演示台
			未提交时显示占位：空烧瓶插画与「填写左侧表单并生成，交互页面将在此打开」
			提交后进入轮询等待后台 AI 异步生成结束
				因指令描述未要求以 JSON 格式输出，轮询该指令流字段本身
				轮询标题:化学可视化,表:化学可视化,字段:可视化文件,输出到:可视化预览,等待消息:分子正在排列，正在生成交互式可视化…
				轮询调用 GetCellValue，数据源:化学可视化/默认表格，payload:可视化文件/当前行
				单元格为空或仍在生成时保持等待动画（三颗分子轨道圆点跳动）
				生成结束后：可视化文件的文本是全局文件名
					可视化预览区用 iframe 打开 https://www.ithinkair.com:3031/private/全局文件名
					iframe 高度至少 70vh，圆角卡片包裹，支持响应式宽度
					预览区右上角按钮组必须全部实现：
						新窗口打开：访问 https://www.ithinkair.com:3031/private/全局文件名
						下载 HTML：访问 https://www.ithinkair.com:3031/download/全局文件名
						刷新预览：再次 GetCellValue 后重载 iframe
			指令流详情：GetCellValue 取到的文本若需展示，使用 Markdown 主题渲染；HTML 文件本身只在 iframe 中打开，不把源码当正文
		API名称:GetCellValue,数据源:化学可视化/默认表格,字段名:题目数据,行号:当前行
		API名称:GetCellValue,数据源:化学可视化/默认表格,字段名:可视化类型,行号:当前行
		API名称:GetCellValue,数据源:化学可视化/默认表格,字段名:展示重点,行号:当前行
		API名称:GetCellValue,数据源:化学可视化/默认表格,字段名:教学场景,行号:当前行
		API名称:GetCellValue,数据源:化学可视化/默认表格,字段名:可视化文件,行号:当前行
		API名称:GetRecordCount,数据源:化学可视化/默认表格
		演示台标题右侧放置浏览按钮 < 和 >
			按钮 < ：当前行减 1 后用 GetCellValue 回填表单四字段并刷新预览
			按钮 > ：当前行加 1 后用 GetCellValue 回填表单四字段并刷新预览
			当前行初始是 0
			当前行<=1 时 < 不可操作
			当前行>=RecordCount 时 > 不可操作
			当前行为 0 时两个按钮都不可操作，表单保持可新建状态
	「可视化库」页面
		左上显示大标题：可视化库
		说明：以卡片浏览、筛选并管理全部化学可视化
		右上按钮：+ 新建可视化，点击跳转「创建可视化」并清空表单、当前行设为 0
		搜索框：按题目数据或展示重点关键词过滤
		筛选器：按可视化类型筛选（含全部）、按教学场景筛选（含全部）
		排序：默认按表格行号降序（新记录在前），可切换为按可视化类型分组
		主体列表必须用卡片形式，不要用拥挤的纯表格作为唯一视图
			API名称:GetTableCSV,数据源:化学可视化/默认表格,字段:[题目数据,可视化类型,展示重点,教学场景]
			主体展示字段必须与表单字段一致，以便点击卡片进入编辑
			每张卡片显示：可视化类型焰色徽章、教学场景胶囊、题目数据前 100 字、展示重点前 50 字
			每张卡片有操作按钮，功能必须全部实现：
				预览：当前行=该卡片行号，GetCellValue 读取可视化文件，弹出全屏模态，iframe 打开 https://www.ithinkair.com:3031/private/全局文件名；文件名为空时提示尚未生成
				编辑：当前行=该卡片行号，跳转「创建可视化」，逐字段 GetCellValue 填充表单（题目数据、可视化类型、展示重点、教学场景），并同时加载可视化预览
				删除：调用 DeleteRecord，data:化学可视化/默认表格，payload:行号.toString()，删除前二次确认，成功后刷新卡片列表与首页统计
				下载：GetCellValue 取可视化文件全局文件名，访问 https://www.ithinkair.com:3031/download/全局文件名
			点击卡片空白区域等同于预览
		页面底部固定一条详情抽屉（未选中时收起）：选中某卡片后展开，用 Markdown 主题显示题目数据与展示重点全文，并内嵌较矮的 iframe 预览
			API名称:GetCellValue,数据源:化学可视化/默认表格,payload:字段名/行
			行号从 1 开始计数
		如需定位某条记录，可使用
			API名称:GetRecordRow,数据源:化学可视化/默认表格,payload:字段名/值
		GetTableCSV 返回不含标题行的 csv 文本；逗号分隔的字段名必须是表「化学可视化」中已定义字段
	各页面使用统一的深青实验室主题，卡片与按钮具有焰色悬停辉光，列表以卡片呈现，首页最近列表点击即看详情。操作按钮对应的功能必须全部实现。字段名只使用表定义中的：题目数据、可视化类型、展示重点、教学场景、可视化文件。不编造 ID 或创建日期字段。指令流字段可视化文件禁止手工填写，仅在 SubmitRecord 之后轮询 GetCellValue 获取全局文件名，并在 iframe 中打开 private 链接。
