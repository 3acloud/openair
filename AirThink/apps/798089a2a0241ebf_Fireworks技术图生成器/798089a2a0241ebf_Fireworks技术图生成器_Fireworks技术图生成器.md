# Fireworks技术图生成器
	这是一个专业技术图智能生成网页应用，包含首页、立即生成、图库管理三个页面。页面统一采用深空蓝紫科技主题：背景为 #0B1020 到 #1A1040 的径向渐变，点缀细微粒子光斑与轻微网格线；主色为电光青 #00E5FF 与焰紫 #A855F7，辅色为暖焰橙 #FF8A3D；卡片采用半透明玻璃拟态（backdrop-blur + 1px 亮边），按钮有霓虹描边与悬停发光；字体为现代无衬线，标题略加字距。整体风格专业、克制、可交付感强，像一座「技术图烟火工坊」。

	页面顶部导航栏（固定）
		左侧：Logo（抽象烟花绽放 + 节点连线图标）+ 应用名「Fireworks技术图生成器」
		右侧标签：首页、立即生成、图库管理
		导航栏背景半透明深色，底部 1px 电光青渐变线

	首页
		主标题：Fireworks 技术图生成器
		副标题：根据技术主题、图表类型与视觉风格，智能生成可交付的专业技术图文件
		主操作按钮： 立即生成技术图 → 跳转「立即生成」页面
		次要按钮： 打开图库 → 跳转「图库管理」页面

		统计区（三列卡片，等高，悬停轻微上浮与霓虹边）
			总生成数
				API名称:GetRecordCount,数据源:技术图生成/默认表格
			本周生成数
				API名称:GetTableCSV,数据源:技术图生成/默认表格,字段:[图表类型,视觉风格,输出格式]
				（若无时间字段则用总记录近似展示，或按当前会话新增计数；界面标注「近期」）
			格式分布速览
				API名称:GetTableCSV,数据源:技术图生成/默认表格,字段:[输出格式]
				按 SVG / PNG / GIF / 离线交互HTML 分组计数，以小胶囊标签展示

		图表类型热力条（横向胶囊）
			API名称:GetTableCSV,数据源:技术图生成/默认表格,字段:[图表类型]
			统计各类型出现次数，按次数排序展示前 8 个类型胶囊

		最近生成（卡片列表，最多 6 条）
			标题：最近生成
			API名称:GetTableCSV,数据源:技术图生成/默认表格,字段:[技术内容,图表类型,视觉风格,输出格式,技术图文件]
			按记录倒序取前 6 条；列表用卡片形式
			每张卡片显示：
				- 图表类型徽章 + 视觉风格徽章 + 输出格式徽章
				- 技术内容摘要（前 80 字，超出省略）
				- 预览区：
					先 GetCellValue 取「技术图文件」全局文件名
					若输出格式为 SVG/PNG/GIF：用 https://www.ithinkair.com:3031/download/全局文件名 作缩略图
					若输出格式为 离线交互HTML：显示 HTML 图标占位 +「交互预览」字样
				- 底部操作：查看详情、再次生成（带参跳转立即生成并预填）、下载
			点击整卡进入详情抽屉/模态（见通用详情）

	「立即生成」页面
		左上大标题：立即生成
		说明：填写技术内容，选择图表类型、视觉风格与输出格式，一键生成可交付文件
		右上按钮：图库管理（跳转）

		布局为左右分栏（大屏）/ 上下堆叠（小屏）
		左侧：生成表单卡片
			表单标题:技术图生成,表:技术图生成,字段:[{字段名:技术内容,类型:文本},{字段名:图表类型,类型:单选项,可选项:架构图,数据流图,流程图,智能体架构图,记忆架构图,时序图,对比矩阵,时间线,概念图,UML类图,用例图,状态机图,ER图,网络拓扑图},{字段名:视觉风格,类型:单选项,可选项:扁平图标,暗色终端,蓝图,Notion简洁,玻璃拟态,Claude官方,OpenAI官方,暗黑奢华,C4评审画布,云架构织网,事件地铁图,运维脉冲},{字段名:输出格式,类型:单选项,可选项:SVG,PNG,GIF,离线交互HTML},{字段名:技术图文件,类型:指令流}]
			表单展示规则：
				- 技术内容：大号多行文本域，占位符示例「描述一个多 Agent 协作系统：Router Agent 分发任务，Research Agent 检索，Writer Agent 汇总；含短期记忆与向量长期记忆…」
				- 图表类型：单选网格（图标+名称），必选
				- 视觉风格：单选卡片组（每项显示风格名+一句话气质说明），必选
				- 输出格式：分段控件 SVG | PNG | GIF | 离线交互HTML，必选
				- 技术图文件：不在表单中手工填写（指令流）
			快捷灵感条（点击填入技术内容并选中推荐类型/风格，可改）：
				-「微服务订单链路」→ 推荐 时序图 + 云架构织网
				-「RAG 记忆架构」→ 推荐 记忆架构图 + 暗色终端
				-「Agent 编排」→ 推荐 智能体架构图 + Claude官方
				-「核心域 ER」→ 推荐 ER图 + Notion简洁
			主按钮： 生成技术图
				校验：技术内容非空且三类选项已选
				使用 SubmitRecord 提交，表单数据 JSON 包含：技术内容、图表类型、视觉风格、输出格式
				提交后当前行=1
				按钮进入 loading，文案变为「烟火装填中…」

		右侧：生成结果面板（默认空态插画：未燃放的烟花筒 +「等待一次绽放」）
			提交后进入轮询等待：
				轮询标题:技术图生成,表:技术图生成,字段:技术图文件,输出到:结果面板,等待消息:技术图生成中，正在绘制节点与连线…
				因指令描述未要求“以JSON格式输出”，轮询「技术图文件」字段
				API名称:GetCellValue,数据源:技术图生成/默认表格,payload:技术图文件/当前行
				轮询间隔约 1.5s，直到拿到非空全局文件名
			生成成功后结果面板展示：
				- 顶部信息条：图表类型 · 视觉风格 · 输出格式
				- 技术内容全文（可折叠）
				- 预览区：
					输出格式=SVG/PNG/GIF：<img> 使用 https://www.ithinkair.com:3031/download/全局文件名 （SVG 可再提供「原清晰度」）
					输出格式=离线交互HTML：iframe 打开 https://www.ithinkair.com:3031/private/全局文件名
				- 操作按钮组：
					下载文件：跳转 https://www.ithinkair.com:3031/download/全局文件名
					新窗口打开：https://www.ithinkair.com:3031/private/全局文件名
					复制下载链接
					再次编辑（保留字段，当前行保持，可改后用 SetCellValue 更新非指令流字段；若需重新生成则再次 SubmitRecord 新纪录）
					生成同款变体（复制当前表单值，轻微提示用户可改风格/类型后再次提交）
			失败/超时：展示重试按钮（重新 SubmitRecord）与「返回修改」


	「图库管理」页面
		左上大标题：图库管理
		说明：浏览、检索、预览与导出全部已生成技术图
		右上按钮：+ 新建技术图 → 跳转「立即生成」并清空表单（当前行=0）

		工具条
			搜索框：按技术内容关键词过滤（前端过滤 GetTableCSV 文本）
			筛选器：
				图表类型（多选胶囊，选项同表定义）
				视觉风格（多选胶囊）
				输出格式（多选：SVG/PNG/GIF/离线交互HTML）
			排序：默认最新在前；支持按图表类型名、输出格式排序

		主体：卡片瀑布/网格（优先卡片形式，不要呆板大表）
			API名称:GetTableCSV,数据源:技术图生成/默认表格,字段:[技术内容,图表类型,视觉风格,输出格式,技术图文件]
			主体表格/卡片展示字段与表单一致，便于点选进入编辑/详情
			每张卡片：
				徽章行：图表类型、视觉风格、输出格式
				技术内容摘要（前 100 字）
				缩略预览（同首页规则；HTML 显示占位封面）
				操作：查看详情、编辑、下载、删除
					查看详情：打开通用详情
					编辑：当前行=行号；用 GetCellValue 逐字段回填表单（技术内容、图表类型、视觉风格、输出格式）；技术图文件只读展示；保存时对非指令流字段逐个 SetCellValue（payload:字段名/行/值）；若用户点击「重新生成文件」则再次走 SubmitRecord 新建记录并轮询
					删除：callAppBridge({type:"DeleteRecord", data:"技术图生成/默认表格", payload:行号.toString()})，成功后刷新列表
					下载：https://www.ithinkair.com:3031/download/全局文件名
			空态：尚无技术图，引导按钮「生成第一张图」

	通用详情（抽屉或模态，首页卡片与图库共用）
		标题：技术图详情
		字段展示：
			技术内容（Markdown 主题渲染，便于代码块/列表）
			图表类型、视觉风格、输出格式（徽章）
			技术图文件：
				API名称:GetCellValue,数据源:技术图生成/默认表格,payload:技术图文件/行号
				文本内容若为说明性 Markdown 则用 Markdown 主题显示；若为全局文件名则按格式预览
				SVG/PNG/GIF：大图预览 + 下载
				离线交互HTML：iframe（https://www.ithinkair.com:3031/private/全局文件名）+ 下载 + 新窗口
		底部：关闭、下载、在「立即生成」中基于此新建

	数据与交互硬性规则
		字段名只能使用表定义中的：技术内容、图表类型、视觉风格、输出格式、技术图文件；不编造 ID/创建日期等字段
		新建：SubmitRecord，提交后当前行=1；指令流后台异步生成，必须轮询「技术图文件」
		修改已有记录：禁止用 SubmitRecord 覆盖；对可写字段依次 SetCellValue
		读取列表：GetTableCSV；读单元格：GetCellValue；写单元格：SetCellValue；计数：GetRecordCount；删行：DeleteRecord（行号 toString）
		布尔值若出现用「是/否」（本表无布尔字段）
		全局文件名图片/文件链接：
			下载导出：https://www.ithinkair.com:3031/download/全局文件名
			浏览器打开/HTML iframe：https://www.ithinkair.com:3031/private/全局文件名
		当前行初始为 0；提交成功后为 1 或列表点选行号
		首页若出现最近列表，点击进入详情
		所有操作按钮（生成、轮询展示、下载、打开、编辑、删除、筛选、搜索、再次生成、导航跳转）必须实现完整可用
		表格/卡片支持按最新记录优先；卡片悬停发光，点击可展开详情
		不需要用户登录页面
		页面响应式：导航在移动端收为汉堡菜单；生成页小屏改为上下结构；卡片单列

	文案与微交互彩蛋（增强创意，不影响功能）
		生成中随机等待文案池：「点燃导火索…」「校准锚点与正交线…」「给架构图洒上星尘…」「压缩像素烟花…」
		成功toast：「绽放完成，已可交付」
		删除确认：「确认熄灭这张技术图？此操作不可恢复」
