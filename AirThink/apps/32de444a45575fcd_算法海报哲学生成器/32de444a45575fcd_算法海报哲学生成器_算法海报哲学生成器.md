# 算法海报哲学生成器
	这是一个极简主义风格的网页应用，包含首页、创作海报、海报画廊三个页面。
	页面整体采用黑白灰极简设计，大面积留白，强调排版与字体，按钮无边框或纯黑底白字，体现现代设计哲学。
	页面顶部导航栏，使用纯白背景与黑灰底部边框
		左侧显示应用名称：算法海报哲学生成器
		右侧显示标签：首页、创作海报、海报画廊
	首页
		主标题：算法海报哲学生成器，说明：输入主题与文案，基于视觉约束自动生成系统化设计哲学与极简 SVG 海报。
		中央大按钮：开始创作，点击跳转到‘创作海报’页面。
		接下来是数据统计区，包含两个极简数据卡片：
			总生成数量卡片，显示已生成的海报总数
				API名称:GetRecordCount,数据源:海报生成/默认表格
			视觉流派统计卡片，显示最新使用的视觉取向
				API名称:GetTableCSV,数据源:海报生成/默认表格,字段:[视觉取向]
				展示最近一条记录的视觉取向字段值，若无则显示“暂无”。
		接下来是最近作品集：显示最近 3 条记录，以极简卡片排布。
			API名称:GetTableCSV,数据源:海报生成/默认表格,字段:[主题,视觉取向,背景倾向]
			按行号降序排列（假定最新生成的在最后，倒序显示3条），卡片上展示对应字段内容。
	‘创作海报’页面
		左上显示大标题：创作海报，说明：设定关键信息，等待算法设计师的思考与生成。
		页面主体分为左右两栏（或上下布局）。
		左侧为配置表单：
			表单标题:海报生成,表:海报生成,字段:[{字段名:主题,类型:文本},{字段名:核心文案,类型:文本},{字段名:辅助信息,类型:文本},{字段名:视觉取向,类型:单选项,可选项:[极简,品牌视觉,作品集封面,AI生成艺术,排版系统]},{字段名:背景倾向,类型:单选项,可选项:[白色,近黑]}]
			表单底部按钮：生成海报。
			提交表单时，调用SubmitRecord，提交完成后当前行为1。
		右侧为生成结果预览：
			提交后开始轮询，轮询标题:海报生成,表:海报生成,字段:海报,输出到:海报预览区,等待消息:“哲学家与算法设计师正在思考排版与生成...”
			因指令未指定JSON输出，需直接轮询‘海报’字段。
			生成结果包含文本和极简SVG，获取到内容后必须使用 Markdown 主题格式在右侧预览区完整渲染显示。
	‘海报画廊’页面
		左上显示大标题：海报画廊，说明：所有过往生成的设计哲学与海报归档。
		右上是按钮：+ 新建创作，点击跳转到‘创作海报’页面。
		主体是网格布局的记录列表卡片：
			API名称:GetTableCSV,数据源:海报生成/默认表格,字段:[主题,核心文案,视觉取向,背景倾向]
			每张卡片显示：主题、核心文案（截取前30个字）、视觉取向、背景倾向。
			每张卡片有操作按钮：查看海报、删除记录。
			点击“查看海报”弹出模态详情框：
				调用 API名称:GetCellValue,数据源:海报生成/默认表格,字段名:海报,行号:当前卡片对应行号
				在详情模态框中，使用 Markdown 格式渲染该‘海报’指令流字段的详细文本与 SVG 内容。
			点击“删除记录”：
				调用 API名称:DeleteRecord,数据源:海报生成/默认表格,payload:行号.toString()
				删除成功后刷新当前列表。
	各页面操作按钮对应的功能必须要都实现。UI交互需流畅，卡片悬停时有轻微的阴影渐现效果。页面不含任何用户登录功能。只读的系统不需要显示无用元素。
