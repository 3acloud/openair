# 调研转图谱
	这是一个知识星图网页应用：围绕研究主题自动开展网络调研，梳理关键实体与关系，选择调研深度与图谱布局，生成含可选参考资料的PDF图谱。包含首页、发起调研、图谱库三个页面。不需要用户登录页面。
	统一主题：深空墨蓝到靛蓝的径向渐变背景，叠加极淡的节点连线网格；主色为电青 #22D3EE，辅色为琥珀金 #F5B942，文字为浅雾白；卡片为半透明玻璃拟态（毛玻璃、细青边、柔光阴影），悬停时边框发光并轻微上浮；按钮为电青渐变胶囊，危险操作为琥珀描边。字体为优雅无衬线。全站卡片、表格行、筛选芯片均需悬停动效。操作按钮对应的功能必须要都实现。当前行初始为0。列表采用卡片形式。
	页面顶部导航栏，使用深空蓝半透明背景并带底部电青细线
		左侧显示Logo（六节点星图图标）和「调研转图谱」
		右侧显示标签：首页、发起调研、图谱库；当前页高亮为电青下划线
	首页
		主标题：调研转图谱，副标题：把一次网络调研，收成一张层次清晰的知识星图
		说明：输入研究主题，选择可视化工具、布局方向与调研深度，后台自动收集核实信息、提取实体与关系，输出不超过50个节点的中文PDF图谱；可选择是否在同一PDF中追加主题说明与参考资料链接
		中央大按钮：开始一次调研，点击跳转到「发起调研」页面
		接下来是并列的四个统计卡片
			图谱总数
				API名称:GetRecordCount,数据源:调研图谱/默认表格
			深度调研数
				API名称:GetTableCSV,数据源:调研图谱/默认表格,字段:[调研深度]
				筛选调研深度为deep的记录计算数量
			含参考资料数
				API名称:GetTableCSV,数据源:调研图谱/默认表格,字段:[附参考资料]
				筛选附参考资料为「是」的记录计算数量
			可视化工具分布
				API名称:GetTableCSV,数据源:调研图谱/默认表格,字段:[可视化工具]
				按graphviz、plantuml、mermaid分组统计数量，以三枚小徽章展示
		接下来是最近调研卡片墙：显示最近6条，以卡片形式展示研究主题、可视化工具、布局方向、调研深度、是否附参考资料
			API名称:GetTableCSV,数据源:调研图谱/默认表格,字段:[研究主题,可视化工具,布局方向,调研深度,附参考资料,图谱文件]
			按记录倒序取前6条
			每张卡片顶部用不同颜色的深度徽章（quick青、medium金、deep靛），中部显示研究主题（最多两行），下部显示工具与布局芯片；附参考资料为「是」时显示书卷小标
			点击最近列表卡片进入详情：当前行=对应行号，调用GetCellValue逐字段读取并打开详情抽屉（见图谱库详情交互）
	「发起调研」页面
		左上显示大标题：发起调研，说明：填写主题与参数，提交后由任务智能体异步生成唯一PDF图谱
		右上是按钮：查看图谱库，点击跳转到「图谱库」页面
		左侧为参数编排区（占约4成宽），右侧为生成预览区（占约6成宽）
		表单标题:调研图谱,表:调研图谱,字段:[{字段名:研究主题,类型:文本},{字段名:可视化工具,类型:单选项,可选项:graphviz,plantuml,mermaid},{字段名:布局方向,类型:单选项,可选项:TB,LR,BT,RL},{字段名:调研深度,类型:单选项,可选项:quick,medium,deep},{字段名:附参考资料,类型:布尔},{字段名:图谱文件,类型:指令流}]
			字段名必须使用表定义中的字段名，不得编造ID或创建日期等字段
			研究主题：多行文本，占位符「例如：量子纠缠在量子通信中的应用」
			可视化工具：分段选择器，展示名 graphviz / plantuml / mermaid，未选择时默认 graphviz
			布局方向：四宫格选择，展示名 自上而下(TB)、自左向右(LR)、自下而上(BT)、自右向左(RL)，提交值仍为 TB/LR/BT/RL，未选择时默认 TB
			调研深度：三段选择，展示名 快速(quick)、标准(medium)、深度(deep)，未选择时默认 deep；下方用一行小字解释：quick侧重主干、medium补充分支、deep尽量核实来源
			附参考资料：开关，开为「是」、关为「否」，默认「否」
			图谱文件为指令流，不是用户手工填写；表单上不提供输入框
		主操作按钮：生成图谱，仅当研究主题非空时启用
			点击使用SubmitRecord提交记录，表单数据是json文本
			API名称:SubmitRecord,数据源:调研图谱,payload:表单json
			提交字段仅包含：研究主题、可视化工具、布局方向、调研深度、附参考资料（布尔用「是」或「否」）
			提交后当前行是1
		提交后进入等待态：右侧预览区显示星图脉冲动画与等待文案「正在围绕主题开展网络调研，梳理实体、分类与关系…」
			因表单包含指令流字段，SubmitRecord后必须轮询等待后台AI异步生成结束
			指令描述未指定「以JSON格式输出」，因此轮询该指令流字段本身
			轮询标题:调研图谱,表:调研图谱,字段:图谱文件
			API名称:GetCellValue,数据源:调研图谱/默认表格,payload:图谱文件/当前行
			每隔约2秒轮询一次，直到返回非空的全局文件名
			等待过程中禁用「生成图谱」按钮，提供「取消等待」仅停止轮询不删除记录
		生成结束后，右侧预览区展示结果
			图谱文件的文本是文件的全局文件名
			在iframe中打开：https://www.ithinkair.com:3031/private/全局文件名
			提供按钮：在浏览器打开（同上private链接）、下载PDF（https://www.ithinkair.com:3031/download/全局文件名）
			指令流详情同时用GetCellValue获取，文本内容若存在则用Markdown主题显示在PDF下方的「生成说明」折叠面板中
		预览区顶部显示本次参数摘要芯片：主题截断、工具、布局、深度、是否附参考资料
		右下新建按钮标题：+ 再调研一次，点击清空表单与预览、当前行设为0，参数恢复默认 graphviz / TB / deep / 否
	「图谱库」页面
		左上显示大标题：图谱库，说明：浏览、打开、下载与管理全部调研图谱
		右上是按钮：+ 发起调研，点击跳转到「发起调研」页面
		搜索框：按研究主题模糊搜索
		筛选器芯片：可视化工具（全部/graphviz/plantuml/mermaid）、布局方向（全部/TB/LR/BT/RL）、调研深度（全部/quick/medium/deep）、附参考资料（全部/是/否）
		排序：默认最新在前；可切换按研究主题
		主体以卡片网格展示，不使用单独只读页
			API名称:GetTableCSV,数据源:调研图谱/默认表格,字段:[研究主题,可视化工具,布局方向,调研深度,附参考资料,图谱文件]
			GetTableCSV获取的是不包含标题行的csv文本；文件字段的文本是文件的全局文件名
			主体展示字段必须与表单字段一致，以便点击单行/单卡进入编辑
			每张卡片显示：研究主题、可视化工具、布局方向、调研深度、附参考资料、图谱文件状态（有全局文件名显示「PDF已生成」，否则显示「生成中/缺失」）
			每张卡片操作按钮：查看详情、打开PDF、下载PDF、编辑、删除；功能必须全部实现
				查看详情：当前行=行号，对每个字段调用GetCellValue获取单元格详情
					API名称:GetCellValue,数据源:调研图谱/默认表格,payload:字段名/行
					详情以右侧抽屉展示，指令流文本用Markdown主题显示；PDF用iframe加载 private 链接
				打开PDF：若图谱文件非空，访问 https://www.ithinkair.com:3031/private/全局文件名
				下载PDF：若图谱文件非空，访问 https://www.ithinkair.com:3031/download/全局文件名
				编辑：当前行=行号，用GetCellValue逐字段填充表单（研究主题、可视化工具、布局方向、调研深度、附参考资料）；图谱文件只读展示
					修改表单不得使用SubmitRecord，须依次SetCellValue写回当前记录行各可编辑字段
					API名称:SetCellValue,数据源:调研图谱/默认表格,payload:字段名/行/值
					布尔值仍用「是」或「否」
					保存后刷新卡片数据
				删除：二次确认后调用DeleteRecord
					API名称:DeleteRecord,数据源:调研图谱/默认表格,payload:行号.toString()
					payload必须是文本，行号从1开始计数，需要toString()再传
		详情抽屉底部提供记录翻页
			API名称:GetRecordCount,数据源:调研图谱/默认表格
			按钮标题:< 与 >，点击读取上一行/下一行各字段，数据来源于GetCellValue
			当前行<=1时<不可操作；当前行>=RecordCount时>不可操作
		空状态：尚无图谱时展示星图插画与按钮「发起第一次调研」
	数据与交互总则
		所有表格操作均通过callAppBridge：GetTableCSV、SubmitRecord、GetRecordCount、GetRecordRow、DeleteRecord、GetCellBullet、GetCellValue、SetCellValue，参数形态遵循说明
		GetTableCSV的逗号分隔字段名必须是「调研图谱」表中已定义字段
		查看字段详情用GetCellValue；新建用SubmitRecord（提交后当前行是1）；修改用SetCellValue而不是SubmitRecord
		指令流字段由后台AI在SubmitRecord后异步生成；展示其详情前先GetCellValue
		不要出现登录页；不要在主体列表中发明或显示ID类、创建日期类字段
		点击首页最近卡片或图谱库卡片均可进入同一套详情/编辑体验
		全站生成中、空数据、PDF缺失、删除确认均需有明确状态反馈
