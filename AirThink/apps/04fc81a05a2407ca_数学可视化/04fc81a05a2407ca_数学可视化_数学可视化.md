# 看见数学
	这是一个数学可视化网页应用，将数学题目转化为可拖拽、可调节的交互式可视化页面，覆盖几何、函数、动点等问题，帮助学生看见数学。包含首页、创建可视化、可视化工坊三个页面。不需要用户登录。
	页面统一采用“午夜坐标纸”主题：深靛蓝到午夜蓝渐变背景，叠加极淡的坐标网格与细黄金分割线；主色为靛蓝，强调色为琥珀金与电光青；卡片为半透明玻璃拟态、大圆角、轻阴影，悬停上浮并浮现几何光晕；按钮为琥珀金填充或青色描边；题型以彩色胶囊标签区分（平面几何-蓝、立体几何-紫、函数图像-青、动点问题-橙、解析几何-绿、方程不等式-玫红、向量问题-金）；字体为柔和 sans-serif，标题可点缀细衬线与数学符号装饰。Logo 为圆规与抛物线组合图标。
	页面顶部导航栏，使用深蓝半透明背景，底部一道细琥珀金线
		左侧显示 Logo 和「看见数学」
		右侧显示标签：首页、创建可视化、可视化工坊
	首页
		主标题：看见数学，说明：把题目变成可拖拽、可调节的交互世界，让几何动起来、让函数会呼吸
		中央大按钮：+ 把这道题变成可视化，点击跳转到「创建可视化」页面
		接下来是并列的统计卡片：题目总数、已生成可视化数、题型覆盖数
			题目总数卡片显示全部记录数量
				API名称:GetRecordCount,数据源:可视化题目/默认表格
			已生成可视化数卡片显示可视化文件非空的记录数量
				API名称:GetTableCSV,数据源:可视化题目/默认表格,字段:[题目,题目类型,题目图片]
				再对每行调用 GetCellValue 读取可视化文件，统计有全局文件名的条数
			题型覆盖数卡片显示出现过的题目类型种数
				API名称:GetTableCSV,数据源:可视化题目/默认表格,字段:[题目类型]
				对题目类型去重后计数
		接下来是题型分布条：七个彩色小胶囊，显示各类型数量
			API名称:GetTableCSV,数据源:可视化题目/默认表格,字段:[题目类型]
			按题目类型分组统计
		接下来是最近可视化列表：显示最近 5 条，以卡片形式展示，字段包括：题目类型、题目（摘要前 60 字）、题目图片缩略
			API名称:GetTableCSV,数据源:可视化题目/默认表格,字段:[题目,题目类型,题目图片]
			列表倒序，取前 5 条
			题目图片用全局文件名拼接 https://www.ithinkair.com:3031/download/全局文件名 作为缩略图；无图片时显示对应题型的几何纹样占位
			每张卡片右下显示「打开可视化」按钮
			点击卡片或「打开可视化」进入可视化详情：当前行=对应行号，用 GetCellValue 逐字段读取 题目、题目类型、题目图片、可视化文件，弹出详情层
	「创建可视化」页面
		左上显示大标题：创建可视化，说明：写下题目、选好类型，可选配题目图片，后台将生成可交互的 HTML 数学世界
		右上是按钮：前往工坊，跳转到「可视化工坊」页面
		左侧为题目工作室卡片，右侧为可视化舞台（初始显示虚线几何占位与文案「提交后，这里将上演你的数学」）
		表单标题:可视化题目,表:可视化题目,字段:[{字段名:题目,类型:文本},{字段名:题目类型,类型:单选项,可选项:平面几何,立体几何,函数图像,动点问题,解析几何,方程不等式,向量问题},{字段名:题目图片,类型:图片}]
			不要编造 ID、创建日期等表定义中不存在的字段
			题目：多行文本，占位符如「已知抛物线 y=x 上有动点 P…」
			题目类型：单选胶囊，必填
			题目图片：可选
				按钮：从相册选择，调用 SelectImage 返回图片全局文件名
				按钮：拍摄题目，调用 CapturePhoto 返回图片全局文件名
				已选图片以 https://www.ithinkair.com:3031/download/全局文件名 预览，可清除
		主按钮标题：生成交互可视化，仅当题目与题目类型均已填写时启用，点击提交表单
			使用 SubmitRecord 提交，表单数据是包含 题目、题目类型、题目图片 的 json 文本
			提交后当前行是 1
		提交后开始轮询等待后台异步生成结束
			轮询标题:看见数学,表:可视化题目,字段:可视化文件,输出到:可视化舞台,等待消息:正在把题目绘制成可拖拽的数学世界，请稍候…
			因指令描述未要求以 JSON 格式输出，轮询该「指令流」字段可视化文件
			轮询使用 GetCellValue，数据源:可视化题目/默认表格，字段名:可视化文件，行号:当前行
			生成结束后，可视化文件单元格值为 HTML 的全局文件名
			可视化舞台用 iframe 打开 https://www.ithinkair.com:3031/private/全局文件名
			舞台右上提供「全屏」按钮（iframe 全屏）与「新窗口打开」按钮（访问同一 private 链接）
			同时用 Markdown 主题展示 GetCellValue 读到的可视化文件详情文本
		生成成功后，舞台下方出现按钮：再做一题（清空表单与舞台、当前行设为 0）、在工坊中查看（跳转可视化工坊）
		当前行初始是 0
	「可视化工坊」页面
		左上显示大标题：可视化工坊，说明：浏览、预览和管理所有已生成的数学可视化
		右上是按钮：+ 新建可视化，跳转到「创建可视化」页面
		搜索框，可按题目全文搜索
		筛选器：按题目类型筛选，选项为 全部、平面几何、立体几何、函数图像、动点问题、解析几何、方程不等式、向量问题
		主体以卡片网格展示，不使用普通数据表格作为主视图；卡片字段与表单字段一致，便于点击进入编辑
			API名称:GetTableCSV,数据源:可视化题目/默认表格,字段:[题目,题目类型,题目图片]
			每张卡片显示：题目类型彩色胶囊、题目摘要（前 80 字）、题目图片缩略（https://www.ithinkair.com:3031/download/全局文件名，无图则题型纹样占位）
			每张卡片操作按钮：查看可视化、编辑、删除
				查看可视化：当前行=行号，GetCellValue 读取可视化文件，打开详情层，iframe 加载 https://www.ithinkair.com:3031/private/全局文件名 ；同时展示题目全文、题目类型、题目图片原图
				编辑：当前行=行号，点击行或编辑按钮加载表单，API名称:GetCellValue 逐字段获取 题目、题目类型、题目图片 填充；题目图片可重新 SelectImage 或 CapturePhoto；修改后依次 SetCellValue 更新当前行各字段，数据源:可视化题目/默认表格，payload为 字段名/行/值，不要用 SubmitRecord
				删除：调用 DeleteRecord，数据源:可视化题目/默认表格，payload:行号.toString()，删除后刷新卡片列表
		详情层（首页最近列表与工坊卡片共用）
			左侧：题目类型、题目全文（Markdown）、题目图片
			右侧：可视化 iframe 舞台，HTML 链接为 https://www.ithinkair.com:3031/private/全局文件名
			若可视化文件仍为空，显示「可视化正在生成或尚未生成」并提供返回创建页的入口
			关闭详情不改变导航位置
		编辑表单标题:编辑可视化题目,表:可视化题目,字段:[{字段名:题目,类型:文本},{字段名:题目类型,类型:单选项,可选项:平面几何,立体几何,函数图像,动点问题,解析几何,方程不等式,向量问题},{字段名:题目图片,类型:图片}]
			字段名必须与表定义一致，表单字段与 GetTableCSV 字段一致
	可视化详情中展示指令流内容时，先 GetCellValue 获取可视化文件，文本用 Markdown 主题显示；文件则以 iframe 打开 private 链接。
	各页面使用统一的午夜坐标纸主题，卡片与按钮具备悬停效果。操作按钮对应的功能必须要都实现。当前行初始为 0，SubmitRecord 成功后当前行为 1。
