# 真人IP封面工坊
	这是一个真人IP封面设计网页应用，包含首页、创作工坊、作品库三个页面。整体定位为高端内容创作者的封面设计工作室：深空墨黑底、香槟金描边、品红点缀，纸纹噪点与玻璃拟态卡片，标题用衬线展示体（中文思源宋体 / 英文 Playfair Display），正文用干净无衬线。封面缩略图悬停时轻微上浮并泛出金色光晕。不包含登录页。操作按钮对应的功能必须全部实现。

	页面顶部固定导航栏，背景为半透明深墨黑加 1px 香槟金底边
		左侧显示Logo（金色裁切框中的人像剪影）和『真人IP封面工坊』
		右侧显示标签：首页、创作工坊、作品库
		当前页标签用品红下划线高亮

	首页
		全宽英雄区：左侧主标题『把真人IP做成可发布的高清封面』，说明：提供文章主题与参考素材，选择风格和视觉重点，由 AI 结合真人形象生成教程、产品介绍与经验分享封面
		主按钮：立即开始创作，点击跳转到『创作工坊』页面
		次按钮：浏览作品库，点击跳转到『作品库』页面
		英雄区右侧放三张叠放的示例封面卡片（仅装饰，不读表）
		接下来是并列的三个统计卡片
			总作品数
				API名称:GetRecordCount,数据源:封面设计/默认表格
			真人出镜作品数
				API名称:GetTableCSV,数据源:封面设计/默认表格,字段:[真人使用方式]
				筛选真人使用方式为『使用参考人物』或『原图直接放入或抠图』的记录计算数量
			九种风格覆盖数
				API名称:GetTableCSV,数据源:封面设计/默认表格,字段:[风格]
				统计风格不为空且不为『自动选择』的去重数量，右下角用小字展示『/ 9』
		接下来是『九种封面风格橱窗』：三行三列风格卡片（暖色手绘教程风、产品主视觉风、深色科技爆发风、撕纸拼贴风、编辑杂志风、黑金步骤爆款风、高饱和实测冲击风、手写结果承诺风、产品后台沉浸风），每张卡片含风格名、一句气质说明和色块预览；点击某风格卡片跳转创作工坊并预填风格
		接下来是最近封面：以卡片墙显示最近 6 条作品
			API名称:GetTableCSV,数据源:封面设计/默认表格,字段:[文章标题或主题,风格,视觉重点,真人使用方式,素材文件,封面比例,补充要求]
			封面图通过 GetCellValue 获取该行『封面图片』（指令流，输出为图片全局文件名），图片地址为 https://www.ithinkair.com:3031/download/全局文件名
			每张卡片上方 21:9 封面预览，下方显示文章标题或主题、风格标签、视觉重点标签
			点击卡片查看详情（弹出详情层，等同作品库的查看详情）

	『创作工坊』页面
		左上显示大标题：创作工坊，说明：填写主题、风格与素材，生成一张可发布的高清文章封面
		右上是按钮：作品库，跳转到『作品库』页面
		页面左右分栏，左为表单，右为画布预览
		左侧表单
			表单标题:封面设计,表:封面设计,字段:[{字段名:文章标题或主题,类型:文本},{字段名:风格,类型:单选项,可选项:自动选择,暖色手绘教程风,产品主视觉风,深色科技爆发风,撕纸拼贴风,编辑杂志风,黑金步骤爆款风,高饱和实测冲击风,手写结果承诺风,产品后台沉浸风},{字段名:视觉重点,类型:单选项,可选项:自动选择,标题,真人,产品或界面,流程,结果,故事场景},{字段名:真人使用方式,类型:单选项,可选项:使用参考人物,原图直接放入或抠图,不使用真人},{字段名:素材文件,类型:文本},{字段名:封面比例,类型:文本},{字段名:补充要求,类型:文本},{字段名:封面图片,类型:指令流}]
			文章标题或主题：大号输入框，占位『例如：3天搭好个人知识库』，必须完整保留用户标题，不改写
			风格：默认『自动选择』；除下拉外，同步展示九宫格风格选择器，点选即写入该字段
			视觉重点：默认『自动选择』；以图标单选项呈现（标题 / 真人 / 产品或界面 / 流程 / 结果 / 故事场景）
			真人使用方式：三张并列选择卡
				使用参考人物：保持身份一致，未指定姿势时按视觉重点选择
				原图直接放入或抠图：保持脸、表情、动作、服装和发型不变
				不使用真人：画面不加入人物，不虚构用户身份
			素材文件：展示已选文件名；按钮组
				按钮：选择图片，调用 SelectImage 返回图片全局文件名，写入素材文件
				按钮：选择文件，调用 SelectFile 返回文件全局文件名，写入素材文件（可与已有文件名以逗号拼接，支持人物照、产品图、界面截图）
				按钮：拍摄参考，调用 CapturePhoto 返回图片全局文件名，写入素材文件
				已选素材以缩略图条展示，图片地址为 https://www.ithinkair.com:3031/download/全局文件名 ，支持移除某一项后回写素材文件
			封面比例：文本字段，界面提供快捷比例胶囊：21:9、16:9、3:4、1:1、9:16、4:3，点选写入；占位提示『留空则使用 21:9』
			补充要求：多行文本，占位『可写真人姿势、必须保留的文字、希望避开的颜色；不要虚构品牌 Logo』
			封面图片字段不由用户手工填写，表单上不显示输入框，仅在右侧画布呈现生成结果
		表单底部按钮
			按钮标题：生成高清封面，点击提交表单（文章标题或主题为空时禁用）
				使用 SubmitRecord 提交，表:封面设计，payload 为表单 JSON 文本
				提交后当前行是 1
			按钮标题：清空重做，点击清空表单与画布，当前行设为 0
		右侧画布
			比例框按当前封面比例（空则 21:9）绘制安全区与标题占位
			未生成时显示『等待生成』与当前风格色票
			提交后进入轮询
				轮询标题:封面设计,表:封面设计,字段:封面图片,输出到:封面画布,等待消息:正在结合真人形象与风格绘制高清封面…
				API名称:GetCellValue,数据源:封面设计/默认表格,字段名:封面图片,行号:当前行
				指令描述未要求 JSON，故轮询该指令流字段本身，直到返回图片全局文件名
				生成完成后仅展示单张高清封面，不展示目录、样图或低清预览
				图片地址：https://www.ithinkair.com:3031/download/全局文件名
			画布右上角按钮（仅生成成功后可用）
				下载封面：访问 https://www.ithinkair.com:3031/download/全局文件名
				新窗口打开：访问 https://www.ithinkair.com:3031/private/全局文件名
				再做一张：保留当前表单值，当前行设为 0，可再次 SubmitRecord 生成新作品
		当前行初始是 0

	『作品库』页面
		左上显示大标题：作品库，说明：浏览、回看和整理全部封面作品
		右上是按钮：+ 新建封面，跳转到创作工坊并清空表单，当前行设为 0
		搜索框：按文章标题或主题、补充要求模糊搜索
		筛选器：按风格筛选、按视觉重点筛选、按真人使用方式筛选、按封面比例筛选
		主体以卡片网格展示（不要用冷冰冰的纯表格当主视图），卡片字段与表单字段对齐，便于点击后进入编辑
			API名称:GetTableCSV,数据源:封面设计/默认表格,字段:[文章标题或主题,风格,视觉重点,真人使用方式,素材文件,封面比例,补充要求]
			每张卡片封面图：API名称:GetCellValue,数据源:封面设计/默认表格,字段名:封面图片,行号:该行
			卡片展示：封面预览、文章标题或主题、风格、视觉重点、真人使用方式、封面比例
			卡片悬停显示操作：查看详情、编辑、删除、下载
		查看详情：弹出杂志风详情层
			API名称:GetCellValue 逐字段读取当前行：文章标题或主题、风格、视觉重点、真人使用方式、素材文件、封面比例、补充要求、封面图片
			封面图片用大图呈现；素材文件以缩略图列表呈现；补充要求用 Markdown 主题显示
			详情层按钮：下载、编辑、关闭
		编辑：点击卡片或编辑按钮后，当前行=行号，跳转创作工坊并回填表单
			API名称:GetCellValue,数据源:封面设计/默认表格,逐字段填充
			修改表单不得使用 SubmitRecord，而是依次 SetCellValue
				API名称:SetCellValue,数据源:封面设计/默认表格,payload:字段名/行/值
			编辑页显示『保存修改』：逐字段 SetCellValue 写回当前行（不含封面图片，指令流不由用户填写）
			编辑页另提供『按当前设定重新生成』：以当前表单值 SubmitRecord 新增一条并轮询新的封面图片（新记录当前行为 1）
		删除：二次确认后
			API名称:DeleteRecord,数据源:封面设计/默认表格,payload:行号.toString()
			删除后刷新卡片墙与首页统计
		下载：取该行封面图片全局文件名，访问 https://www.ithinkair.com:3031/download/全局文件名
		点击首页最近列表或作品库卡片，均打开同一套详情层

	统一交互与约束
		字段名只能使用表定义中的：文章标题或主题、风格、视觉重点、真人使用方式、素材文件、封面比例、补充要求、封面图片；不要编造 ID、创建日期或其他字段
		主体列表/卡片展示的字段与 GetTableCSV 字段、表单字段保持一致，保证点选一行即可回填编辑
		布尔值若出现用『是』或『否』（本表无布尔字段）
		指令流封面图片在 SubmitRecord 之后由后台异步生成，前端必须轮询等待；展示详情时先 GetCellValue
		缺少产品素材时仍允许提交，由后台使用抽象浏览器、流程或结果元素补全
		选择『不使用真人』或未提供真人参考且未明确要求使用真人时，预览提示『无真人方案』，不虚构用户身份
		各页面使用统一的深空黑 + 香槟金 + 品红主题，卡片与按钮具有悬停效果，列表优先卡片形式
		所有导航、生成、轮询、下载、编辑、删除、筛选、回填功能必须完整实现
