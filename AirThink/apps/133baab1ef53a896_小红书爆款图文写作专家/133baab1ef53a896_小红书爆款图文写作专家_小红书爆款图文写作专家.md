# 小红书爆款图文写作专家
	这是一个面向内容创作者的小红书爆款图文写作网页应用，包含首页、创作工坊、作品库三个页面。页面统一采用小红书品牌潮流主题：主色珊瑚红 #FF2442，辅色蜜桃粉 #FF6B8A、奶油白 #FFF7F8、墨黑 #1F1F1F；背景为奶油白到浅粉的柔和渐变，点缀细碎闪光与圆角便签质感；卡片白底、大圆角、轻阴影，悬停时轻微上浮并带红色描边；按钮为圆角胶囊，主按钮珊瑚红白字，次按钮白底红边；字体为柔和时尚的 sans-serif。不包含用户登录页面。操作按钮对应的功能必须要都实现。列表一律使用卡片形式。

	页面顶部导航栏，使用珊瑚红到玫红的横向渐变，白字
		左侧显示 Logo（笔记本+火花图标）和「小红书爆款写作专家」
		右侧显示标签：首页、创作工坊、作品库
		当前页标签加白底红字胶囊高亮

	首页
		主标题：小红书爆款图文写作专家
		说明：输入一个主题，自动匹配爆款风格模板，一键生成正文、配图方案、封面文案和搜索关键词
		中央大按钮：开始创作爆款，点击跳转到「创作工坊」页面
		接下来是并列的三个统计卡片（悬停上浮）
			总作品数卡片显示全部爆款图文记录数量
				API名称:GetRecordCount,数据源:爆款图文/默认表格
			风格最热卡片显示出现次数最多的风格名称及数量
				API名称:GetTableCSV,数据源:爆款图文/默认表格,字段:[风格]
				按风格分组统计，取数量最多的一项；无数据时显示「期待你的第一篇爆款」
			待灵感卡片显示主题非空的记录数量
				API名称:GetTableCSV,数据源:爆款图文/默认表格,字段:[主题]
				统计主题文本非空的行数
		接下来是「八大爆款风格」入口区：八张小风格卡片横滑或网格排列，点击某风格跳转到「创作工坊」并预填该风格
			好物推荐型、干货教程型、情感成长型、探店打卡型、日常vlog型、母婴亲子型、穿搭美妆型、创业副业型
			每张风格卡片使用不同浅色底与对应 emoji 图标（购物袋、书本、心跳、地点、摄像机、亲子、口红、火箭）
		接下来是最近作品列表：以小红书笔记卡片网格显示最近 6 条，字段包括主题、风格、参考图片缩略、图文方案摘要（前 60 字）
			API名称:GetTableCSV,数据源:爆款图文/默认表格,字段:[主题,风格,参考图片,图文方案]
			按表格原有顺序取前 6 条
			参考图片用全局文件名拼接链接 https://www.ithinkair.com:3031/download/全局文件名 作为封面缩略图；无图时用该风格对应的渐变色块占位
			图文方案摘要若为空显示「生成中或暂无内容」
			点击任一最近卡片查看详情：当前行=该卡片对应行号，弹出详情抽屉或跳转作品库并打开该条详情
				API名称:GetCellValue,数据源:爆款图文/默认表格,字段名:主题,行号:当前行
				API名称:GetCellValue,数据源:爆款图文/默认表格,字段名:风格,行号:当前行
				API名称:GetCellValue,数据源:爆款图文/默认表格,字段名:参考图片,行号:当前行
				API名称:GetCellValue,数据源:爆款图文/默认表格,字段名:图文方案,行号:当前行
				图文方案文本用 Markdown 主题渲染

	「创作工坊」页面
		左上显示大标题：创作工坊
		说明：写下主题，选个风格（也可交给 AI 智能匹配），可选上传或拍摄参考图，一键生成爆款方案
		右上是按钮：查看作品库，点击跳转到「作品库」页面
		左侧为创作表单区，右侧为生成结果预览区（宽屏左右分栏；窄屏上下堆叠）
		表单标题:爆款图文创作,表:爆款图文,字段:[{字段名:主题,类型:文本},{字段名:风格,类型:单选项,可选项:好物推荐型,干货教程型,情感成长型,探店打卡型,日常vlog型,母婴亲子型,穿搭美妆型,创业副业型},{字段名:参考图片,类型:图片},{字段名:图文方案,类型:指令流}]
			主题：多行输入框，占位符「例如： indiesong 咖啡馆周末brunch / 学生党平价护肤 / 职场一年的真实感受」
			风格：八个可点选胶囊，单选；额外提供「智能匹配」胶囊表示不指定风格（提交时风格为空，由后台按主题自动匹配）
			参考图片：展示当前图片预览（有全局文件名时用 https://www.ithinkair.com:3031/download/全局文件名）；无图时显示虚线上传占位
				按钮：上传参考图，调用 SelectImage 返回图片全局文件名，写入参考图片
				按钮：拍摄参考图，调用 CapturePhoto 返回图片全局文件名，写入参考图片
				按钮：移除图片，清空参考图片
			图文方案为指令流类型，不在表单中手工填写，提交后由后台 AI 异步生成
		主按钮标题：生成爆款方案，仅当主题非空时启用
			点击使用 SubmitRecord 提交记录，表单数据是 json 文本，字段仅包含主题、风格、参考图片（风格未选则为空字符串，参考图片为全局文件名或空）
			API名称:SubmitRecord,数据源:爆款图文,payload:表单json
			提交后当前行是 1
		提交后必须轮询等待后台 AI 异步生成结束
			轮询标题:爆款图文创作,表:爆款图文,字段:图文方案,输出到:方案预览,等待消息:正在为你打磨爆款文案，稍等几秒…
			轮询调用 GetCellValue
				API名称:GetCellValue,数据源:爆款图文/默认表格,字段名:图文方案,行号:当前行
			当图文方案返回非空文本时结束轮询，用 Markdown 主题渲染到右侧「方案预览」
		右侧方案预览区
			初始展示空状态插画与文案「主题就绪后，爆款正文、配图方案、封面文案和搜索关键词会出现在这里」
			生成中显示骨架屏与等待消息
			生成完成后以小红书笔记纸样式呈现 Markdown 内容（正文、配图描述、封面文案、搜索关键词等章节按原文标题层级排版）
			预览区顶部显示当前主题与风格标签；若有参考图片，在预览顶部以圆角封面图展示
			预览区右上提供按钮：再写一篇
				点击清空主题、风格、参考图片与方案预览，当前行设为 0，停留在创作工坊
		当前行初始是 0

	「作品库」页面
		左上显示大标题：作品库
		说明：浏览、回看和打理你做过的全部爆款图文
		右上是按钮：+ 新建爆款，点击跳转到「创作工坊」并清空表单、当前行设为 0
		搜索框：按主题关键词模糊筛选
		筛选器：按风格筛选，选项为全部 + 八种风格
		主体为卡片网格，不用传统表格行。每张卡片显示：参考图片封面（或风格色块占位）、主题、风格胶囊、图文方案前 80 字摘要
			API名称:GetTableCSV,数据源:爆款图文/默认表格,字段:[主题,风格,参考图片,图文方案]
			卡片封面图链接：https://www.ithinkair.com:3031/download/全局文件名
			筛选与搜索在前端对 GetTableCSV 结果处理
			主体卡片展示的字段与表单字段一致（主题、风格、参考图片、图文方案），以便点击单卡进入编辑/详情
		每张卡片操作：查看详情、编辑、删除（三个按钮都必须实现）
			查看详情：当前行=该卡片行号（行号从 1 开始），弹出右侧详情抽屉
				API名称:GetCellValue,数据源:爆款图文/默认表格,字段名:主题,行号:当前行
				API名称:GetCellValue,数据源:爆款图文/默认表格,字段名:风格,行号:当前行
				API名称:GetCellValue,数据源:爆款图文/默认表格,字段名:参考图片,行号:当前行
				API名称:GetCellValue,数据源:爆款图文/默认表格,字段名:图文方案,行号:当前行
				详情顶部大图展示参考图片（有则显示），主题作标题，风格作红色胶囊
				图文方案详情用 Markdown 主题显示
				详情抽屉右上角提供 < 和 > 切换上一条 / 下一条
					API名称:GetRecordCount,数据源:爆款图文/默认表格
					当前行<=1 时 < 不可操作
					当前行>=RecordCount 时 > 不可操作
					切换后按新行号重新 GetCellValue 四个字段并刷新抽屉
			编辑：当前行=该卡片行号，打开编辑表单并回填
				API名称:GetCellValue 逐字段获取主题、风格、参考图片、图文方案并填充
				表单标题:编辑爆款图文,表:爆款图文,字段:[{字段名:主题,类型:文本},{字段名:风格,类型:单选项,可选项:好物推荐型,干货教程型,情感成长型,探店打卡型,日常vlog型,母婴亲子型,穿搭美妆型,创业副业型},{字段名:参考图片,类型:图片},{字段名:图文方案,类型:指令流}]
				参考图片支持重新选择：SelectImage 或 CapturePhoto，预览用 download 链接
				图文方案在编辑表单中只读，用 Markdown 展示，不提供手工改写
				保存时禁止 SubmitRecord，依次 SetCellValue 更新当前行的主题、风格、参考图片
					API名称:SetCellValue,数据源:爆款图文/默认表格,payload:字段名/行/值
				保存成功后刷新卡片网格
			删除：二次确认后调用 DeleteRecord
				API名称:DeleteRecord,数据源:爆款图文/默认表格,payload:行号.toString()
				删除后刷新卡片网格与首页统计
		点击卡片主体（非按钮区域）等同查看详情
		无数据时展示空状态：「还没有爆款作品，去创作工坊写第一篇吧」，按钮跳转创作工坊

	各页面统一珊瑚红主题，卡片与按钮均需悬停反馈，点击最近列表项与作品卡片均可查看详情。字段名只使用表定义中的主题、风格、参考图片、图文方案，不编造 ID 或日期字段。指令流字段图文方案在 SubmitRecord 之后轮询 GetCellValue，以 Markdown 呈现。
