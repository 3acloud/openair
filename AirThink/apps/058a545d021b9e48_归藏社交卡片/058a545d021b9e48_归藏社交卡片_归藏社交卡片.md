# 归藏社交卡片
	这是一个归藏风格社交卡片制作工坊网页应用，将文章、截图与视频素材转为归藏风格社交卡片，支持小红书图文、实况拼图和公众号双封面。包含首页、制作工坊、作品库三个页面。不包含用户登录页面。
	整体视觉采用瑞士国际主义与电子墨水杂志的融合语言：宣纸底、墨色字、朱砂点缀、严格网格、大量留白。背景为宣纸色浅渐变（#F7F3EB 至 #EFE8DC），主文字墨黑（#1A1A1A），强调色朱砂红（#B83B3B），辅助青灰（#6E6E6E）。标题使用衬线中文（思源宋体/Songti），正文与界面使用干净无衬线。卡片如杂志剪报，细线边框、轻微纸质纹理，悬停时上浮并出现朱砂细下划线。列表一律以卡片形式呈现，不用沉重数据表作为主视觉。
	页面顶部导航栏，使用墨色横条，底部一道极细朱砂线
		左侧显示Logo（方框中的「藏」字，瑞士国际主义几何处理）和「归藏社交卡片」
		右侧显示标签：首页、制作工坊、作品库
		当前页标签用朱砂下划线标出
	首页
		主标题：归藏社交卡片
		说明：把长文、截图与视频，收成一张可发布的归藏风格卡片。覆盖小红书图文、实况拼图、公众号双封面。
		主按钮：开始制作，点击跳转到「制作工坊」页面
		次按钮：浏览作品库，点击跳转到「作品库」页面
		接下来是并列的四个统计卡片（杂志封面编号感，左上角小号序号 01–04）
			总作品数
				API名称:GetRecordCount,数据源:社交卡片/默认表格
			小红书作品
				API名称:GetTableCSV,数据源:社交卡片/默认表格,字段:[目标平台]
				筛选目标平台包含「小红书」的记录计算数量
			公众号作品
				API名称:GetTableCSV,数据源:社交卡片/默认表格,字段:[目标平台]
				筛选目标平台包含「微信公众号」的记录计算数量
			实况作品
				API名称:GetTableCSV,数据源:社交卡片/默认表格,字段:[卡片形式]
				筛选卡片形式为「单视频实况卡片」「二宫格实况拼图」「三宫格实况拼图」「四宫格实况拼图」的记录计算数量
		接下来是「最近出品」区块，标题右侧显示「全部作品 →」，点击进入作品库
			以卡片网格显示最近 6 条，每张卡片展示：目标平台色条徽章、卡片形式、视觉风格、画面比例、源内容前 80 字、制作要求摘要
			API名称:GetTableCSV,数据源:社交卡片/默认表格,字段:[源内容,目标平台,卡片形式,画面比例,视觉风格,配图来源,素材文件,制作要求]
			按记录顺序取最新 6 条（列表顶部为最新）
			素材文件若为图片全局文件名，卡片左侧显示缩略图，图片链接为 "https://www.ithinkair.com:3031/download/全局文件名"
			点击任一最近卡片，打开作品详情浮层（见下方「作品详情浮层」），用 GetCellValue 读取该行各字段与生成结果
	「制作工坊」页面
		左上显示大标题：制作工坊
		说明：填写源内容与约束，提交后由归藏技能异步构图、渲染并完成视觉检查
		右上是按钮：查看作品库，跳转到「作品库」页面
		页面分左右两栏（大屏）或上下结构（小屏）
			左栏为制作表单（杂志网格铺陈）
			右栏为「作品呈现区」，提交前显示空状态文案：「墨稿尚未落成。填写左侧表单后点击生成。」
		表单标题:制作归藏社交卡片,表:社交卡片,字段:[{字段名:源内容,类型:文本},{字段名:目标平台,类型:多选项,可选项:小红书,微信公众号,其他},{字段名:卡片形式,类型:单选项,可选项:静态图文卡片,单视频实况卡片,二宫格实况拼图,三宫格实况拼图,四宫格实况拼图,公众号双封面},{字段名:画面比例,类型:单选项,可选项:按平台默认,3:4,1:1,21:9,21:9与1:1双封面},{字段名:视觉风格,类型:单选项,可选项:自动选择,瑞士国际主义,电子墨水杂志},{字段名:配图来源,类型:单选项,可选项:用户提供,网络素材,AI生成,由智能体选择},{字段名:素材文件,类型:文本},{字段名:制作要求,类型:文本}]
			不要编造表定义中不存在的 ID、创建日期等字段
			源内容：大段文本域，占位「粘贴文章、口播稿、笔记或需要转化的文字…」
			目标平台：多选芯片，可同时选择；选中「小红书」时提示常用 3:4；选中「微信公众号」时提示双封面常用 21:9 与 1:1
			卡片形式：单选；当选择「公众号双封面」时，若画面比例不是「21:9与1:1双封面」，给出轻提示但不强制；当选择任一实况形式时，提示需在素材中提供视频并尽量写明时间范围与裁切重点
			画面比例、视觉风格、配图来源：单选按钮组，视觉处理成杂志栏目标签
			制作要求：多行文本，占位「可选：内容类别、固定标题、页数、主题配色、素材出现位置、视频时间范围及裁切重点等」
			素材文件：文本保存全局文件名（多个文件名用英文逗号分隔）
				按钮：选择图片，调用 SelectImage，返回图片全局文件名，追加到素材文件
				按钮：选择文件，调用 SelectFile，返回文件全局文件名，追加到素材文件（用于视频、压缩包、文档）
				按钮：拍摄素材，调用 CapturePhoto，返回图片全局文件名，追加到素材文件
				已选素材以标签列表显示，可单独移除；图片用 "https://www.ithinkair.com:3031/download/全局文件名" 显示缩略预览；点击标签用 "https://www.ithinkair.com:3031/private/全局文件名" 在新视图打开
				若配图来源为「用户提供」，未选择任何素材时，「生成卡片」按钮禁用并提示需要素材
		表单底部主按钮标题：生成卡片
			校验：源内容必填；配图来源为「用户提供」时素材文件必填
			点击后使用 SubmitRecord 提交，表:社交卡片，payload 为表单 JSON 文本，字段仅包含表定义中的用户字段：源内容、目标平台、卡片形式、画面比例、视觉风格、配图来源、素材文件、制作要求
			提交后当前行是 1
			「生成结果」为指令流字段，不是用户手工填写，由后台 AI 异步生成
			提交后轮询等待异步生成结束
				轮询标题:制作归藏社交卡片,表:社交卡片,字段:生成结果,输出到:作品呈现区,等待消息:正在提炼内容、规划版式并渲染归藏卡片，请稍候…
				轮询调用 GetCellValue，数据源:社交卡片/默认表格, payload:"生成结果/当前行"
				指令流文本用 Markdown 主题显示，不要把目录当作交付结果
				生成结果中的图片预览、成品链接、实况包与配套视频，按 Markdown 渲染；若出现全局文件名，图片与下载使用 "https://www.ithinkair.com:3031/download/全局文件名"，浏览器打开使用 "https://www.ithinkair.com:3031/private/全局文件名"；若为 HTML 成品，使用 "https://www.ithinkair.com:3031/private/全局文件名" 在 iframe 中打开
		右下新建按钮标题：+ 新稿
			位置:右下
			点击清空表单与作品呈现区，当前行设为 0
		作品呈现区右上角提供两个浏览按钮
			按钮标题:< ，点击读取上一行各字段与生成结果
			按钮标题:> ，点击读取下一行各字段与生成结果
			数据来源于 GetCellValue
				API名称:GetCellValue,数据源:社交卡片/默认表格,字段名:源内容,行号:当前行
				API名称:GetCellValue,数据源:社交卡片/默认表格,字段名:目标平台,行号:当前行
				API名称:GetCellValue,数据源:社交卡片/默认表格,字段名:卡片形式,行号:当前行
				API名称:GetCellValue,数据源:社交卡片/默认表格,字段名:画面比例,行号:当前行
				API名称:GetCellValue,数据源:社交卡片/默认表格,字段名:视觉风格,行号:当前行
				API名称:GetCellValue,数据源:社交卡片/默认表格,字段名:配图来源,行号:当前行
				API名称:GetCellValue,数据源:社交卡片/默认表格,字段名:素材文件,行号:当前行
				API名称:GetCellValue,数据源:社交卡片/默认表格,字段名:制作要求,行号:当前行
				API名称:GetCellValue,数据源:社交卡片/默认表格,字段名:生成结果,行号:当前行
			API名称:GetRecordCount,数据源:社交卡片/默认表格
			当前行初始是 0
			当前行<=1 时，< 按钮不可操作
			当前行>=RecordCount 时，> 按钮不可操作
			切换行时，表单回填该行用户字段，作品呈现区用 Markdown 显示生成结果；若生成结果仍为空，显示「该稿尚未完成渲染」
	「作品库」页面
		左上显示大标题：作品库
		说明：以卡片墙浏览、筛选、回看与再制作全部归藏社交卡片
		右上是按钮：+ 制作新卡片，跳转到「制作工坊」并清空为新稿（当前行设为 0）
		搜索框，可按源内容或制作要求关键词过滤
		筛选器：按目标平台筛选、按卡片形式筛选、按视觉风格筛选、按配图来源筛选
		主体不以传统表格为第一视觉，使用卡片网格（杂志墙）。但卡片展示字段必须与表单用户字段一致，以便点击单卡进入编辑
			API名称:GetTableCSV,数据源:社交卡片/默认表格,字段:[源内容,目标平台,卡片形式,画面比例,视觉风格,配图来源,素材文件,制作要求]
			每张卡片显示：目标平台徽章、卡片形式、画面比例、视觉风格、配图来源、源内容前 60 字、制作要求前 40 字、素材缩略（若素材文件含图片全局文件名）
			卡片悬停显示操作条，每张卡片操作按钮必须全部实现：
				查看作品：打开作品详情浮层，当前行=该记录行号；生成结果用 GetCellValue 获取并以 Markdown 显示
				编辑：打开编辑表单（可在本页右侧抽屉或全宽表单），当前行=行号，逐字段 GetCellValue 回填；素材文件可重新 SelectImage / SelectFile / CapturePhoto
				删除：确认后调用 DeleteRecord，数据源:社交卡片/默认表格, payload:行号.toString()，然后刷新卡片墙与统计
				再制作：将该卡字段复制到制作工坊表单（不带生成结果），跳转制作工坊，当前行设为 0，等待用户点击生成卡片以 SubmitRecord 新稿
		点击卡片主体（非操作按钮）同样打开作品详情浮层
		编辑表单标题:编辑社交卡片,表:社交卡片,字段与制作工坊一致（源内容、目标平台、卡片形式、画面比例、视觉风格、配图来源、素材文件、制作要求）
			修改已有记录时，依次通过 SetCellValue 设当前记录行各字段的值，不要用 SubmitRecord
			API名称:SetCellValue,数据源:社交卡片/默认表格,payload:"字段名/行/值"
			保存后刷新该卡片显示；生成结果不会因 SetCellValue 自动重算；若用户要重新出图，使用「再制作」走 SubmitRecord 新记录并轮询生成结果
			布尔类型若出现用「是」或「否」，本表无布尔字段
		查看字段详情时调用 GetCellValue 获取单元格详情数据；如需项目符号结构可调用 GetCellBullet，数据源:社交卡片/默认表格, payload:"字段名/行"
	作品详情浮层
		杂志跨页布局：左侧元信息，右侧生成结果
		左侧展示该行：源内容、目标平台、卡片形式、画面比例、视觉风格、配图来源、制作要求、素材文件列表
			素材文件下载："https://www.ithinkair.com:3031/download/全局文件名"
			素材文件打开："https://www.ithinkair.com:3031/private/全局文件名"
		右侧「生成结果」
			API名称:GetCellValue,数据源:社交卡片/默认表格,字段名:生成结果,行号:当前行
			文本用 Markdown 主题显示，包含制作说明、成品图片预览与链接、成品文件链接；实况作品展示实况包及配套图片与视频链接
			不要把目录当作交付结果；空结果时显示「墨稿生成中或尚无成品」
		浮层底部按钮：关闭、去编辑、再制作、删除，功能与作品库卡片操作一致
	数据与交互总则
		调用 GetTableCSV 获取表格数据，payload 为逗号分隔的字段名，返回不含标题行的 csv；图片字段文本是图片全局文件名，文件字段文本是文件全局文件名；逗号分隔的字段名必须是「社交卡片」表中已定义字段
		新建使用 SubmitRecord，提交后当前行是 1；若表单包含指令流字段，提交后必须轮询生成结果直到结束
		修改已有记录只用 SetCellValue，不用 SubmitRecord
		删除用 DeleteRecord，payload 必须是行号的字符串
		可用 GetRecordRow，数据源:社交卡片/默认表格, payload:"字段名/值" 获取从 1 开始的行号
		当前行初始为 0；首页最近列表与作品库点击后设置当前行再读详情
		字段名必须是表定义中出现过的字段，不得自行增加 ID、创建日期或其他字段
		操作按钮对应的功能必须都实现；卡片与浮层具有悬停反馈；页面主题在三页保持统一
		无需用户登录页；只读内容（生成结果）不要单独做成一个导航页面，放入呈现区与详情浮层即可
