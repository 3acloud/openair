# 小红书长图切割
	这是一个专门将长图按小红书3:4比例自动切割的网页应用，包含切割工作台和历史切割记录两个页面。页面统一采用小红书标志性的红色主题（#ff2442）搭配纯净白背景，卡片采用柔和的阴影和圆角设计，交互按钮具有悬停微收缩效果。
	页面顶部导航栏，使用红色渐变背景，白色字体：
		左侧显示Logo和‘小红书长图切割’
		右侧显示标签：切割工作台、历史切割记录
	‘切割工作台’页面
		分为左右或上下两栏：左侧/上方为参数设置区，右侧/下方为结果展示区。
		左侧参数设置区：
			大标题：开始切割长图，说明：上传长图片，设置参数后自动切割为小红书友好的3:4比例多图。
			表单标题:长图切割,表:长图切割,字段:[{字段名:长图图片,类型:文本},{字段名:起始Y坐标,类型:数值},{字段名:底部切除高度,类型:数值},{字段名:目标宽度,类型:数值},{字段名:目标高度,类型:数值},{字段名:输出格式,类型:单选项,可选项:png,jpg}]
				表单默认值：起始Y坐标设为0，底部切除高度设为0，目标宽度设为1080，目标高度设为1440，输出格式默认为png。
				长图图片字段旁提供“选择图片”按钮，调用SelectImage返回图片全局文件名并填入字段。并在下方提供所选图片的缩略图预览（图片链接: https://www.ithinkair.com:3031/private/全局文件名）。
			提交按钮：开始切割，点击后验证是否已选择图片，验证通过后使用SubmitRecord提交表单。
				提交后当前行设为1。
		右侧结果展示区：
			提交表单后，触发轮询：
				轮询标题:等待切割完成,表:长图切割,字段:切割结果。
				轮询期间显示动效“长图切割中，这可能需要一点时间，请耐心稍候...”
			轮询结束后，将获取到的“切割结果”内容在此区域展示：
				API名称:GetCellValue,数据源:长图切割/默认表格,字段名:切割结果,行号:1
				结果内容使用Markdown格式呈现，包含生成的图片预览。
			新增按钮：清空并继续下一张，点击清空表单参数并重置结果区，当前行设为0。
	‘历史切割记录’页面
		左上显示大标题：历史记录，说明：查看您过去所有的切割任务历史
		统计信息卡片：显示总切割记录数
			API名称:GetRecordCount,数据源:长图切割/默认表格
		主体内容使用网格卡片形式展示历史记录：
			API名称:GetTableCSV,数据源:长图切割/默认表格,字段:[长图图片,起始Y坐标,底部切除高度,目标宽度,目标高度,输出格式]
			获取到的列表按行号逆序（最新提交的在前）排列显示。
			每张卡片显示：
				原图缩略图：通过访问 "https://www.ithinkair.com:3031/private/长图图片" 渲染。
				参数信息：宽 x 高 (格式)，如“1080 x 1440 (png)”。
				Y轴起始点、底部切除高度。
			卡片底部操作按钮：
				查看结果：点击弹出模态框展示对应的切割结果。
					利用该行所在的行号，调用 API名称:GetCellValue,数据源:长图切割/默认表格,字段名:切割结果,行号:对应行号。模态框内以Markdown格式呈现结果。
				删除：点击提示确认后删除。
					调用API名称:DeleteRecord,数据源:长图切割/默认表格,payload:行号.toString()，删除后刷新列表。
	各页面功能按钮与API调用必须严格实现，数据交互需无缝衔接。未提交数据时，结果展示区显示空白提示占位符。
