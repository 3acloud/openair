# 主题研究HTML生成
	这是一个自动化主题研究与HTML网页生成应用，包含首页、新建研究、历史研究库三个页面。
	页面整体采用深邃藏青色（科技蓝）主题，白色背景卡片，具有圆角、平滑阴影和悬停交互效果，字体采用现代无衬线字体，界面响应式适配。
	页面顶部导航栏，使用藏青色科技风背景
		左侧显示Logo（文档图标）和‘主题研究生成器’
		右侧显示导航标签：首页、新建研究、历史研究库
	首页
		主标题：主题研究HTML生成器，说明：输入任意研究主题，AI智能体将自动全网搜索、深度研究，并为您生成专业的响应式HTML网页报告。
		中央大按钮：+ 开始新建研究，点击跳转到‘新建研究’页面
		接下来是数据统计卡片：
			累计研究次数卡片：显示历史执行的研究总数。
				API名称:GetRecordCount, 数据源:主题研究/默认表格
		接下来是最近研究列表：显示最近生成的几个主题研究记录，以整洁的卡片列表形式展示。
			API名称:GetTableCSV, 数据源:主题研究/默认表格, 字段:[研究主题]
			将列表按顺序倒序排列，显示最新5条。
	‘新建研究’页面
		左上显示大标题：新建主题研究，说明：请输入您想要研究的主题，AI将为您搜集资料并生成响应式网页。
		右上角按钮：查看历史记录，点击跳转到‘历史研究库’页面
		中央显示新建表单区域：
			表单标题:新建主题研究, 表:主题研究, 字段:[{字段名:研究主题, 类型:文本}, {字段名:HTML文件, 类型:指令流, 指令类型:任务智能体, 指令描述:"请使用技能'a194e39e695efa2c_主题研究HTML生成'，针对以下主题执行搜索与研究，整理关键内容并生成响应式HTML文件：{{研究主题}}", 输出类型:文件}]
			在表单界面上只显示“研究主题”输入框。
			提交按钮标题为“开始研究并生成HTML”。
			点击提交时，使用SubmitRecord提交记录，此时当前行为1。
			提交后，锁定表单并显示居中的加载提示动画，提示文案：“正在全网搜索与深度研究，为您生成响应式HTML文件，请稍候...”。
			轮询标题:新建主题研究, 表:主题研究, 字段:HTML文件。
			轮询等待后台AI异步生成结束后，获取“HTML文件”字段返回的文件全局文件名。
		预览区域（生成完成后出现）：
			表单下方呈现“生成结果预览”区块。
			区块内放置一个全宽 iframe（高度至少600px），iframe的src设为"https://www.ithinkair.com:3031/private/全局文件名"。
			注：HTML文件不能直接下载导出，需确保直接在此 iframe 里加载并打开。
	‘历史研究库’页面
		左上显示大标题：历史研究库，说明：查看和管理所有已生成的主题研究HTML报告。
		右上是按钮：+ 新建研究，点击跳转到‘新建研究’页面。
		顶部搜索框：可按“研究主题”实时筛选过滤表格记录。
		主体是研究记录表格，显示字段：研究主题。
			API名称:GetTableCSV, 数据源:主题研究/默认表格, 字段:[研究主题]
			列表按数据原序反转呈现（最新生成的记录在最前）。
			每行右侧具有操作按钮组：预览报告、删除。
			点击“删除”按钮：弹出确认提示，确认后调用DeleteRecord, 数据源:主题研究/默认表格, payload传入该行的行号（使用 行号.toString()）。删除完成后重新调用GetTableCSV刷新当前表格和统计数。
			点击“预览报告”按钮：
				通过API名称:GetCellValue, 数据源:主题研究/默认表格, payload:"HTML文件/行号" 获取对应生成结果的全局文件名。
				弹出一个宽大的模态窗口，标题栏显示“预览报告 - [研究主题]”。
				模态窗口主体放置一个 iframe（宽度100%，高度70vh以上），iframe的src设为"https://www.ithinkair.com:3031/private/全局文件名"以直接在 iframe 里打开预览。
				模态窗口右上角或底部提供“关闭”按钮。
	应用无须登录即可操作，各页面之间需平滑切换，表格及所有的操作按钮对应的功能必须要都实现。不要编造表定义中不存在的字段。
