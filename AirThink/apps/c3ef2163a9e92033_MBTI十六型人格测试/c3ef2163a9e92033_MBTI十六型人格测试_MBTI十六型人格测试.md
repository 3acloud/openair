# MBTI十六型人格测试

这是一个MBTI十六型人格测试网页应用，包含首页、人格测试、测试档案、类型图鉴、双型对照五个页面。不包含登录页。前端不自行计分、不编造类型、不预置十六型中文别名；类型、中文名与解读只来自指令流字段。界面分组、字母着色只为点选，不代表测试结论。

统一主题为「星夜心镜」：页面背景是深夜靛到暮紫的纵向渐变，内容面板为暖象牙色，主色使用鸢尾紫，强调色使用暗金。标题用衬线体，正文用柔和无衬线体。卡片与按钮有轻微抬起和金色描边悬停。四字母分别着固定色：E暖珊瑚、I夜靛、S苔绿、N鸢尾、T石板蓝、F玫粉、J暗金、P青绿。空状态、加载态、失败态都要有文案，不能只留空白。

## 数据操作约定

所有表操作都通过 `callAppBridge`，调用都要等待返回。数据源写作「表名/默认表格」。字段名只能使用表定义中的字段，不要编造编号、日期或其他字段。布尔值本应用不使用。单选项只能取给定可选项。

- `callAppBridge({type:"GetTableCSV", data:"数据源", payload:"逗号分隔的字段名"})` 获取不含标题行的 CSV。字段顺序必须与 payload 一致。
- `callAppBridge({type:"SubmitRecord", data:"表", payload:"表单数据"})` 新建记录。payload 是 JSON 文本。提交后当前行是 1。
- `callAppBridge({type:"GetRecordCount", data:"数据源"})` 获取记录数。
- `callAppBridge({type:"GetRecordRow", data:"数据源", payload:"字段名/值"})` 获取从 1 开始的行号。
- `callAppBridge({type:"DeleteRecord", data:"数据源", payload:"行"})` 删除记录。行号必须先 `toString()`。
- `callAppBridge({type:"GetCellValue", data:"数据源", payload:"字段名/行"})` 查看单元格详情。
- `callAppBridge({type:"SetCellValue", data:"数据源", payload:"字段名/行/值"})` 修改当前行字段。
- 指令流不是用户填写的。新建只用 `SubmitRecord` 提交用户字段；提交后轮询指令流字段。本应用的指令描述都没有指定「以JSON格式输出」，因此分别轮询「测试报告」「类型解读」「对比报告」。
- 修改已有记录时，依次 `SetCellValue`，不要用 `SubmitRecord`。修改不会重新生成指令流。
- `GetTableCSV` 返回顺序对应原始行号，第一行是 1。排序和筛选只改变展示，查看、编辑、删除必须使用原始行号。
- 可能含逗号或换行的文本字段放在 CSV payload 最后，解析时前面的字段按逗号拆，剩余整段算作最后一字段。提交前把答案、关注内容中的换行换成空格。
- 指令流详情用 `GetCellValue` 获取，并以 Markdown 主题渲染。不要把长报告放进 `GetTableCSV`。
- 当前行初始为 0。当前行小于 1 时，依赖当前行的上一行、保存、删除不可操作。

## 页面顶部导航栏

导航栏吸顶，背景为半透明深夜靛，底边一条暗金细线。左侧是一面小镜与四颗星组成的 SVG 标志，以及「MBTI十六型人格测试」。右侧标签：首页、人格测试、测试档案、类型图鉴、双型对照。当前页标签用暗金下划线。窄屏时标签收成菜单，菜单按钮必须能打开和关闭。

## 首页

主标题：MBTI十六型人格测试。说明：支持二十八题快测、九十三题标准与二百题完整测试，依据作答生成分层人格报告，并可查询单一类型或对比两种人格。

三个主按钮并排：
- 「开始测试」跳到人格测试页。
- 「查询类型」跳到类型图鉴页。
- 「对比人格」跳到双型对照页。

接下来是三张可点击统计卡，悬停抬起：
- 测试次数。`callAppBridge({type:"GetRecordCount", data:"人格测试/默认表格"})`。点击进入测试档案。
- 查询次数。`callAppBridge({type:"GetRecordCount", data:"类型查询/默认表格"})`。点击进入类型图鉴。
- 对比次数。`callAppBridge({type:"GetRecordCount", data:"类型对比/默认表格"})`。点击进入双型对照。

再下面是「人格星图」：十六型按 NT、NF、SJ、SP 四组排列，每型一张小卡片，只显示四字母和四个着色彩点。分组标题注明「仅便于点选，不是测试结论」。点击某型，跳到类型图鉴并选中该型，不自动提交。

最近测试以卡片显示最多 5 条，不使用大表格。
- `callAppBridge({type:"GetTableCSV", data:"人格测试/默认表格", payload:"题量,报告层级,答案"})`
- 按原始行号从小到大取前 5 条，因为新提交的记录在第 1 行。
- 卡片显示题量、报告层级、答案前 36 字。
- 点击卡片查看详情：用该条原始行号依次 `GetCellValue` 取题量、答案、报告层级、测试报告。测试报告用 Markdown 渲染；为空时显示「报告生成中」，并提供「刷新报告」按钮，重新 `GetCellValue`。弹层有关闭按钮。
- 无记录时显示「还没有测试，先做一次快测吧」，按钮跳到人格测试页。

页脚固定短句：结果仅供自我了解，不构成心理诊断。

## 人格测试

左上大标题：人格测试。说明：选择题量与报告层级，录入 A 或 B；计分由技能完成，未答完不会得到编造分数。右上按钮「查看档案」，跳到测试档案。

题量用三张互斥大卡片，而不是下拉框：快测28题、标准93题、完整200题。选中快测时，卡片下显示「样本较小，仅供参考」。默认不预选，未选时不能提交。

报告层级用三枚互斥芯片：默认、详细、完整。未选时不能提交。旁边小字说明：默认含类型、中文名、四维倾向和简短概述；详细补充优势、注意点与适合方向；完整给出该类型解读。再一行小字：四维票数相等时取 E、S、T、J，由计分技能处理。

作答区有「连写」「逐题」两个切换按钮，都必须可用。
- 连写：一个多行文本框，占位示例为 `1A 2B 3A` 或 `ABBA`。不提供可提交的假答案按钮。
- 逐题：按当前题量生成 28、93 或 200 个只含题号与 A/B 的选择器，不编造题干。二百题要分段或虚拟滚动。每个选择器可改选、可清空。下方实时把选择拼成 `1A 2B` 这种文本，写回答案。
- 「清空答案」清空两种模式中的答案。
- 进度显示已识别的 A/B 个数与当前题量。识别规则与技能一致：A 或 B 可带题号，大小写不限。个数不足时显示「尚未答完，提交后技能不会编造分数」，并禁用生成按钮。个数超出时提示检查重复题号，仍禁用。正好相等才启用。

底部主按钮「生成报告」。点击时：
- 表单标题：人格测试。表：人格测试。字段只有题量、答案、报告层级。
- 答案先去掉换行。payload 示例：`{"题量":"快测28题","答案":"1A 2B","报告层级":"详细"}`。不要加入测试报告或任何自造字段。
- `callAppBridge({type:"SubmitRecord", data:"人格测试", payload:"上述JSON文本"})`。
- 提交后当前行设为 1。
- 轮询标题：人格测试。表：人格测试。字段：测试报告。输出到：本页「测试报告」面板。等待消息：正在依据作答生成人格报告…
- 轮询方式：每 2 秒 `callAppBridge({type:"GetCellValue", data:"人格测试/默认表格", payload:"测试报告/1"})`，最多 45 次。得到非空文本后停止，并用 Markdown 渲染。超时则显示「生成时间较长，可稍后到测试档案刷新查看」，并提供「再查一次」按钮继续轮询。
- 报告面板右上角有「<」「>」。`<` 读取上一行，`>` 读取下一行。行号变化后，用 `GetCellValue` 分别读取题量、答案、报告层级、测试报告并回填页面。
- `callAppBridge({type:"GetRecordCount", data:"人格测试/默认表格"})`。当前行小于等于 1 时 `<` 不可操作；当前行大于等于记录数时 `>` 不可操作。
- 报告面板下方重复显示：本报告不构成心理诊断。快测记录若报告层级区域仍可见题量，同时保留「样本较小，仅供参考」。

本页另有「新的测试」按钮：清空题量、答案、报告层级和报告面板，当前行设为 0，不删除记录。

## 测试档案

左上大标题：测试档案。说明：查看、修正或删除已提交的作答。右上按钮「+ 新的测试」，跳到人格测试页并执行该页的清空。

搜索框按答案文本筛选。筛选芯片按题量和报告层级筛选，可清除筛选。筛选按钮必须真正过滤卡片。

主体用卡片列表，不用单独的只读页。卡片字段与编辑表单一致。
- `callAppBridge({type:"GetTableCSV", data:"人格测试/默认表格", payload:"题量,报告层级,答案"})`
- 每张卡片显示题量、报告层级、答案摘要，并记住原始行号。
- 点击卡片：当前行设为该原始行号，打开编辑表单并逐字段填充。
- 「查看报告」：`GetCellValue` 取 `测试报告/原始行号`，弹层用 Markdown 显示；为空则显示生成中，并有刷新按钮。
- 「删除」：先确认，确认后 `callAppBridge({type:"DeleteRecord", data:"人格测试/默认表格", payload:行号.toString()})`，然后重新加载列表。取消则不删除。

编辑表单标题：编辑人格测试。表：人格测试。字段：题量、答案、报告层级。三个字段都可改，控件与新建时相同。保存按钮依次调用：
- `SetCellValue`，数据源 `人格测试/默认表格`，payload `题量/当前行/新值`
- `SetCellValue`，payload `报告层级/当前行/新值`
- `SetCellValue`，payload `答案/当前行/新值`
保存后关闭表单并刷新卡片。表单内明确提示：保存只会修正记录，不会重新生成测试报告；需要新报告请回人格测试页重新提交。取消按钮丢弃未保存修改。

## 类型图鉴

左上大标题：类型图鉴。说明：选择十六型之一，按层级或某个关注方面生成解读。右上按钮「去做测试」，跳到人格测试页。

上方是十六型点选墙，单选，选中项有金色光环。不显示自造中文别名。

报告层级芯片：默认、详细、完整。未选不能提交。关注内容是单行文本，可空。旁边四个快捷芯片「职业」「爱情」「优势」「注意点」，点击只填入关注内容，不直接提交。「清空关注」清空该框。提示：关注内容为空时按报告层级输出；不为空时只阐述该方面。

按钮「生成解读」。点击时：
- 表：类型查询。字段：人格类型、报告层级、关注内容。
- payload 示例：`{"人格类型":"INFJ","报告层级":"默认","关注内容":""}`。关注内容为空也要提交空字符串。
- `callAppBridge({type:"SubmitRecord", data:"类型查询", payload:"上述JSON文本"})`。当前行设为 1。
- 轮询 `callAppBridge({type:"GetCellValue", data:"类型查询/默认表格", payload:"类型解读/1"})`，等待消息：正在整理类型解读…。节奏与人格测试相同。结果用 Markdown 渲染。
- 面板右上角 `<` `>` 按记录数浏览，规则同人格测试。数据源改为 `类型查询/默认表格`，字段为人格类型、报告层级、关注内容、类型解读。
- 文末显示：仅供自我了解，不构成心理诊断。

下方是查询记录卡片。
- `callAppBridge({type:"GetTableCSV", data:"类型查询/默认表格", payload:"人格类型,报告层级,关注内容"})`
- 可按人格类型搜索，可按报告层级筛选。
- 点击卡片打开编辑表单并填充三个用户字段。
- 「查看解读」用 `GetCellValue` 显示类型解读 Markdown，空内容可刷新。
- 「删除」确认后 `DeleteRecord`，数据源 `类型查询/默认表格`，payload 为原始行号字符串。
- 编辑保存依次 `SetCellValue` 人格类型、报告层级、关注内容。提示保存不重新生成类型解读。

## 双型对照

左上大标题：双型对照。说明：选择两种人格，查看维度异同；正式差异以技能报告为准，页面不替用户下结论。

左右两列类型选择器，各用十六型芯片单选。中间是「互换」按钮，点击后交换两列选择，若已有报告面板则保留到下次生成，不把旧报告说成新结果。两型相同或未选齐时禁用生成，并提示需要两个十六型。

选择完成后显示「字母对照预览」：把两个四字母拆成 E/I、S/N、T/F、J/P，相同字母用同一色，不同字母左右对置。预览标题写明这不是正式报告，中文名以报告为准。

按钮「生成对比」。点击时：
- 表：类型对比。字段只有人格类型、对比类型。
- payload 示例：`{"人格类型":"INFJ","对比类型":"INTJ"}`。
- `callAppBridge({type:"SubmitRecord", data:"类型对比", payload:"上述JSON文本"})`。当前行设为 1。
- 轮询 `callAppBridge({type:"GetCellValue", data:"类型对比/默认表格", payload:"对比报告/1"})`，等待消息：正在对照两种人格…。得到内容后 Markdown 渲染。
- `<` `>` 浏览历史，数据源 `类型对比/默认表格`，读取人格类型、对比类型、对比报告。边界规则同前。
- 报告下方显示：请自行判断更接近哪一型；仅供自我了解，不构成心理诊断。

「重新选择」清空两型选择和当前报告面板，当前行设为 0，不删除记录。

下方对照记录用双型卡片显示。
- `callAppBridge({type:"GetTableCSV", data:"类型对比/默认表格", payload:"人格类型,对比类型"})`
- 可搜索任一类型，可只看包含某型的记录。
- 点击卡片进入编辑：两个类型可改，保存时 `SetCellValue` 人格类型和对比类型。若改成相同类型，禁止保存。提示保存不重新生成对比报告。
- 「查看对比」显示对比报告 Markdown，可刷新。
- 「删除」确认后删除该原始行并刷新。

## 统一交互

五个页面切换时保留各自未提交的草稿，直到用户清空或提交。所有弹层都有关闭按钮，点击遮罩也可关闭。确认删除必须有确认和取消。桥接失败时在原位置显示「暂时无法读取，请重试」，并提供重试按钮，重试要重新调用刚才的接口。卡片、行和按钮都有悬停反馈。页面加载时并行读取首页三组记录数和最近测试，不要串成无法失败恢复的长链。操作按钮对应的功能必须全部实现，不能只做样式。
