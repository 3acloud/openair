# 智拍速记
这是一个智拍速记网页应用，包含首页（中文宣传长页）、随手拍、笔记库。不要用户登录页。页面统一采用「暖暮摄影」主题：背景为暖米白到浅琥珀的柔和渐变，主色深墨蓝 `#1B2430`，点缀琥珀金 `#E8A838` 与珊瑚橙 `#E07A5F`，卡片大圆角、轻胶片颗粒阴影，按钮为墨蓝到琥珀的微渐变并带悬停上浮与光晕，字体使用柔和中文 sans-serif。宣传区用大留白、手机模型、步骤时间线；列表一律卡片化。操作按钮对应的功能必须全部实现。

页面顶部导航栏，使用深墨蓝半透明磨砂背景，滚动时加深
	左侧显示Logo（镜头光圈+声波涟漪图标）和「智拍速记」
	右侧显示标签：首页、随手拍、笔记库
	窄屏时折叠为汉堡菜单

首页（中文宣传网页长页，一屏接一屏向下铺开，模拟宣传长截图）
	首屏英雄区
		主标题：智拍速记
		超级口号：开口说，它自己归档
		副文案：随手拍下照片并写下说明，AI 智能识别画面并自动命名、分类、归档，同时生成解说音频；打开详情即可自动播放，方便搜索与回顾。
		主按钮：开始使用，点击跳转「随手拍」
		次按钮：看看别人怎么记，平滑滚动到用户评价
		右侧或下方展示手机端界面模型（仅展示，非真机）：圆角手机框内是录音/拍摄界面，大圆形麦克风按钮带呼吸灯，顶部显示「正在聆听与识别…」，下方假数据标题「西湖边的桂花糖藕」、地点「杭州 · 西湖」、时间「刚才」
	三步使用流程（横向三卡片，带 01/02/03 数字）
		01 随手拍，开口说：按下快门或选择相册，再补一句当时想记住的话
		02 它自己归档：AI 识别主体、场景、文字与细节，自动命名、分类、打关键词，记下时间地点
		03 听着回顾：自动生成口语解说并配音，打开详情即播放，搜索标题/关键词即达
	功能卖点区（四宫格卡片，悬停微抬）
		自动命名与地点记录：结合画面、文字说明、拍摄时间与地点生成好记的标题
		智能整理：十大分类自动归档，关键词可搜，卡片墙一目了然
		解说音频：专业讲解员口吻约 120 字，打开详情自动播放
		隐私保护：支持「是否私密」标记，私密笔记卡片带锁标，仅自己可见
	分类彩带：生活日常、工作学习、旅行出游、美食餐饮、人物纪念、风景建筑、物品收藏、文档票据、灵感创意、其他（纯展示，点击某分类跳转笔记库并带上该分类筛选）
	数据概览三卡片（并列）
		全部笔记
			API名称:GetRecordCount,数据源:照片笔记/默认表格
		本周新记
			API名称:GetTableCSV,数据源:照片笔记/默认表格,字段:[创建时间,拍摄时间]
			筛选拍摄时间或创建时间为本周的记录计算数量
		私密笔记
			API名称:GetTableCSV,数据源:照片笔记/默认表格,字段:[是否私密]
			筛选是否私密为「是」的记录计算数量
	最近笔记：显示最近 4 条，必须用卡片形式（不要表格）
		API名称:GetTableCSV,数据源:照片笔记/默认表格,字段:[笔记标题,笔记图片,文字说明,识别描述,分类,关键词,拍摄地点,拍摄时间,是否私密,创建时间]
		按拍摄时间降序，取前 4 条
		每张卡片：封面图（笔记图片全局文件名，图片链接 https://www.ithinkair.com:3031/download/全局文件名；若单元格已是识别文本则用占位封面+分类色块）、笔记标题、分类胶囊、关键词、拍摄地点与拍摄时间、私密则显示锁标
		点击卡片进入该条详情（见下方「笔记详情」），当前行设为对应行号
	用户评价区（三则假评价卡片，仅宣传展示）
		「出差拍白板，晚上听解说就能回忆会议重点。」
		「带娃出游不用再翻相册发呆，关键词一搜全出来。」
		「票据和灵感分得清清楚楚，私密开关也让人安心。」
	底部门户条
		大按钮：开始使用 / 立即记录，点击跳转「随手拍」
		辅助文字：无需登录，拍一下，让它替你记得

「随手拍」页面
	左上大标题：随手拍
	说明：拍下这一刻，写下或补一句说明，AI 识别画面并自动命名分类，再生成可听的解说

	上方画幅区：显示当前照片（初始为虚线取景框+镜头图标，提示「拍一张或从相册选」）
	按钮组（必须全部实现）
		按钮：拍照，调用 CapturePhoto，返回图片全局文件名，作为当前图片并预览（https://www.ithinkair.com:3031/download/全局文件名）
		按钮：相册，调用 SelectImage，返回图片全局文件名，作为当前图片并预览

	说明与元信息
		文字说明：多行输入，占位「这一刻想记住什么？一句就够」
		拍摄地点：文本输入，占位「在哪里拍的？」
		拍摄时间：日期时间，默认当前时间
		是否私密：开关，布尔值用「是」或「否」，默认「否」
	主按钮：识别并归档（仅当已有当前图片时启用）
		表单标题:照片笔记,表:照片笔记,字段:[{字段名:笔记标题,类型:文本},{字段名:笔记图片,类型:指令流,指令类型:生成格式化文本,指令描述:请仔细识别照片中的主体、场景、文字和关键细节，生成简洁准确、便于日后搜索与回顾的归档信息。分类必须是以下之一：生活日常、工作学习、旅行出游、美食餐饮、人物纪念、风景建筑、物品收藏、文档票据、灵感创意、其他。以JSON格式输出"笔记标题"、"识别描述"、"分类"、"关键词"。},{字段名:文字说明,类型:文本},{字段名:识别描述,类型:文本},{字段名:分类,类型:单选项,可选项:生活日常,工作学习,旅行出游,美食餐饮,人物纪念,风景建筑,物品收藏,文档票据,灵感创意,其他},{字段名:关键词,类型:文本},{字段名:拍摄地点,类型:文本},{字段名:拍摄时间,类型:日期时间},{字段名:是否私密,类型:布尔},{字段名:创建时间,类型:日期时间}]
			创建时间在表单上要包含但隐藏，提交时设为当前日期时间
			笔记标题、识别描述、分类、关键词不要让用户手工填，提交时先给空值，等待指令流异步回填
			笔记图片字段值：当前图片全局文件名
			使用 SubmitRecord 提交，提交后当前行是 1
		提交后进入「归档中」状态，展示取景动画与文案「正在识别画面并归档…」
		指令描述指定了以 JSON 格式输出，因此轮询 JSON 字段「笔记标题」（同时可读识别描述、分类、关键词）
			轮询：API名称:GetCellValue,数据源:照片笔记/默认表格,字段名:笔记标题,行号:当前行
			若为空或仍在生成则继续轮询，直到笔记标题、识别描述、分类、关键词均有值
			输出到页面模块「识别归档结果」，用 Markdown 主题显示识别描述；分类以胶囊展示；关键词打成标签
			笔记图片详情：API名称:GetCellValue,数据源:照片笔记/默认表格,字段名:笔记图片,行号:当前行 ，文本用 Markdown 主题显示

		文稿标题取「笔记标题」原文或「笔记标题 + 『·解说』」
		表单标题:解说文稿,表:解说文稿,字段:[{字段名:文稿标题,类型:文本},{字段名:笔记标题,类型:关联表,关联表名:照片笔记,关联字段名:笔记标题},{字段名:解说文案,类型:指令流,指令类型:生成文本,指令描述:我是一名专业讲解员，请根据以下照片笔记信息，撰写一段生动自然、适合口语播报的解说词，约120字，语气亲切平实，开头点明主题，接着讲述画面重点和用户想记录的内容，方便日后听着回顾。}]
			笔记标题的可选值来源:
				API名称:GetTableCSV,数据源:照片笔记/默认表格,字段:[笔记标题]
			使用 SubmitRecord 提交解说文稿
			提交后轮询字段:解说文案

				输出到「解说文案」，用 Markdown 主题显示；等待消息：「讲解员正在写稿…」
	解说文案生成后，自动生成语音档案（不要单独做语音档案页面）
		音频标题取「笔记标题 + 『·语音』」
		表单标题:语音档案,表:语音档案,字段:[{字段名:音频标题,类型:文本},{字段名:文稿标题,类型:关联表,关联表名:解说文稿,关联字段名:文稿标题},{字段名:笔记标题,类型:关联表,关联表名:照片笔记,关联字段名:笔记标题},{字段名:解说音频,类型:指令流,指令类型:输出音频,指令描述:{{解说文稿.解说文案}},音色:女性有声书}]
			文稿标题的可选值来源:
				API名称:GetTableCSV,数据源:解说文稿/默认表格,字段:[文稿标题,笔记标题]
			笔记标题的可选值来源:
				API名称:GetTableCSV,数据源:照片笔记/默认表格,字段:[笔记标题]
			使用 SubmitRecord 提交语音档案
			提交后轮询字段:解说音频
				API名称:GetCellValue,数据源:语音档案/默认表格,字段名:解说音频,行号:1
				等待消息：「正在配音，女性有声书音色…」
				生成结束后在本页放入音频播放器，音频文件链接优先 https://www.ithinkair.com:3031/private/全局文件名 ，下载用 https://www.ithinkair.com:3031/download/全局文件名
	全部完成后显示按钮：查看详情（打开本条笔记详情并自动播放）、再记一条（清空画幅、说明、结果区，当前行设为 0）

通用规则
	当前行初始是 0；SubmitRecord 成功后当前行是 1
	字段名只能使用表定义中出现过的字段，不要编造 ID 类字段
	创建时间在卡片/列表上不显示，在表单上包含但隐藏
	指令流字段不是用户手工填写的，SubmitRecord 后由后台 AI 异步生成；有「以JSON格式输出」则轮询这些 JSON 字段，否则轮询该指令流字段
	关联表字段展示时，若需更多信息再 GetTableCSV 取关联表字段
	图片预览与封面一律用 https://www.ithinkair.com:3031/download/全局文件名
	音频在浏览器中播放用 https://www.ithinkair.com:3031/private/全局文件名 ，下载导出用 https://www.ithinkair.com:3031/download/全局文件名
	列表必须卡片形式；首页最近列表点击进入详情
	各页操作按钮、搜索、筛选、提交、轮询、自动播放、删除级联都必须实现
	空状态：笔记库无数据时展示「还没有笔记，去拍一张」按钮跳转随手拍
