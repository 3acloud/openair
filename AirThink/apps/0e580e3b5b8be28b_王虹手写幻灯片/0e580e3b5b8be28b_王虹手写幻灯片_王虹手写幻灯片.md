# 王虹手写幻灯片
	这是一个将主题与内容材料一键制成「王虹学术报告气质」手写风 HTML 幻灯片的网页应用，包含首页、开始制作、作品库三个页面。整体采用学术手账气质：米白宣纸纹理背景、墨色与朱红点缀、细线网格与胶带便签装饰，标题使用略带手写感的衬线字体，卡片带轻微纸张阴影与悬停微抬起效果，按钮为圆角墨条风格。
	页面顶部导航栏，使用深墨灰至炭黑渐变背景，底部有细朱红分隔线
		左侧显示Logo（羽毛笔/笔记本图标）和「王虹手写幻灯片」
		右侧显示标签：首页、开始制作、作品库
	首页
		主标题：王虹手写幻灯片，说明：把主题与材料整理成连续故事线，生成 Notability 手写视觉的 16:9 学术 HTML 幻灯片，支持原版、时间轴演示版与逐页 PNG 导出
		中央大按钮：开始制作幻灯片，点击跳转到「开始制作」页面
		接下来是并列的三个统计卡片（不同淡彩底色）：
			作品总数
				API名称:GetRecordCount,数据源:幻灯片制作/默认表格
			本月制作数
				API名称:GetTableCSV,数据源:幻灯片制作/默认表格,字段:[演示日期]
				筛选演示日期为当前月的记录计算数量
			含时间轴版作品数
				API名称:GetTableCSV,数据源:幻灯片制作/默认表格,字段:[输出版本]
				筛选输出版本包含「时间轴」的记录计算数量
		接下来是「最近作品」区域：以卡片列表显示最近 5 条，字段包括：演示主题、署名、演示场合、演示日期、输出版本
			API名称:GetTableCSV,数据源:幻灯片制作/默认表格,字段:[演示主题,内容材料,署名,演示场合,演示日期,输出版本]
			按演示日期降序，取前 5 条；内容材料卡片上只显示前 60 字摘要
			每张卡片可点击查看详情（跳转作品库并定位该行）；卡片右下显示「打开成品」入口（若该行幻灯片文件已生成）
	「开始制作」页面
		左上显示大标题：开始制作，说明：填写主题与材料，后台将按王虹学术手写风整理故事线、生成讲稿备注，并按所选版本打包 ZIP（HTML、本地资源、逐页 PNG、总览图）
		右上按钮：查看作品库，跳转到「作品库」页面
		主区域为制作表单（居中卡片，纸张阴影）
			表单标题:幻灯片制作,表:幻灯片制作,字段:[{字段名:演示主题,类型:文本},{字段名:内容材料,类型:文本},{字段名:署名,类型:文本},{字段名:演示场合,类型:文本},{字段名:演示日期,类型:日期},{字段名:输出版本,类型:单选项,可选项:原版和时间轴版,仅原版,仅时间轴版},{字段名:幻灯片文件,类型:指令流}]
			表单仅展示并填写：演示主题、内容材料（多行大文本框）、署名、演示场合、演示日期、输出版本
			演示主题必填；内容材料必填，支持长文本粘贴
			输出版本默认「原版和时间轴版」
			演示日期默认为当天
			不显示「幻灯片文件」输入框（指令流由后台异步生成）
		主按钮：生成手写幻灯片，点击校验必填后 SubmitRecord 提交
			API名称:SubmitRecord,表:幻灯片制作,payload:表单数据(JSON文本)
			提交后当前行=1
		提交后进入生成等待区（同一卡片下方展开）
			显示手写风格等待文案：「正在整理故事线 · 绘制 Notability 手写页 · 渲染逐页与总览…」
			轮询标题:幻灯片制作,表:幻灯片制作,字段:幻灯片文件,输出到:生成结果区
			轮询方式：定时调用 GetCellValue
				API名称:GetCellValue,数据源:幻灯片制作/默认表格,字段名:幻灯片文件,行号:当前行
			当幻灯片文件字段返回有效全局文件名后结束等待
			生成结果区：
				用 Markdown 主题展示完成说明与文件名
				提供按钮「下载 ZIP 成品」：链接为 https://www.ithinkair.com:3031/download/全局文件名
				提供按钮「浏览器打开」（若可识别为 HTML 入口则用 https://www.ithinkair.com:3031/private/全局文件名，可在 iframe 预览；否则仍走下载）
				若用户选择「仅时间轴版」，结果区文案注明仅包含时间轴版及相应导出成果
		结果区右上角提供「再做一份」：清空表单可见字段、清空生成结果区，当前行设为 0，输出版本恢复默认
		页面底部以折叠便签展示制作小贴士：每页聚焦一个问题、统一手写视觉、自动结构检查/翻页检查/逐页渲染检查/总览检查
	「作品库」页面
		左上显示大标题：作品库，说明：浏览、回看与管理已生成的手写幻灯片作品
		右上按钮：+ 新建作品，跳转到「开始制作」页面
		搜索框：按演示主题、署名、演示场合关键词过滤
		筛选器：按输出版本筛选；按演示日期范围筛选
		主体以卡片网格展示作品（优先卡片，不再用密集大表）
			API名称:GetTableCSV,数据源:幻灯片制作/默认表格,字段:[演示主题,内容材料,署名,演示场合,演示日期,输出版本]
			卡片展示：演示主题（标题）、署名 · 演示场合、演示日期、输出版本标签、内容材料前 80 字
			每张卡片操作：
				查看详情：弹出模态，Markdown 渲染完整内容材料与元信息；并读取指令流文件字段
					API名称:GetCellValue,数据源:幻灯片制作/默认表格,字段名:幻灯片文件,行号:该行
					若已生成：模态内提供下载 ZIP、iframe 打开 HTML（private 链接）
					若未生成或生成中：显示「成品生成中或未完成」
				编辑：将当前行设为该行号，拉取各字段到表单
					API名称:GetCellValue,数据源:幻灯片制作/默认表格,字段名:演示主题/内容材料/署名/演示场合/演示日期/输出版本,行号:当前行
					编辑表单字段与「开始制作」一致；修改后用 SetCellValue 逐字段更新（不要用 SubmitRecord）
					API名称:SetCellValue,数据源:幻灯片制作/默认表格,payload:字段名/行/值
					注意：幻灯片文件为指令流，编辑普通字段不会自动重跑；若需重新生成，提供「重新生成成品」按钮——再次 SubmitRecord 提交一份新记录（或明确提示用户新建），避免覆盖混乱
				删除：确认后 DeleteRecord
					API名称:DeleteRecord,数据源:幻灯片制作/默认表格,payload:行号.toString()
				下载成品：GetCellValue 取幻灯片文件全局文件名，跳转 https://www.ithinkair.com:3031/download/全局文件名
		支持按演示日期降序排序；列表在增删改后刷新
		点击首页最近作品进入时，自动打开对应卡片详情
	生成与指令流约定（全应用遵守）
		「幻灯片文件」为指令流，非手工填写；仅在 SubmitRecord 后由后台任务智能体异步生成
		指令描述已固定为技能制作 16:9 王虹学术手写风 HTML，并按输出版本打包 ZIP；前端只负责提交字段：演示主题、内容材料、署名、演示场合、演示日期、输出版本
		SubmitRecord 后必须轮询 GetCellValue(幻灯片文件) 直至获得全局文件名或明确失败信息
		展示指令流详情时，文本用 Markdown 主题；文件用 download/private 链接；HTML 可用 iframe 打开 private 链接
		全局文件名图片/文件链接规则：
			下载：https://www.ithinkair.com:3031/download/全局文件名
			浏览器打开：https://www.ithinkair.com:3031/private/全局文件名
	交互与数据规则
		当前行初始为 0；新建 SubmitRecord 成功后当前行为 1
		主体列表/卡片展示字段与表单字段保持一致方向，便于点选进入编辑
		字段名严格使用表定义：演示主题、内容材料、署名、演示场合、演示日期、输出版本、幻灯片文件
		布尔值若出现用「是/否」；本表无布尔、无关联表、无自动 ID 字段，勿编造 ID 字段
		不需要用户登录页；所有导航、搜索、筛选、提交、轮询、下载、iframe 预览、编辑、删除按钮功能必须实现
		各页面统一米白宣纸 + 墨色朱红学术手账主题，卡片与按钮具备悬停反馈，空状态给出「还没有作品，去开始制作」引导
