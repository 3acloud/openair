# Bento 演示工坊
	这是一个智能 Bento 演示文稿网页应用，把演示需求与可选素材装进一格格便当式卡片，由后台技能自动编排图表、动画、逐页讲稿，并输出可独立打开的 .bento.html。包含首页、创作工坊、文稿库三个页面。不需要用户登录页。页面像打开的多层便当盒：大圆角隔间、留白充足、格子清晰。统一主题为「和纸工坊」——背景浅米纸色渐变（#F6F0E6 → #EFE6D9），主色柿朱 #D85A30，辅色墨青 #1F3A3A，点缀青磁 #3A8F7B 与淡金 #C9A227；标题用衬线（有则 Noto Serif SC，无则 serif），正文用柔和无衬线；卡片白底微暖（#FFFBF5），圆角 22px，轻阴影，悬停时轻微上浮并露出柿朱描边；按钮为柿朱实心或墨青描边，按压有 120ms 缩放。全局不要出现表定义以外的字段名，不要编造 ID / 创建日期字段。当前行初始为 0。
	页面顶部导航栏，使用墨青到深松绿的横向渐变，底部一条淡金细线
		左侧显示 Logo（三格便当图标）和「Bento 演示工坊」
		右侧显示标签：首页、创作工坊、文稿库；当前页标签用柿朱下划线
	首页
		主标题：Bento 演示工坊
		说明：用一段需求，可选地附上素材，智能生成结构清晰、风格统一、带逐页讲稿的 Bento 演示；也可在已有文稿上按新需求改版
		中央大按钮：开始创作演示，点击跳转到「创作工坊」且当前行设为 0、清空表单与预览
		接下来是并列的三个便当格卡片（各有不同淡底色：柿朱浅、青磁浅、淡金浅）
			文稿总数
				API名称:GetRecordCount,数据源:演示文稿/默认表格
			本周新作
				API名称:GetTableCSV,数据源:演示文稿/默认表格,字段:[演示需求,素材文件,演示文件]
				若无法按日期筛选，则展示记录总数并标注「全部文稿」；有可推断的新记录时取最近若干条计数
			可预览成片
				API名称:GetTableCSV,数据源:演示文稿/默认表格,字段:[演示需求,素材文件,演示文件]
				筛选演示文件字段非空的记录计算数量
		接下来是「最近文稿」区域，标题右侧小字「点击卡片查看详情」
			以卡片网格（每行最多 3 张）显示最近 6 条，列表必须用卡片形式
			API名称:GetTableCSV,数据源:演示文稿/默认表格,字段:[演示需求,素材文件,演示文件]
			卡片内容：演示需求前 80 字（空则显示「未填写需求」）、素材状态（有全局文件名显示「已附素材」否则「无素材」）、成片状态（演示文件非空显示「可预览」否则「生成中 / 未生成」）
			点击任一最近卡片：当前行设为对应行号（行号从 1 开始，与 CSV 顺序一致），跳转文稿库详情态（全屏预览该行演示文件；若演示文件为空则打开创作工坊并回填该行）
	「创作工坊」页面
		左上显示大标题：创作工坊
		说明：描述你要讲的故事、受众与风格；有素材就带上，有旧文稿就把旧文件当作素材以便改版
		右上按钮组：
			按钮：查看文稿库，跳转到「文稿库」
			按钮：新建空白，清空演示需求与素材、关闭预览、当前行设为 0
		页面左右分栏（窄屏改为上下）：左侧是需求便当格，右侧是成片预览便当格
		左侧表单
			表单标题:Bento演示文稿,表:演示文稿,字段:[{字段名:演示需求,类型:文本},{字段名:素材文件,类型:文本},{字段名:演示文件,类型:指令流}]
			演示需求：大段文本域，占位符示例「为新产品发布会做 10 页 Bento 演示，面向投资人，强调增长、差异化与路线图，视觉偏深色科技，每页要有讲稿」
			素材文件：不是手工填文本。显示已选文件名；按钮「选择素材」调用 SelectFile 返回文件全局文件名并写入素材文件；按钮「清除素材」将素材文件置空。提示：可上传参考图片、文档或已有 .bento.html，技能会据其组织或改版
			不在表单上展示演示文件输入框（指令流由后台异步生成）
			主按钮标题：生成 / 改版演示，仅当演示需求非空时启用
				点击使用 SubmitRecord 提交，表单数据为 json 文本，字段仅包含演示需求、素材文件（无素材则空字符串）
				提交后当前行是 1
				提交后必须轮询等待后台 AI 异步生成结束
				轮询标题:Bento演示文稿,表:演示文稿,字段:演示文件,输出到:成片预览,等待消息:正在为你编排图表、转场与逐页讲稿，请稍候…
				轮询使用 GetCellValue，数据源:演示文稿/默认表格,字段名:演示文件,行号:当前行；直到单元格返回非空的全局文件名
			次按钮：保存需求到当前行（仅当前行>=1 时启用）
				依次 SetCellValue 更新演示需求、素材文件；不要用 SubmitRecord；不触发轮询
				API名称:SetCellValue,数据源:演示文稿/默认表格,payload:字段名/行/值
		右侧成片预览
			初始文案：「生成后将在此嵌入预览」
			轮询期间显示等待消息与缓慢脉冲的三格便当动画，禁止操作预览区按钮
			演示文件有值后：
				HTML 预览必须用 iframe 打开链接 https://www.ithinkair.com:3031/private/全局文件名
				iframe 高度至少 70vh，圆角裁剪，白底
				预览标题栏右侧按钮：
					在新标签打开：访问 https://www.ithinkair.com:3031/private/全局文件名
					下载成片：访问 https://www.ithinkair.com:3031/download/全局文件名
				若 GetCellValue 返回的是可展示文本而非文件名，则用 Markdown 主题显示该文本；一旦识别为全局文件名则始终优先 iframe
			成片预览下方显示当前行的演示需求全文（只读）与素材下载（素材文件非空时链接 https://www.ithinkair.com:3031/download/全局文件名）
		创作工坊底部窄条记录翻页（参考文稿库同一套行号）
			按钮标题:< ，点击当前行-1 并回填
			按钮标题:> ，点击当前行+1 并回填
			API名称:GetRecordCount,数据源:演示文稿/默认表格
			API名称:GetCellValue,数据源:演示文稿/默认表格,字段名:演示需求,行号:当前行
			API名称:GetCellValue,数据源:演示文稿/默认表格,字段名:素材文件,行号:当前行
			API名称:GetCellValue,数据源:演示文稿/默认表格,字段名:演示文件,行号:当前行
			当前行<=1 时 < 不可操作；当前行>=RecordCount 或 RecordCount=0 时 > 不可操作；当前行=0 时两个翻页都不可操作
			回填后：演示需求写入文本域，素材文件显示文件名，演示文件非空则刷新 iframe
	「文稿库」页面
		左上显示大标题：文稿库
		说明：所有已提交的 Bento 演示，卡片浏览、预览、改版或删除
		右上是按钮：+ 新的演示，跳转创作工坊，当前行=0，清空表单
		搜索框：按演示需求关键字过滤卡片
		筛选器：全部 / 已成片 / 未成片（根据演示文件是否非空）
		主体不用传统宽表做唯一视图，而以卡片网格为主（大屏 3 列、中屏 2 列、小屏 1 列）
			API名称:GetTableCSV,数据源:演示文稿/默认表格,字段:[演示需求,素材文件,演示文件]
			GetTableCSV 字段必须与表单字段一致，便于点卡片进入编辑
			每张卡片显示：需求摘要（前 60 字）、素材标签、成片标签
			卡片主按钮：预览
				若演示文件非空，页面下部或侧抽屉打开 iframe：https://www.ithinkair.com:3031/private/全局文件名，并提供新标签打开与下载
				若为空，提示「尚未生成，去创作工坊重新提交」，并带出该行
			卡片操作：改版、删除
				改版：当前行=该卡片行号，跳转创作工坊，GetCellValue 逐字段回填演示需求与素材文件；用户改需求后点「生成 / 改版演示」再次 SubmitRecord（新提交后当前行变 1 并重新轮询演示文件）。提示用户：若要在旧成片上修改，请先把旧 .bento.html 当作素材选入
				删除：调用 DeleteRecord,数据源:演示文稿/默认表格,payload:行号.toString()；确认对话框后执行；成功后刷新卡片与 RecordCount，若删的是当前行则当前行=0
			点击卡片空白区域同样视为进入详情：当前行=行号，展开详情便当格
				详情中用 Markdown 展示演示需求全文
				素材文件：有则给出下载链接 https://www.ithinkair.com:3031/download/全局文件名
				演示文件：GetCellValue 取全局文件名，iframe 嵌入 https://www.ithinkair.com:3031/private/全局文件名
		详情便当格右上角同样提供 < 与 > 在记录间切换，规则与创作工坊相同
		空状态：无记录时展示插画式空便当格与按钮「创作第一份演示」
	数据与桥接约定（必须遵守）
		数据源一律为：演示文稿/默认表格
		调用 GetTableCSV 获取不包含标题行的 csv 文本，逗号分隔字段名必须是：演示需求,素材文件,演示文件
		csv 中文件字段文本是全局文件名；图片若出现亦是全局文件名
		新建只用 SubmitRecord；修改已有行的普通字段用 SetCellValue，不用 SubmitRecord
		指令流字段演示文件不可手工填写；SubmitRecord 之后轮询该指令流字段本身（指令描述未要求以 JSON 格式输出）
		要显示指令流详情：先 GetCellValue，文件则 iframe，文本则 Markdown
		GetRecordRow 用于按「字段名/值」定位行号（从 1 计数）；DeleteRecord 的 payload 必须是行号的 toString()
		需要时可用 GetCellBullet 取单元格 Bullet
		选择素材只用 SelectFile；不要把用户没选的文件名写进表单
		下载导出访问 https://www.ithinkair.com:3031/download/全局文件名；浏览器打开或 iframe 预览 HTML 访问 https://www.ithinkair.com:3031/private/全局文件名
	各页面操作按钮对应的功能必须都实现。表格/卡片点击可进入同一套表单字段编辑。卡片与预览均需悬停反馈。生成中禁止重复提交。网络或空值要有友好错误提示，不得阻断整页。
