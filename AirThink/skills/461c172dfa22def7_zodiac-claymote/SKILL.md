# 十二生肖黏土软萌风表情包生成器

用**原创十二生肖角色**呈现受欢迎的软萌黏土画风内核：黏土软胶材质、圆滚滚比例、生活化微场景、夸张但温和的情绪表达。输出成套可直接上微信表情开放平台的表情包。

## 核心原则（先读，别跳）

这套东西好用的原因不是某个具体形象，而是四个可拆解的**画风要素**：

1. **材质**：聚合物黏土 / 软胶盲盒手感，哑光、圆角、有轻微指纹压痕，无锐利边角
2. **比例**：头身比 1:1 ~ 1:1.5 的 chibi，短手短脚，身体是一个"圆球 + 小四肢"
3. **情绪**：表情极度夸张但不带攻击性——委屈只是眼眶含泪，生气只是鼓腮皱眉
4. **场景**：日常生活切片（沙发、办公桌、被窝、奶茶杯），背景干净，主体突出

**只借要素，不借形象。** 具体合规红线见下方。

## 工作流

### Step 0 · 定需求（缺项才问，别过度询问）
需要确认的最小集合：**生肖**（哪个/哪几个）、**职业人设**、**场景主题**、**张数**（默认 16 张一套，微信表情包常用规格）。
用户没说的做合理默认：全套 12 生肖 × 混合职业 × 日常+职场各半。

### Step 1 · 选角色
`references/zodiac-characters.md` → 每个生肖有：主色/辅色十六进制值、体貌特征、性格标签、招牌小动作、职业适配倾向。
再叠加 `references/professions.md` 的职业服装与道具。

### Step 2 · 排场景矩阵
`references/scenes-emotions.md` → 从 24 个情绪 × 生活场景 × 职场场景里挑，保证**情绪不重复、场景有层次**（不要 16 张全是崩溃）。
配比建议：正面情绪 30% / 负面宣泄 40% / 摆烂摸鱼 20% / 节日祝福 10%。

### Step 3 · 装配提示词
```bash
python scripts/build_prompt.py --zodiac 龙 --job 工程师 --emotion 崩溃 --scene 线上出Bug
python scripts/build_prompt.py --set 16 --mix --out prompts.md
python scripts/build_prompt.py --list
```
脚本输出**中文说明 + 英文提示词**（英文提示词对生图模型更稳定，中文说明用于人工核对）。

### Step 4 · 生成图片
用生图工具逐张生成，参数：`1:1` 正方形、`--ar 1:1`、高细节。
一次生成一张，别让模型自己排九宫格（会串味、会缩水）。
**保留一套无文字原图**（后面横幅要用），再复制一份用于叠文案。

### Step 5 · 清除工具水印
部分生图服务会加角标水印，投稿前必须清除：
```bash
python scripts/remove_watermark.py --input ./raw --corner br --area "0.35,0.08" --preview   # 先预览框选
python scripts/remove_watermark.py --input ./raw --corner br --area "0.35,0.08" --method fill  # 确认后清除
```
水印位置不准就改 `--region "x,y,w,h"` 精确指定；装了 opencv-python 可用 `--method inpaint` 效果更好。

### Step 6 · 加中文文案
**不要在提示词里写中文**——生图模型中文渲染几乎必错。
正确做法：生成无字图 → 用脚本叠加文案：
```bash
python scripts/caption_sticker.py --input ./cleaned --caption-map captions.json --size 240
```
自动完成：裁切正方 → 叠加描边白字（黑体）→ 导出 240×240 主图。

### Step 7 · 一键生成微信投稿素材包
```bash
python scripts/wechat_pack.py --input ./sticker_out --raw-src ./cleaned --banner-src ./cleaned \
  --cover 01.png --icon 09.png --with-tips --zip --name "专辑名"
```
严格按微信表情开放平台规范产出：表情主图 240×240（8~24 张）+ 缩略图 120×120 +
封面 240×240（圆外透明）+ 聊天面板图标 50×50（圆外透明）+ 详情页横幅 750×400（无文字、非白底），
自动逐项校验尺寸/格式/体积，输出《投稿清单.md》和可直接对照上传的 zip。

实测审核驳回经验（2026-09，已内置为默认行为）：
- **主图默认保留原始背景，不要传 `--transparent`**——奶白/浅色黏土主体与浅色背景
  色距过近，阈值抠图必然把脸部/身体掏洞，白底预览看不出，暗夜气泡里全是黑洞，
  审核原话"角色形象没有填充颜色，暗夜模式下无法清晰辨识"。带背景主图完全合规
- **封面/图标/横幅/赞赏图默认圆形徽章样式**（`--showcase-style circle`）：不抠像素、
  圆外透明+抗锯齿+同色系深色描边环，暗夜模式必然可见
- **图标必须是头部徽章**（`--icon` 选头像正面大图，`--icon-span/--icon-cy` 微调取景）：
  整幅场景缩到 50px 会糊成一团，审核原话"聊天页图标展示位置小，去除不必要的文字信息和装饰"
- `--raw-src / --banner-src` 必须指向**无文字原图**：官方要求横幅避免文字
- `--outline auto`（默认）：亮度 >185 的封面/图标自动加同色系深色描边
- 主体与背景色距大的素材才可用 `--transparent --showcase-style cutout` 抠图模式

### Step 8 · 合规 + 质量自检
跑一遍下方清单和 `references/wechat-spec.md` 第六节的提交前自查清单，
有问题回到 Step 3 调提示词重生成。

## 提示词装配公式

```
[主体] 生肖物种 + 配色 + 体貌 + 服装 + 道具 + 动作
[表情] 五官细节 + 情绪 + 漫画效果符号
[风格] 黏土软胶材质 + chibi 比例 + 盲盒玩具质感
[场景] 微场景 + 干净背景色
[镜头] 3/4 正面 + 略俯视 + 居中构图
[技术] 1:1 + 高细节 + 主体孤立易抠图
[负向] 见 style-bible.md
```
完整模板与 20+ 条可直接抄的示例见 `references/prompt-templates.md`。

## 质量自检清单

- [ ] 主体占画面 70–80%，四周留白，缩到 48px 仍能看清情绪
- [ ] 无文字乱码（文案是后期叠加的，不是生成的）
- [ ] 无水手指 / 无多余肢体 / 无变形五官
- [ ] 四肢齐全且对称，握持道具的手部合理
- [ ] 背景干净，无杂物干扰主体
- [ ] 情绪到位：眉毛角度 + 嘴形 + 眼形三者一致表达同一情绪
- [ ] 同套内画风统一（同一套只用一个材质描述 + 一套打光参数）
- [ ] 通过相似度自检三问

## 微信表情包成品规格（官方，2026-09 核对）

详细要求与审核红线见 `references/wechat-spec.md`，用 `scripts/wechat_pack.py` 一键产出。

| 项 | 要求 |
|---|---|
| 表情主图 | 240×240 px，PNG/JPG/GIF，**单张 ≤ 500KB**，一套 8~24 张，全套统一动/静态；浅色主体**保留背景最稳** |
| 表情封面图 | 240×240 px PNG，**圆外透明**（圆形徽章），≤ 500KB，无白边无锯齿，避免文字 |
| 聊天面板图标 | 50×50 px PNG，**圆外透明**（头部徽章），≤ 100KB，无文字无装饰 |
| 详情页横幅 | 750×400 px JPG/PNG，≤ 500KB，**避免任何文字**，避免白底与透明底 |
| 缩略图 | 120×120 px PNG，≤ 500KB |
| 命名 | `01.png` … `24.png`，顺序即展示顺序 |
| 文案 | 名称 ≤8 字无标点；含义词 ≤4 字且整套不重复；禁止"官方/正版/认证"字样 |
| 硬红线 | 无水印、无二维码、无网址、无他人 IP、无真人肖像 |
