## 四、成套配比建议（16 张 / 24 张）

**16 张一套**
- 正面情绪 5 张：开心、狂喜、得意、撒娇、期待
- 负面宣泄 6 张：抓狂、崩溃、委屈、大哭、生气、心碎
- 摆烂摸鱼 3 张：摆烂、摸鱼、困倦
- 社交万能 2 张：无语、阴阳怪气

**24 张一套**：上述 16 张 + 羞耻/社恐 2 张 + 节日祝福 2 张 + 感谢/道歉 2 张 + 加油打气 2 张

**顺序技巧**：第 1 张放最万能的（开心 / 无语），最后一张放祝福类，中间穿插情绪起伏，避免连续三张同为负面。

## 五、中文文案库（后期叠加用，不进提示词）

按情绪分类，每条 ≤ 6 字，表情包文案要短：

- **开心/正向**：好耶 / 收到 / 太好了 / 哈哈哈 / 冲！/ 稳了 / 有戏 / 给你点赞 / 爱了
- **摆烂/摸鱼**：算了 / 摆了 / 摸了 / 与我无关 / 随缘 / 佛系 / 明天再说 / 已读不回
- **崩溃/抓狂**：我裂开 / 救命 / 崩不住 / 别说了 / 我疯了 / 啊啊啊
- **无语/不屑**：？？？ / 无语 / 就这？ / 谢谢你 / 好家伙 / 典中典
- **委屈/撒娇**：委屈 / 呜呜 / 抱抱 / 求放过 / 我不是故意的 / 人家错了
- **职场专用**：在改了 / 马上 / 收到收到 / 好的老板 / 我这就去 / 周五了 / 下班！/ 周报写好没 / 需求又变了
- **祝福类**：新年快乐 / 恭喜发财 / 好运来 / 节日快乐 / 顺顺利利 / 暴富

**排版规则**：底部居中，白字 + 深色描边（2–3px），字号约占画面高度 12–16%，不超过两行。
