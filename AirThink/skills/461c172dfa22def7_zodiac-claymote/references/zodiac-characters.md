# 十二生肖原创角色设定卡

> 全部为**原创设计**，仅借用"生肖物种"这一公有领域题材。配色、五官排布、招牌动作均为独立设定，请勿与任何在售 IP 对齐。
> 用法：取「主色 + 体貌 + 性格 + 招牌动作」四项填入提示词主体段。

---

## 🐭 鼠 · Ratty（英文名提示词：round chubby mouse）

- **主色**：雾蓝灰 `#A9BACB`｜**辅色**：奶白肚皮 `#FBF7F0`、粉耳 `#FFC2CE`
- **体貌**：水滴形身体，两片薄荷叶状大圆耳（比头还大的 60%），两颗明显的小门牙，细长卷曲尾巴（尾尖打个小卷），四只粉色小肉垫
- **性格**：机灵、精打细算、消息灵通、爱囤零食
- **招牌动作**：双手捧一颗瓜子啃 / 耳朵一抖竖起来偷听 / 从口袋里掏出一堆小东西
- **职业适配**：财务、采购、数据分析、行政、仓管

## 🐂 牛 · Moo（round chubby calf / baby bull）

- **主色**：奶白 `#F7F1E8`｜**辅色**：焦糖角 `#C98F4E`、牛仔蓝围裙 `#5B7C99`
- **体貌**：身体最敦实的一个，肩膀比头宽，两只短圆角（像刚冒芽的小角），鼻头是粉色的椭圆，四条小短腿，尾巴尖一撮毛
- **性格**：踏实、倔、闷头干活不抱怨、被催才急
- **招牌动作**：低头顶东西 / 鼻孔喷气 / 默默扛着一摞比自己高的箱子
- **职业适配**：工程、制造、物流、建筑、运维、农业

## 🐯 虎 · Roar（round chubby tiger cub）

- **主色**：暖橘 `#F2A03D`｜**辅色**：深棕条纹 `#8A5A2B`（**只保留 3 道**：额头 2 道 + 身侧 1 道）、奶白胸口
- **体貌**：圆脸宽腮，耳朵是小半圆贴在头顶两侧，腮帮鼓鼓，短粗尾巴上翘，肉垫粉橘
- **性格**：外强中干、嗓门大心软、爱放狠话但立刻怂、护短
- **招牌动作**：张牙舞爪后秒变乖 / 鼓腮帮瞪眼 / 拍桌然后缩手
- **职业适配**：销售、管理、安保、体育教练、团队负责人

## 🐰 兔 · Bun（round chubby lop-eared rabbit）

- **主色**：奶白粉 `#FBEFEA`｜**辅色**：内耳桃粉 `#FFAFBC`、胡萝卜橙 `#F07B3F`
- **体貌**：两只长耳**垂到肩膀以下**（垂耳兔，不是竖耳），身体像一颗糯米团子，尾巴是圆球棉花，三瓣嘴
- **性格**：敏感、温柔、容易受惊、社交电量低、细节控
- **招牌动作**：耳朵突然竖起警觉 / 抱紧胡萝卜当抱枕 / 缩成一团装蘑菇
- **职业适配**：教师、客服、护士、编辑、HR、幼教

## 🐲 龙 · Sprout（round chubby baby dragon）

- **主色**：青苔绿 `#7FB77E`｜**辅色**：金黄肚皮 `#F5C542`、浅金小角 `#E8D6A0`
- **体貌**：圆滚滚的桶状身体，两只**小短角**（像嫩芽，不是锋利大角），背上三片软鳍（圆头不是尖的），小翅膀短到飞不起来，肚皮有鳞片纹路
- **性格**：中二、热血、爱立 flag、执行力忽高忽低、爱吹牛
- **招牌动作**：仰头喷出一小簇心形火苗 / 举起小爪子发誓 / 翅膀努力扇但离地三厘米
- **职业适配**：产品、创业、新媒体、市场、策划、直播

## 🐍 蛇 · Coily（round chubby snake）

- **主色**：薄荷绿 `#9FD8CB`｜**辅色**：奶黄腹部 `#F7E9A0`、腮红粉
- **体貌**：身体盘成**弹簧圈**坐地（下半身是螺旋，上半身立起），没有手脚（用尾巴尖当手），舌尖分叉小芯子，眼睛是竖椭圆
- **性格**：冷静、毒舌吐槽、观察者、不主动但一针见血
- **招牌动作**：盘成一坨装睡 / 尾巴尖举着奶茶吸 / 伸长脖子偷看屏幕
- **职业适配**：法务、风控、测试、审计、研究员、编辑审稿

## 🐴 马 · Dash（round chubby pony）

- **主色**：栗棕 `#B07D56`｜**辅色**：米色鬃毛 `#EFDCC3`、马蹄灰褐 `#6B5140`
- **体貌**：鬃毛是三撮圆球状蓬松毛（不是飘逸长鬃），脖子短粗，四蹄是小圆墩，尾巴是刷子状短毛
- **性格**：急性子、赶 deadline 狂魔、行动力强、容易透支
- **招牌动作**：原地踏步冒烟 / 前蹄扬起冲锋 / 跑着跑着鞋飞了
- **职业适配**：外卖快递、销售、记者、项目交付、急诊

## 🐑 羊 · Cloud（round chubby sheep）

- **招牌动作**：原地织毛线 / 被卷进羊毛堆只露脸 / 慢悠悠嚼东西

## 🐵 猴 · Pop（round chubby monkey）

- **体貌**：脸盘大呈心形，耳朵贴在头两侧像小把手，尾巴细长末端卷成问号，手脚灵活（是唯一有明显手指的，5 指简化为 4 指）
- **性格**：皮、爱整活、点子多、三分钟热度、气氛组
- **招牌动作**：倒挂 / 挠头毛乱飞 / 一手三个手机 / 突然冒出来吓人

- **招牌动作**：仰头张嘴喊 / 翅膀拍桌 / 举着小喇叭
- **职业适配**：教师、班主任、客服、培训、销售、团队 leader

- **职业适配**：自由职业、餐饮、休长假中、任何"已放弃挣扎"的状态

## 使用提示

1. **一图一肖**：不要在同一张表情里出现两个不同生肖（会削弱识别度），情侣/对手戏可用同生肖两只，仅靠颜色深浅区分。
2. **配色不可混**：龙的绿不要用在虎身上。整套里每个生肖的主色是它的身份标识。
3. **面部简化**：越简单越像表情包。五官细节超过 7 个元素就会显脏。
4. **物种特征保留 1 个就够**：老鼠只要大耳 + 门牙，兔子只要垂耳，龙只要小角 + 软鳍。堆太多会变写实。
