# 多工种职业设定库

> 用法：取「服装 + 道具 + 场景 + 痛点梗」四项填入提示词，与生肖角色叠加。
> 职业服饰要**符号化**——观众一眼认出即可，细节越简越好（黏土风堆细节会糊）。

---

## 🎓 教师（重点角色）

- **服装**：藏青/米色开衫马甲 + 白衬衫，领口别一支红笔；或运动服 + 哨子（体育老师）
- **道具**：教案本、红笔、粉笔头、保温杯（泡枸杞）、教鞭、一摞作业本、扩音小蜜蜂
- **场景**：讲台、黑板（写满板书）、办公桌堆作业、教室后排、监考时踱步
- **痛点梗**：改作业改到眼花 / 连堂四节课嗓子冒烟 / 学生说"老师这题我懂了"然后做错 / 早自习查岗 / 家长群 99+ / 公开课被听课 / 作业本堆成山 / 下课铃响被"老师再讲一道"
- **推荐生肖**：鸡（操心打鸣）、兔（温柔）、狗（操劳）、蛇（冷眼批卷）
- **示例提示词片段**
  ```
  wearing a navy knit vest over a white shirt with a red pen clipped at the collar,
  holding a stack of exercise books taller than its head, red pen behind ear,
  in front of a small chalkboard covered in neat writing
  ```

## 🧑‍🎓 学生（重点角色）

- **服装**：校服（白上衣 + 藏青裤）/ 连帽卫衣 + 双肩包 / 眼镜 + 学生头
- **道具**：比头高的书堆、试卷、笔袋、保温杯、手机（藏课本下）、耳机
- **场景**：课桌前、图书馆、宿舍上铺、考试现场、课间趴桌、放学路上
- **痛点梗**：考前一夜突击 / 老师说"这题送分" / 考完对答案心碎 / 早八困到灵魂出窍 / 论文查重率 / 小组作业只有自己干 / 毕业答辩 / 食堂排队
- **推荐生肖**：猪（早八困）、兔（考试紧张）、猴（课上偷玩）、牛（死磕刷题）
- **示例提示词片段**
  ```
  in a school uniform with a backpack, sitting at a small desk buried under a
  tower of textbooks, dark circles under eyes, holding a pen like a sword
  ```

## 💻 工程师 / 程序员（重点角色）

- **服装**：格子衬衫（灰蓝/墨绿）+ 冲锋衣 / 连帽衫，工牌挂绳，框眼镜
- **道具**：双屏显示器、机械键盘、马克杯（咖啡）、便签贴满的显示器边框、耳机、服务器机柜、报错弹窗
- **场景**：工位（隔断）、机房、深夜办公室只剩自己一盏灯、线上事故现场
- **痛点梗**：代码在我机器上能跑 / 改需求第 8 版 / 上线前 5 分钟 / 线上出 Bug / 祖传代码不敢动 / 周一晨会假装听懂 / 需求文档只有一句话 / 编译 40 分钟 / 删库跑路（玩笑）/ 产品经理说"就改个小地方"
- **推荐生肖**：牛（闷头干）、蛇（debug 冷静）、猴（爱折腾）、马（赶工狂魔）
- **示例提示词片段**
  ```
  in a plaid shirt with a lanyard badge, sitting at a desk with two monitors
  covered in sticky notes, mechanical keyboard, a red error popup on screen,
  hands frozen over the keyboard
  ```

## 🏥 医生 / 护士

- **服装**：白大褂 + 听诊器 / 护士服（浅粉或浅蓝）+ 护士帽，口罩拉到下巴
- **道具**：病历夹、听诊器、注射器、体温枪、值班表、咖啡
- **场景**：诊室、护士站、值班室、走廊推车
- **痛点梗**：夜班 / 连续手术 / 患者百度问诊 / 病历写不完 / 值班室泡面

## 📊 产品经理

- **服装**：简洁衬衫 + 针织衫，永远拿着 MacBook
- **道具**：MacBook、需求文档、白板 + 便利贴、原型图、马克笔
- **场景**：会议室白板前、需求评审、工位
- **痛点梗**：这个需求很简单 / 明天上线 / 老板说再改改 / 背锅 / 排期又被压缩

## 🎨 设计师

- **服装**：黑 T / 宽松衬衫，帆布包，圆框眼镜
- **道具**：数位板、色卡、PS 界面、咖啡杯
- **场景**：显示器前、灵感墙
- **痛点梗**：五彩斑斓的黑 / 再大一点同时再小一点 / 第 27 版 / 甲方审美 / 字体侵权

## 📈 运营 / 市场

- **服装**：休闲通勤，工牌，手机永远在手
- **道具**：手机（后台数据）、数据表、活动物料、KPI 看板
- **场景**：工位、活动会场、数据大屏前
- **痛点梗**：拉新转化 / 追热点 / 数据掉了 / 老板要 10w+ / 活动翻车

## 💰 销售

- **服装**：西装（略紧）+ 领带 / 商务休闲，拎公文包
- **道具**：手机贴耳、名片、合同、公文包
- **场景**：客户门口、酒桌、车站候车、车内
- **痛点梗**：月底冲业绩 / 客户已读不回 / 陪笑脸 / 报价被砍半 / 回款难

## 🧾 财务 / 会计

- **服装**：素色衬衫 + 马甲，袖套
- **道具**：计算器、凭证、发票、Excel 表格、印章
- **场景**：票据堆中、月末结账、税务申报
- **痛点梗**：月底加班 / 发票贴到眼花 / 报销单被打回 / 年度审计

## 🏛️ 公务员 / 窗口办事员

- **服装**：白衬衫 + 深蓝西裤 / 制服，党徽/工牌（避免具体标识）
- **道具**：文件筐、印章、取号机、表格
- **场景**：办事窗口、办公室、会议室
- **痛点梗**：材料不齐 / 排队叫号 / 写材料 / 会议材料改十遍

## 👮 安保 / 保安

- **服装**：深蓝制服 + 帽子
- **道具**：对讲机、登记本、手电
- **场景**：门岗亭、监控室
- **痛点梗**：夜班巡逻 / 登记外来人员 / 困但不敢睡

## 🍳 厨师 / 餐饮

- **服装**：白色厨师服 + 高帽 / 围裙 + 头巾
- **道具**：炒勺、锅、菜单、托盘
- **场景**：后厨、出餐口、外卖打包台
- **痛点梗**：出餐高峰 / 客人催单 / 差评 / 站着炒一天

## 🛵 外卖 / 快递

- **服装**：冲锋衣 + 头盔（颜色自定，避免平台配色）
- **道具**：保温箱、手机支架、扫码枪、包裹
- **场景**：电动车旁、电梯口、暴雨中、超时倒计时
- **痛点梗**：超时 / 找不到楼栋 / 电梯堵 / 爬 6 楼 / 差评申诉

## 🚗 司机 / 网约车

- **服装**：便装 + 颈枕
- **道具**：方向盘、接单手机、保温杯
- **场景**：车内、堵车、机场排队
- **痛点梗**：堵车 / 乘客取消 / 跑车 12 小时 / 找车位

## ⚖️ 法务

- **服装**：正装 + 细框眼镜
- **道具**：合同、法条书、红笔批注、公章
- **场景**：会议室、文件堆
- **痛点梗**：合同审到凌晨 / 这条款有风险 / 业务说"你别管了"

## 🧹 保洁 / 后勤

- **服装**：工装 + 围裙 + 手套
- **道具**：拖把、扫帚、垃圾袋、清洁车
- **场景**：走廊、办公室角落
- **痛点梗**：刚拖完就踩 / 弯腰一天

## 🏗️ 建筑 / 工人

- **服装**：反光背心 + 安全帽（黄/白，无 logo）
- **道具**：安全帽、卷尺、手套、水泥铲
- **场景**：工地、脚手架、板房
- **痛点梗**：日晒 / 工期紧 / 回家倒头睡

## 🧪 科研 / 研究生

- **服装**：白大褂 + 护目镜
- **道具**：试管、移液枪、论文、文献
- **场景**：实验室、文献堆、组会
- **痛点梗**：实验失败 99 次 / 论文被拒 / 导师消息 / 数据不显著

## 📰 新媒体小编

- **服装**：休闲，耳机常戴
- **道具**：手机、热点榜单、剪辑时间线
- **场景**：工位、手机屏幕前
- **痛点梗**：追热点 / 标题党 / 阅读量 / 深夜发稿 / 评论区

## 👔 老板 / 领导

- **服装**：深色西装 + 领带 / 皮带
- **道具**：茶杯、会议桌、PPT 翻页笔
- **场景**：会议室主位、办公室、站着讲话
- **痛点梗**：画饼 / 开长会 / 说"我讲两句"讲了半小时 / 周一例会

## 🤝 HR

- **服装**：职业套装
- **道具**：简历堆、面试表、offer
- **场景**：面试间、工位
- **痛点梗**：招不到人 / 员工离职 / 谈薪 / 背调

## 🧑‍🔧 客服

- **服装**：工服 + 耳麦
- **道具**：耳麦、工单系统、话术本
- **场景**：工位、客服坐席
- **痛点梗**：被骂 / 差评 / 重复一百遍 / 情绪劳动
