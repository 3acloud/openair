# 多语种实时翻译（含语音朗读）
一款轻量化、无付费依赖、支持全球主流语种的实时翻译技能，翻译结果附带标准发音朗读，适合日常交流、学习、出行、跨境沟通使用。

## 功能介绍
- 支持中、英、日、韩、法、德、西、俄、泰、越南、印尼、阿拉伯等数十种语言互译
- 自动识别输入文本的源语言，无需手动选择
- 翻译结果附带语音朗读链接，支持标准母语发音
- 全程使用免费公共翻译接口，无需密钥、无额度限制、无广告
- 响应快速、轻量化运行，不占用系统资源
- 支持短句、日常用语、常用对话、学习例句等场景翻译

## 支持语种
中文、英语、日语、韩语、法语、德语、西班牙语、俄语、泰语、越南语、葡萄牙语、意大利语、阿拉伯语、印地语、印尼语、荷兰语、希腊语、匈牙利语、瑞典语、捷克语、波兰语、罗马尼亚语、土耳其语、丹麦语、芬兰语、挪威语等。

## 使用方式
### 1. 基础翻译
直接说：
- 翻译 你好
- 帮我翻译一下 I love you
- 翻译 こんにちは

### 2. 指定目标语言
- 把 你好 翻译成英语
- 将 Hello 翻译成日语
- 翻译 早上好 为韩语

### 3. 自动识别模式
系统会自动判断你输入的语言，并翻译成中文：
- 翻译 Bonjour
- 翻译 안녕하세요
- 翻译 Hola

## 接口参数说明
### 入参
```json
{
  "text": "需要翻译的文本内容",
  "from": "源语言（默认自动识别）",
  "to": "目标语言（默认中文）"
}
### 出参
{
  "code": 200,
  "original": "原文",
  "translated": "翻译结果",
  "from": "源语言",
  "to": "目标语言",
  "voice_url": "语音朗读地址"
}
