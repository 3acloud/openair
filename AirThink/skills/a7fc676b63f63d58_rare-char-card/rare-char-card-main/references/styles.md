# 风格速查与文案范例

## 四种风格视觉规格

### magnolia-blue 蓝底玉兰
- 背景：深蓝径向渐变 #3A5A94 → #233766
- 文字：金黄 #E9C784（释义/文案 #D8BC85）
- 装饰：左上玉兰花枝（金色枝干+暖金花朵）+ 6 片飘落花瓣
- 无标题（模板不显示标题）
- 气质：贵气、沉静、适合意境深的字

### magnolia-sage 灰绿玉兰
- 背景：灰绿线性渐变 #77857A → #5F6F64
- 文字：米白 #F2EDE0
- 装饰：左上玉兰花枝（米白系）
- 显示标题（常规样式，如"每天认识一组生僻字"）
- 气质：文艺、清新、适合温柔的字

### fan-orange 暖橙扇形
- 背景：橙色渐变 #F6B04E → #E8862E，中央米色纸面板 #F8F1E4
- 文字：暖橙棕 #C05A22（标题为米白，落在橙色区域）
- 装饰：左上折扇（米色扇面+橙色扇骨）
- 显示标题（两行式，如"解读古人智慧 / 发现文字之美"）
- 气质：温暖、国风、适合治愈系文案

### wave-beige 米色波浪
- 背景：米色 #EDE6D6 + 柔和抽象色块（橙/棕/青绿）
- 文字：棕色 #7A5C42
- 装饰：底部棕青双层波浪
- 显示标题且自动带「」方括号
- 气质：简约、杂志感、适合现代文案

## 文案范例库（心理锚点 × 字义）

写文案先定锚点再动笔。以下为验证过走向的搭配：

- 彧（才华内敛）×【努力不被看见】：「不爱表现的人 / 常常被误以为平庸 / 可才华这种东西 / 藏得越深，越贵重 / 你只管慢慢发光，时间会看见」
- 婳（娴静美好）×【安静被误解】：「他们总说你太安静 / 可安静从来不是错 / 那是你和世界相处的方式 / 静水流深，自有力量」
- 昶（白昼舒畅）×【情绪低谷】：「熬过长夜的人 / 最懂得珍惜光 / 那些没能打倒你的 / 终将变成你的晴天」
- 翀（向上直飞）×【被现实压住仍想飞】：「生活把你按在地上 / 你心里却一直装着天空 / 没关系，慢慢来 / 属于你的那阵风，还在路上」
- 甯（安宁）×【内耗松弛】：「想太多的人 / 往往过得最累 / 今天就允许自己 / 什么都不想，好好睡一觉」
- 姝（美好）×【讨好型人格】：「你小心翼翼讨好全世界 / 却忘了最该讨好的 / 是镜子里的那个人」

**三段式结构**：第一行戳痛点（说出没说出口的话）→ 中间用字义翻转定义 → 收尾温柔留白，不说教。
