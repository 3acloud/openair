# 生僻字卡片生成器

生成小红书风格的生僻字科普卡片（1080×1440，3:4），复刻“每日一组生僻字”爆款模板。

## 卡片固定结构（从上到下）

1. 可选标题（如“每天认识一组生僻字”）
2. 拼音（衬线大字）
3. 生僻字主体（超大衬线字）
4. 【谐音】同音常见字/词
5. 【释义】字面解释
6. 情感文案 3~5 行（金句感，与字义呼应）
7. 底部互动语（默认“快试试你手机能打出来吗”）

## 执行流程

### 第 1 步：确定内容

用户给了字就直接用；没给就自己挑一个常用度高、寓意好的生僻字（如 彧、婳、昶、翀、燚、淼、赟、旻、甯、彧）。**选字时同步定心理锚点**——问自己"这张卡片想让哪类人看完想保存转发"：是不被看见的努力者？还是正陷在情绪低谷里的人？锚点定了，文案才有靶心。内容必须包含：

- `char`：生僻字
- `pinyin`：拼音（可带声调，如 yuán）
- `homophone`：谐音说明，格式参考 `同「渊」`，可加同音词
- `meaning`：释义，一句话，通俗有画面感
- `emotion`：**心理锚点（文案的靶心）**——这张卡片要戳中哪种具体心理状态，见下方文案心法
- `copy`：文案 3~5 行的数组，短句、金句感、与字义呼应
- `title`：可选标题
- `cta`：默认“快试试你手机能打出来吗”，可省略

**文案心法（核心，决定卡片是不是爆款）**：

字只是钩子，**情绪才是内容**。爆款逻辑 = 谐音破冰 → 心理共鸣 → 温柔肯定。写文案前必须先定一个"心理锚点"——一张卡片只瞄准一种具体心理状态，禁止泛泛的正能量。

常用心理锚点库（选一个，写透）：

| 心理锚点 | 适用字型 | 文案走向 |
|---|---|---|
| 努力不被看见 | 彧、懿（才华内敛型） | 先共情委屈，再翻转定义 |
| 性格安静被误解 | 婳、甯（安静美好型） | 肯定其存在方式本身就是力量 |
| 情绪低谷/长夜 | 昶、晗（光明破晓型） | "熬过长夜"叙事，给盼头不给压力 |
| 被现实压住仍想飞 | 翀、骉（腾飞型） | 承认当下狼狈，保留心里那块天空 |
| 内耗/想太多 | 甯、宓（安宁型） | 允许停下，松弛感 |
| 讨好型人格 | 媖、姝（美好型） | "你不必讨好任何人" |
| 孤独/不合群 | 獬、特立独行型 | 孤独是筛选，不是缺陷 |

**三段式写法**（每行短句，每行 ≤14 字）：

1. **第一行戳痛点**：直接说出读者心里那句没说出口的话（"不爱表现的人 / 常常被误以为平庸"）
2. **中间翻转**：用字义重新定义这个"缺点"（"可才华这种东西 / 藏得越深，越贵重"）
3. **收尾留白**：温柔收，不说教不喊口号（"你只管慢慢发光 / 时间会看见"）

反面案例（禁止这样写）："所有蛰伏的日子 / 都是为了起飞那一刻"——修辞对但没有心理对象，谁看了都不会觉得"这说的是我"。

### 第 2 步：确定风格

| 风格参数 | 视觉 | 适合 |
|---|---|---|
| `magnolia-blue` | 深蓝底+金色字+玉兰花枝飘瓣，无标题 | 通用首选，最贵气 |
| `magnolia-sage` | 灰绿底+米白字+玉兰枝，带标题 | 清新文艺 |
| `fan-orange` | 暖橙底+米色纸面板+折扇，带标题 | 温暖治愈 |
| `wave-beige` | 米色底+抽象色块+波浪，标题带「」 | 简约高级 |

用户没指定风格时，默认 `magnolia-blue`；做系列图时每张换一种风格轮换。

### 第 3 步：渲染

把数据写成 JSON（写到 `/tmp/rare-char-<字>.json`），然后执行：

```bash
python3 \
  ~/.workbuddy/skills/rare-char-card/scripts/render.py \
  --data /tmp/rare-char-<字>.json --style magnolia-blue \
  --out ./output/<字>_<风格>.png
```

输出目录固定用 `./output/`。

### 自定义背景模式（图片模型路线）

用户想要独特背景时：

1. 先用 ImageGen 生成纯装饰背景（要求：3:4、无任何文字、留白充足、色彩不过于复杂），保存为本地文件
2. 渲染时加 `--bg <背景图路径> --overlay 0.25~0.45`，文字自动变白色并加暗色遮罩+文字投影保证可读性
3. 遮罩强度：背景越花哨 overlay 越大

```bash
... render.py --data data.json --style magnolia-blue --bg bg.png --overlay 0.35 --out card.png
```

### 第 4 步：交付

用 present_files 展示生成的图片。系列图一次全部展示。

## 技术说明

- 渲染原理：HTML/CSS 模板（`templates/card.html`）+ Chrome 无头截图，无任何 pip/npm 依赖
- 4 种风格的装饰元素（玉兰花枝、飘瓣、折扇、波浪、色块）均为内联 SVG，可无限复用
- 字体：系统宋体栈（Songti SC → STSong → Noto Serif SC）
- 若 Chrome 路径变化，脚本会自动探测 Chrome/Chromium/Edge
- 样例数据见 `assets/samples/*.json`

## 常见问题

- Chrome 报 sandbox 错误：脚本已内置 `--no-sandbox`，无需处理
- 生僻字显示为方框：系统缺字库，换一个常用一点的生僻字
- 文案太长溢出：每行控制在 14 字以内，行数不超过 5
