# 科普型：写给没有背景的读者

面向大众的长篇科普——一个领域的现状综述、一项研究的深度解读、
一个复杂议题的入门读本。读者没有专业背景，也不打算获得专业背景，
但他要用这些内容做真实的决定。

**它和学术型的差别不在严谨度，在叙述骨架。**
把严谨等同于学术腔，是这个原型最常见、也最难自查的失败——
数字全对、口径全标、局限性单独成节，读者读了三页就放下了。

---

## 什么时候用它 / 什么时候不用

| 用它 | 不用它 |
|---|---|
| 读者要理解一个领域并据此行动 | 读者要引用你的数字（→ 学术型） |
| 结论违反直觉，需要被"接受"而不只是被"知道" | 读者已经是同行（→ 研报型/论文型） |
| 议题被大量劣质信息污染，读者需要判断力 | 内容本身就是一张数据表 |
| 篇幅 30 页以上，需要读者一直读下去 | 一页纸的简报 |

判据只有一个：**读者读到第三页会不会继续读。**
学术型不需要回答这个问题（读者是被职责推着读的），科普型必须回答。

---

## 唯一的硬约束

**读者读完带走的是判断力，不是结论。**

结论会过期。一份科普如果只交付结论，它的保质期等于该领域的更新周期——
通常是十八个月。交付判断方法的那一份不会过期，因为方法适用于下一批结论。

这条约束有一个可执行的形式：**全文必须有一章是工具，不是内容。**
它教读者下次自己遇到同类主张时问哪几个问题。
这一章通常放在末尾，是全书被记住时间最长的部分。

没有这一章，产出就只是一篇长的科学新闻。

---

## 先说不要做的事：不要模仿声音

看完几本好科普之后，最容易走的一条路是模仿它们的语气——
宏大的排比、对宇宙的赞叹、"想象一下……"开头的段落。

**这条路一定会失败**，原因很实际：那些作者的语气是他们思考方式的副产品，
不是可以剥离出来的皮肤。剥下来贴上去，得到的是华丽的空话，
而且因为它读起来"很像科普"，你自己很难发现它已经空了。

可迁移的不是声音，是**他们共同解决的那几个结构问题的解法**。
下面六条就是那些解法。它们是动作，不是风格——
每一条都能被检查"做了没做"，而不是"像不像"。

---

## 六个承重手法

### 手法一　入口是一个人在一个具体时刻

**动作**：全书和每一章的第一段，写一个具体的人、一个具体的时刻、一件具体的事。
不写这个领域是什么，不写为什么重要，不写研究现状。

**为什么有效**：抽象内容需要一个抓手才能进入工作记忆。
一个具体场景是读者不需要付出任何代价就能持有的东西，
而定义需要他先付出代价才能持有。

**做错的样子**：
- ❌「衰老生物标志物领域近年来发展迅速，其中表观遗传时钟最受关注。」
- ✅「你把一管血寄了出去。三周后邮件到了，第一页正中间印着一个数字。你今年四十五岁，报告上写的是三十八点四。」

第二句里没有一个专业词，但它已经把全书的问题摆好了。

**变体**：整本书的入口可以是一个**真实的人问的一个真实问题**，
全书就是回答这一个问题。这种结构自带贯穿力——读者永远知道你在干什么。

### 手法二　先给读者一个他自己会想到的错答案

**动作**：在给出正确解释之前，先让读者自己产生一个答案，
而且那个答案是错的或不完整的。然后你才有东西可以推翻。

**为什么有效**：直接给正确答案，读者只是"知道"了；
先犯错再被纠正，读者"改变"了。这两者在留存率上差一个量级。
更重要的是，被推翻的过程本身就是张力——它让人想读下去。

**做错的样子**：把它写成设问句然后自己答（「那么，这是为什么呢？原因在于……」）。
设问不是这个手法。这个手法要求读者**真的停下来产生一个答案**。

**做对的例子**（来自一份抗衰综述）：

> 假设这件事落到你头上——要你造一把能量出"一个人老到什么程度"的尺子，
> 你打算怎么造？
>
> 大多数人的第一个念头是对的，而且和科学家想的一样：
> 找一个随年龄稳定变化的东西，然后用它倒推年龄。
>
> ……
>
> 回到你刚才的设计。你造这把尺子的方式是：训练一个模型去预测年龄。
> 你训练得越好，它就越接近于——把你的出生证明重新念一遍。

读者亲手造出了那个缺陷，所以他不会忘记它。

### 手法三　比喻必须承重

**动作**：每个抽象概念绑定一个读者已有的具体经验。
但绑定之后要检查一件事：**这个比喻能不能被用来推导？**

**为什么有效**：装饰性比喻（"细胞就像一座工厂"）只帮助读者觉得自己懂了，
不帮助他做任何推理。承重比喻能推出新结论，因此它真的传递了结构。

**检查方法**：写完比喻，试着用它推出一个你没直接说过的结论。
推不出来，这个比喻就是装饰，删掉或换掉。

**做对的例子**：把两类衰老指标比作汽车的里程表和速度表。
可推导出：一个抽了二十年烟、三个月前戒烟的人，
里程表读数很难看而速度表已经降下来了，两个都对——
读者自己就能得出"只看一个数会得出错误结论"。

**做错的样子**：「表观遗传时钟就像身体的年轮。」听起来很好，
但你没法用年轮推出任何关于干预的结论。年轮不能变少。

### 手法四　数字必须被翻译

**动作**：每个数字后面跟一个读者身体尺度上的对照物。

**为什么有效**：读者对百分比和效应量没有直觉，
对"爬四层楼喘不喘"有直觉。不翻译的数字会被跳过，
被跳过的数字等于没写。

**做错的样子**：
- ❌「心肺耐力每提高 1 个 MET，全因死亡风险下降 13%。」
- ✅「快走大约是 3 到 4 个 MET，慢跑大约 7 到 8 个。每提高 1 个，全因死亡风险下降 13%。」

第二句只多了一行，但读者第一次知道"1 个 MET"有多远。

**注意**：翻译不等于降低精度。原数字必须原样出现，
翻译是加在旁边的，不是替换。

### 手法五　把不确定写进正文，不写进脚注

**动作**：证据的强弱、替代解释、"这一条我没能核实"，
全部写在读者正在读的那一段里，用正常字号。

**为什么有效**：这是科普与营销的分界线，而且读者能感觉到差别。
一份坦白说出自己边界的材料，会让读者更信任它没有说出边界的部分。
反过来，通篇没有不确定性的科普，读者的默认假设是"它在卖东西"。

**具体做法**：
- 用竞争假说的形式给机制：不是"因为 A"，而是"可能是 A，也可能是 B，
  现有数据能不能分辨——能，理由是……／不能，需要做的是……"
- 主动降级自己的结论，比等别人来降级体面
- 如果引用的研究有利益关系，写出来。读者有权知道

**一个反直觉的事实**：主动认领局限性的段落，
往往是全文可信度最高、被引用最多的段落。

### 手法六　结尾是工具，不是总结

**动作**：最后一章交付一套可迁移的判断方法——
通常是三到五个问题，加一份红旗清单。

**为什么有效**：见上面"唯一的硬约束"。

**质量标准**：这些问题必须**不要求读者懂专业知识**。
「这项研究的统计功效够吗」不是好问题；
「这是在健康人还是病人身上做的」是好问题——
后者任何人都能问，而且能筛掉大量东西。

**红旗清单的写法**：左栏"看到这个"，右栏"它意味着什么"。
每一条都要能对应到现实中真实存在的例子，
写不出真实例子的红旗是想象出来的，删掉。

## 三幕骨架

科普型不用学术型的章节骨架（研究问题 → 发现 → 局限 → 结论）。
它用戏剧骨架，因为读者需要的是动力，不是索引。

```
封面（书名是一句话，不是一个主题）
序章        一个场景 → 一个悬念 → 这本书分三幕
目录

第 1 幕　建立      这个东西是怎么来的，为什么当初所有人都觉得它对
  ├ 1  起源：那个让所有人激动的时刻
  └ 2  关键区分：读者必须先掌握的那一个分辨

第 2 幕　推翻      有人去查了，结果不一样
  ├ 3  谁去查的、怎么查的
  ├ 4  第一个坏消息
  └ 5  更难的那个（这里放竞争假说与替代解释）

第 3 幕　剩下什么   清算之后还站着的东西，以及读者该做什么
  ├ 6  真正有证据的那些
  ├ 7  读者自己的处境（分人群，这是全书最实用的一章）
  ├ 8  正在发生的事（前沿，给未来感）
  └ 9  工具箱

尾声        回到序章那个场景，收束
附录一      词汇表
附录二      文献（一条来源一行，不按数据点展开——见 结构骨架.md「附录放什么」）
```

**幕与幕之间用整页的分隔页**，只有"第 N 幕"、幕名、一句话。
这几页看起来浪费，实际上它们是读者的换气口——
40 页以上的读物没有换气口，读者会在第二幕中间放下。

**每章结尾留钩子。** 不是悬念噱头，是把下一章的问题提出来：
「那么，在尺子造好之前，有没有什么是我们已经确定知道的？有。而且比你想的多。」

## 声音

**允许出现"我"，不允许含糊。**

学术型里"本报告认为"是外行标志，科普型里第一人称是必需品——
读者需要知道有一个人在跟他说话，这个人会承认自己不确定。

但第一人称的额度只用在两个地方：
下判断的时候（「我在这里下一个可以被证伪的判断」）、
承认边界的时候（「这一条我没能核实」）。
不用在叙述事实的时候。

**句子长度必须变速。** 连续五个长句会让读者失去节奏感。
关键结论用短句单独成段——

> 它们并没有。

这一行的作用大于把它并进上一段。

**幽默是温和的，且不针对人。** 它出现在对处境的观察上，
不出现在对某个研究者或某类消费者的调侃上。
嘲笑读者可能相信过的东西，会让他停止阅读。

## 严谨性搬家

科普型不降低严谨度，它换一个地方放。

| 内容 | 学术型 | 科普型 |
|---|---|---|
| 效应量、p 值、置信区间 | 正文 | 侧栏，正文只留读者需要的那个数 |
| 样本量与口径 | 正文括号 | 侧栏「这个数字从哪来」 |
| 完整数据表 | 随交付物给文件 | 随交付物给文件（**不印进附录**，见 结构骨架.md「附录放什么」） |
| 局限性 | 单独一章 | 拆开写进相关的那一段 |
| 利益冲突 | 声明段 | 正文里说，就在讨论该结论的地方 |

**侧栏是这个原型的关键组件。** 它让正文保持流动，
同时让想核查的读者随时能停下来核查。
样式上要明确区别于正文（浅底 + 左侧色条 + 小一号字），
读者一眼就知道"这一块可以跳过，也可以细看"。

**侧栏也是口径的归宿。** 科普型不把口径攒到书末——攒起来就没人读，
而且会让附录膨胀到荒唐的体量。哪个数字值得配侧栏，判据是
「读者知道了这个口径，对结论的判断会不会变」。

**数据表仍然先于正文建。** 见 `生产流水线.md`。
口径写不出一句完整的话的数字，在科普型里同样不能用——
读者看不到口径，不代表口径可以不存在。

## 排版上的差异

沿用 `视觉方向库.md` 选定的方向，但有五处按"书"调：

| | 学术型 | 科普型 |
|---|---|---|
| 正文字号／行距 | 10–10.5pt / 1.72 | 10.5–11pt / 1.80–1.85 |
| 章首页 | 章号 + 标题 | 章号 + 标题 + **一句钩子** |
| 幕间页 | 无 | 有，整页，居中，极简 |
| 首字下沉 | 无 | 每章第一段用 |
| 整段引文 | 无 | 有，用于全书最锋利的那几句 |
| 书眉 | 面包屑 | 同左，但**不加通栏横线** |

三个具体的坑，都踩过：

1. **书眉不要加通栏横线。** 短标题配满幅细线会留下一长段裸线，
   而且线与正文之间的空隙几乎总是不够，正文页顶端会显得局促。
   书里的做法是让一行浅灰小字轻轻浮在上面，下方留 11–12mm。
2. **首字下沉要避开笔画极简的字。** 「一」「二」「十」做成首字下沉是一根横杠，
   读者看不出那是个字。写章首句时就要避开，不要等排版阶段再改。
3. **幕间页和章首页会被几何自检判为全出血页跳过边距检查**，
   这些页必须肉眼确认。

## 自检

内容层（在 SKILL.md 的通用清单之外另加）：

- [ ] 序章和每一章的第一段，是一个具体的人／时刻／动作，不是定义或综述
- [ ] 全书至少有一处让读者自己先产生一个错答案
- [ ] 每个核心比喻都能推出一个未直接陈述的结论（推不出的是装饰，已删）
- [ ] 每个出现在正文的数字都有身体尺度的对照物
- [ ] 至少一处机制以竞争假说形式给出，并说明现有数据能否分辨
- [ ] 有一章是工具而不是内容，且其中的问题不要求专业知识
- [ ] 利益关系写在讨论该结论的地方，不是压在末页
- [ ] 每章结尾有钩子，不是小结
- [ ] 通读一遍：有没有一段是"听起来像科普"但其实没有信息的
- [ ] 关键数字的口径写在读者正在读的那一页（侧栏），不是攒在书末
- [ ] 附录是文献表不是数据表转印，且总长不超过正文的 10%

节奏层（只能读出来查）：

- [ ] 把任意三页念出声，有没有连续五个以上的长句
- [ ] 关键结论有没有被并进长段落里（应当短句独立成段）
- [ ] 幽默有没有落在人身上（应当落在处境上）

## 这些手法是从哪归纳的

下面这些作品被用来提取**结构解法**，不是用来提取语气。
读它们的时候要问"他在这一页解决了什么结构问题"，
不要问"他这句话怎么写得这么好"。

| 作品 | 它解决的结构问题 |
|---|---|
| 《思考，快与慢》 | 怎么让读者先犯错再被纠正；怎么把抽象机制人格化成可指认的角色 |
| 《魔鬼出没的世界》《宇宙》 | 怎么把怀疑的方法本身交给读者；怎么把尺度换算到人体经验 |
| 《时间简史》 | 怎么用物理图像替代公式；怎么让一章只承担一个概念 |
| 《上帝掷骰子吗》 | 怎么把知识史写成有人物、有阵营、有转折的叙事 |
| 费曼的讲义与随笔 | 怎么区分"知道名字"和"真的理解"；怎么在承认无知的同时不含糊 |
| 《人类简史》 | 怎么用一个可复述的宏观骨架（三次革命）扛起全书；怎么给熟悉的事物一个反直觉的重命名 |
| 《枪炮、病菌与钢铁》 | 怎么用一个真实的人提的一个真实问题贯穿全书；怎么逐层排除错误答案 |

**再说一次：不要写成其中任何一位的样子。**
这七行的价值在于它们指向七个不同的结构问题，
一份好的科普读物同时解决其中的四到五个，而读起来不像其中任何一本。
