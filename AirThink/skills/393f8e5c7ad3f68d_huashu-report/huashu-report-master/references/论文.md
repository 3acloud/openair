# 论文型：写一篇能投出去的论文

报告的读者是决策者，论文的读者是同行和审稿人。同一批数据，报告问「所以该做什么」，
论文问「这个测量可信吗、相对文献新在哪」。骨架见 `结构骨架.md` 论文型；
本页讲渠道约束、写法差异和生产流水线。

## 渠道硬约束（先读，能一票否决选题）

这些是 arXiv 现行规则，任何一条撞上都不是「写好一点」能解决的：

- **cs 分类不再直接收 review / survey / position paper**（2025-10 起）：
  这三种体裁要求先经期刊或会议同行评审并被接收，投稿时附 journal reference + DOI。
  豁免口子是「研究科技对社会影响的科学论文」——**豁免的是体裁不是分类**，
  换到 cs.CY 但仍写成观点文照样拒。econ、physics 等其他 archive 无此限制
  （econ.GN 实际收综述）。⇒ 独立研究者最稳的体裁是 **measurement / field study**：
  有自采数据、有口径、有量化发现。
- **背书（endorsement）是关键路径，按周估不按天估。** 自动豁免要求机构邮箱
  **且**该领域已有被收录论文，两者同时满足。背书码在**发起投稿之后**才生成，
  所以流程只能是：完稿 → 发起投稿 → 拿背书码 → 找背书人。「先拿背书再动笔」不存在。
- **找背书人的纪律：** 一次只联系一位（官方禁群发，且同领域候选人常互为合著者，
  群发会被看出是扫射）；禁止对同一人重复请求；对方是否有背书资格，
  以其论文 abstract 页底部「Which authors of this paper are endorsers?」为准，
  不凭「他发过很多论文」猜——有论文但没在 arXiv 认领作者身份的人没有资格。
  各分类的背书阈值投稿页会写明（例：需在该组内提交满 3 篇、时间在 3 个月至 5 年之间，
  交叉列出也计入），用 arXiv API 实数，别目测。
- **选独立性有据可查的赛道。** 判据：你的数据是不是「别人花钱或花时间就能重采」的。
  是，就不构成贡献的护城河；观测位置独特（你能拿到别人拿不到的现场数据）才构成。

## 写法上与报告的五个不同

1. **Contributions 显式列出。** Introduction 末尾 3–5 条 bullet，每条「动词开头 + 可检验」：
   "We measure … across N …"，不写 "We discuss …"。报告靠摘要传播，论文靠这几条被引用。
2. **Related Work 按脉络不按论文。** 每段是一条研究线（谁建立了什么框架 → 谁修正了它），
   段末一句话说明本文相对这条线的位置：印证 / 修正 / 补上未建模的维度。
   罗列式的 "X et al. did A. Y et al. did B." 是审稿人最快失去耐心的写法。
3. **方法以可复现为标准。** 报告写「口径」，论文要写到别人能重跑：数据获取方式与时间窗、
   纳入排除规则、工具及版本、阈值的选取理由。放不进正文的进附录，不省略。
4. **降级声明是资产。** 描述性测量就明说 "descriptive, not causal"，并写清做因果解释
   还差哪些条件。主动降级的结论反而被引用得最多——审稿人替你降级就是另一回事了。
5. **英文行文**：短句、每段首句是论点句、不用修辞性设问。中文报告的行文规范
   （`行文.md`）在句式层面不迁移，在「结论式图题、数字带分母」层面照旧适用。

## 生产流水线（LaTeX 路线，不走 HTML）

HTML/chart.py 流水线到论文这里换轨：arXiv 与期刊生态的事实标准是 LaTeX，
PDF 排版质量和公式支持也不是 CSS 分页能比的。

- **文档类**：默认 `article` + `natbib`/`biblatex` + `booktabs` + `graphicx`。
  不套会议模板，除非真的在投那个会——套错模板比不套更业余。
- **编译**：环境里有 LaTeX 相关 skill 就用它；否则 `tectonic`（零配置、自动拉宏包）。
- **图表**：matplotlib 出 PDF 矢量图（配色沿用 `图表模式库.md` 的约束：
  分类色 ≤6、Y 轴从零、直接标注优先）；不要截图位图。图字号排进版面后
  不小于脚注字号（约 8pt）——缩得太小是 LaTeX 论文最常见的图表病。
- **数据层照旧**：`数据表.json` 承重（value / basis / n / src / verified），
  正文数字一律从数据表来。这套纪律不因换排版工具而豁免。
- **arXiv 投稿包**：TeX 源文件 + 图（arXiv 要求 TeX 产物必须交源码，只交 PDF 过不了）；
  `\pdfoutput=1` 放主文件首行；bbl 文件一并打包。

## 引用纪律（最高频翻车点）

**每条参考文献必须由独立 agent 逐条核实**：标题、作者、年份、venue、DOI/arXiv id
真实存在且相互匹配。语言模型编造引用是论文生产里最高频、后果最重的翻车——
一条假引用毁掉整篇的可信度，且审稿人专门查这个。

- 写作时只引读过 abstract 以上的文献；「应该有人做过」不是引用
- 转引（A 引了 B 的数字）标转引或去核 B 原文，不把 A 当 B 用
- 核实用 arXiv API / Crossref / Semantic Scholar 实查，不凭训练数据背书

## 交付前自检（在 SKILL.md 内容层之上追加）

- [ ] 体裁自查：这是 measurement 还是观点文？投 cs 分类的观点文会被拒
- [ ] Contributions 每条可检验，与 Results 各节一一对应
- [ ] Related Work 每段末句有本文的相对位置
- [ ] 编译零 error；overfull hbox 逐条看过（双栏溢出在 PDF 上是文字戳出栏边）
- [ ] 所有 Figure/Table 在正文中被引用；编号连续
- [ ] 参考文献已由独立 agent 核实，核查记录落盘
- [ ] Limitations 写的是证据有效性，不是工具故障
- [ ] 摘要最后一句有最强的单一数字发现
