# 图表模式库

12 个从 42 份报告实测提炼的做法。每条给出「什么时候用」，不是「好看」。

## 1. 分组语义标签取代排序

ICONIQ 的做法：七个职能的招聘计划不是简单按数值排序，而是分成三组并给每组一个语义标签：

```
GROWING TEAMS      研发 / 销售 / 产品设计
MIXED SIGNAL       客户成功 / 市场
DECLINING TEAMS    客服 / G&A
```

**用在**：排序结果本身有意义、但读者需要被告知「分界线在哪」的时候。纯排序只给顺序，分组给的是判断。

## 2. 发散堆叠条 + 方向箭头

七档李克特量表（大减 → 大增）从中间零点向两边发散，两端加箭头标签：`◀ HEADCOUNT DECREASE` / `HEADCOUNT INCREASE ▶`。

**用在**：量表题、满意度、变化预期。**不要用普通堆叠条**——普通堆叠条让读者没法比较"净正面"。

## 3. 象限图直接标注个体

PwC 的职业散点图：四象限，每个象限里直接标注代表性职业名（"医疗秘书""系统管理员"），不用图例。象限外侧写语义轴标签（`AI raises expertise required ▲` / `AI reduces expertise required ▼`），每个象限角落标占比（26% of advertised jobs）。

**用在**：两个连续变量 + 读者关心具体个体在哪。图例会强迫读者在图和图例之间来回跳，直接标注省掉这一步。

**限制**：能标注的点不超过 15 个，否则改用高亮少数 + 其余淡化。

## 4. 直接标注取代图例（时间序列版）

AI Index 的算力散点图：几百个点，只标注 8 个有名字的模型（GPT-4、DeepSeek-V3、Grok 4…），用细引线连到点。

**用在**：点多但读者只认识其中几个。标注那几个，其余交给分类色。

**加强版（晚点小数据）**：折线末端不标名字，标**数值**，而且数值着该系列的色——
`英伟达 66.2%`（绿）、`苹果 32.6%`（红）、`特斯拉 1.4%`（青）。
名字和数字一次给全，读者不用回头去纵轴上找。
数值必须用**表格数字**，否则三条线末端的数字会左右参差。

**真要图例时，键用纯几何实心点，贴在文字前面，不要图例框。**
两系列对比图上是这样一行：`● 发布时价格　　● 调价后`——键与文字同色，
居中放在图上方，没有边框、没有底色、没有圆角。
图例框（那个带描边和浅底的小方框）是图表库的出厂默认，删掉它不需要理由。

## 5. 倍数徽章

BCG 的做法：三根对比柱（19% / 39% / 65%）上方加一个绿底圆角标签 `3.4x`，配一个从首柱指向末柱的箭头。

**用在**：对比的重点不是绝对值而是倍数关系。**读者记不住 19 和 65，但记得住 3.4 倍。**

## 6. 机制图承载多个数据点

BCG 的 flywheel：中心一个五步循环箭头图，每一步向外挂一组三根对比柱 + 倍数徽章。一张图同时给出「机制」和「五组数据」。

**用在**：多个数据点之间存在因果或循环关系，分开画会丢掉关系。**不要为了好看硬套**——数据之间没有机制关系时，机制图是谎言。

## 7. 甜甜圈 + 箭头 = 时间推移

Deloitte 的做法：`56% Today` ●→● `77% in 2 years`，两个甜甜圈中间一个箭头。

**用在**：只有两个时间点、且要按地区/群体重复多次。三个以上时间点改用折线。

## 8. 大数字视觉锚

Reuters DNR：一个粗环形图中间放 `42%`，下面两行小字说明「说自己经常或有时回避新闻」，环外一行 `Up from 29% in 2017`。

**用在**：整份报告最重要的那两三个数字。**一页最多一个**——遍地大数字等于没有重点。

## 9. 地图做空间锚定，不做地理精度

Deloitte 把三组甜甜圈压在一张淡灰世界地图上。地图不承载数据（不是等值图），只提供「美洲/EMEA/亚太」的空间位置。

**用在**：分区域数据 + 读者需要瞬间定位。**不要用等值填色图**表达三四个大区的数据——它会让读者误以为国家级精度存在。

## 10. 国旗/图标做排行

DNR 的「新闻回避率最高的国家」：国旗圆形图标 + 大号百分比 + 国名。

**用在**：Top 3–5 的排行榜。比条形图更快被扫描，也更容易被单独截图传播。

## 11. 桑基图做生态流向

HF 用桑基图画模型衍生关系：基座模型 → 各种微调方式 → 终止/再衍生，每条流标注占比。

**用在**：一个总量在多个阶段被分流，且读者关心「流到哪去了」。**限制**：分支超过 12 条就不可读，把长尾合并成 Other。

## 12. 高密度表格（研报专用）

Morgan Stanley 的做法：深蓝表头 + 左列行标签用品牌色块 + 纯数字网格 + 最右一列 Total，一页放三张。

**用在**：读者要查具体数字而非看趋势。**deck 的留白规则在这里不适用**——查数的人要的是密度。

配套要求：数字右对齐、用表格数字、百分号统一放在数值后、零值写 0% 不留空。

## 13. 焦点色：颜色从一个转折点开始

晚点小数据的 DRAM 价格图：2023/03 到 2025/07 整整两年半是一条灰线，
从 2025/07 那个点起才翻成饱和红，一路拉到 538.74。
**颜色不是在编码「系列」，它在编码「故事从哪一刻开始」。**

同一机制的另一面是内存厂那张晶圆分配图：图例只有两项——
`HBM`（砖红）和 `其他 DRAM`（中性灰 `#D9D9D9`）。八个堆叠条、十六个色块，
颜色只回答一个问题：这里面有多少是留给 AI 的。

对照着看能把边界划清：同一组卡片里，iPhone RAM 容量那张图 17 根柱子**全是红的**，
一件灰的都没有——因为那页要回答的是「涨了多少」，不是「哪一根才是重点」。
焦点色是给「有焦点」的数据用的。

**用在**：读者要看的不是「每条线各是多少」，而是「什么时候变的」「哪一段才是重点」。
答案是**一个转折点、一段区间、或一根柱**的时候用它；
答案是「系列之间的差别」时，才轮到分类色板。

**上色前必须先找到那条分界线。** 这个机制不是「把重要的涂红」——
那是用颜色表达你的判断，`视觉系统.md` 配色节和绝大多数机构规范都不许，
而且它没有可复制的判据：什么算重要？成立的用法是，
**被涂色的那一半本身有一条数据里就存在的分界**：

| 分界线 | 例子 |
|---|---|
| 时间上的前 / 后 | 2025/07 之前是灰的，之后是红的——分界点是那场发布会 |
| 归属上的是 / 否 | `HBM` 涂红、其他 DRAM 留灰——分界是产品类别 |
| 口径上的实际 / 预计 | 只有最后一根柱子是红的，因为它是预测值 |

读者看到的「重点」是这条分界的**结果**，不是你替他做的判断。
找不到这样一条分界线，就说明这份数据没有焦点——那就老实按分类色板来。

**落法**：
```
背景/历史数据   文字 #8E8E8E   填充 #D9D9D9   线 #3C3C3C
焦点            砖红 #D84532（这一类版式的惯用色）
对照（变化前）   深青 #21687D
```
「分类色板最多 6 类」那条规则在这个机制里不适用——它通常只有**一个**彩色在说话。

**别滥用**：一页上出现两个焦点色，就等于没有焦点。

## 选型速查

| 读者要比什么 | 用 |
|---|---|
| 类别之间的大小 | 横条（类别名长）/ 竖柱（时间或有序） |
| 随时间的变化 | 折线；只有两点用箭头连接的圆点 |
| 构成比例 | 堆叠条；**别用饼图**除非只有 2–3 块 |
| 量表/正负分布 | 发散堆叠条 |
| 两个变量的关系 | 散点 + 直接标注 |
| 分布形态 | 直方图 / 箱线图 |
| 流向与转化 | 桑基 |
| 具体查数 | 表格 |
| 单一关键数字 | 大数字 + 一行说明，别画图 |

## 每张图必须有

1. 标题（结论式，研报型除外）
2. 数据源行（区分采数方和分析方）
3. 样本量 N（该图的 N，不是全报告的 N）
4. 单位（%、pp、美元、次/人）
5. 调研图另加问卷原题
6. 编号（学术 Figure / 研报 Exhibit，一份报告内不混用）

## 三个会改变读者结论的陷阱

这三个和「不好看」不是一个量级——它们会让读者得出错误的结论，而且不会有任何报错。

**一、负值被画成零高度。** 如果图表代码没处理负值，`-11%` 会渲染成 0 高度的柱子，
于是「下降 11%」和「没有变化」在图上完全一样。任何可能出现负值的数据，
画完先确认：零线在哪？负值在零线下方吗？标签有没有带符号？

**二、选错图型产生无意义的元素。** 用成对柱去画只有一组数据的对比，
第二根柱子会是 0 高度并老老实实标注「0%」——读者会以为那是个真实的零值。
**一组数据用横条，两组才用成对柱。**

**三、Y 轴不从零开始且不标注。** 把 3% 的差异画成三倍高。
如果确实需要截断坐标轴（比如比较 97% 和 99%），必须在轴上明确标出断裂，
并在图注里写明。默认永远从零开始。

## 常见坏做法

- Y 轴不从零开始又不标注——把 3% 的差异画成 3 倍
- 3D 饼图、阴影、渐变填充——装饰墨水挤占数据墨水
- 双 Y 轴——两条轴的缩放可以拼出任何想要的"相关性"
- 图例在图外很远处——读者在两处之间来回跳
- 用彩虹色做有序数据——彩虹在感知上不是单调递增的
- 只用颜色区分——约 8% 男性有色觉障碍，形状/位置/直接标注要能独立工作
