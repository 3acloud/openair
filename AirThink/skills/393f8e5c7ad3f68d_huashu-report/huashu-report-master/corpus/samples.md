# 实证样本清单

43份报告的完整清单，按日期排序。**这个仓库不存报告实物**——43份一律只列官方来源，需要的话照链接自己下载。

这么做有两个原因。一是这批报告里 32份的版权不支持再分发；二是剩下 11份虽然许可允许，但把 90 多MB 的 PDF 塞进一个装进 agent 就要 clone 的 skill 仓库，等于让每个用户都为少数人的需求多下这个体积。链接同样能到达，代价小得多。

许可状态逐份扫过 PDF 内的版权页，分三档：

- **开放许可（11份）**——CC BY / CC BY-NC / CC BY-ND / OGL。这类你可以自由使用，包括再分发，署名即可
- **保留所有权利（17份）**——版权方明确保留再分发权
- **未声明许可（15份）**——公开发布但没有给出使用条款，按版权法默认仍是保留版权

标 ᵃ 的 2 份是后来补入的，未进入量化解剖（`anatomy.json` 覆盖 41 份）。

**采集时下错了文件的有 3 份**，备注列注明实际下到的是什么。那几份的量化数据来自实际下载到的文件，不是标称的那份报告——用的时候注意。

## 采集与口径

- **扫描范围**：2026-01-01 以后发布、由顶级机构出品的 AI 主题报告。37个渠道：Stanford HAI、McKinsey、BCG、OpenAI、Anthropic、OECD、世界银行、RAND、Reuters Institute 等
- **筛选方式**：19个 agent 的并行 workflow，按来源权威／数据原创性／信息增量／时效／可得性等七个维度打分，出74份总榜，再逐份实测能否下到全文
- **落盘标准**：PDF 而非网页快照，且通过内容级校验（标题实词与 PDF 前三页的命中率）
- **规模**：43份，41 份进入量化解剖

## 解剖数据里有什么

`anatomy.json` 每份记录：页数、页面尺寸与横竖、书签大纲、字体清单与字号分布、正文颜色使用、图表密度代理指标（矢量绘图对象数）。它只含量化结果，不含报告原文。

skill 里的量化规范就是从这些字段的中位数与分布里反推的——「正文98%用近黑」量的是每一份的 `text_colors`，「超过60页必须有书签」量的是 `toc_depth`。想验证某条规范，或者给自己领域的报告立一套基线，都从这里开始量。
