## 二、排版规范

### 网格系统
```
画布：1080×1350px
边距：60px（四周）
内容区：960×1230px

垂直分区：
├─ 头部区域：标题 + 副标题（占20%）
├─ 核心内容区（占60%）
└─ 底部区域：来源 + 页码（占10%）
```

### 字号层级
| 元素 | 大小 | 字重 | 用途 |
|:---|:---|:---|:---|
| 卡片序号 | 28px | Bold | 圆形数字标 |
| 主标题 | 56-64px | 800 | 核心主题 |
| 副标题 | 24-28px | 500 | 补充说明 |
| 引用金句 | 32-36px | 600 | 重点强调 |
| 正文内容 | 26-28px | 400 | 普通段落 |
| 标签文字 | 18-20px | 600 | 分类标签 |
| 页脚文字 | 20-22px | 500 | 来源/页码 |

### 间距规范
- **大间距**：40-50px（模块之间）
- **中间距**：28-32px（段落之间）
- **小间距**：16-20px（行内元素）
- **圆角统一**：16px（卡片），20px（引用框）

## 四、快速应用指南

### 步骤1：确定主题色
根据内容类型选择配色主题（历史/心理学/职场/投资）

### 步骤2：选择组件
- 有步骤/清单 → 用组件5
- 有案例场景 → 用组件3
- 有金句 → 用组件2
- 有洞察 → 用组件4

### 步骤3：应用字号层级
- 数字标：28px Bold
- 标题：64px 800
- 副标题：24px 500
- 正文：26px 400

### 步骤4：检查CRAP原则
- [ ] **对比**：标题>正文>标签，层级清晰
- [ ] **重复**：配色、圆角、字号风格统一
- [ ] **对齐**：所有元素有明确对齐线
- [ ] **亲密性**：相关内容靠近，不同内容远离
