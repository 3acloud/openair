# Knowledge Card Designer

## 概述

本技能用于生成美观、专业的知识卡片图片，支持微信读书小绿书格式（封面900×383px，正文1080×1350px）。

应用设计规范：
- CRAP设计原则（对比、重复、对齐、亲密性）
- 色彩心理学（冷色背景+暖色强调）
- 知识可视化方法

## 设计规范参数

### 字体层级
| 元素 | 大小 | 字重 | 用途 |
|------|------|------|------|
| 标题 | 24pt | Bold | 主标题 |
| 副标题 | 18pt | Medium | 次级标题 |
| 正文 | 14pt | Regular | 内容文字 |
| 标签 | 12pt | Regular | 标签、说明 |

### 间距规范
- 四周留白：30px
- 行距：1.5倍
- 组内间距：20px
- 组间间距：40px

### 圆角规范
- 卡片：12px
- 按钮：8px
- 标签：4px

### 色彩策略
- **冷色系**（蓝、绿、紫）：背景、客观信息
- **暖色系**（红、橙、黄）：强调重点、行动召唤

## 工作流程

### 1. 内容分析
确定信息类型：
- 数据对比 → 使用柱状图/饼图
- 流程步骤 → 使用时间轴/流程图
- 概念解析 → 使用信息图/示意图
- 对比分析 → 使用对比表格
- 清单要点 → 使用列表/复选框

### 2. 选择模板
根据内容选择对应HTML模板：
- 封面模板（深蓝黑渐变+金色装饰）
- 正文模板（主题色渐变背景）
- 对比模板（左右/上下对比布局）
- 时间线模板（步骤可视化）

### 3. 应用设计
- 使用网格系统对齐
- 应用CRAP原则
- 冷色背景+暖色强调
- 保持留白呼吸感

### 4. 生成输出
- HTML预览文件
- PNG图片文件（多尺寸）
- PDF导出（可选）

## 使用示例

**用户请求**：生成《纳瓦尔宝典》小绿书

**执行步骤**：
1. 分析书籍内容，确定6张卡片结构
2. 选择对应模板（封面+5张正文）
3. 应用设计规范生成HTML预览
4. 导出PNG图片（900×383封面 + 1080×1350正文）
5. 发送给用户

## 输出规格

| 类型 | 尺寸 | 用途 |
|------|------|------|
| 封面 | 900×383px | 微信读书首页展示 |
| 正文 | 1080×1350px | 知识卡片正文 |
| 文件大小 | <300KB | 平台上传要求 |

## 检查清单

生成卡片前检查：
- [ ] 对齐：所有元素有明确视觉对齐线
- [ ] 对比：层级清晰（标题>正文>标签）
- [ ] 亲密性：相关内容靠近，不同内容远离
- [ ] 留白：四周30px，信息有呼吸感
- [ ] 重复：配色、字体、图标风格统一
- [ ] 色彩：冷色背景，暖色强调重点

## 小绿书平台优化策略（2026年3月更新）

基于微信读书小绿书推荐算法（CES评分机制），内容生成必须遵循以下策略：

### 一、推荐算法核心机制

**CES评分公式**（2026年最新）：
```
总分 = 点赞(1分) + 收藏(1分) + 评论(4分) + 转发(4分) + 关注(8分)
```

**流量分发逻辑**：
1. **初始流量池**：100-500次展示
2. **晋级条件**：点击率>2.5%、收藏率>1.5%、完播率>40%
3. **搜索流量占比**：70%月活用户有搜索行为

### 二、标题优化策略

**必须遵循的公式**：
```
标题 = 数字量化 + 结果导向 + 悬念设置
```

**标题前15字必须包含**：
- 2-3个核心关键词（搜索友好）
- 数字（3个/5个/7天）
- 结果承诺（避免/找到/提升）

**示例对比**：
| ❌ 原标题 | ✅ 优化后 |
|:---|:---|
| 《在不确定性中寻找锚点》 | 《**3个方法**｜在**不确定时代**找到**人生锚点**》 |
| 《侥幸心理：现代人的精神鸦片》 | 《**为什么你总是侥幸心理**？**5个心理学陷阱**让你**不断犯错**》 |
| 《5个让你少犯傻的心理学效应》 | 《**5个心理学效应**｜**聪明人都在用**的**决策工具**》 |

### 三、封面优化策略

**封面点击率决定80%流量入口**

**高点击率封面公式**：
```
竖版3:4 (1080×1440px) + 高对比配色 + 大号数字 + ≤8字核心词
```

**6大爆款封面模板**：
1. **数字封面**："5个动作｜肩颈酸痛消失"
2. **对比封面**：痘痘肌→牛奶肌
3. **留白封面**：70%图像+30%留白
4. **深色封面**：黑/红/蓝高对比
5. **钩子封面**："没想到..." "竟然..."
6. **分析封面**：数据可视化

**配色规范**（必须执行）：
- 背景：深蓝(#1a1a2e) / 深紫(#16213e) / 墨绿(#1b4332)
- 强调：橙色(#ff6b35) / 黄色(#ffd93d) / 红色(#e74c3c)
- 文字与背景对比度必须>70%

**封面文字层级**：
```
┌─────────────────────────┐
│   [冷色渐变背景]         │
│                         │
│      数字（48pt）        │  ← 暖色强调
│      核心词（32pt）      │  ← 白色粗体
│      副标题（18pt）      │  ← 浅灰
│                         │
│   [极简图标]             │
└─────────────────────────┘
```

### 四、内容结构优化

**必须包含的互动钩子**（CES评分关键）：

| 位置 | 钩子类型 | 示例文案 | 算法权重 |
|:---|:---|:---|:---:|
| **开头3秒** | 冲突引入 | "你是不是也经常..." | 完播率 |
| **正文每30秒** | 互动提问 | "你中招了吗？" | 评论4分 |
| **结尾** | 行动召唤 | "你同意吗？评论区聊聊" | 评论4分 |
| **结尾** | 关注引导 | "关注我，每周3个心理学工具" | 关注8分 |
| **结尾** | 转发引导 | "转给总犯傻的朋友" | 转发4分 |

**结尾标准模板**：
```
💬 你有过类似经历吗？
👇 评论区说说你的想法

👉 关注我，每周3个心理学工具
📌 收藏起来，下次犯傻前看看
🔁 转给需要的朋友
```

### 五、选题策略优化

**从"纯心理学"转向"实用工具+情绪共鸣"**：

| 原方向 | 优化方向 | 示例 |
|:---|:---|:---|
| 深度思考类 | 职场工具类 | 《**3个思维模型**｜**老板眼前一亮**的汇报技巧》 |
| 批判观点类 | 情绪共鸣类 | 《**总被误解**？**5个沟通陷阱**让你**越说越错**》 |
| 知识清单类 | 热点结合类 | 《**哪吒2破100亿**｜**3个心理学原理**揭秘**国漫崛起**》 |

**蹭热点策略**：
- 每周一盘点上周热点
- 用心理学角度解读热点
- 标题必须带热点关键词

### 六、发布策略

| 维度 | 规范 | 原因 |
|:---|:---|:---|
| **时间** | 晚8-10点 | 用户活跃高峰 |
| **频率** | 每周至少3篇 | 培养阅读习惯 |
| **标签** | 每篇5个标签，含1个年度热点词 | 算法加权 |
| **系列化** | "7天心理学"系列 | 培养追更 |

### 七、生成前强制检查清单

生成小绿书内容前，必须确认：

- [ ] **标题**：前15字含2-3个核心关键词+数字
- [ ] **封面**：竖版3:4 + 高对比 + 大号数字 + ≤8字
- [ ] **开头**：3秒冲突引入
- [ ] **正文**：每30秒一个互动钩子
- [ ] **结尾**：评论区引导+关注引导+转发引导
- [ ] **标签**：5个标签，含1个热点词
- [ ] **原创声明**：开启可获得额外流量倾斜

### 八、避坑指南

**2026年小绿书限流红线**：
- ❌ 画面模糊度过高（<720P直接限流）
- ❌ 文案信息密度过低（<30%干货占比）
- ❌ 同一WiFi下多账号互动
- ❌ 诱导性评论（"互赞必回"等）
- ❌ 纯图文笔记（视频笔记流量占比75%）
- ❌ 标签超过5个或使用过气网红词
