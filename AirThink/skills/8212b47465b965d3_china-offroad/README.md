# 越野纵横（china-offroad）

一个免费开源的 AI 技能（Skill）：像一位跑了二十年越野的老领队一样，帮你规划越野、穿越和自驾路线。

- **路线：** 沙漠、高原、冰雪、入门练手，标注了难度和季节
- **注意事项与红线：** 保护区、无人区、边防证、草原保护
- **保障：** 车辆检查、装备、通讯、车队规则、保险救援、补给、高反
- **吃喝玩乐：** 沿途的特色菜和值得去的地方
- **会联网核实：** 封路、开放日期这类会变的信息，都会先查最新消息

## 怎么用
- **WorkBuddy：** 技能 → 添加技能 → 上传技能，选择本压缩包
- **Claude / 其他支持 Skills 的 AI 工具：** 把 `china-offroad` 文件夹放进对应的 skills 目录
- 用的时候直接问就行，比如"十一想去腾格里，原厂车能玩吗？"
