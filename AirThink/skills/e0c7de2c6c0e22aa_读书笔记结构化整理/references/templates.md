# 读书笔记输出模板（按需套用）

从 `SKILL.md` 判定体裁后，复制对应模板填写。只输出用户需要的模块，删除不适用章节。

---

## 模板 B：社科 / 论文引用

```markdown

## 全书框架
- 研究问题 / 核心命题：
- 章节逻辑（问题→概念→论证→结论）：
- 作者主要贡献（归纳，1–3 句）：

## 分章节核心观点
### 第 X 章
- 本章要回答的问题：
- 核心观点（条列，尽量贴近原文）：
- 关键概念（定义句）：
- 主要论据 / 案例：
- 可延伸的论文角度（可选，标「建议」）：

## 可引用金句
| 金句 | 章/页 | 适合支撑的论点 | 引用注意 |
|------|-------|----------------|----------|
| 「…」 | | | 直引/转述 |

## 概念对照（可选）
| 概念 | 书中界定 | 易混淆点 |
|------|----------|----------|
```
