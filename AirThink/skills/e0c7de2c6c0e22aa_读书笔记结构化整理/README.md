# reading-notes · 读书笔记结构化整理

上传书籍文本 / 摘抄段落，梳理书籍核心框架、人物关系、核心论点、金句摘抄，分章节生成思维导图式结构化笔记。

## 使用效果

粘贴书籍内容或上传书籍截图，输出分层结构化笔记：全书整体框架、分章节核心论点、关键案例、可直接摘抄金句，逻辑清晰，适合读书报告、课堂作业使用。

## 提示词示例

1. 上传这本社会学书籍摘抄，分章节梳理核心观点，整理可用于论文引用的金句。
2. 整理这本文学小说读书笔记，梳理人物关系、故事脉络、中心主旨，做成简洁框架。
3. 专业教材读书笔记，提取每章核心理论、关键案例，标注考试可背诵考点。
