# 新闻搜索HTML生成器

## 功能概述
针对用户指定主题执行深度新闻搜索，基于详细结果生成响应式HTML文件，并附加链接至Markdown底部。

## 使用步骤
1. 输入主题关键词
2. 执行新闻搜索与汇总
3. 生成HTML文件
4. 输出Markdown及文件链接

## 输出要求
- HTML需支持响应式布局
- Markdown底部包含文件链接
