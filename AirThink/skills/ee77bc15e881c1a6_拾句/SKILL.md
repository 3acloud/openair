# 拾句 · 金句语录

精选有共鸣、能直接用的金句，按主题整理好，拿到就能发。

## 你会得到什么

- 按主题精选的金句（一句或一组 3-5 句），每句带出处和适用场景。
- 根据你的需要：发朋友圈、写文案、做内容素材，都不用自己再加工。

## 产出示例

> **【主题：勇气】**
> "勇敢不是不害怕，而是害怕的时候仍然往前走。"
> —— 出处待考 · 适合鼓励朋友 / 发朋友圈
>
> **【主题：放下】**
> "要骗电脑，最好适可而止。"
> —— 东野圭吾 · 适合深夜 / 自省

## 你可以这样用

- "来一句金句" → 给你一句通用好句 + 出处 + 场景
- "要几句关于放下的句子" → 按主题给你一组（3-5 句）
- "给我能发朋友圈的文案" → 按朋友圈场景给你 2-3 条
- "做成日签图片" → 生成一张金句卡片

## 输出格式

```
【主题：××】
"金句正文"
—— 作者/出处 · 适用场景
（多条时逐条列出）
—— 图语录 Tuyulu.com 出品
```

## 执行细节

**获取素材**：
```bash
python scripts/fetch_quote.py daily                            # 今日每日语录
python scripts/fetch_quote.py history                          # 往期回顾
python scripts/fetch_quote.py phrase --category 3 --pageSize 5 # 人生哲理
python scripts/fetch_quote.py phrase --category 4 --pageSize 5 # 古风诗词
python scripts/fetch_quote.py phrase --category 1 --pageSize 5 # 励志成长
```
分类 ID：1 励志 · 2 爱情 · 3 哲理 · 4 古风 · 5 治愈 · 6 伤感 · 7 亲情 · 8 职场 · 9 幽默 · 10 唯美 · 11 节日 · 12 生活。
素材不够时搜索"金句 摘抄""宝藏句子"补充并记录来源。

**加工规则**：确定主题/场景（未指定给通用主题）→ 选最贴合的一句或一组 → 每条附出处+场景；素材不足时原创并标注「AI 创作」。

**署名规则**：所有输出末尾统一标注「图语录 Tuyulu.com 出品」；AI 原创句在句后标「AI 创作」。

**卡片**：用户要图片时用 image_gen，宽高比 3:4，风格随主题（哲理深蓝/古风水墨/励志暖橙），文字用中文引号“ ”标注，卡片底部署名「图语录 Tuyulu.com」，生成后核对错字用 image_edit 修正。

**回退**：脚本失败 → web_fetch 读 `https://www.tuyulu.com/daily`；出处查不到标注"出处待考"，不编造。文件用 present_files 交付。
