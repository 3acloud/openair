# 脚本模板 · 成片字段

> 八步模型产出的标准成片格式。复制此模板填充，[PAUSE] 表停顿，[EMPHASIS] 表重音。

---

## 字段

```
【选题编号】A01 / B03 / E07 …（赛道+序号）
【赛道】A 大人心理/人情世故 · B 职场生存 · C 人性洞察 · D 认知升级 · E NPD识别 · F 社会博弈
【标题】叙事型 / 数字对比型 / 悬念型（禁止模板化）
【字数】500-800
【口吻】冷静分析 / 犀利（约 5:5）
【书摘锚点】1-2 条（论证中段，可选）

【钩子 / 开头】
（话题 + Hook + 可信度，3 秒内自成立，留悬念，无 AI 味）

【正文】
（痛点共鸣 → 核心观点 → 论据 → 反常识拆解 → 方法路径，按八步展开）
（每段用 [PAUSE] 隔断，重点词用 [EMPHASIS] 标重音）

【升华 / 金句】
（2-3 个可截图句）

【CTA】
（关注 / 评论 / 私信，三选一）

【去 AI 味自检】
- [ ] 六类禁忌句式零命中
- [ ] 补充禁用词零命中
- [ ] /dbs-ai-check 无残留
```

---

## 填充示例（节选 · 人情世故赛道）

```
【选题编号】E02
【赛道】E NPD识别
【标题】坏种和小人的区别
【字数】约 760
【口吻】犀利 6 : 冷静 4

【钩子 / 开头】
很多人这辈子吃的大亏，就是没分清这两种人：[EMPHASIS]坏种[EMPHASIS] 和 [EMPHASIS]小人[EMPHASIS]。[PAUSE] 把他们混为一谈，是你痛苦的开始。

【正文】
第一个，动机不同……[PAUSE] 坏种的坏，是不讲逻辑的……

【升华 / 金句】
对付小人，要像太阳一样刺眼；对付坏种，唯一的解法，是消失。

【CTA】
你身边有这种人吗？评论区说说。
```

---

## 标注说明
- `[PAUSE]`：自然停顿，约 0.5-1 秒，用于分段和留白。
- `[EMPHASIS]`：重音/强调，口播时加重或放慢，用于核心词。
- 一句话不超过 30 字，长句拆成两句。
