# 数字卡片格式规范 (Travel Card Format Specification)

本文档定义了 Travel Planner Skill 生成旅行数字卡片的标准格式。
AI 在生成卡片时应严格遵循此格式。

## 一、卡片结构（含实拍图）

数字卡片为单文件 HTML，包含以下区域：

```
┌──────────────────────────────┐
│      头部大图区域               │
│  (目的地实拍大图 + 渐变遮罩     │
│   + 目的地名称 + 天数 + 风格)   │
├──────────────────────────────┤
│      统计数据区                 │
│  (天数 | 景点数 | 餐厅数)       │
├──────────────────────────────┤
│      精选景点实拍图轮播          │
│  (4 张景点实拍图，横向滑动)     │
├──────────────────────────────┤
│      每日主题区（含景点缩略图）   │
│  Day 1 主题 + 景点 + 缩略图×3   │
│  Day 2 主题 + 景点 + 缩略图×3   │
│  Day 3 主题 + 景点 + 缩略图×3   │
├──────────────────────────────┤
│      预算区                    │
│  (总预算 + 人均)               │
├──────────────────────────────┤
│      页脚                      │
│  (生成来源 + 日期)             │
└──────────────────────────────┘
```

## 三、图片来源与获取方式

### 3.1 头部大图（目的地全景照）

| 位置 | 尺寸 | 来源 | 获取方法 |
|---|---|---|---|
| 卡片头部 | 380×200px | 目的地城市实拍 | AI 通过 WebSearch 搜索 "{destination} city skyline photo" 获取图片 URL |

### 3.2 精选景点实拍图（4 张）

| 位置 | 尺寸 | 来源 | 获取方法 |
|---|---|---|---|
| 统计区下方轮播 | 100×75px | 行程中 4 个核心景点实拍 | 从行程中选取 4 个代表性景点，搜索 "{place_name} {destination} photo" 获取 URL |

### 3.3 每日景点缩略图（每天 2-3 张）

| 位置 | 尺寸 | 来源 | 获取方法 |
|---|---|---|---|
| 每日行程条目右侧 | 56×56px | 当天核心景点实拍 | 搜索当天景点的实拍图 URL |

### 3.4 图片获取流程

AI 生成卡片时，按以下步骤获取图片 URL：

1. **头部大图**：搜索 "{destination} city" → 选取一张高质量城市实拍 URL
2. **精选景点图**：从行程中选取 4 个最具代表性的景点 → 逐一搜索 "{place} {destination} photo" → 获取 URL
3. **每日缩略图**：从每天的行程中选取 2-3 个核心景点 → 搜索实拍图 URL

### 3.5 图片降级策略（图片加载失败时）

- 每个 `<img>` 标签添加 `onerror` 属性，加载失败时自动隐藏或替换为默认图
- 头部大图失败 → 替换为 Unsplash 随机旅行图：`https://source.unsplash.com/380x200/?travel,city`
- 景点图失败 → 隐藏该图片，不影响卡片整体展示
- 所有图片均使用 `object-fit: cover` 确保比例统一

## 四、数据字段

| 字段 | 来源 | 说明 |
|---|---|---|
| emoji | 按目的地自动选择 | 如东京→🗼、巴黎→🗼、巴厘岛→🌴 |
| destination | 行程总览 | 目的地名称（当地语言 + 英文） |
| days | 用户输入 | 旅行天数 |
| style_label | 用户输入/默认 | 经济型/舒适型/豪华型 |
| dates | 用户输入/默认 | 旅行日期范围 |
| places_count | 行程统计 | 景点总数 |
| restaurants_count | 行程统计 | 餐厅总数 |
| header_img_url | WebSearch 获取 | 目的地城市实拍大图 URL |
| gallery_img_1~4 | WebSearch 获取 | 4 张精选景点实拍图 URL |
| gallery_name_1~4 | 行程提取 | 精选景点名称 |
| day_cards | 行程每日主题 | 每天的主题 + 景点 + 缩略图 URL |
| budget_total | 预算明细 | 总预算金额 |
| budget_per_person | 预算明细 | 人均预算 |
| generated_date | 系统时间 | 卡片生成日期 |

## 五、每日主题卡片格式（含缩略图）

每天生成一个主题条目，包含景点缩略图：

```html
<div class="day-item">
  <div class="day-num">1</div>
  <div class="day-content">
    <div class="day-theme">传统文化线</div>
    <div class="day-places">浅草寺 · 雷门 · 上野公园</div>
    <div class="day-photos">
      <img class="day-photo" src="https://景点1图片URL" alt="浅草寺" onerror="this.style.display='none'">
      <img class="day-photo" src="https://景点2图片URL" alt="雷门" onerror="this.style.display='none'">
      <img class="day-photo" src="https://景点3图片URL" alt="上野公园" onerror="this.style.display='none'">
    </div>
  </div>
</div>
```

- day_num：天数序号（1, 2, 3...）
- day_theme：当日主题（4-8字，如"传统文化线"）
- day_places：核心景点（2-3个，用 · 分隔）
- day-photos：当天景点实拍缩略图（56×56px，2-3张）

## 六、生成规则

1. 卡片宽度固定 380px，适合手机竖屏截图
2. 头部使用目的地实拍大图 + 渐变遮罩 + 目的地名称
3. 统计数据区三等分：天数/景点数/餐厅数
4. 精选景点区：4 张实拍图横向滑动轮播
5. 每日主题最多显示 5 天（超过 5 天只显示前 5 天 + "..."）
6. 每天附带 2-3 张景点缩略图
7. 预算区使用浅色背景突出显示
8. 页脚标注"由 Travel Planner 生成"
9. 卡片为自包含 HTML，CSS 内联，图片引用在线 URL
10. 所有图片加载失败时自动降级（隐藏或替换默认图），不影响卡片展示
11. 支持中文和英文两种语言版本

## 七、使用方式

1. AI 生成 HTML 代码块（含图片 URL）
2. 用户复制代码到 `.html` 文件
3. 用浏览器打开（需联网加载图片）
4. 截图保存为图片
5. 分享到朋友圈/小红书/微信
