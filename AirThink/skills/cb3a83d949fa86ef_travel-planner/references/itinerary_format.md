# 行程格式规范 (Itinerary Format Specification)

本文档定义了 Travel Planner Skill 生成行程计划的标准格式。
WorkBuddy 在生成行程时应严格遵循此格式。

## 一、总览 (Overview)

```
## 目的地概览

- **目的地**: [城市名 + 英文名]
- **最佳旅行季节**: [月份范围] 
- **本次旅行天数**: [N 天 N 晚]
- **旅行日期**: [起始日期 → 结束日期]
- **天气预估**: [温度范围 + 天气特征]
- **签证/入境**: [签证要求简述]
- **货币汇率**: [1 CNY = X 当地货币]（如适用）

### 核心亮点
1. [亮点1]
2. [亮点2]  
3. [亮点3]
```

## 二、每日行程 (Day-by-Day Itinerary)

每天按 早 / 午 / 晚 三个时段拆分：

```
### Day 1 — [日期] [主题/区域名]

**上午 (09:00-12:00)**
- 📍 [地点名] — [活动描述]
- ⏱ 建议时长: [X 小时]
- 💰 预估花费: [金额]
- 🚶 交通方式: [步行/地铁/出租车]

**午餐 (12:00-13:30)**
- 🍜 [餐厅名] — [菜系] — [人均消费]

**下午 (14:00-17:00)**
- 📍 [地点名] — [活动描述]
- ⏱ 建议时长: [X 小时]
- 💰 预估花费: [金额]

**晚餐 (18:00-20:00)**
- 🍽 [餐厅名] — [菜系] — [人均消费]

**晚间 (20:00-)**
- [可选夜间活动]
```

## 三、住宿推荐 (Hotels)

每晚提供 2-3 个选项，覆盖不同价位：

```
### 住宿推荐

| 酒店 | 区域 | 价格/晚 | 评分 | 特点 |
|------|------|---------|------|------|
| [酒店名1] | [区域] | ¥[XXX] | ⭐[X.X] | [亮点] |
| [酒店名2] | [区域] | ¥[XXX] | ⭐[X.X] | [亮点] |
| [酒店名3] | [区域] | ¥[XXX] | ⭐[X.X] | [亮点] |

**预订建议**: [最佳预订平台 / 提前天数 / 注意事项]
```

## 四、美食推荐 (Food)

按天列出推荐餐厅：

```
### 美食地图

| 餐厅 | 位置 | 菜系 | 人均 | 推荐菜 |
|------|------|------|------|--------|
| [餐厅名] | [区域] | [菜系] | ¥[XX] | [招牌菜1, 招牌菜2] |
```

## 五、交通方案 (Transport)

```
### 交通规划

**城际交通**
- 去程: [方式] [时长] [费用] — [备注]
- 返程: [方式] [时长] [费用] — [备注]

**市内交通**
- 方案A: [交通卡/Pass] — [价格] — [覆盖范围]
- 方案B: [打车/网约车] — [预估日均费用]
- 建议: [最优方案推荐]
```

## 六、预算总览 (Budget)

```
### 预算明细

| 类别 | 明细 | 预估费用 |
|------|------|----------|
| 交通-城际 | [往返机票/高铁] | ¥[XXXX] |
| 交通-市内 | [N天交通费] | ¥[XXX] |
| 住宿 | [N晚 × 均价] | ¥[XXXX] |
| 餐饮 | [N天 × 日均] | ¥[XXX] |
| 门票/活动 | [景点列表] | ¥[XXX] |
| 购物/备用 | [弹性预算] | ¥[XXX] |
| **合计** | | **¥[XXXXX]** |

**人均费用**: ¥[XXXX]
**预算等级**: [经济型/舒适型/豪华型]
```

## 格式约束

1. 所有金额统一使用一种货币（默认 CNY ¥）
2. 时间使用 24 小时制
3. 地点名提供当地语言 + 中文/英文
4. 表格保持对齐
5. 如果信息不确定，标注"预估"并说明依据
