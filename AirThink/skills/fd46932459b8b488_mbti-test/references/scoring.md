# MBTI 计分规则

标准 MBTI 四维度计分：每题 A/B 各映射 E/I/S/N/T/F/J/P 之一，按组取高分侧拼成四字母类型。

## 步骤

1. 初始化：`E=I=S=N=T=F=J=P=0`
2. 遍历本次测试的题目列表；对用户每题答案：
   - 选 **A** → 累加 `options[0].characterType`
   - 选 **B** → 累加 `options[1].characterType`
3. 四组对比（**相等取左侧字母**）：
   - `E ≥ I` → `E`，否则 `I`
   - `S ≥ N` → `S`，否则 `N`
   - `T ≥ F` → `T`，否则 `F`
   - `J ≥ P` → `J`，否则 `P`
4. 拼接得四字母类型，如 `INTJ`

## 维度倾向（展示用）

每组可算百分比，例如 E=12、I=8 → E 60% / I 40%。

## 答案格式

会话内维护答案表：`{ "题号": "A"|"B" }`，键为题目 `id`（数字转字符串均可）。
