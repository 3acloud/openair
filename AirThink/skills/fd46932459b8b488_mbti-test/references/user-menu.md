# 用户菜单与能力

用户首次触发 skill（或意图不明）时，**先展示本菜单**，再进入对应流程。不要直接开始出题。

## 开场模板

```markdown
# MBTI 十六型人格测试

你想做什么？回复数字或关键词即可：

| # | 功能 | 怎么说 |
|---|------|--------|
| 1 | **快测 28 题**（约 5 分钟） | `28` / `快测` |
| 2 | **标准 93 题**（推荐，约 15 分钟） | `93` / `标准` |
| 3 | **完整 200 题**（约 30 分钟） | `200` / `完整` |
| 4 | **查人格类型** | `解读 INFJ` / `INFP 是什么` |
| 5 | **对比两个类型** | `INFJ 和 INFP 区别` |
| 6 | **16 型一览** | `有哪些类型` |

> 本测试供自我了解与参考，不构成心理诊断。
```

用户已明确意图（如「28题」「解读 INFP」）→ **跳过菜单**，直接进入对应模式。

## 能力速查

| 功能 | Agent 行为 |
|------|-----------|
| 快测 / 标准 / 完整 | Read 对应 `data/decks/<deck>.json`，分批出题 → 计分 → 报告 |
| 查型 | Read `data/results/<TYPE>.md`，按 [result-format.md](result-format.md) L1 或用户要求层级输出 |
| 对比 | 遵循 [type-compare.md](type-compare.md) |
| 16 型一览 | 展示 [types-overview.md](types-overview.md) 表格 |
| 看某一块 | 只读报告中指定章节（职业 / 爱情 / 优势等） |
| 续测 | 见 [session-flow.md](session-flow.md) §续测 |
