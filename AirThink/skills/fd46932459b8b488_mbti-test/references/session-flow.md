## 完整测试流程

```text
菜单(可选) → 选题量 → Read 题卷 → 逐批出题 → 收齐答案 → 计分 → 分层报告
```

### 逐批出题

- 每批 **5 题**（末批可不足 5）
- 批次标题：`### 第 N 批（x–y / 总数）` + `进度 y/总数`
- 快测 28 题可注 `约剩 Z 分钟`（按每题 ~10s 估算）

格式示例：

```markdown
### 第 1 批（1–5 / 28） · 进度 5/28

**1.** 当你要外出一整天，你会
- A. 计划你要做什么和在什么时候做
- B. 说去就去

…

回复方式（任选）：`A B A B A` · `1A 2B 3A` · 大小写均可
```

### 答题格式（硬规则）

| 规则 | 说明 |
|------|------|
| 大小写 | `a`/`A` 均有效 |
| 本批简写 | 仅本批 5 题时，可按序写 `A B A A B`，默认对应当批题号 |
| 跨批 | 须带题号：`6A 7B` |
| 未答完 | 禁止计分；列出未答题号 |

### 计分

Read [scoring.md](scoring.md)。答案键为题目 `id`（卷内 `questions[].id`）。

### 出报告

遵循 [result-format.md](result-format.md) 分层与边界维度规则。

## 续测

题卷文件含固定 `deckId` + `seed`。续测时：

1. Read **同一** deck 文件
2. 根据已答 `id` 列表，从下一未答题继续
3. 向用户确认：`你上次做到第 X 题，从第 X+1 题继续`

## 禁止

- 未 Read 题卷就编造题目
- 运行时 shuffle（已废弃，见 [shuffle.md](shuffle.md)）
- 更改计分规则（相等取左侧）
- 与 SBTI 十五维测试混用
