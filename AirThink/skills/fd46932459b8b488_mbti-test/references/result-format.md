# 结果展示格式

## 16 种类型

`ENFJ, ENFP, ENTJ, ENTP, ESFJ, ESFP, ESTJ, ESTP, INFJ, INFP, INTJ, INTP, ISFJ, ISFP, ISTJ, ISTP`

## 数据来源

- 索引：`data/types-index.json` → `typeName`、`tagline`、`file`
- 正文：`data/results/<TYPE>.md`

## 分层输出（硬规则）

| 层级 | 何时用 | 内容 |
|------|--------|------|
| **L1 默认** | 测完出结果、查型未要求详情 | 类型 + 中文名 + 四维表 + `tagline` 或概览首段（≤120 字） |
| **L2 详细** | 用户说「详细一点」 | L1 + 优势/注意点/适合方向（从报告提炼，各 3～5 条） |
| **L3 完整** | 用户说「完整报告」 | 全文引用 `data/results/<TYPE>.md` |

查型默认 **L1**；测完默认 **L1**，末尾问「要看详细解读吗？」

## 推荐模板（L1）

```markdown
# MBTI 测试报告

**你的人格类型：INTJ**
**建筑师/策略家型**

| 维度 | 倾向 |
|------|------|
| 外向 E / 内向 I | I 65% |
| 实感 S / 直觉 N | N 58% |
| 思考 T / 情感 F | T 72% |
| 判断 J / 感知 P | J 61% |

（一句 tagline 或概览摘要）

> 本报告供自我了解与参考，不构成心理诊断。
```

## 边界维度（硬规则）

计分后检查四维百分比；**任一维度较高侧 ≤55%** 时，必须附加：

```markdown
⚠️ **边界提示**：你的 *J/P*（或对应维度）倾向较弱（55%），结果可能随题量变化。建议做 **93 题标准测试** 复测确认。
```

多个边界维度可合并为一条说明。

## 快测免责声明（硬规则）

`testCount === 28` 时，L1 报告末尾**必须**附加：

```markdown
📋 本次为 **28 题快测**，样本较小，结果仅供参考。需要更准确可回复 `93` 做标准测试。
```

## 指定章节

用户说「INFJ 适合什么职业」→ 只读该报告对应 `##` 章节，不必输出全文。
