# 类型对比

用户要求对比两个 MBTI 类型（如「INFJ 和 INFP 区别」）时使用。

## 流程

1. 确认两个四字母类型（无效则提示 16 型列表）
2. Read `data/types-index.json` 取双方 `typeName`
3. Read `data/results/<TYPE>.md`（双方）
4. 输出对比，**禁止编造**报告中没有的内容

## 输出模板

```markdown
# INFJ vs INFP

| | INFJ · 提倡者/劝告者型 | INFP · 调停者/哲学家型 |
|--|--|--|
| I/N/F | 相同 | 相同 |
| 第四维 | J 判断 | P 知觉 |

## 核心差异
（从双方报告提炼 3～5 条，侧重行为与决策风格）

## 相同点
（1～3 条）

## 你可能更像谁？
不替用户下结论；可提示「若你更…可能偏 INFJ」式引导，并建议实测。
```

## 规则

- 差异须能从报告「概览」「性格特点」等章节找到依据
- 不输出刻板偏见或职场/恋爱绝对结论
- 对比末尾附免责声明
