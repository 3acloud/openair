# 学霸笔记 · 质量检查清单

生成笔记后，逐项检查以下内容。

---

## P0 · 必须通过

- [ ] `<title>` 标签已替换为笔记标题（不含占位符 `[必填]`）
- [ ] HTML 文件可在浏览器中正常打开
- [ ] 所有中文内容使用 `lang="zh-CN"`
- [ ] 字体加载正常（Kalam, Patrick Hand, Zeyada）
- [ ] 螺旋装订孔正常显示
- [ ] 纸质背景（横线 + 红色装订线）正常显示
- [ ] 所有 `.write-in` 元素的 `animation-delay` 按顺序递增
- [ ] 没有使用 emoji 作为图标（必须使用 Lucide SVG 图标库）

## P1 · 强烈建议

- [ ] 便签 `.side-note` 位置合理，不遮挡正文
- [ ] 便签有适当的旋转角度（2-4度）
- [ ] 便签颜色与内容语义匹配（黄=补充、粉=警告、蓝=信息、绿=安全、紫=技术）
- [ ] 流程图 `.flow-box` 箭头方向正确
- [ ] 对比框 `.compare-box` 新旧/正反标签颜色正确
- [ ] 警告框 `.big-warning` 用于真正需要强调的内容（不要滥用）
- [ ] 代码术语使用 `.code-term` 而非普通引号
- [ ] Lucide 装饰图标不超过 3 个，且 opacity ≤ 0.15
- [ ] 咖啡渍不超过 2 个

## P2 · 建议

- [ ] 整体内容节奏合理：标题 → 概述 → 详细 → 总结
- [ ] 段落之间有适当的 `.section` 间距
- [ ] 颜色使用一致（不要随意新增 CSS 变量）
- [ ] 响应式布局在移动端正常（便签变为相对定位）
- [ ] 页面总长度适中（建议 800-1500 行 HTML）

## P3 · 可选优化

- [ ] 添加了合适的 Lucide 装饰图标（与主题相关）
- [ ] 关键位置有便签旁注增加阅读趣味
- [ ] 使用了分割线 `.divider` 区分大章节
- [ ] 攻击链/步骤使用了编号样式 `.step-num`

---

## 常见问题

### Q: 便签在移动端被截断？
A: 检查是否包含了 `@media (max-width: 768px)` 中的便签响应式样式。

### Q: 动画不生效？
A: 检查是否引入了底部的 JavaScript（IntersectionObserver + setTimeout）。

### Q: 字体不显示？
A: 检查 Google Fonts 链接是否正确，网络是否可达。

### Q: 螺旋孔位置偏移？
A: 检查 `.notebook` 的 `padding-left` 是否为 `6rem`。
