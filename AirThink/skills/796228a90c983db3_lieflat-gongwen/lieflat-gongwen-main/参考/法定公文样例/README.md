# 法定公文样例（版式参照，非蒸馏语料）

> 7 篇中国政府网公开政策文件，覆盖批复、复函、通知、决定、条例五个文种。
> 来源：中国政府网政策栏目，公开发布文件，无版权限制。

## 为什么只作参照，不做蒸馏

法定公文的正文结构由制度锁定，不是"写作技法"而是**固定填空**：

```
批复 →  你省关于X的请示收悉。现批复如下：一、同意…  二、你省及X要…  三、你省与X部要加强指导监督
通知 →  根据X，现将Y通知如下：一、…  二、…  三、…
复函 →  你部关于X的请示收悉。经研究，现函复如下：…
```

蒸馏这些没有增量——文种手册里本来就有。这批样例的价值在**公文语料里缺失的那部分**：

| 要素 | 公文语料 | 本样例 |
|------|-----------|--------|
| 发文字号 | ✗ 删除 | ✓ 国函〔2026〕80号 |
| 主送机关 | ✗ 删除 | ✓ 山东省人民政府： |
| 发文机关署名 | ✗ 删除 | ✓ 国务院 |
| 成文日期 | ✗ 删除 | ✓ 2026年7月21日 |
| 公开标识 | ✗ 删除 | ✓ （此件公开发布） |

写通知/请示/批复时，对照真件比对照描述可靠。

## 从这 7 篇能直接看出的规律

**1. 批复的三段式极其固定**（830 字的批复）
```
段1  你省关于X的请示收悉。现批复如下：      ← 承启句，一句话
一、 同意X。（附同意理由：历史悠久、资源丰富…）  ← 表态在最前
二、 你省及X市人民政府要…                  ← 主体要求，最长
三、 你省与X部、X局要加强指导、监督和检查      ← 落到监督主体
```
**表态永远在第一条**，理由跟在表态后面而非前面。这与调研报告的"先铺垫后结论"完全相反。

**2. "的通知"文种的真实归属**
《关于印发X规划的通知》——文种是**通知**不是规划，规划是附件。标题里"印发…的通知"是标准结构。

**3. 篇幅跨度极大**
508 字（复函）到 6,927 字（印发规划的通知）。法定公文没有"标准篇幅"，事项说完即止。这与事务性材料（2,500-4,400 字有明确区间）不同。

**4. 短件不分层**
508 字的复函没有"一、二、三"，直接成段。1,442 字的通知才开始分条。

**5. 承启句是文种指纹**
```
批复/复函 → "…收悉。现批复如下：" / "…收悉。经研究，现函复如下："
通知      → "现将…通知如下：" / "现印发给你们，请…"
```
用错承启句等于用错文种。

## 用法

写法定公文时：
1. 按文种打开对应样例，看版式要素的位置和写法
2. 抄承启句和结语的句式（这部分是程式，照抄不算抄）
3. 正文分条逻辑参照样例的"表态→要求→监督"顺序

**注意**：这 7 篇均为国务院/国办层级文件，口径高、篇幅偏正式。地市县级发文的语气和篇幅会更实、更短，不要照搬这个层级的表述方式。
