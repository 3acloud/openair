# 标题技法库

> 统计语料：984 个真实标题
> - 短评 120 个（均长 11.6 字）
> - 党建创新经验材料 77 个（均长 16.7 字）
> - 公文篇名 228 个（均长 17.1 字）
> - 公文一级标题 559 个（均长 18.0 字）
>
> 方法：正则技法识别，全量统计，可多标签命中
>
> **本文的百分比来自上述全量统计，但所有示例标题都是自造的**，标注 `〔示意〕`。
> 语料原文与原标题不随本 skill 分发（版权），示例只按各技法的结构特征重新拟写，
> 用来说明"这个技法长什么样"，不代表任何真实文章。
>
> **短评列只作对照，不代表本 skill 支持写网评。** 网评已从覆盖范围移除，但下表的
> 技法浓度梯度靠它当参照才有意义：喻体承载、条件递进、对照结构这三种技法在公文里
> 出现率近零，恰恰因为它们是评论体的东西。删掉这一列，"公文标题别用什么"就没有了
> 依据。

## 一、技法浓度梯度（本库最重要的发现）

同一套技法在四类文本中的使用率差异极大，构成清晰梯度：

| 技法 | 短评〔对照〕 | 党建 | 公文篇名 | 公文一级标题 |
|------|------|------|---------|-------------|
| **引号概念化** | **48%** | 29% | 12% | 21% |
| **严格对仗** | 25% | **34%** | 7% | 9% |
| **虚词起首** | **22%** | 21% | 6% | 4% |
| **双概念对置** | **17%** | 6% | 3% | 3% |
| **喻体承载** | **11%** | 6% | 0% | 1% |
| **条件递进** | **6%** | 0% | 0% | 0% |
| **对照结构** | **5%** | 0% | 0% | 0% |
| 双分句 | 6% | 16% | 2% | **31%** |
| 成效动词收尾 | 4% | **22%** | 2% | 5% |
| 数字概括 | 1% | 4% | 6% | 3% |
| 三段并列 | 0% | 0% | 4% | 2% |
| **素朴陈述（无技法）** | 18% | 13% | **69%** | 45% |

**三条判读**：

1. **技巧密度：短评 > 党建 > 公文一级标题 > 公文篇名**。公文篇名 69% 无技法——法定标题受"发文机关+事由+文种"约束，不玩花样。

2. **公文一级标题 31% 用双分句**，是四类中最高。但它的双分句多为"动作+目的"的功能性拼接（`加强XX，保障XX`），不是评论体那种对仗审美。

3. **条件递进（方能/才能）和对照结构（与/不是）几乎是评论体专属**。这两种技法在公文中出现率近零——因为它们承载的是"论证"，公文标题只需"标示"。

## 二、九种技法（示例均为自造）

### 技法1｜引号概念化 — 使用率最高（短评 48%）

把日常词加引号，升格为分析对象。三种子类：

**a. 单概念聚焦**
```
把"慢功夫"下在见效慢的事上          〔示意·短评〕
用好为民服务"最后一米"             〔示意·短评〕
把牢质量管理"总闸门"：从源头抓起严把关口   〔示意·党建〕
```

**b. 双概念对置**（短评 17%，本技法的高阶用法）
```
以"小切口"带动"大改观"             〔示意·短评〕
主动"补位"，精准"让位"             〔示意·短评〕
以"服务暖"换来"人心齐"             〔示意·党建〕
拧紧"责任螺丝"焊牢"落实链条"        〔示意·公文篇名〕
从"审批"到"服务"体现职能定位的深层调整   〔示意·公文一级标题〕
```

**c. 概念群**（三个及以上，多见于公文）
```
牢牢守住"三条底线"  集中整治"四类顽症"   〔示意·公文篇名〕
"三个到位"夯实"学"的根基              〔示意·公文一级标题〕
```

> **写作参数**：评论体标题必含至少 1 处引号概念；公文一级标题可用，篇名慎用。

---

### 技法2｜严格对仗 — 党建最高（34%）

两个片段字数差 ≤2，结构对称。

```
严管有尺度，厚爱有温度                          〔示意·短评〕
脚下沾泥土 心中有分寸                           〔示意·短评〕
技能提起来 收入涨起来                           〔示意·党建〕
组织建在链上 服务送到门前                        〔示意·党建〕
夯实基础练本领 优化服务聚人心                     〔示意·党建〕
真抓实干 精准施策 坚决打赢改革攻坚硬仗             〔示意·公文篇名〕
```

> **写作参数**：党建经验材料首选此技法。注意两半必须**语法结构同构**，不只是字数相等。

---

### 技法3｜虚词起首（让/把/以/用/为/向/从/在）

用虚词开头，把标题变成一个动作指令。

```
让"边角地"长出便民"新空间"        〔示意·短评〕
把"公私之界"守在心里              〔示意·短评〕
让基层探索成为改革动力源            〔示意·短评〕
以组织优势驱动升级 用实绩回应群众期待  〔示意·党建〕
以高质量党建推动产业转型提质          〔示意·党建〕
```

> 短评 22%、党建 21%，但公文只有 4-6%。**这是评论体的标志**。

---

### 技法4｜喻体承载 — 评论体专属（11%，公文近 0%）

用具象喻体替代抽象概念。

**语料中观察到的喻体类型**（可复用）：
```
土气/地气   — 基层作风
冷板凳      — 基础研究、长期坚守
答卷        — 工作成效
磨刀石      — 问题、挫折
方寸之地    — 小空间大服务
小支点      — 关键抓手
动力引擎    — 驱动力
钥匙        — 解决方案
生命线      — 极端重要性
组合拳      — 系统性措施
活水        — 持续动力
压舱石      — 稳定作用
指挥棒      — 导向作用
```

示例：
```
守"冷板凳"才有真"答卷"                  〔示意·短评〕
把老手艺当作乡村振兴的"活水"              〔示意·短评〕
三把"钥匙"打开治理"新局面"               〔示意·党建〕
党建赋能装上人才培养"动力引擎"            〔示意·党建〕
打好"组合拳"破解"三类难题"               〔示意·公文篇名〕
```

> **公文一级标题喻体使用率仅 1%** —— 想在公文里用喻体，放在篇名或讲话稿标题，别放在一级标题。

---

### 技法5｜条件递进（方能/才能/更需）— 评论体专属

标题本身就是一个论证。

```
下"深功夫"方能出"真成效"      〔示意·短评〕
人岗相宜方能各尽其才           〔示意·短评〕
"情况明"方能"决策准"          〔示意·短评〕
理清旧账方能算准新账           〔示意·短评〕
建成是开头 管好才是答案        〔示意·短评〕
"冷门岗"更需热心人            〔示意·短评〕
```

> 6% 使用率但**全部集中在评论体**。公文语料 787 个标题中仅 1 例。

---

### 技法6｜对照结构（与/不是）— 评论体专属

并置两个概念，制造张力。

```
真出成绩与出真成绩              〔示意·短评〕  ← 同词异序，最精巧
"抓眼前"与"谋长远"              〔示意·短评〕
"摘果"与"育苗"                  〔示意·短评〕
乘势而上与埋头深耕               〔示意·短评〕
```

**同词异序**是这类技法的极致形态，984 个标题中仅 4 例：
```
真出成绩与出真成绩              〔示意·短评〕
把难事做实 把实事做细            〔示意·短评〕
```

> 极稀缺技法。用对了很亮，但难度高、易生硬。

---

### 技法7｜成效动词收尾 — 党建标志（22%）

`[主体] + [做法/机制] + [成效动词]`

**成效动词清单**（按语料频次）：
```
推动、助推、激活、锻造、撬动、注入、交出、跑出、走出、谱写、绘就、解锁、赋能
```

示例：
```
某公司党委一体推进学查改见实效               〔示意·党建〕
某集团"四项工程"助推产业链加速升级            〔示意·党建〕
"区域联建"激活流动党员新动能                 〔示意·党建〕
为基层减负工作注入"新生力量"                 〔示意·党建〕
以组织优势驱动发展 某单位交出实干答卷          〔示意·党建〕
```

> **党建经验材料的标准标题公式**。22% 使用率是四类中最高。**主体一律用"某公司""某单位"占位**，写作时替换成本单位名称。

---

### 技法8｜数字概括

用数字打包做法。

```
某集团"五项工程"助推产业链加速升级       〔示意·党建〕
传承优良作风 培育"四类骨干"            〔示意·党建〕
三把"钥匙"打开治理"新局面"             〔示意·党建〕
夯实"三项基础"，不打折扣完成既定动作     〔示意·公文一级标题〕
"三个到位"夯实"学"的根基               〔示意·公文一级标题〕
"三个聚力"抓住"做"的关键               〔示意·公文一级标题〕
"三个见效"确保"改"的实效               〔示意·公文一级标题〕
```

> 注意最后三例构成**一组连续的一级标题**——用同一数字格式串起全文，这是"成组标题"技法（见下）。

---

### 技法9｜三段并列 — 公文专属

三个片段并列，多见于篇名和长标题。

```
真抓实干 精准施策 坚决打赢改革攻坚硬仗            〔示意·公文篇名〕
夯实三项基础 优化三种方式 做实三个衔接            〔示意·公文篇名〕
强宣传：顺势而为，改革创新，扎实改进宣传工作       〔示意·公文一级标题〕
落实政策红利，算清发展细账，满怀信心迎接产业新阶段  〔示意·公文一级标题〕
推动五项振兴，打造五个品牌，努力创造群众幸福生活   〔示意·公文一级标题〕
端正思想认识，压实各方主体责任，健全长效管理机制   〔示意·公文一级标题〕
```

> 短评和党建 0% 使用——**短文体撑不起三段并列**。

## 三、成组标题技法（跨标题的一致性）

单个标题好不够，**一组一级标题必须同构**。三种同构方式（示例均为自造）：

**数字同构**
```
一、"三个到位"夯实"学"的根基
二、"三个聚力"抓住"做"的关键
三、"三个见效"确保"改"的实效
```

**设问同构**
```
一、怎么看？当前形势的三个基本判断是……
二、差什么？对照目标要求仍有三方面短板……
三、怎么做？紧密结合本单位实际，重点抓好……
```

**动词+目的同构**（公文一级标题最常见形态，31% 双分句多属此类）
```
一、健全监管机制，保障公平竞争
二、强宣传：顺势而为，改革创新
三、强协同：领导带头，齐抓共管
```

> **规则**：一组标题内**不可混用技法**。要么全用数字式，要么全用设问式，要么全用动宾式。

## 四、按文体选技法（决策表）

| 你在写 | 首选技法 | 可用 | 避免 |
|--------|---------|------|------|
| **党建族材料**（千字级） | 严格对仗 + 成效动词 | 引号概念化、数字概括 | 条件递进、对照结构 |
| **法定公文篇名**（通知/请示/报告） | 素朴陈述（三要素） | — | 全部技法 |
| **事务材料篇名**（调研/汇报/总结） | 素朴陈述 或 引号概念化 | 数字概括、三段并列 | 喻体、条件递进 |
| **公文一级标题**（分析类） | 双分句（动作+目的） | 引号概念化、数字概括 | 喻体、对照结构 |
| **公文一级标题**（业务类） | 素朴陈述（4-8字） | — | 全部技法 |
| **领导讲话标题** | 对仗 或 三段并列 | 喻体、数字概括 | — |

## 五、字数参数

| 文体 | 标题字数 |
|------|---------|
| 党建族材料 | **16-17 字** |
| 公文篇名 | 17 字 |
| 公文一级标题（分析类） | **17-18 字** |
| 公文一级标题（业务类） | **4-8 字**（如"一、指导思想""二、主要做法"） |

> 业务类一级标题短到 4 字，分析类长到 18 字，**同为一级标题相差 4 倍**。这个差异比技法选择更影响"像不像"。

## 六、给 AI 的标题生成流程

```
1. 判文体 → 查上表"按文体选技法"决策表
2. 定字数 → 查上表字数参数
3. 若为法定公文篇名 → 直接用"发文机关+事由+文种"，停止
4. 若为其他 → 从首选技法中选 1-2 种叠加
5. 若生成一组一级标题 → 检查是否同构（同技法、同字数±3）
6. 自检：
   □ 党建族材料是否用了成效动词？
   □ 公文一级标题是否误用喻体？（使用率仅1%）
   □ 一组标题是否混用技法？
   □ 是否照抄了本文的示意标题？（它们是自造示例，不是可交付的标题）
```
