# 公文文章结构模板（L2 主体架构层）

> 原为 8 文种 × 3 篇精读 = 24 篇，每文种按篇幅三分位（短/中/长）抽样；占比＝该一级段字数÷全篇字数。
> 心得体会一节已随该文种移出覆盖范围一并删除，现存 7 文种 21 篇的精读结果。
> **精读原文与抽样清单未随包分发（版权）**，本文的提炼结果无法回溯到原文逐条复核。
> 频率类结论引自 `结构全量统计.md`（全量 229 篇，其中含 38 篇心得体会），本文只做主体架构：段序、功能、长度配比、段内构造、过渡。

## 一、工作方案（甲组 n=11）

**主体架构**（导语／各一级段占比）

- 《大气污染防治行动计划》实施方案：导语2.1 → 总体要求9.2 → **重点任务66.7** → 保障措施22.0
- 人民监督员选任管理方式改革试点意见：导语6.2 → 重要意义12.9 → 总体要求5.1 → **主要内容48.9** → 实施步骤10.1 → 组织保障16.7
- “圆梦女孩志愿行动”工作方案：背景13.1 → 宗旨理念12.0 → 时间地点3.0 → 参加人员7.7 → **活动形式38.1** → 媒体宣传26.1

任务段是唯一重心（38-67%），保障/宣传段收口（16-26%），前置的意义与要求段压在 5-13%，导语 2-6% 只写依据和目的。分歧在前段要素：政策型用「意义—要求」，活动型（《圆梦女孩》）改用「时间地点—人员」且**无导语**，直接以「一、背景」起笔。

**段落内部结构**　唯一大量用三级标题（19/12/23 个）、「一是」全为 0 的文种。构造：（一）动宾＋句号 → 一句总体路径 → 1．2．3．按年份分解。

> （三）发展气象干预措施，实施人工影响天气改善空气质量。在重污染天气条件下采取可行的气象干预措施……1．开展人工消减雾霾试验，形成业务能力。2013年，组织制定京津冀人工影响天气改善空气质量工作方案……2014年，总结试验经验，形成可有效降低污染改善空气质量……

年份是方案的落点标记，替代了其他文种的判断句。

**过渡手法**　三篇均无段间过渡句，靠标题硬切。《大气十条》实施方案「二、重点任务」之前仍是上段收束语（"……提高公众大气污染防治参与意识和重污染天气防御能力"），下一句即二级标题。连接责任全交给编号。

**骨架公式**　`[依据目的] → [意义/总体要求] → [任务分述（过半）] → [实施步骤] → [组织保障]`；活动型变体 `[背景] → [宗旨] → [时间/地点/人员] → [活动形式] → [宣传]`

## 二、调研报告（甲组 n=31）

**主体架构**（导语／各一级段占比）

- 北京广东城市生活垃圾分类调研报告：导语1.5 → 做法成效37.4 → 问题原因33.1 → 思考建议27.9
- 部属高校信访工作调研报告：导语3.9 → 基本情况10.2 → 亮点38.0 → 主要问题25.5 → 建议22.4
- 水利行业精神的实践探索和理论思考：导语3.5 → 精神与核心价值观19.0 → 实践基础24.2 → 丰富发展18.2 → **深刻启示35.1**

标准型三大段近乎均分，**无一段超过 40%**——与工作方案的单段独大正相反。导语 1.5-3.9%，以「现将有关情况报告如下」收尾。第三篇是理论探索型变体，**无问题段**，段序为概念界定→历史来源→发展演进→启示。三篇共同点仅在末段功能：必须落到建议或启示。

**段落内部结构**　提领句（背景＋判断）→（一）（二）（三）分条 →「比如/例如」举证。《垃圾分类》问题段的四个二级标题全是加引号的现象白描：「垃圾分类，知易行难」「前端分类，后端杂烩」「利大抢收、利小少收、无利不收」「一堆部门搞不定一堆垃圾」。用群众口语给问题命名，比「体制机制不健全」有信息量。

**过渡手法**　过渡句一律置于**新段段首**，不在上段段尾：

> 做法→问题：“垃圾分类在北京、广州、深圳等试点城市取得一定进展，但由于种种原因，10多年来仍处于‘试点’阶段。”
> 问题→建议：“我们每个人每天都要产生生活垃圾，一个三口之家一年产生约1吨垃圾。从可持续发展角度看，分类处理是最好的垃圾处理方式……”
> 分述→启示（《水利行业精神》）：“回顾水利事业与水利行业精神相辅相成发展的历史进程，从中可以得出许多深刻的启示：”

第二例不用连接词，把视角从政府拉回个人，用共情重新起势。

**骨架公式**　`[缘起] → [做法成效] → [问题原因] → [建议]`；理论型变体 `[概念] → [来源] → [演进] → [启示（最长）]`

## 三、经验材料（甲组 n=22）

**主体架构**（导语／各一级段占比）

- 妥善处理中欧光伏贸易摩擦的经验及启示：导语8.7 → 案件情况15.7 → **经验总结47.1** → 几点启示28.5
- 服务问计 民为本源：导语8.2 → 问需于民15.3 → 问计于民28.4 → 问德于民15.8 → 问效于民32.4
- 关于改革和优化国家药品标准形成机制的思考：导语5.1 → 整体思考7.5 → 总体思路28.1 → **策略建议59.2**

做法段是绝对主体（47-59%）。**「启示」段是经验材料区别于调研报告的结构标记**：调研报告末段是给上级的建议（对方去做），经验材料末段把个案抽象成可复制规律（别人可用）。《中欧光伏》五条启示全写成普适命题：「科学的机制和方法是应对贸易摩擦案件的基础」「对话磋商是解决贸易争端的有效途径」。《服务问计》是并列变体，四段以「问需—问计—问德—问效」排比贯通，**不设独立启示段**。第三篇 59.2% 是建议，已偏向方案，说明二者边界在实践中并不清晰。

**段落内部结构**　「一是」在此文种最密（14/0/12 个）。《中欧光伏》「二、案件应对具体经验总结」提领句：

> 此案事关我产业及国家重大经济利益，机电商会从案前预警、案中应对和案后执行入手，凝聚行业形成合力、抗辩游说结合，多管齐下，最终妥善解决摩擦。

「案前—案中—案后」恰好预告下面四个二级标题（超前预警／依托机制／积极协调／高效组织）。**提领句预先交出下文的分类轴**，是段内构造的核心动作。《服务问计》证明并列型可完全不用分层标记（二级标题 0、「一是」0），靠四个排比式一级标题撑全篇。

**过渡手法**　靠「结果句→下一段」推进，不写连接词。做法段末尾「……欧委会官员也面对我外交使团官员称赞商会为‘最值得信赖的合作伙伴’」，下段即「三、几点启示」；情况段末尾「该公司在欧盟立案时已处于破产边缘，立场极为强硬，难以通过企业间的合作化解摩擦」，下段首即上引提领句。**成效句就是过渡句。**

**骨架公式**　`[背景] → [做法分述（近半）] → [启示（抽象为规律）]`；并列变体 `[背景] → [同构动词×4 的并列做法段]`

## 四、领导讲话（乙组 n=45）

**主体架构**（导语／各一级段占比）

- 用心用情 真帮实干 坚决打赢脱贫攻坚硬仗：导语4.4 → 使命光荣27.3 → 精准施策38.2 → 齐心协力30.0
- 深入学习再鼓干劲：导语12.1 → 把握精神实质45.0 → 认识艰巨性18.3 → 增强信心24.5
- 学习贯彻上级全会精神（讲话）：导语11.3 → 汲取力量34.7 → 找准途径32.3 → 展现担当21.7

**三篇全部恰为 3 个一级段**，功能序列一致：**为什么 → 做什么 → 谁来干**。一级标题全为双分句（前半动作＋后半目的），与全量统计「乙组 34% 双分句、均长 17 字」吻合。导语承担称谓、会议目的、议程预告三事，其中一篇导语末句直接报菜单：〔示意〕「今天，我围绕三个方面谈一下怎么学习贯彻（上级全会精神）、走好‘最后一公里’的问题」。

**段落内部结构**　场景化提领→分条→承诺句落点，区别于其他文种的是大量口语与俗谚：

> 俗话说，“火车跑得快，全靠车头带”，如果我们把全国看成一列火车，那么这个车头就是党中央，火车驾驶员就是我们习近平总书记……

上述那篇学习贯彻类讲话，二级标题干脆是三个口语短句「要转观念」「要补短板」「要搞特色」，段内嵌连续设问（"路怎么样？""引水工程怎么样？"）。**段内节奏由设问—俗语—比喻控制，而非编号。**

**过渡手法**　唯一使用显式口语过渡的文种：

> “最后说一说党员干部履行职责使命的问题。”
> 〔示意〕“前面我们学习领悟（上级全会精神）的时候，看到了上级帮扶脱贫攻坚的决心，但基础的工作还需要我们自己来做。”（先复述再转折）
> “同志们、乡亲父老们，经过这几年各级各部门和大家的共同努力……”（段中再呼称谓，把听众拉回现场）

收尾符合全量统计「乙组号召/展望式占 11%」：三篇末句分别是「确保2019年成功摘掉贫困村的帽子」「在大家脱贫的那一天我们来给大家拜年！谢谢大家！」「为实现打赢脱贫攻坚战……不懈奋斗」。

**骨架公式**　`[称谓＋目的＋议程预告] → [认识（为什么）] → [任务（做什么）] → [责任号召（谁来干）]`

## 五、调研报告（乙组 n=45）

**主体架构**（导语／各一级段占比）

- 聚焦问题补短板弘扬美德树作风：导语9.9 → 四类浪费25.6 → 四大短板25.4 → **四处着力39.1**
- 关注形式主义“花样翻新”：导语4.9 → 主要特征39.3 → 剖析病因31.3 → 从根源解决24.5
- X省机关深入开展党史学习教育调研报告：导语13.6 → 现状考察28.8 → 直面短板20.7 → 抽丝剥茧14.0 → 路径构建23.0

与甲组同属「问题—原因—对策」谱系，三处系统差异：标题承载观点与数字口号（甲组写「一、问题和原因」，乙组写「一、四类浪费让人触目惊心」）；对策段更重（23-39%）；前两篇**不用二级标题**（各 0 个），全靠「一是」（12／9 个）撑段内层次，与全量统计「乙组三级标题几乎归零」一致。段数有分歧：前两篇把问题与原因合并为三段，第三篇拆成四段并给每个标题加「现状考察：」「直面短板：」「抽丝剥茧：」「路径构建：」功能前缀，24 篇中仅此一例。

**段落内部结构**　《聚焦问题补短板》三段用同一数字「四」贯穿（四类浪费—四大短板—四处着力），**数字统摄三段形成呼应**：

> 经过调研，我们了解到，当前机关浪费现象普遍存在，让人触目惊心，其主要表现为四种类型。一是司空见惯的“习惯式浪费”。这是机关浪费现象的主要表现形式，重点体现在餐饮中的粮食浪费情况……据调研了解，机关自助餐的浪费量至少在15%以上。

「调研动作＋总判断＋数量预告 → 一是＋加引号命名＋定位句＋数据」。自造加引号概念（"习惯式浪费"）与甲组给问题起口语名同源。

**过渡手法**　以问题属性判断引出对策段：

> “形式主义问题点多面广、形式多样、成因复杂，必须坚持系统思维、重点突破、全面发力，推动问题从根源上得到解决。”
> “调研中，我们坚持问题导向、目标导向、结果导向，紧扣机关存在的四类浪费情况……提出四个方面对策建议。”（回指第一段"四类浪费"闭环）

**骨架公式**　`[缘起] → [问题表现（可数字命名）] → [原因] → [对策（最重）]`

## 六、工作意见（乙组 n=25）

**主体架构**（导语／各一级段占比）

- 川委厅〔2020〕110号（为基层减负）：导语12.9 → 总体要求22.5 → **重点任务52.9** → 保障措施11.7
- 关于加强机关党的政治建设的意见：导语2.0 → 总体要求19.0 → **重点任务43.8** → 要素保障35.2
- 关于进一步加强机关党员干部能力建设的意见：导语5.3 → 总体要求12.3 → 政治建设17.3 → 理论武装17.7 → 集中培训11.4 → 实践历练12.0 → 作风建设13.0 → 组织领导11.0

前两篇是铁三段：**总体要求19-23% → 重点任务44-53% → 保障措施12-35%**。第三篇是平铺变体，把重点任务拆成 5 个并列一级段，各占 11-18% 高度均匀，首尾仍保留总体要求与组织领导。两种形态可互换，取决于任务条目是否需要各自命名。「总体要求」内部有固定三件套且两篇完全一致：（一）指导思想（二）基本原则（三）目标要求，是 24 篇中唯一可逐字复用的结构模块。

**段落内部结构**　二级标题最密（13/14/21 个），「一是」三篇均为 0。构造：（一）四字动宾＋句号 → 判断句 →「要……」排比句群。

> （一）提升政治站位。机关工作是政治工作，机关干部首先要讲政治。政治站位的高低决定了机关党员干部政治视野的广度、服务中心大局的力度。要聚焦提升政治站位，定期组织形势政策教育，结合重大会议、重要节点开展中央、省委精神集中宣讲活动……

判断句为动作提供合法性，「要」字句给出可执行动作。这正是全量统计中乙组要求词密度 10.08/千字（甲组 5.79）的来源。

**过渡手法**　与工作方案同，无段间过渡句，靠三个固定标签自我说明。全篇唯一承担连接功能的是导语末句：

> 〔示意〕“按照党的十九大报告提出新时代党的建设总要求和习近平总书记关于党的政治建设的重要论述，根据（省委全会）关于加强党的政治建设的总体部署，结合（本机关）党建工作实际，制定本意见。”

「按照……根据……结合……制定本意见」四段式收束，是意见类导语的稳定句式。

**骨架公式**　`[目的依据＋制定本意见] → [总体要求（指导思想/基本原则/目标要求）] → [重点任务（近半）] → [保障措施]`；平铺变体 `[总体要求] → [任务段×5-9（各 11-18%）] → [组织领导]`

## 七、经验总结（乙组 n=8）

**主体架构**（导语／各一级段占比）

- 聚焦关键环节注重常态长效：导语5.9 → 学32.1 → 做31.2 → 改30.8
- 抓实三个环节 创新三种方式 做好三个结合：导语8.2 → 三个环节43.4 → 三种方式22.8 → 三个结合25.6
- 坚持深“学”真“做”实“改”：导语7.8 → 学38.0 → 做25.9 → 改28.3

**8 文种中最均衡的一类**，三篇均 3 段，第一篇三段相差不足 1.3 个百分点。功能序列不是「问题—对策」，而是工作环节的自然三分：两篇直接用「学—做—改」，第三篇用「规定动作—自选动作—成果扩大」。三篇**均无问题段、均无启示段**，与甲组经验材料（必带启示）明确分野：甲组抽象可复制规律，乙组只陈列做法并用数据收口。一级标题全是「动词＋带引号数字短语，确保／推动＋效果」双分句，数字短语（四个立足／三个结合／三大手段）是标志性构件。

**段落内部结构**　提领句（本环节方法论）→ 一是/二是/三是（每条：加引号命名＋做法＋数据成效）：

> 坚持把“两学一做”学习教育的实际成果转化为工作的强大动力，把做合格党员与工作实际有机结合，确保互促互进。一是结合岗位职能奋力争当“时代先锋”。大力开展党员立足岗位主动“亮身份、亮职责、亮承诺”的“三亮”活动……推送表彰共产党员示范岗3个、示范团队1个、示范单位1个……二是结合支部特点全力打造“特色品牌”……三是结合脱贫攻坚倾力推进致富奔康……先后协调争取专项扶贫资金60余万元……脱贫退出步伐全面提速。

每个「一是」都以绝对值数据收尾（示范岗3个、专项资金60余万元、整改问题93个），**不用百分比**，与全量统计「乙组 72% 完全不用百分比」一致。

**过渡手法**　三段并列无转折，靠提领句同构句式制造节奏。三段段首分别为「坚持把理论武装作为首要前提……」「坚持把‘两学一做’学习教育的实际成果转化为工作的强大动力……」「坚持立说立行抓整改……」，全部以「坚持把／坚持」起头。**句式重复即过渡**，读者靠排比感知段落平级。

**骨架公式**　`[总体成效] → [环节一] → [环节二] → [环节三]`（三段等分，无问题段、无启示段）

**三条跨文种规律**

重心分布分两族。单段独大型（工作方案 38-67%、工作意见 44-53%、经验材料 47-59%）把重量压在「做什么」；均衡型（调研报告 23-38%、经验总结 23-43%、领导讲话 18-45%）要求各功能段等重。**误把调研报告写成单段独大，等于写成了经验材料。**

段内标记与文种强相关，可反向校验。工作方案、工作意见两个文种的精读篇目「一是」计数**全部为 0**；经验总结三篇为 10/9/5，经验材料两篇为 14/12。唯一例外是经验材料中的并列型《服务问计》，它取消了一切分层标记（二级标题 0、「一是」0），靠四个排比式一级标题分层。除此之外，「一是」的有无可作为区分规范性文件与经验类文件的可靠指标。

过渡强度按文种递减：领导讲话用显式口语过渡 → 调研报告/经验材料把转折句与成效句放在新段段首 → 工作方案与工作意见完全无过渡句。**越是规范性文件越不需要过渡，越要说服人的文体过渡越显性。**
