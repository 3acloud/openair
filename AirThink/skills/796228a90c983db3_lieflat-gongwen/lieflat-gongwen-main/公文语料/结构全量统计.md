## 二、层级深度规律（全量）

| 篇幅区间 | 甲组 一级/二级/三级 | 乙组 一级/二级/三级 |
|---------|---------------------|---------------------|

**两条硬规律**：

1. **乙组几乎不用三级标题**（平均 0.0-0.6 个）——层级压到两层：`一、` + `（一）`

**给 AI 的参数**：

## 四、收尾模式分布（全量）

| 模式 | 甲组 | 乙组 |
|------|--------|--------|
| 自然收束（无程式化结语） | 92 (87%) | 92 (75%) |
| 总结升华式 | 7 (7%) | 4 (3%) |
| 号召/展望式 | 2 (2%) | 14 (11%) |
| 汇报机制式 | 2 (2%) | 1 (1%) |
| 执行要求式 | 2 (2%) | 3 (2%) |
| 建议/期望式 | 1 (1%) | 9 (7%) |

**重大发现：优秀公文的收尾以"自然收束"为主（75-87%），而非程式化结语。**

这与模板类 skill 的假设正好相反。模板通常规定"通知结尾用'请遵照执行'、请示用'妥否请批示'"，但在这 229 篇里，程式化结语出现率极低。

原因推测（需验证）：
- 乙组和"经验材料/调研报告"类不需要程式化结语
- 法定公文（通知/请示）在语料中占比小

**乙组"号召/展望式"占 11%**——领导讲话必须以鼓劲收尾。

**给 AI 的参数**：
```
调研报告/经验材料 → 自然收束或总结升华，不加程式化结语
领导讲话 → 号召/展望式收尾
法定公文（通知/请示/报告） → 用程式化结语（但语料支撑不足，需另找样本）
```

## 七、数据密度（全量）

| | 甲组 | 乙组 |
|---|---|---|
| 完全不用百分比的篇数 | 64/106 (60%) | 88/123 (72%) |
| 百分比数量中位 | 0 | 0 |
| 75 分位 | 2 | 1 |
| 最大值 | 48 | 11 |

**这是最反直觉的发现：60-72% 的真实公文完全不用百分比。**

含义：
1. **数据不是公文质量的必需品**——本语料中大多数篇目没有精确统计数据
2. 数据密度呈极端分布——少数业务型文件数据密集（最大 48 个百分比），多数靠逻辑和判断力取胜
3. 对 AI 写公文的直接启示：**无法核实的数据不要编造，用逻辑深度替代**

**给 AI 的参数**：
```
不掌握真实数据时 → 不编造，靠分析逻辑和判断力撑起文章
掌握真实数据时 → 用对比/递进关系呈现，而非堆砌绝对值
百分比目标：0-3 个（除专门的数据分析类文件）
```

## 八、力度词密度（全量，每千字）

| 力度等级 | 甲组 | 乙组 |
|---------|--------|--------|
| 强制（应当/必须/不得/严禁） | 0.58 | 0.56 |
| 要求（要/切实/确保/务必） | 5.79 | 10.08 |
| 建议（建议/可以/鼓励/支持） | 1.30 | 0.76 |
| 期望（希望/期望/争取/力争） | 0.19 | 0.58 |

**规律**：

1. **强制词密度稳定在 0.56-0.58/千字**——两组高度一致，说明这是公文的"结构性常数"。一篇 3000 字公文约 1.7 个强制词
2. **要求词是主力**，乙组近乎甲组 2 倍（党建类文书要求性表述更密集）
3. **甲组"建议"是乙组 1.7 倍**——甲组含大量向上级建言的政策建议
4. **乙组"期望"是甲组 3 倍**——领导讲话需要鼓劲收尾

**给 AI 的参数**：
```
3000 字公文的力度配额：
  强制词（必须/应当/不得）：1-2 个
  要求词（要/切实/确保）：17-30 个
  建议词：2-4 个（上行文加倍）
  期望词：0-2 个（讲话稿加倍）
```

## 九、与模板类 skill 的假设冲突

本次全量统计推翻了几个常见假设：

| 常见假设 | 全量数据 |
|---------|---------|
| 公文开头都用"根据…""为…" | 依据式仅 6-8%，目的式 8-13% |
| 公文结尾必须用程式化结语 | 75-87% 是自然收束 |
| 好公文要有数据支撑 | 60-72% 完全不用百分比 |
| 一级标题应简短标示内容 | 分析类文件标题平均 17 字，承载观点 |
| "必须/应当"体现文件力度 | 密度仅 0.57/千字，是稀缺资源 |

**结论**：模板化的"公文套路"其实是平庸公文的特征。本语料的真实公文在开头、标题、收尾上高度多样化，真正的共性在**层级结构规律**和**力度词配比**上。
