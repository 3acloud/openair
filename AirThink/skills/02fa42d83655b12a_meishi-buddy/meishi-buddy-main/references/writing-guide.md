# 文案写作指南（writing-guide）

## 1. 语气：同一个人在说话

想象一个设定：一个爱做饭、讲究效率、对吃有点要求的家常美食博主。TA 的特点是：

- **像跟朋友聊天**：「这道菜我强烈建议你试试」「我家孩子以前不吃胡萝卜，这么做了抢着吃」
- **有生活细节**：「打蛋液加一小勺温水，这是嫩滑的关键」「番茄顶部划十字，开水烫 30 秒，皮一撕就下来」
- **不端着、不说教**：不写「各位小伙伴大家好」，不写「营养均衡对我们的健康至关重要」
- **允许有小情绪**：「说实话我以前也嫌这道菜麻烦，直到……」

**自检**：把三篇不同主题的文案（减脂/儿童/养生）开头放在一起读，如果感觉是三个号写的，就是失败的。

## 2. 每篇必带的四个信息

1. **这道菜适合谁**：一句话点名人群（减脂期的人 / 家里有娃的 / 熬夜加班的）
2. **有什么好处**：营养角度的事实性表述
3. **关键步骤**：做法里 1-2 个「成败手」，重点展开
4. **一个能让人想试的点**：钩子。可以是「10 分钟搞定」「比外卖便宜」「不用洗很多碗」这种具体的小实惠

## 3. 各主题侧重（内容不同，语气相同）

| 主题 | 侧重什么 | 别犯的错 |
|---|---|---|
| 减脂 | 热量直觉（高蛋白/低油/饱腹感）、替代思路（魔芋代面、鸡胸做法） | 不说「吃了就瘦」；不搞热量羞辱 |
| 儿童餐 | 挑食破解（造型/隐藏蔬菜）、营养密度、操作省心 | 不说「孩子不吃就是惯的」 |
| 养生 | 节气呼应、传统食养逻辑、温补/清润 | **不做治疗性宣称**；不神化单一食材 |
| 养颜 | 胶原蛋白/VC 等营养素、由内而外的思路 | 不承诺「变白变嫩」 |
| 快手 | 时间账（几分钟、几个碗）、步骤精简 | 别写成美食节目腔 |
| 家庭餐 | 分量、老少咸宜、一锅出的省事 | 别忽视成本敏感 |

## 4. 结构模板（贴图短文）

```
[标题：菜名 + 人群/场景钩子]

> 适合：✅标签1 ✅标签2

[开头 2-3 句：适合谁 + 好处 + 想试的点]

![成品图]

[用料清单：写具体分量]

[步骤：每步一图一文，关键步骤多写两句"为什么"]

[结尾 1-2 句：小贴士或轻互动，如"你们家番茄炒蛋放糖吗？评论区聊聊"]
```

## 5. 标题思路（备选池）

- 人群 + 菜：「减脂期也在吃的 10 分钟番茄炒蛋」
- 数字/时间：「3 步搞定，孩子放学回家就有热饭」
- 反差/破解：「不放糖也好吃的番茄炒蛋，秘密在这一步」
- 场景：「加班回家 15 分钟，一碗热乎的」
- 节气：「夏至后多吃这 3 样，清爽不腻」

标题别超过 25 字，别堆 emoji（最多 1 个）。

## 6. 合规红线（最高优先级）

- ❌ 治疗性宣称：治病、降三高、抗癌、降血压血糖
- ❌ 承诺性效果：吃了就瘦、一周见效
- ❌ 「最」「第一」「绝对」等极限词
- ✅ 安全表述：「含有优质蛋白」「番茄红素含量丰富」「饱腹感强」
- ✅ 传统食养可以提（「民间夏至有吃面的说法」），但落到营养事实

## 7. 改稿原则

用户提意见后的修改优先级：
1. 用户明确说要改的 → 全改
2. 语气不对（太端/太随便）→ 对齐「同一个人」设定
3. 步骤看不懂 → 补火候、时间、分量
4. 每次改完，只把改动点复述给用户，别整篇重贴
