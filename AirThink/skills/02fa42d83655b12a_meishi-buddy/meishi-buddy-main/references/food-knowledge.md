# 人群 / 节气 / 功效食材对应表（food-knowledge）

入口 B/C 推荐菜时的底层依据。推荐理由必须落到这张表的逻辑上，别凭空编。

## 1. 人群 → 需求 → 食材方向

| 人群 | 核心需求 | 食材方向 | 推荐菜示例 |
|---|---|---|---|
| 学生（儿童青少年） | 长高补钙、护眼、大脑营养 | 鸡蛋、牛奶、鱼虾、深绿蔬菜（护眼叶黄素）、坚果 | 虾仁蒸蛋、芝士厚蛋烧、清蒸鲈鱼 |
| 上班族/白领 | 快手、带饭复热、抗疲劳 | 鸡胸、牛肉、粗粮、便当作友好的菜 | 番茄牛腩（高压锅版）、杂粮饭、咖喱鸡 |
| 减脂人群 | 高蛋白低脂、饱腹感、控油 | 鸡胸、虾、魔芋、西兰花、菌菇、豆腐 | 魔芋凉拌、鸡胸肉饼、虾仁西兰花 |
| 宝妈/家庭 | 一锅出、老少咸宜、成本可控 | 排骨、鸡腿、当季蔬菜 | 山药排骨汤、土豆炖鸡、番茄肥牛汤 |
| 熬夜/气色差人群 | 补铁、VC、气色 | 猪肝、红枣、菠菜、番茄、乌鸡 | 菠菜猪肝汤、红枣银耳羹 |
| 老人 | 软烂易嚼、少油盐、钙质 | 豆腐、蒸蛋、鱼、山药 | 肉沫蒸蛋、清蒸鳕鱼 |
| 一人食 | 分量小、不剩菜、一口锅 | 面条、焖饭、砂锅 | 番茄鸡蛋面、腊肠煲仔饭 |

## 2. 节气/季节 → 食养逻辑（北半球，按公历月份速查）

| 时段 | 节气锚点 | 食养逻辑 | 推荐方向 |
|---|---|---|---|
| 2-4 月 | 立春/春分 | 升发、养肝 | 韭菜、豆芽、荠菜、菠菜 |
| 5-7 月 | 立夏/夏至 | 清热、祛湿、补钾 | 苦瓜、冬瓜、绿豆、鸭肉、番茄（夏至面） |
| 8-10 月 | 立秋/秋分 | 润燥、滋阴 | 银耳、百合、梨、山药、莲藕 |
| 11-1 月 | 立冬/冬至 | 温补、驱寒 | 羊肉、萝卜、红枣、鸡汤（冬至饺子/汤圆） |

**注意**：节气内容用「民间有……的说法」+ 营养事实双轨表述，不做功效宣称（见 writing-guide.md 合规红线）。

## 3. 常见功效诉求 → 食材（事实性表述）

| 用户会说 | 实际营养逻辑 | 菜方向 |
|---|---|---|
| 「补钙长高」 | 钙 + 蛋白质 + 维D（晒太阳） | 奶制品、虾皮、豆腐、鱼 |
| 「补钾」 | 夏天出汗流失，电解质 | 香蕉、土豆、菌菇、深绿菜 |
| 「护眼」 | 叶黄素、VA | 菠菜、胡萝卜、南瓜、蛋黄 |
| 「补铁」 | 血红素铁 + VC 促吸收 | 猪肝、牛肉 + 彩椒/番茄同炒 |
| 「优质蛋白」 | 完全蛋白、低脂来源 | 鸡胸、虾、蛋白、豆腐 |
| 「控糖」 | 低 GI、慢碳水 | 杂粮、燕麦、魔芋、绿叶菜 |
| 「膳食纤维」 | 饱腹、肠道友好 | 菌菇、燕麦、芹菜、豆类 |

## 4. 一周选题排期原则（入口 C 用）

1. **荤素/蛋白来源错开**：别连着两天都是鸡肉菜；畜禽肉、鱼虾、蛋、豆制品轮着来
2. **难度节奏**：快手菜（≤15 分钟）和费时菜（炖煮类）穿插，工作日偏快手、周末上硬菜
3. **餐段完整**：7 天里覆盖早餐 1-2 次、正餐为主，可插一篇汤/甜品
4. **主题不漂移但不单调**：用户定了「这周减脂」就 7 天都服务减脂，但角度要换（主食替代/高蛋白/低卡零食/外食救急）
5. **成本感知**：一周里至少 2 道是「便宜大碗」的菜，别全是牛油果三文鱼
6. 每天给「一句话卖点」，用户确认时一眼能判断要不要换
