# Stoic Coach · 斯多葛刻意练习教练

> 你无法控制发生在自己身上的事，但可以控制如何应对它。

一个 [CodeBuddy](https://www.codebuddy.com/) / Claude Code 风格的 **Skill**：不做甩清单的工具人，做**一步步提问引导你完成练习**的斯多葛教练，并把每次练习存档，随时间积累出"更了解自己"的洞察。

## 它能做什么

- 🏛️ **25 项斯多葛练习**（5 大模块）：控制二分法、四大美德、正念与智慧模式、热爱命运与全然接纳、韧性训练
- 🗣️ **教练式逐问引导**：一次只问一个问题，先共情后引导，苏格拉底式地把结论留给你自己
- 📈 **持久化追踪**：每次练习记录前后不适分数与一句话收获（JSONL 追加写入，安全不丢数据）
- 🔍 **自我洞察报告**：你的练习模式、最有效的练习、高频情绪标签、尚未探索的领域——用你自己的原话照镜子
- 📜 **每日一句**：按日期轮换的斯多葛语录（同一天稳定同一句）
- 📂 **随时导出**：Markdown / JSON 备份你的练习史

## 快速开始

```bash
# 安装到 CodeBuddy 的 skills 目录
git clone https://github.com/bonniegeng-max/stoic-coach.git ~/.codebuddy/skills/stoic-coach
```

也可以从 ClawHub 安装：

```bash
clawhub install @bonniegeng-max/stoic-coach
```

然后对 CodeBuddy 说：

| 你说 | 它做 |
|------|------|
| "开始今天的斯多葛练习" | 教练开场 → 推荐 → 逐问引导 → 存档 |
| "我有点焦虑，想练一下斯多葛" | 直接进入教练流程，推荐匹配练习 |
| "看看我的斯多葛练习进度" | 统计总览 + 洞察报告 |
| "复盘一下我的练习记录" | 深度模式分析 |
| "来一句斯多葛语录" | 每日一句 + 解读 |

> 触发说明：本 skill 仅响应**明确提及斯多葛/练习**的意图。单纯的情绪倾诉（未提到斯多葛或练习）不会触发。

## 数据与隐私

所有记录只存在你本地：

- 默认：`~/.stoic-coach/journal.jsonl`
- 多设备同步：设置环境变量 `STOIC_COACH_DATA_DIR` 指向网盘同步目录
- 导出：`python3 scripts/stoic.py export --format md`
- 注意：记录为**明文 JSONL**，包含你的心得原话。如涉及敏感内容，建议将存储目录设到加密盘，导出的备份也请妥善保管

## 目录结构

```
stoic-coach/
├── SKILL.md              # 触发条件 + 教练工作流
├── README.md             # 本文件
├── references/
│   ├── exercises.md      # 25 项练习库（含逐问式教练脚本 + 状态映射表）
│   ├── quotes.md         # 斯多葛语录库
│   └── coach-guide.md    # 教练话术心法
└── scripts/
    └── stoic.py          # 数据引擎（纯 Python 标准库，零依赖）
```

## 设计哲学

1. **教练和说教者的区别，是一次只问一个问题**
2. 数字只是镜子，镜子里的人是你——洞察报告永远引用你自己的原话
3. 斯多葛主义是"进步者之路"：追求进步，而非完美
4. 本 skill 是哲学练习工具，不替代专业心理帮助
